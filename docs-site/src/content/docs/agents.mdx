AI 编程助手写 ShikiForm 时最常犯的错，集中在几条规则上。把 [/llms.txt](/llms.txt) 交给它：那是仓库根目录 [AGENTS.md](https://github.com/charlzyx/shikiform/blob/main/AGENTS.md)（英文）加一段索引。下面是中文摘要。

## 六条规则

1. **handle 不是 value。** `d.user.name` 只是 path；读写用 `$value`。不要修改 `$value` 返回的对象，写字段自己的 path。handle 不是数组，不能 `.map` / `.length`。
2. **reaction 派生，watch 做动作。** reaction 立即运行、读到的都是依赖；watch 首次不运行、只认 `source`。派生值不要藏在 watch 里。
3. **刚写的值不要在同一轮读回**，先放局部变量（UI 状态除外）。
4. **`reaction.each` / `watch.each` 只有两个参数**，回调是 `(row, ctx)`。`ctx` 含 `key`、`index`、`depth`、`parent`、`path`、`pos`（以及根 draft `d`）。对象数组会自动往下走。嵌套在对象里的基本类型数组不进；对字符串数组本身调用 `each` 时，回调仍在 `depth === 0` 触发。按 `ctx.key` / `ctx.depth` 自己过滤。组件里用 `useArray()` / `useIndex()` / `useRecord()` / `useTreeNode()`。
5. **值按 path 写，对象型 UI 状态按键打补丁**：`d.city.$componentProps.placeholder = '…'` 只改一个键；整体赋值会替换下层。
6. **`<Field>` 拥有 path，`FormItem` 只是装饰器**：`<Field name title required decorator={[FormItem]} component={[Input]} />`。

开发构建会对 1、3 和「把 handle 当数组」抛 `ShikiUsageError`，错误信息里写了正确写法。

## 对照

```ts
d.user.$value.name = 'x'                                  // ✗ 改了不可变快照
d.user.name.$value = 'x'                                  // ✓

d.items.forEach((row) => { row.total.$value = 1 })        // ✗ handle 不是数组
reaction.each((d) => d.items, (row) => {                  // ✓ 每行一个实例
  row.total.$value = row.price.$value * row.qty.$value
})

d.total.$value = d.price.$value * d.qty.$value
d.tax.$value = d.total.$value * 0.1                       // ✗ 读回了刚写的值
const total = d.price.$value * d.qty.$value               // ✓
d.total.$value = total
d.tax.$value = total * 0.1

reaction.each((d) => d.rows, (row) => {}, { childrenKey: 'children' }) // ✗ 没有第三个参数
reaction.each((d) => d.rows, (row, { depth, key }) => { if (depth !== 0) return }) // ✓
```

```tsx
<FormItem name="email" label="邮箱" required><Input /></FormItem>                        // ✗ FormItem 没有 name
<Field name="email" title="邮箱" required decorator={[FormItem]} component={[Input]} />  // ✓

<Field name="city" component={[Select, { disabled: form.getValue('kind') === 'b' }]} />   // ✗ 不是响应式的
reaction((d) => { d.city.$componentProps.disabled = d.kind.$value === 'b' })             // ✓
```
