以下三个示例保持业务数据的原始形状（平铺 SKU 数组、嵌套的供应商与订单树）。单元格合并与行展开仅发生在展示层，各字段仍按真实路径读写和校验。

## SKU 价格表

**场景**：按颜色合并单元格的 SKU 价格表。修改合并格里的颜色时，同步更新该颜色分组下的每一行；动态勾选显示「渠道」列时，已填写的价格与库存数据不受影响。

```tsx preview play=sku-editor
import { useState } from 'react';
import { Field, Form, useForm, useFormContext, useWatch, type Draft } from '@shikiform/react';

type Sku = { skuId: string; color: string; storage: string; price: number; stock: number; channel: string };
type Values = { rows: Sku[]; channel: boolean };

const SKUS: Sku[] = [
  { skuId: 'B-128', color: '黑色', storage: '128G', price: 999, stock: 12, channel: '' },
  { skuId: 'B-256', color: '黑色', storage: '256G', price: 1499, stock: 3, channel: '' },
  { skuId: 'W-128', color: '白色', storage: '128G', price: 999, stock: 0, channel: '' },
  { skuId: 'W-256', color: '白色', storage: '256G', price: 1499, stock: 8, channel: '' },
];

function computeRowSpans<T>(rows: T[], groupOf: (row: T) => string): number[] {
  const spans = new Array<number>(rows.length).fill(0);
  let i = 0;
  while (i < rows.length) {
    const key = groupOf(rows[i]!);
    let end = i + 1;
    while (end < rows.length && groupOf(rows[end]!) === key) end++;
    spans[i] = end - i;
    i = end;
  }
  return spans;
}

function SkuTable() {
  const form = useFormContext<Values>();
  const rows = useWatch((d: Draft<Values>) => d.rows.$value);
  const channel = useWatch((d: Draft<Values>) => d.channel.$value);
  const spans = computeRowSpans(rows, (row) => row.color);
  const paint = (from: string, to: string) =>
    form.setValue('rows', rows.map((row) => (row.color === from ? { ...row, color: to } : row)));
  return (
    <>
      <label style={{ display: 'inline-flex', alignItems: 'center', gap: 6, marginBottom: 8 }}>
        <input type="checkbox" checked={channel} onChange={(e) => form.setValue('channel', e.target.checked)} />
        显示渠道列
      </label>
      <table>
        <thead>
          <tr>
            <th>颜色</th>
            <th>容量</th>
            <th>价格</th>
            <th>库存</th>
            {channel && <th>渠道</th>}
          </tr>
        </thead>
        <tbody>
          {rows.map((row, index) => (
            <tr key={row.skuId}>
              {spans[index]! > 0 && (
                <td rowSpan={spans[index]}>
                  <input
                    aria-label="颜色"
                    style={{ width: 72 }}
                    value={row.color}
                    onChange={(e) => paint(row.color, e.target.value)}
                  />
                </td>
              )}
              <td>{row.storage}</td>
              <td>
                <Field name={`rows.${index}.price`}>
                  {(f) => (
                    <input
                      type="number"
                      min={0}
                      style={{ width: 72 }}
                      value={Number(f.value ?? 0)}
                      onChange={(e) => f.onChange(Number(e.target.value))}
                    />
                  )}
                </Field>
              </td>
              <td>
                <Field name={`rows.${index}.stock`}>
                  {(f) => (
                    <input
                      type="number"
                      min={0}
                      style={{ width: 64 }}
                      value={Number(f.value ?? 0)}
                      onChange={(e) => f.onChange(Number(e.target.value))}
                    />
                  )}
                </Field>
              </td>
              {channel && (
                <td>
                  <Field name={`rows.${index}.channel`}>
                    {(f) => (
                      <input
                        style={{ width: 88 }}
                        value={String(f.value ?? '')}
                        onChange={(e) => f.onChange(e.target.value)}
                      />
                    )}
                  </Field>
                </td>
              )}
            </tr>
          ))}
        </tbody>
      </table>
    </>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({ initialValues: { rows: SKUS, channel: false }, fields: { channel: { omit: true } } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <SkuTable />
      <button type="submit" style={{ marginTop: 8 }}>提交</button>
      <pre>{result}</pre>
    </Form>
  );
}
```

- 数据保持平铺 SKU 数组，展示层按 `groupOf` 计算相邻分组的 `rowSpan`，合并仅发生在 `<table>` 渲染层。
- 切换显示「渠道」列或修改单个价格时不会重建行对象，已有字段状态和错误信息保留在原 `skuId` 行上。
- 修改合并单元格会更新同组行的 `color`（写入 `rows`），单个价格与库存输入框则按 `rows.N.price` 单独更新。

## 供应商与产品：合并单元格

**场景**：供应商与产品为一对多嵌套结构，表格需要按供应商合并单元格；同时要求校验「供应商名称不能重复」，以及「C 级供应商的产品单价不能超过 1000」。

```tsx preview play=merged
import { Field, Form, useArrayField, useField, useForm, useFormContext, useWatch, type Draft } from '@shikiform/react';

type Product = { id: string; name: string; price: number };
type Supplier = { id: string; name: string; level: 'A' | 'B' | 'C'; products: Product[] };
type Values = { suppliers: Supplier[] };
/** 表格的一行 = 一个产品；记下它在嵌套数据里的位置。 */
type Line = { id: string; s: number; p: number };

let nextProductId = 4;

function computeRowSpans<T>(rows: T[], groupOf: (row: T) => string): number[] {
  const spans = new Array<number>(rows.length).fill(0);
  let i = 0;
  while (i < rows.length) {
    const key = groupOf(rows[i]!);
    let end = i + 1;
    while (end < rows.length && groupOf(rows[end]!) === key) end++;
    spans[i] = end - i;
    i = end;
  }
  return spans;
}

function TextCell() {
  const f = useField<string>();
  return (
    <div>
      <input style={{ width: 96 }} value={f.value ?? ''} onChange={(e) => f.onChange(e.target.value)} onBlur={f.onBlur} />
      {f.errors[0] && <div><small role="alert" style={{ color: 'crimson' }}>{f.errors[0]}</small></div>}
    </div>
  );
}

function NumberCell() {
  const f = useField<number>();
  return (
    <div>
      <input type="number" style={{ width: 80 }} value={f.value ?? 0} onChange={(e) => f.onChange(Number(e.target.value))} onBlur={f.onBlur} />
      {f.errors[0] && <div><small role="alert" style={{ color: 'crimson' }}>{f.errors[0]}</small></div>}
    </div>
  );
}

function AddProduct({ supplierIndex }: { supplierIndex: number }) {
  const products = useArrayField(`suppliers.${supplierIndex}.products`);
  return (
    <button type="button" onClick={() => products.push({ id: `p${nextProductId++}`, name: '新产品', price: 1 })}>
      加产品
    </button>
  );
}

function Suppliers() {
  const form = useFormContext<Values>();
  const suppliers = useWatch((d: Draft<Values>) => d.suppliers.$value);
  const lines: Line[] = suppliers.flatMap((supplier, s) => supplier.products.map((product, p) => ({ id: product.id, s, p })));
  const spans = computeRowSpans(lines, (line) => suppliers[line.s]!.id);
  return (
    <>
      <table>
        <thead>
          <tr>
            <th>供应商</th>
            <th>产品</th>
            <th>单价</th>
          </tr>
        </thead>
        <tbody>
          {lines.map((line, index) => (
            <tr key={line.id}>
              {spans[index]! > 0 && (
                <td rowSpan={spans[index]} style={{ verticalAlign: 'top' }}>
                  <div style={{ display: 'flex', flexDirection: 'column', gap: 6 }}>
                    <Field
                      name={`suppliers.${line.s}.name`}
                      component={[TextCell]}
                      rules={[
                        { required: true },
                        { validator: (value, ctx) => ((ctx.array as Supplier[] | undefined)?.filter((item) => item.name === value).length ?? 0) > 1 ? '供应商重名' : null },
                      ]}
                    />
                    <Field name={`suppliers.${line.s}.level`}>
                      {(f) => (
                        <select value={String(f.value ?? 'A')} onChange={(e) => f.onChange(e.target.value)}>
                          {(['A', 'B', 'C'] as const).map((level) => (
                            <option key={level} value={level}>{level} 级</option>
                          ))}
                        </select>
                      )}
                    </Field>
                    <AddProduct supplierIndex={line.s} />
                  </div>
                </td>
              )}
              <td>
                <Field name={`suppliers.${line.s}.products.${line.p}.name`} component={[TextCell]} />
              </td>
              <td>
                <Field
                  name={`suppliers.${line.s}.products.${line.p}.price`}
                  component={[NumberCell]}
                  rules={{
                    validator: (value, ctx) => (ctx.parent?.level === 'C' && Number(value) > 1000 ? 'C 级供应商单价不能超过 1000' : null),
                  }}
                />
              </td>
            </tr>
          ))}
        </tbody>
      </table>
      <button type="button" style={{ marginTop: 8 }} onClick={() => { void form.validate().catch(() => {}); }}>
        校验
      </button>
    </>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: {
      suppliers: [
        { id: 'a', name: '供应商 A', level: 'C', products: [{ id: 'p1', name: '螺丝', price: 1200 }, { id: 'p2', name: '螺母', price: 20 }] },
        { id: 'b', name: '供应商 A', level: 'A', products: [{ id: 'p3', name: '垫片', price: 5000 }] },
      ],
    },
  });
  return <Form form={form}><Suppliers /></Form>;
}
```

- 点击「校验」后，「螺丝」会因为归属 C 级供应商且单价超出 1000 报错，两个「供应商 A」也会报重名错误，而归属 A 级供应商的「垫片」则可以正常通过。按钮上的 `void` 只表示不使用返回值：通过时 `form.validate()` resolve 整表提交值。
- 在校验函数 `validator(value, ctx)` 中，`ctx.record` 指向当前所在对象（产品），`ctx.parent` 越过所属数组指向上一层对象（供应商），`ctx.array` 则是当前所在的数组，详见 [校验](/guide/validation)。
- 表单数据始终保持原始的嵌套结构（`suppliers.N.products.M`），用于驱动合并单元格的展平列表只记录坐标索引而不复制业务数据。

## 订单与可展开明细

**场景**：订单列表展开每一行后可编辑其商品明细，要求实时计算行金额和订单总计；「已发货」的订单整单只读，「待付款」订单的单行商品数量不能超过 99。

```tsx preview play=orders
import { Fragment, useState } from 'react';
import { ArrayField, Field, Form, defineEffects, useField, useForm, useRecord } from '@shikiform/react';

type Item = { id: string; sku: string; qty: number; price: number; line: number };
type Order = { id: string; no: string; status: string; amount: number; items: Item[] };
type Values = { editable: boolean; orders: Order[] };

const STATUS = [
  { label: '待付款', value: 'pending' },
  { label: '已付款', value: 'paid' },
  { label: '已发货', value: 'shipped' },
];

const effects = defineEffects<Values>(({ reaction, draft }) => {
  reaction((d) => {
    d.orders.$readOnly = d.editable.$value ? undefined : true;
  });
  reaction.each(draft.orders, (order, { d, depth }) => {
    if (depth !== 0) return; // items 也是对象数组；这一轮只处理订单
    order.$readOnly = order.status.$value === 'shipped' ? true : undefined; // 已发货：整单预览
    order.status.$readOnly = !d.editable.$value; // false 退出父级只读；状态本身跟随总开关
    let amount = 0;
    order.items.$value.forEach((item, index) => {
      const line = item.qty * item.price;
      order.items[index].line.$value = line;
      amount += line;
    });
    order.amount.$value = amount;
  });
});

function NumberCell({ min }: { min?: number }) {
  const f = useField<number>();
  return (
    <div>
      {f.readOnly ? (
        <span>{f.value}</span>
      ) : (
        <input
          type="number"
          min={min}
          style={{ width: 68 }}
          value={f.value ?? 0}
          onChange={(e) => f.onChange(Number(e.target.value))}
          onBlur={f.onBlur}
        />
      )}
      {f.errors[0] && <div><small role="alert" style={{ color: 'crimson' }}>{f.errors[0]}</small></div>}
    </div>
  );
}

function ItemRow() {
  const item = useRecord<Item>();
  return (
    <tr>
      <td><code>{item.sku}</code></td>
      <td>
        <Field
          name="qty"
          component={[NumberCell, { min: 1 }]}
          rules={{
            validator: (value, ctx) => (ctx.parent?.status === 'pending' && Number(value) > 99 ? '待付款单行不能超过 99' : null),
          }}
        />
      </td>
      <td><Field name="price" component={[NumberCell, { min: 0 }]} /></td>
      <td><Field name="line" readOnly component={[NumberCell]} /></td>
    </tr>
  );
}

function OrderRow({ expanded, onToggle }: { expanded: boolean; onToggle: () => void }) {
  const record = useRecord<Order>();
  return (
    <Fragment>
      <tr>
        <td>
          <button type="button" onClick={onToggle}>{expanded ? '▾' : '▸'}</button>
        </td>
        <td>{record.no}</td>
        <td>
          <Field name="status" enum={STATUS}>
            {(f) => f.readOnly ? (
              <span>{f.options.find((o) => o.value === f.value)?.label ?? String(f.value)}</span>
            ) : (
              <select value={String(f.value ?? '')} onChange={(e) => f.onChange(e.target.value)}>
                {f.options.map((opt) => (
                  <option key={String(opt.value)} value={String(opt.value)}>{opt.label}</option>
                ))}
              </select>
            )}
          </Field>
        </td>
        <td>
          <Field name="amount" readOnly component={[NumberCell]} />
        </td>
      </tr>
      {expanded && (
        <tr>
          <td colSpan={4} style={{ paddingLeft: 24 }}>
            <table>
              <thead>
                <tr><th>商品</th><th>数量</th><th>单价</th><th>行金额</th></tr>
              </thead>
              <tbody>
                <ArrayField name="items" rowKey="id">
                  {() => <ItemRow />}
                </ArrayField>
              </tbody>
            </table>
          </td>
        </tr>
      )}
    </Fragment>
  );
}

export default function App() {
  const [expanded, setExpanded] = useState<Record<string, boolean>>({ o1: true });
  const form = useForm<Values>({
    initialValues: {
      editable: true,
      orders: [
        { id: 'o1', no: 'A001', status: 'pending', amount: 0, items: [{ id: 'i1', sku: 'pen', qty: 1, price: 10, line: 0 }, { id: 'i2', sku: 'ink', qty: 2, price: 8, line: 0 }] },
        { id: 'o2', no: 'A002', status: 'shipped', amount: 0, items: [{ id: 'i3', sku: 'box', qty: 1, price: 20, line: 0 }] },
      ],
    },
    fields: { editable: { omit: true } },
    effects: [effects],
  });
  const toggle = (id: string) => setExpanded((prev) => ({ ...prev, [id]: !prev[id] }));
  return (
    <Form form={form}>
      <Field<Values, 'editable'> name="editable" title="可编辑">
        {(f) => (
          <p>
            <label htmlFor={f.id}>
              <input id={f.id} type="checkbox" checked={Boolean(f.value)} onChange={(e) => f.onChange(e.target.checked)} />{' '}
              {f.title}
            </label>
          </p>
        )}
      </Field>
      <table>
        <thead>
          <tr><th /><th>订单号</th><th>状态</th><th>合计</th></tr>
        </thead>
        <tbody>
          <ArrayField name="orders" rowKey="id">
            {({ key }) => <OrderRow expanded={Boolean(expanded[key])} onToggle={() => toggle(key)} />}
          </ArrayField>
        </tbody>
      </table>
    </Form>
  );
}
```

- 订单内的 `items` 也是对象数组，`reaction.each` 会递归进入内层；开头判断 `if (depth !== 0) return` 使该回调只处理外层订单，修改某张订单的状态或明细时只重算该订单。
- 展开区位于外层 `<ArrayField name="orders">` 的行作用域内，因此 `<ArrayField name="items">` 会自动解析为 `orders.N.items`，内部的 `<Field name="qty">` 同样直接写相对路径。
- 「已发货」订单整单只读，是因为子字段继承了 `order.$readOnly`。状态列在可编辑时写了 `order.status.$readOnly = false`，所以仍能改回「已付款」，整单恢复可编辑。合计和行金额自己声明了 `readOnly`，阅读态展示计算结果。
- 上述表格直接在原数据上实时修改，若希望「确认后再写回、取消可丢弃」，请使用 [草稿表单（useShadowForm）](/examples/pro#草稿表单useshadowform)。

## 策略矩阵大表单（显隐矩阵 + 双向适配 + 提交门禁）

**场景**：复杂的发布/促销策略配置页。不同策略类型只展示对应区块（隐藏字段同时自动 `$omit` 不参与提交），接口 DTO 与前端表单模型通过 `fromApi / toApi` 双向适配器隔离，高预算提交前触发二次确认门禁。

```tsx preview
import { useState } from 'react';
import { defineEffects, Field, Form, Submit, useForm, useWatch, type Draft } from '@shikiform/react';

type PolicyType = 'flash' | 'bundle' | 'referral';
type PolicyDto = {
  policy_id: string;
  policy_type: PolicyType;
  title: string;
  budget_cents: number;
  flash_cap?: number;
  bundle_min_items?: number;
  referral_bonus?: number;
};
type PolicyValues = {
  type: PolicyType;
  title: string;
  budget: number;
  flashCap: number;
  bundleMinItems: number;
  referralBonus: number;
};

const SHOW_MAP: Record<PolicyType, { flashCap: boolean; bundleMinItems: boolean; referralBonus: boolean }> = {
  flash: { flashCap: true, bundleMinItems: false, referralBonus: false },
  bundle: { flashCap: false, bundleMinItems: true, referralBonus: false },
  referral: { flashCap: false, bundleMinItems: false, referralBonus: true },
};

const fromApi = (dto: PolicyDto): PolicyValues => ({
  type: dto.policy_type,
  title: dto.title,
  budget: Math.round(dto.budget_cents / 100),
  flashCap: dto.flash_cap ?? 500,
  bundleMinItems: dto.bundle_min_items ?? 2,
  referralBonus: dto.referral_bonus ?? 30,
});

const toApi = (values: Partial<PolicyValues>, id: string): PolicyDto => ({
  policy_id: id,
  policy_type: values.type ?? 'flash',
  title: (values.title ?? '').trim(),
  budget_cents: Math.round((values.budget ?? 0) * 100),
  ...(values.flashCap !== undefined ? { flash_cap: values.flashCap } : {}),
  ...(values.bundleMinItems !== undefined ? { bundle_min_items: values.bundleMinItems } : {}),
  ...(values.referralBonus !== undefined ? { referral_bonus: values.referralBonus } : {}),
});

const policyEffects = defineEffects<PolicyValues>(({ reaction }) => {
  reaction((d) => {
    const show = SHOW_MAP[d.type.$value] ?? SHOW_MAP.flash;
    d.flashCap.$visible = show.flashCap;
    d.flashCap.$omit = !show.flashCap;
    d.bundleMinItems.$visible = show.bundleMinItems;
    d.bundleMinItems.$omit = !show.bundleMinItems;
    d.referralBonus.$visible = show.referralBonus;
    d.referralBonus.$omit = !show.referralBonus;
  });
});

function RiskBanner() {
  const budget = useWatch((d: Draft<PolicyValues>) => d.budget.$value);
  if (budget < 50000) return null;
  return (
    <p style={{ margin: '6px 0', padding: '6px 10px', border: '1px solid #f59e0b', borderRadius: 4, fontSize: 12 }}>
      高预算策略（≥ ¥50,000）：提交时将触发二次风控确认。
    </p>
  );
}

const INITIAL_DTO: PolicyDto = {
  policy_id: 'PL-2026-01',
  policy_type: 'flash',
  title: '春季限时满减策略',
  budget_cents: 6000000,
  flash_cap: 300,
};

export default function App() {
  const [pendingDto, setPendingDto] = useState<PolicyDto | null>(null);
  const [savedDto, setSavedDto] = useState<PolicyDto | null>(null);

  const form = useForm<PolicyValues>({
    initialValues: fromApi(INITIAL_DTO),
    fields: {
      type: {
        title: '策略类型',
        required: true,
        enum: [
          { label: '限时秒杀', value: 'flash' },
          { label: '组合满件', value: 'bundle' },
          { label: '裂变拉新', value: 'referral' },
        ] as const,
      },
      title: { title: '策略名称', required: true },
      budget: { title: '预算上限（元）', required: true, rules: { min: 100 } },
      flashCap: { title: '单人限购件数', required: true, rules: { min: 1 } },
      bundleMinItems: { title: '最低成团件数', required: true, rules: { min: 2 } },
      referralBonus: { title: '单次邀新奖励（元）', required: true, rules: { min: 1 } },
    },
    effects: [policyEffects],
  });

  return (
    <Form
      form={form}
      onSubmit={(values) => {
        const dto = toApi(values, INITIAL_DTO.policy_id);
        if (dto.budget_cents >= 5000000) {
          setPendingDto(dto);
          return;
        }
        setSavedDto(dto);
      }}
    >
      <div style={{ display: 'grid', gap: 8, maxWidth: 420 }}>
        <Field<PolicyValues, 'type'> name="type">
          {(f) => (
            <label>
              {f.title}：
              <select value={f.value} onChange={(e) => f.onChange(e.target.value as PolicyType)}>
                {f.options.map((opt) => (
                  <option key={String(opt.value)} value={String(opt.value)}>{opt.label}</option>
                ))}
              </select>
            </label>
          )}
        </Field>
        <Field<PolicyValues, 'title'> name="title">
          {(f) => (
            <label>
              {f.title}：
              <input value={f.value ?? ''} onChange={(e) => f.onChange(e.target.value)} />
              {f.errors[0] && <span style={{ color: '#dc2626', marginLeft: 6 }}>{f.errors[0]}</span>}
            </label>
          )}
        </Field>
        <Field<PolicyValues, 'budget'> name="budget">
          {(f) => (
            <label>
              {f.title}：
              <input type="number" value={f.value ?? 0} onChange={(e) => f.onChange(Number(e.target.value))} />
            </label>
          )}
        </Field>
        <RiskBanner />
        <Field<PolicyValues, 'flashCap'> name="flashCap">
          {(f) => (
            <label>
              {f.title}：
              <input type="number" value={f.value ?? 1} onChange={(e) => f.onChange(Number(e.target.value))} />
            </label>
          )}
        </Field>
        <Field<PolicyValues, 'bundleMinItems'> name="bundleMinItems">
          {(f) => (
            <label>
              {f.title}：
              <input type="number" value={f.value ?? 2} onChange={(e) => f.onChange(Number(e.target.value))} />
            </label>
          )}
        </Field>
        <Field<PolicyValues, 'referralBonus'> name="referralBonus">
          {(f) => (
            <label>
              {f.title}：
              <input type="number" value={f.value ?? 1} onChange={(e) => f.onChange(Number(e.target.value))} />
            </label>
          )}
        </Field>
        <Submit>{(s) => <button type="submit" disabled={s.disabled}>提交策略</button>}</Submit>
      </div>
      {pendingDto && (
        <div style={{ marginTop: 8, padding: 8, border: '1px solid #f59e0b', borderRadius: 4 }}>
          <p style={{ margin: '0 0 6px' }}>预算达到 ¥{pendingDto.budget_cents / 100}，确认发布？</p>
          <button type="button" onClick={() => { setSavedDto(pendingDto); setPendingDto(null); }}>确认发布</button>{' '}
          <button type="button" onClick={() => setPendingDto(null)}>取消</button>
        </div>
      )}
      {savedDto && <pre style={{ marginTop: 8, fontSize: 12 }}>{JSON.stringify(savedDto, null, 2)}</pre>}
    </Form>
  );
}
```

- 用 `SHOW_MAP` 集中管理各模式区块显隐并同步设置 `$omit`，切换类型后未激活区块既不参与校验，也不会被提交进 `toApi` 载荷。
- 单位换算（元 ↔ 分）与字段命名转换完全收敛在 `fromApi / toApi`，表单内部只面对干净的前端模型。

## 多租户共享单抽屉与实时属性面板（`scopeKey` + `onValuesChange`）

**场景**：中后台常见的「列表页共享 1 个编辑浮层 + 右侧草稿属性面板」。表格所有行共用同一个 `useShadowForm({ scopeKey })` 实例（避免 N 行挂 N 个弹窗），切换工作空间 `scopeKey` 时自动取消正在打开的编辑态并作废在途加载；下方属性面板使用 `useForm({ values, onValuesChange })` 实现无需点提交的实时草稿同步。

```tsx preview
import { useState } from 'react';
import { Field, Form, useForm, useShadowForm } from '@shikiform/react';

type Rule = { id: string; name: string; weight: number; enabled: boolean };

const WORKSPACE_RULES: Record<string, Rule[]> = {
  'ws-east': [
    { id: 'R-01', name: '新客首单优惠', weight: 80, enabled: true },
    { id: 'R-02', name: '会员周末加倍', weight: 50, enabled: false },
  ],
  'ws-west': [
    { id: 'R-09', name: '区域满额包邮', weight: 90, enabled: true },
  ],
};

export default function App() {
  const [workspace, setWorkspace] = useState<'ws-east' | 'ws-west'>('ws-east');
  const [store, setStore] = useState(WORKSPACE_RULES);
  const [selectedId, setSelectedId] = useState('R-01');
  const rows = store[workspace] ?? [];
  const activeRow = rows.find((r) => r.id === selectedId) ?? rows[0];

  // 全表共享唯一 1 个草稿编辑实例；切换 workspace 时 scopeKey 自动取消当前浮层
  const editor = useShadowForm<Rule, { id: string }>({
    scopeKey: workspace,
    fields: {
      name: { title: '规则名称', required: true },
      weight: { title: '优先级权重', required: true, rules: { min: 1, max: 100 } },
    },
    onOk: (values, ctx) => {
      if (!ctx) return;
      setStore((prev) => ({
        ...prev,
        [workspace]: (prev[workspace] ?? []).map((r) => (r.id === ctx.id ? { ...r, ...values } : r)),
      }));
    },
  });

  // 实时属性面板：切换选中行时通过 values 自动重置，用户编辑通过 onValuesChange 实时写回草稿
  const inspector = useForm<Rule>({
    values: activeRow,
    onValuesChange: (next) => {
      if (!activeRow) return;
      setStore((prev) => ({
        ...prev,
        [workspace]: (prev[workspace] ?? []).map((r) => (r.id === activeRow.id ? { ...r, ...next } : r)),
      }));
    },
  });

  return (
    <div style={{ display: 'grid', gap: 12 }}>
      <div>
        工作空间：
        <button type="button" onClick={() => { setWorkspace('ws-east'); setSelectedId('R-01'); }}>
          华东 ({workspace === 'ws-east' ? '当前' : '切换'})
        </button>{' '}
        <button type="button" onClick={() => { setWorkspace('ws-west'); setSelectedId('R-09'); }}>
          华西 ({workspace === 'ws-west' ? '当前' : '切换'})
        </button>
      </div>

      <table>
        <thead>
          <tr><th>编号</th><th>规则名称</th><th>权重</th><th>操作</th></tr>
        </thead>
        <tbody>
          {rows.map((row) => (
            <tr key={row.id}>
              <td>{row.id}</td>
              <td>{row.name}</td>
              <td>{row.weight}</td>
              <td>
                <button type="button" onClick={() => setSelectedId(row.id)}>选中实时改</button>{' '}
                <button type="button" onClick={() => void editor.open(row, { id: row.id })}>共享浮层改</button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>

      {editor.visible && (
        <div style={{ padding: 10, border: '1px solid #3b82f6', borderRadius: 4 }}>
          <p style={{ margin: '0 0 8px', fontWeight: 600 }}>共享浮层编辑 · {editor.context?.id}</p>
          <Form form={editor.form}>
            <Field<Rule, 'name'> name="name">
              {(f) => <label>名称：<input value={f.value ?? ''} onChange={(e) => f.onChange(e.target.value)} /></label>}
            </Field>{' '}
            <Field<Rule, 'weight'> name="weight">
              {(f) => <label>权重：<input type="number" style={{ width: 64 }} value={f.value ?? 1} onChange={(e) => f.onChange(Number(e.target.value))} /></label>}
            </Field>
          </Form>
          <div style={{ marginTop: 8 }}>
            <button type="button" onClick={() => void editor.confirm()}>确认写回</button>{' '}
            <button type="button" onClick={() => editor.cancel()}>取消</button>
          </div>
        </div>
      )}

      {activeRow && (
        <div style={{ padding: 10, border: '1px dashed #94a3b8', borderRadius: 4 }}>
          <p style={{ margin: '0 0 6px', fontSize: 12 }}>实时属性面板（onValuesChange 即时同步 · {activeRow.id}）：</p>
          <Form form={inspector}>
            <Field<Rule, 'name'> name="name">
              {(f) => <label>名称：<input value={f.value ?? ''} onChange={(e) => f.onChange(e.target.value)} /></label>}
            </Field>{' '}
            <Field<Rule, 'weight'> name="weight">
              {(f) => <label>权重：<input type="number" style={{ width: 64 }} value={f.value ?? 1} onChange={(e) => f.onChange(Number(e.target.value))} /></label>}
            </Field>
          </Form>
        </div>
      )}
    </div>
  );
}
```

- 打开任意一行的「共享浮层改」后，点击顶部切换工作空间，`scopeKey` 会立即关闭旧租户浮层，避免把旧租户草稿误提交到新租户。
- 下方属性面板结合 `values`（切换选中行自动重置）与 `onValuesChange`（仅用户编辑触发，外部重置不回弹），适合菜单编辑器、节点属性面板等即时生效场景。
