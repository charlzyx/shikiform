## 注册：整表 schema

**场景**：注册表单的校验逻辑已经用 Zod 写成了一整份 Schema，希望直接拿来校验包含嵌套对象和跨字段比对在内的整个表单。

```tsx preview play=schema
import { useState } from 'react';
import { Button, Space } from 'antd';
import { z } from 'zod';
import { isFieldErrors } from '@shikiform/core';
import { Field, Form, ObjectField, useForm } from '@shikiform/react';
import { FormItem, FormLayout, Input } from '@shikiform/antd';

const schema = z
  .object({
    email: z.string().email('邮箱格式不对'),
    password: z.string().min(6, '至少 6 位'),
    confirm: z.string(),
    nick: z.string().min(1, '昵称必填'),
    address: z.object({ city: z.string().min(1, '城市必填'), street: z.string() }),
  })
  .refine((values) => values.password === values.confirm, { path: ['confirm'], message: '两次密码不一致' });

type Values = z.infer<typeof schema>;

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { email: '', password: '', confirm: '', nick: '', address: { city: '', street: '' } },
    validate: schema,
  });
  const submit = async () => {
    try {
      const values = await form.submit();
      setOut(`提交：${JSON.stringify(values)}`);
    } catch (error) {
      const errors = isFieldErrors(error) ? error : [];
      setOut(`错误：${errors.map((item) => item.path).join('、')}`);
    }
  };
  const setNick = (mode: 'visible' | 'hidden' | 'omit') => form.batch((d) => {
    d.nick.$visible = mode !== 'hidden';
    d.nick.$omit = mode === 'omit';
  });
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        <Field name="email" title="邮箱" decorator={[FormItem]} component={[Input]} />
        <Field name="password" title="密码" decorator={[FormItem]} component={[Input.Password]} />
        <Field name="confirm" title="确认密码" decorator={[FormItem]} component={[Input.Password]} />
        <Field name="nick" title="昵称" decorator={[FormItem]} component={[Input]} />
        <ObjectField name="address">
          <Field name="city" title="城市" decorator={[FormItem]} component={[Input]} />
          <Field name="street" title="街道" decorator={[FormItem]} component={[Input]} />
        </ObjectField>
      </FormLayout>
      <Space wrap>
        <Button type="primary" onClick={submit}>提交</Button>
        <Button onClick={() => setNick('hidden')}>昵称 hidden</Button>
        <Button onClick={() => setNick('omit')}>昵称 omit</Button>
        <Button onClick={() => setNick('visible')}>昵称 visible</Button>
      </Space>
      <pre aria-live="polite">{out}</pre>
    </Form>
  );
}
```

- `useForm({ validate: schema })` 支持任何实现 [Standard Schema](https://standardschema.dev) 规范的校验库；校验问题中的路径会自动映射回对应字段（例如 `['address', 'city']` 会显示在 `address.city` 下方）。
- 可以通过底部按钮分别切换「昵称」的 `hidden`、`virtual`、`none` 状态，观察校验与提交结果的差异，完整规则见 [显隐、pattern 与提交](/guide/concepts#显隐pattern-与提交)。
- 更多字段级规则与异步校验用法请参考 [校验](/guide/validation)。

## 显隐对照

**场景**：联系方式分组需要随顶部开关切换展示模式，直观对比四种 `display` 状态对渲染、校验和提交的影响。

```tsx preview play=display
import { useState } from 'react';
import { Button } from 'antd';
import { isFieldErrors } from '@shikiform/core';
import { Field, Form, ObjectField, defineEffects, useForm } from '@shikiform/react';
import { FormItem, FormLayout, Input, Radio } from '@shikiform/antd';

type Mode = 'visible' | 'hidden' | 'omit' | 'readOnly';
type Values = { mode: Mode; contact: { email: string; phone: string } };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    const mode = d.mode.$value;
    d.contact.$visible = mode !== 'hidden';
    d.contact.$omit = mode === 'omit';
    d.contact.$readOnly = mode === 'readOnly';
  });
});

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { mode: 'visible', contact: { email: '', phone: '13800000000' } },
    fields: { 'contact.email': { required: true } },
    effects: [effects],
  });
  const submit = async () => {
    try {
      const values = await form.submit();
      setOut(`提交：${JSON.stringify(values)}`);
    } catch (error) {
      const errors = isFieldErrors(error) ? error : [];
      setOut(`被挡住：${errors.map((item) => item.path).join('、')}`);
    }
  };
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="mode" title="contact" omit enum={['visible', 'hidden', 'omit', 'readOnly']}
          decorator={[FormItem]} component={[Radio, { optionType: 'button' }]} />
        <ObjectField name="contact">
          <Field name="email" title="邮箱" decorator={[FormItem]} component={[Input]} />
          <Field name="phone" title="电话" decorator={[FormItem]} component={[Input]} />
        </ObjectField>
      </FormLayout>
      <Button type="primary" onClick={submit}>提交</Button>
      <pre aria-live="polite">{out}</pre>
    </Form>
  );
}
```

| 状态 | 是否渲染 | 空邮箱是否阻止提交 | 提交结果是否包含 `contact` |
|---|---|---|---|
| `visible` | ✓ | ✓ | ✓ |
| `hidden`（`$visible = false`） | ✗ | ✗ | ✓ |
| `omit` | ✓ | ✓ | ✗ |
| `readOnly` | 预览 | ✗ | ✓ |

- `omit` 不继承。这里写在 `contact` 上，整段对象离开提交结果；`visible` / `readOnly` 会按 OR 传给里面的邮箱和电话，子字段写 `false` 可以退出。
- 顶部的 `mode` 开关自己也声明了 `omit`，所以它不进提交结果。

## 标签页与未挂载字段

**场景**：表单拆分成多个标签页，切换标签时未激活的页签组件会被条件卸载，但其中的必填项在提交时依然需要拦截表单。

```tsx preview play=tabs
import { useState } from 'react';
import { Button } from 'antd';
import { isFieldErrors } from '@shikiform/core';
import { Field, Form, Watch, useForm, type Draft } from '@shikiform/react';
import { FormItem, FormLayout, Input, Radio } from '@shikiform/antd';

type Values = { tab: 'base' | 'extra'; name: string; code: string; note: string };

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { tab: 'base', name: '', code: '', note: '' },
    fields: {
      name: { required: true }, // 声明在引擎中的规则：无论组件是否挂载都会校验
      code: { required: true },
    },
  });
  const submit = async () => {
    try {
      await form.submit();
      setOut('通过');
    } catch (error) {
      const errors = isFieldErrors(error) ? error : [];
      setOut(`被挡住：${errors.map((item) => item.path).join('、')}`);
    }
  };
  return (
    <Form form={form}>
      <Field name="tab" omit enum={[{ label: '基本', value: 'base' }, { label: '附加', value: 'extra' }]}
        component={[Radio, { optionType: 'button' }]} />
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }} style={{ marginTop: 16 }}>
        <Watch select={(d: Draft<Values>) => d.tab.$value}>
          {(tab) => tab === 'base' ? (
            <Field name="name" title="名称" decorator={[FormItem]} component={[Input]} />
          ) : (
            <>
              <Field name="code" title="编码" decorator={[FormItem]} component={[Input]} />
              {/* JSX 上的规则仅在组件挂载期间生效 */}
              <Field name="note" title="备注" required decorator={[FormItem]} component={[Input]} />
            </>
          )}
        </Watch>
      </FormLayout>
      <Button type="primary" onClick={submit}>提交</Button>
      <pre aria-live="polite">{out}</pre>
    </Form>
  );
}
```

- 停留在「基本」页直接点击提交时，`code` 同样会报错（因为它的 `required` 规则声明在 `fields` 选项中），而 `note` 不会报错（因为它的 `required` 写在 JSX 属性上，未挂载时规则尚未注册）。
- 在实际业务中如果直接使用 `@shikiform/antd` 的 [`FormTab`](/guide/containers)，各个面板默认保持挂载且仅切换隐藏状态，不仅 JSX 规则与错误能完整保留，提交失败时还会自动切回存在错误的页签。不同位置声明规则的生命周期差异见 [规则写在哪](/guide/validation#规则写在哪)。
