## 注册：整表 schema

场景：注册表单的规则已经写成一份 Zod schema，想直接拿来校验整张表，包括嵌套对象和跨字段的「两次密码一致」。

```tsx preview play=schema
import { useState } from 'react';
import { Button, Space } from 'antd';
import { z } from 'zod';
import { Field, Form, ObjectField, useForm } from 'shikiform';
import { FormItem, FormLayout, Input } from 'shikiform/antd';

const schema = z
  .object({
    email: z.string().email('邮箱格式不对'),
    password: z.string().min(6, '至少 6 位'),
    confirm: z.string(),
    nick: z.string().min(1, '昵称必填'),
    address: z.object({ city: z.string().min(1, '城市必填'), street: z.string() }),
  })
  .refine((values) => values.password === values.confirm, { path: ['confirm'], message: '两次密码不一致' });

type Values = z.infer<typeof schema>;

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { email: '', password: '', confirm: '', nick: '', address: { city: '', street: '' } },
    validate: schema,
  });
  const submit = async () => {
    const result = await form.submit();
    setOut(result.ok ? `提交：${JSON.stringify(result.values)}` : `错误：${result.errors.map((error) => error.path).join('、')}`);
  };
  const setNick = (display: 'visible' | 'hidden' | 'none') => form.batch((d) => { d.nick.$display = display; });
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        <Field name="email" title="邮箱" decorator={[FormItem]} component={[Input]} />
        <Field name="password" title="密码" decorator={[FormItem]} component={[Input.Password]} />
        <Field name="confirm" title="确认密码" decorator={[FormItem]} component={[Input.Password]} />
        <Field name="nick" title="昵称" decorator={[FormItem]} component={[Input]} />
        <ObjectField name="address">
          <Field name="city" title="城市" decorator={[FormItem]} component={[Input]} />
          <Field name="street" title="街道" decorator={[FormItem]} component={[Input]} />
        </ObjectField>
      </FormLayout>
      <Space wrap>
        <Button type="primary" onClick={submit}>提交</Button>
        <Button onClick={() => setNick('hidden')}>昵称 hidden</Button>
        <Button onClick={() => setNick('none')}>昵称 none</Button>
        <Button onClick={() => setNick('visible')}>昵称 visible</Button>
      </Space>
      <pre aria-live="polite">{out}</pre>
    </Form>
  );
}
```

- `useForm({ validate: schema })` 接任何 [Standard Schema](https://standardschema.dev)；issue 的 `path` 落到对应字段，`['address', 'city']` → `address.city`。
- 昵称设成 `hidden` 后看不见，但空昵称仍挡住提交；设成 `none`（`$visible = false` 就是它）才既不校验、也不进提交结果。见 [显隐与提交](/guide/concepts#显隐pattern-与提交)。
- 字段级规则和异步校验见 [校验](/guide/validation)。完整版另有 Valibot 版本和 `typed<Address>()` 字段片段。

## 显隐对照

场景：一组联系方式随开关显示、隐藏或彻底排除，想看清三种状态对校验和提交各有什么影响。

```tsx preview play=display
import { useState } from 'react';
import { Button } from 'antd';
import { Field, Form, ObjectField, defineEffects, useForm, type Display } from 'shikiform';
import { FormItem, FormLayout, Input, Radio } from 'shikiform/antd';

type Values = { mode: Display; contact: { email: string; phone: string } };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    d.contact.$display = d.mode.$value; // 子字段继承父级的 display
  });
});

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { mode: 'visible', contact: { email: '', phone: '13800000000' } },
    fields: { 'contact.email': { required: true } },
    effects: [effects],
  });
  const submit = async () => {
    const result = await form.submit();
    setOut(result.ok ? `提交：${JSON.stringify(result.values)}` : `被挡住：${result.errors.map((error) => error.path).join('、')}`);
  };
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="mode" title="contact" display="virtual" enum={['visible', 'hidden', 'none']}
          decorator={[FormItem]} component={[Radio, { optionType: 'button' }]} />
        <ObjectField name="contact">
          <Field name="email" title="邮箱" decorator={[FormItem]} component={[Input]} />
          <Field name="phone" title="电话" decorator={[FormItem]} component={[Input]} />
        </ObjectField>
      </FormLayout>
      <Button type="primary" onClick={submit}>提交</Button>
      <pre aria-live="polite">{out}</pre>
    </Form>
  );
}
```

| `contact.$display` | 渲染 | 空邮箱挡住提交 | 提交结果里有 `contact` |
|---|---|---|---|
| `visible` | ✓ | ✓ | ✓ |
| `hidden`（`$hidden = true`） | ✗ | ✓ | ✓ |
| `none`（`$visible = false`） | ✗ | ✗ | ✗ |

- `mode` 写了 `display="virtual"`：参与联动，不进提交结果；选项是原始值数组，标签就是值本身。
- 只写父级 `d.contact.$display`，子字段跟着变；子字段自己写了 `$display` 就用自己的。

## 标签页与没挂载的字段

场景：表单分成两个标签页，切走的那页组件已经卸载，但它的必填项仍要挡住提交。

```tsx preview play=tabs
import { useState } from 'react';
import { Button } from 'antd';
import { Field, Form, Watch, useForm, type Draft } from 'shikiform';
import { FormItem, FormLayout, Input, Radio } from 'shikiform/antd';

type Values = { tab: 'base' | 'extra'; name: string; code: string; note: string };

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { tab: 'base', name: '', code: '', note: '' },
    fields: {
      name: { required: true }, // 声明的规则：不管挂没挂载都查
      code: { required: true },
    },
  });
  const submit = async () => {
    const result = await form.submit();
    setOut(result.ok ? '通过' : `被挡住：${result.errors.map((error) => error.path).join('、')}`);
  };
  return (
    <Form form={form}>
      <Field name="tab" display="virtual" enum={[{ label: '基本', value: 'base' }, { label: '附加', value: 'extra' }]}
        component={[Radio, { optionType: 'button' }]} />
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }} style={{ marginTop: 16 }}>
        <Watch select={(d: Draft<Values>) => d.tab.$value}>
          {(tab) => tab === 'base' ? (
            <Field name="name" title="名称" decorator={[FormItem]} component={[Input]} />
          ) : (
            <>
              <Field name="code" title="编码" decorator={[FormItem]} component={[Input]} />
              {/* JSX 规则：只在这个组件挂载时生效 */}
              <Field name="note" title="备注" required decorator={[FormItem]} component={[Input]} />
            </>
          )}
        </Watch>
      </FormLayout>
      <Button type="primary" onClick={submit}>提交</Button>
      <pre aria-live="polite">{out}</pre>
    </Form>
  );
}
```

- 停在「基本」页提交：`code` 仍报错（`fields` 声明），`note` 不报（它的规则写在 JSX 上，组件没挂载就不存在）。
- 切到「附加」再切回来，`note` 的规则随组件卸载一起释放。规则放哪的完整对照见 [规则写在哪](/guide/validation#规则写在哪)。
