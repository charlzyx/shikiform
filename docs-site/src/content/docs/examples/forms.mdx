## 登录校验

登录表单通常需要拦截空账号、非法邮箱格式和过短的密码。将这些规则声明在字段上后，只有全部校验通过，提交事件才会进入 `onSubmit`。

```tsx preview
import { useState, type ReactNode } from 'react';
import { Form, Submit, typed, useFieldDecorator, useForm } from '@shikiform/react';
import { Button, Card, FieldInput } from '@site/ui';

type Values = { account: string; email: string; password: string };

function FieldRow({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <p className="sf-ui-form-item" style={{ margin: 0 }}>
      <span className="sf-ui-form-label">
        <label {...d.labelProps}>{d.label}：</label>
        {d.required && <span className="sf-ui-form-required" aria-hidden="true">*</span>}
      </span>
      {children}
      {d.errorProps && <small {...d.errorProps} className="sf-ui-form-error">{d.errors[0]}</small>}
    </p>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({ initialValues: { account: '', email: '', password: '' } });
  const F = typed(form);
  return (
    <Card title="账号登录" description="字段规则与失焦校验全部通过后才进入提交回调" style={{ maxWidth: 440 }}>
      <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
        <F.Field
          name="account"
          title="账号"
          required
          decorator={[FieldRow]}
          component={[FieldInput, { placeholder: '请输入账号，如 alice' }]}
        />
        <F.Field
          name="email"
          title="邮箱"
          required
          rules={{ format: 'email', message: '邮箱格式不对' }}
          decorator={[FieldRow]}
          component={[FieldInput, { placeholder: 'alice@example.com' }]}
        />
        <F.Field
          name="password"
          title="密码"
          required
          rules={{ minLength: 8, message: '至少 8 位' }}
          decorator={[FieldRow]}
          component={[FieldInput, { type: 'password', placeholder: '至少 8 位字符' }]}
        />
        <div>
          <Submit>
            {(s) => (
              <Button type="submit" variant="primary" disabled={s.disabled} loading={s.submitting}>
                登录
              </Button>
            )}
          </Submit>
        </div>
        <pre aria-live="polite">{result}</pre>
      </Form>
    </Card>
  );
}
```

<Aside type="tip" title="空值校验分工">
`''`、`null` 和 `undefined` 等空值仅由 `required` 规则拦截。`minLength`、`pattern`、`format` 等格式或长度规则遇到空值直接放行，选填字段可直接搭配这些规则。
</Aside>

## 跨字段与异步校验

校验函数的第二个参数 `ctx.record` 提供同一对象上的其他字段值（适用于确认密码比对）。请求接口的异步校验在新输入到来时会自动触发 `ctx.signal` 中止旧请求并丢弃过期结果，校验函数内监听 `signal` 结束 Promise 即可。

```tsx preview
import { useState, type ReactNode } from 'react';
import { Form, Submit, typed, useField, useFieldDecorator, useForm } from '@shikiform/react';
import { Button, Card, FieldInput, LoaderIcon } from '@site/ui';

type Values = { username: string; password: string; confirm: string };

function lookupName(username: string, signal?: AbortSignal): Promise<string | undefined> {
  return new Promise((resolve) => {
    const timer = setTimeout(() => {
      resolve(username.trim().toLowerCase() === 'admin' ? '已被占用' : undefined);
    }, 400);
    signal?.addEventListener(
      'abort',
      () => {
        clearTimeout(timer);
        resolve(undefined);
      },
      { once: true },
    );
  });
}

function FieldRow({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  const f = useField();
  return (
    <p className="sf-ui-form-item" style={{ margin: 0 }}>
      <span className="sf-ui-form-label">
        <label {...d.labelProps}>{d.label}：</label>
        {d.required && <span className="sf-ui-form-required" aria-hidden="true">*</span>}
      </span>
      {children}
      {f.validating && (
        <small className="sf-ui-form-desc" style={{ display: 'inline-flex', alignItems: 'center', gap: 4 }}>
          <LoaderIcon size={12} /> 校验中…
        </small>
      )}
      {d.errorProps && <small {...d.errorProps} className="sf-ui-form-error">{d.errors[0]}</small>}
    </p>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { username: '', password: '', confirm: '' },
    asyncDebounceMs: 300,
  });
  const F = typed(form);
  return (
    <Card title="账号注册" description="输入 admin 触发异步查重；确认密码标记 omit，不随表单提交" style={{ maxWidth: 440 }}>
      <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
        <F.Field
          name="username"
          title="用户名"
          required
          rules={{ validator: (value, ctx) => lookupName(String(value ?? ''), ctx.signal) }}
          decorator={[FieldRow]}
          component={[FieldInput, { placeholder: '试试输入 admin 或 alice' }]}
        />
        <F.Field
          name="password"
          title="密码"
          required
          rules={{ minLength: 8, message: '至少 8 位' }}
          decorator={[FieldRow]}
          component={[FieldInput, { type: 'password', placeholder: '至少 8 位字符' }]}
        />
        <F.Field
          name="confirm"
          title="确认密码"
          required
          omit
          rules={{
            validator: (value, ctx) => (value && value !== ctx.record?.password ? '两次密码不一致' : undefined),
          }}
          decorator={[FieldRow]}
          component={[FieldInput, { type: 'password', placeholder: '再次输入密码' }]}
        />
        <div>
          <Submit>
            {(s) => (
              <Button type="submit" variant="primary" disabled={s.disabled} loading={s.submitting}>
                注册
              </Button>
            )}
          </Submit>
        </div>
        <pre aria-live="polite">{result}</pre>
      </Form>
    </Card>
  );
}
```

<Aside type="caution" title="被中止后结束 Promise">
引擎触发 `abort` 后会忽略该次异步校验的返回值，校验函数内的 Promise 仍应调用 `resolve(undefined)` 并清理定时器，避免留下未决 Promise 或未捕获异常。
</Aside>

## 注册：整表 schema

**场景**：注册表单的校验逻辑已经用 Zod 写成了一整份 Schema，希望直接拿来校验包含嵌套对象和跨字段比对在内的整个表单。

```tsx preview play=schema
import { useState, type ReactNode } from 'react';
import { z } from 'zod';
import { isFieldErrors } from '@shikiform/core';
import { Field, Form, ObjectField, useFieldDecorator, useForm } from '@shikiform/react';
import { Badge, Button, Card, FieldInput, Toolbar } from '@site/ui';

const schema = z
  .object({
    email: z.string().email('邮箱格式不对'),
    password: z.string().min(6, '至少 6 位'),
    confirm: z.string(),
    nick: z.string().min(1, '昵称必填'),
    address: z.object({ city: z.string().min(1, '城市必填'), street: z.string() }),
  })
  .refine((values) => values.password === values.confirm, { path: ['confirm'], message: '两次密码不一致' });

type Values = z.infer<typeof schema>;

function FieldRow({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <p className="sf-ui-form-item" style={{ margin: 0 }}>
      <label {...d.labelProps} className="sf-ui-form-label">
        <span>{d.label}：</span>
      </label>
      {children}
      {d.errorProps && <small {...d.errorProps} className="sf-ui-form-error">{d.errors[0]}</small>}
    </p>
  );
}

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { email: '', password: '', confirm: '', nick: '', address: { city: '', street: '' } },
    validate: schema,
  });
  const submit = async () => {
    try {
      const values = await form.submit();
      setOut(`提交：${JSON.stringify(values)}`);
    } catch (error) {
      const errors = isFieldErrors(error) ? error : [];
      setOut(`错误：${errors.map((item) => item.path).join('、')}`);
    }
  };
  const setNick = (mode: 'visible' | 'hidden' | 'omit') => form.batch((d) => {
    d.nick.$visible = mode !== 'hidden';
    d.nick.$omit = mode === 'omit';
  });
  return (
    <Card
      title="注册信息"
      description="整表 Standard Schema（Zod）校验与嵌套地址映射"
      extra={<Badge variant="brand">Zod</Badge>}
      style={{ maxWidth: 520 }}
    >
      <Form form={form}>
        <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(190px, 1fr))', gap: 12 }}>
          <Field name="email" title="邮箱" decorator={[FieldRow]} component={[FieldInput, { placeholder: 'a@b.co' }]} />
          <Field name="nick" title="昵称" decorator={[FieldRow]} component={[FieldInput, { placeholder: 'ada' }]} />
          <Field name="password" title="密码" decorator={[FieldRow]} component={[FieldInput, { type: 'password', placeholder: '至少 6 位' }]} />
          <Field name="confirm" title="确认密码" decorator={[FieldRow]} component={[FieldInput, { type: 'password', placeholder: '再次输入密码' }]} />
        </div>
        <Card variant="muted" padding="sm" title="收货地址">
          <ObjectField name="address">
            <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(180px, 1fr))', gap: 12 }}>
              <Field name="city" title="城市" decorator={[FieldRow]} component={[FieldInput, { placeholder: '杭州' }]} />
              <Field name="street" title="街道" decorator={[FieldRow]} component={[FieldInput, { placeholder: '文一西路（选填）' }]} />
            </div>
          </ObjectField>
        </Card>
        <Toolbar>
          <Button variant="primary" size="sm" onClick={submit}>提交</Button>
          <Button variant="outline" size="sm" onClick={() => setNick('hidden')}>昵称 hidden</Button>
          <Button variant="outline" size="sm" onClick={() => setNick('omit')}>昵称 omit</Button>
          <Button variant="outline" size="sm" onClick={() => setNick('visible')}>昵称 visible</Button>
        </Toolbar>
        <pre aria-live="polite">{out}</pre>
      </Form>
    </Card>
  );
}
```

- `useForm({ validate: schema })` 支持任何实现 [Standard Schema](https://standardschema.dev) 规范的校验库；校验问题中的路径会自动映射回对应字段（例如 `['address', 'city']` 会显示在 `address.city` 下方）。
- 底部按钮把「昵称」切到 `hidden`（不渲染、仍提交）、`omit`（仍渲染、不提交）或 `visible`。完整规则见 [四个布尔](/guide/concepts#四个布尔)。
- 更多字段级规则与异步校验用法请参考 [校验](/guide/validation)。

## 显隐对照

**场景**：联系方式分组随顶部开关切换 `visible` / `omit` / `readOnly`，对照渲染、校验和提交。

```tsx preview play=display
import { useState, type ReactNode } from 'react';
import { isFieldErrors } from '@shikiform/core';
import { Field, Form, ObjectField, defineEffects, useFieldDecorator, useForm } from '@shikiform/react';
import { Button, Card, FieldInput, FieldRadioGroup, FormItem } from '@site/ui';

type Mode = 'visible' | 'hidden' | 'omit' | 'readOnly';
type Values = { mode: Mode; contact: { email: string; phone: string } };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    const mode = d.mode.$value;
    d.contact.$visible = mode !== 'hidden';
    d.contact.$omit = mode === 'omit';
    d.contact.$readOnly = mode === 'readOnly';
  });
});

function FieldRow({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <p className="sf-ui-form-item" style={{ margin: 0 }}>
      <span className="sf-ui-form-label">
        <label {...d.labelProps}>{d.label}：</label>
        {d.required && <span className="sf-ui-form-required" aria-hidden="true">*</span>}
      </span>
      {children}
      {d.errorProps && <small {...d.errorProps} className="sf-ui-form-error">{d.errors[0]}</small>}
    </p>
  );
}

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { mode: 'visible', contact: { email: '', phone: '13800000000' } },
    fields: { 'contact.email': { required: true } },
    effects: [effects],
  });
  const submit = async () => {
    try {
      const values = await form.submit();
      setOut(`提交：${JSON.stringify(values)}`);
    } catch (error) {
      const errors = isFieldErrors(error) ? error : [];
      setOut(`被挡住：${errors.map((item) => item.path).join('、')}`);
    }
  };
  return (
    <Card title="显隐模式对照" description="切换 contact 分组的四种状态，观察渲染、校验与提交载荷变化" style={{ maxWidth: 520 }}>
      <Form form={form}>
        <Field<Values, 'mode'>
          name="mode"
          title="contact"
          omit
          enum={['visible', 'hidden', 'omit', 'readOnly']}
          decorator={[FormItem, { layout: 'inline' }]}
          component={[FieldRadioGroup]}
        />
        <Card variant="muted" padding="sm" title="联系方式">
          <ObjectField name="contact">
            <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(180px, 1fr))', gap: 12 }}>
              <Field name="email" title="邮箱" decorator={[FieldRow]} component={[FieldInput, { placeholder: 'a@b.co' }]} />
              <Field name="phone" title="电话" decorator={[FieldRow]} component={[FieldInput]} />
            </div>
          </ObjectField>
        </Card>
        <div>
          <Button variant="primary" onClick={submit}>提交</Button>
        </div>
        <pre aria-live="polite">{out}</pre>
      </Form>
    </Card>
  );
}
```

| 状态 | 是否渲染 | 空邮箱是否阻止提交 | 提交结果是否包含 `contact` |
|---|---|---|---|
| `visible` | ✓ | ✓ | ✓ |
| `hidden`（`$visible = false`） | ✗ | ✗ | ✓ |
| `omit` | ✓ | ✓ | ✗ |
| `readOnly` | 预览 | ✗ | ✓ |

- `omit` 写在 `contact` 上时，整段对象离开提交结果，里面的邮箱和电话读到的 `$omit` 也是 `true`，不能用 `omit: false` 单独提交。`visible` / `readOnly` 同样沿字段路径传下去：这一层写了 `true` 或 `false` 就用这一层，没写就保持上一层。
- 顶部的 `mode` 开关自己也声明了 `omit`，所以它不进提交结果。

## 标签页与未挂载字段

**场景**：表单拆分成多个标签页，切换标签时未激活的页签组件会被条件卸载，但其中的必填项在提交时依然需要拦截表单。

```tsx preview play=tabs
import { useState, type ReactNode } from 'react';
import { isFieldErrors } from '@shikiform/core';
import { Field, Form, Watch, useFieldDecorator, useForm, type Draft } from '@shikiform/react';
import { Button, Card, FieldInput, Tabs, TabsList, TabsTab } from '@site/ui';

type Values = { tab: 'base' | 'extra'; name: string; code: string; note: string };

function FieldRow({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <p className="sf-ui-form-item" style={{ margin: 0 }}>
      <span className="sf-ui-form-label">
        <label {...d.labelProps}>{d.label}：</label>
        {d.required && <span className="sf-ui-form-required" aria-hidden="true">*</span>}
      </span>
      {children}
      {d.errorProps && <small {...d.errorProps} className="sf-ui-form-error">{d.errors[0]}</small>}
    </p>
  );
}

export default function App() {
  const [out, setOut] = useState('');
  const form = useForm<Values>({
    initialValues: { tab: 'base', name: '', code: '', note: '' },
    fields: {
      name: { required: true }, // 声明在引擎中的规则：无论组件是否挂载都会校验
      code: { required: true },
    },
  });
  const submit = async () => {
    try {
      await form.submit();
      setOut('通过');
    } catch (error) {
      const errors = isFieldErrors(error) ? error : [];
      setOut(`被挡住：${errors.map((item) => item.path).join('、')}`);
    }
  };
  return (
    <Card title="多标签页校验" description="引擎级 fields 规则在页签卸载时仍会拦截，JSX 规则仅在挂载期生效" style={{ maxWidth: 460 }}>
      <Form form={form}>
        <Field<Values, 'tab'> name="tab" omit enum={[{ label: '基本', value: 'base' }, { label: '附加', value: 'extra' }]}>
          {(f) => (
            <Tabs value={f.value ?? 'base'} onValueChange={(v) => f.onChange(v as Values['tab'])} variant="segmented">
              <TabsList className="sf-ui-tabs-list">
                {f.options.map((opt) => (
                  <TabsTab key={String(opt.value)} value={String(opt.value)} className="sf-ui-tabs-tab">
                    {opt.label}
                  </TabsTab>
                ))}
              </TabsList>
            </Tabs>
          )}
        </Field>
        <Watch select={(d: Draft<Values>) => d.tab.$value}>
          {(tab) => tab === 'base' ? (
            <Field name="name" title="名称" decorator={[FieldRow]} component={[FieldInput, { placeholder: '必填（fields 声明）' }]} />
          ) : (
            <div style={{ display: 'grid', gap: 12 }}>
              <Field name="code" title="编码" decorator={[FieldRow]} component={[FieldInput, { placeholder: '必填（fields 声明）' }]} />
              {/* JSX 上的规则仅在组件挂载期间生效 */}
              <Field name="note" title="备注" required decorator={[FieldRow]} component={[FieldInput, { placeholder: '必填（仅 JSX 挂载期）' }]} />
            </div>
          )}
        </Watch>
        <div>
          <Button variant="primary" onClick={submit}>提交</Button>
        </div>
        <pre aria-live="polite">{out}</pre>
      </Form>
    </Card>
  );
}
```

- 停留在「基本」页直接点击提交时，`code` 同样会报错（因为它的 `required` 规则声明在 `fields` 选项中），而 `note` 不会报错（因为它的 `required` 写在 JSX 属性上，未挂载时规则尚未注册）。
- 在实际业务中，若希望未激活页签的 JSX 规则与错误继续生效，可保持非当前页挂载（如使用 CSS `hidden` 切换显隐），或将规则声明在 `useForm({ fields })` / `reaction` 中。不同位置声明规则的生命周期差异见 [规则写在哪决定「卸载后是否还校验」](/guide/validation#规则写在哪决定卸载后是否还校验)。
