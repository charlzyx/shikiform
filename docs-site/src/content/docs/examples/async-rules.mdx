---
title: 跨字段与异步校验
description: 使用 ctx.record 比对同一记录的密码，并配合 AbortSignal 安全中止过期的异步请求。
---

在校验函数中，可以通过第二个参数 `ctx.record` 获取同一层级的其他字段值（适合做「确认密码」校验）；而对于需要请求后端接口的异步校验（如检查用户名是否已被占用），引擎会在新输入到来时自动中止上一次请求并丢弃过期结果，只需监听 `ctx.signal` 妥善结束 Promise 即可。

```tsx preview
import { useState } from 'react';
import { Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormItem, FormLayout, Input, Submit } from '@shikiform/antd';

type Values = { username: string; password: string; confirm: string };

function lookupName(username: string, signal?: AbortSignal): Promise<string | undefined> {
  return new Promise((resolve) => {
    const timer = setTimeout(() => {
      resolve(username.trim().toLowerCase() === 'admin' ? '已被占用' : undefined);
    }, 400);
    signal?.addEventListener(
      'abort',
      () => {
        clearTimeout(timer);
        resolve(undefined);
      },
      { once: true },
    );
  });
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { username: '', password: '', confirm: '' },
    asyncDebounceMs: 300,
  });
  const F = typed(form);
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        <F.Field
          name="username"
          title="用户名"
          required
          rules={{ validator: (value, ctx) => lookupName(String(value ?? ''), ctx.signal) }}
          decorator={[FormItem]}
          component={[Input]}
        />
        <F.Field
          name="password"
          title="密码"
          required
          rules={{ minLength: 8, message: '至少 8 位' }}
          decorator={[FormItem]}
          component={[Input.Password]}
        />
        <F.Field
          name="confirm"
          title="确认密码"
          required
          display="virtual"
          rules={{
            validator: (value, ctx) => (value && value !== ctx.record?.password ? '两次密码不一致' : undefined),
          }}
          decorator={[FormItem]}
          component={[Input.Password]}
        />
        <FormButtonGroup.FormItem>
          <Submit>注册</Submit>
        </FormButtonGroup.FormItem>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

在用户名中输入 `admin` 并稍作停顿，会收到「已被占用」的异步校验错误；如果紧接着将其改成 `ada`，前一次校验请求会被中止并清理，不会把过期错误覆盖到新输入上。同时，「确认密码」通过 `display="virtual"` 保持渲染与校验能力，在全部校验通过提交时则会被自动从结果 JSON 中剔除。

<Aside type="caution" title="被中止后记得结束 Promise">
虽然引擎在触发 `abort` 后会直接丢弃该次异步校验的结果，但校验函数内部的 Promise 仍应显式 `resolve(undefined)` 并清理定时器，避免产生悬空 Promise 或未捕获的异常。
</Aside>
