---
title: 条件显隐
description: 使用 $visible 控制字段显示，隐藏时自动跳过校验并从提交结果中剔除。
---

当勾选「需要发票」时，税号输入框显示并变为必填；关闭开关后，税号不仅从界面隐藏，也不会阻止表单提交或出现在提交结果中。

需要注意：`$visible = false` 对应的是 `display: 'none'`，而不是 `hidden`。

```tsx preview
import { useState } from 'react';
import { defineEffects, Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormItem, FormLayout, Input, Submit, Switch } from '@shikiform/antd';

type Values = { invoice: boolean; taxId: string };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    const need = d.invoice.$value;
    d.taxId.$visible = need;
    d.taxId.$required = need;
  });
});

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { invoice: false, taxId: '' },
    effects: [effects],
  });
  const F = typed(form);
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        <F.Field name="invoice" title="需要发票" decorator={[FormItem]} component={[Switch]} />
        <F.Field name="taxId" title="税号" decorator={[FormItem]} component={[Input]} />
        <FormButtonGroup.FormItem>
          <Submit>提交</Submit>
        </FormButtonGroup.FormItem>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

默认未开启开关时直接点击提交，输出 JSON 里只有 `invoice: false`；打开开关后税号出现且必填（留空会拦截提交）；填好税号再次关掉开关并提交，`taxId` 会被自动剔除，而重新打开开关时刚才填过的内容依然完整保留。

<Aside type="caution" title="只藏界面时请使用 hidden">
如果是未激活的标签页等「暂时不展示在界面上，但提交前依然需要校验并提交」的场景，请使用 `$hidden = true`，不要用 `$visible = false`。
</Aside>
