---
title: 联动计算
description: 单价乘数量得到金额。reaction 写出来的字段默认仍会提交。
---

金额由单价和数量决定。用 `reaction` 维持它，不要在 `watch` 里偷偷做乘法。

```tsx preview
import { useState } from 'react';
import { defineEffects, Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormItem, FormLayout, InputNumber, Submit } from '@shikiform/antd';

type Values = { price: number | null; qty: number | null; amount: number };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    const amount = (d.price.$value ?? 0) * (d.qty.$value ?? 0);
    d.amount.$value = amount;
  });
});

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { price: 10, qty: 2, amount: 0 },
    effects: [effects],
  });
  const F = typed(form);
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        <F.Field name="price" title="单价" decorator={[FormItem]} component={[InputNumber, { min: 0 }]} />
        <F.Field name="qty" title="数量" decorator={[FormItem]} component={[InputNumber, { min: 0 }]} />
        <F.Field name="amount" title="金额" decorator={[FormItem]} component={[InputNumber]} />
        <FormButtonGroup.FormItem>
          <Submit>提交</Submit>
        </FormButtonGroup.FormItem>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

打开页面，金额已经是 20，而且不能手改。把单价改成 30，金额变成 60。提交 JSON 里有 `amount`。

<Aside type="tip" title="计算字段默认提交">
reaction 写过 `$value` 的字段是阅读态，仍在提交结果里。不想带上它，给这个字段声明 `display: 'virtual'`。
</Aside>

同一轮里不要读刚写的 `$value`。乘积放在 `amount` 这个局部变量里，再赋值。
