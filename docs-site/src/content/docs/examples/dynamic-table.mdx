---
title: 动态表格
description: 使用 reaction.each 按行独立计算订单明细小计。
---

订单明细中每一行有各自的单价、数量和小计。通过 `reaction.each` 为每一行建立独立联动实例，修改任意一行的单价或数量时，只重算该行小计。

对于只有一层的扁平表格，回调函数不需要读取第二个 `ctx` 参数；如果是嵌套子数组或树形结构，可以通过 `ctx.key`、`ctx.depth` 进行层级过滤，详见 [用 ctx 过滤](/guide/linkage#用-ctx-过滤)。

```tsx preview
import { useState, type ReactNode } from 'react';
import { Button } from 'antd';
import { defineEffects, Form, typed, useArrayField, useForm } from '@shikiform/react';
import { FormItem, Input, InputNumber, Submit } from '@shikiform/antd';

type Line = { sku: string; price: number | null; qty: number | null; total: number };
type Values = { lines: Line[] };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction.each((d) => d.lines, (row) => {
    const total = (row.price.$value ?? 0) * (row.qty.$value ?? 0);
    row.total.$value = total;
  });
});

const blank = (): Line => ({ sku: '', price: 0, qty: 1, total: 0 });

function Lines({ children }: { children?: ReactNode }) {
  const lines = useArrayField<Line>();
  return (
    <>
      {children}
      <Button htmlType="button" onClick={() => lines.push(blank())}>添加一行</Button>
    </>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { lines: [{ sku: '贴纸', price: 2, qty: 4, total: 0 }] },
    effects: [effects],
  });
  const F = typed(form);
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <F.ArrayField name="lines" component={Lines}>
        {(row) => (
          <div style={{ display: 'flex', gap: 8, marginBottom: 8 }}>
            <row.Field name="sku" title="商品" decorator={[FormItem]} component={[Input]} />
            <row.Field name="price" title="单价" decorator={[FormItem]} component={[InputNumber, { min: 0 }]} />
            <row.Field name="qty" title="数量" decorator={[FormItem]} component={[InputNumber, { min: 0 }]} />
            <row.Field name="total" title="小计" decorator={[FormItem]} component={[InputNumber]} />
          </div>
        )}
      </F.ArrayField>
      <Submit style={{ marginLeft: 8 }}>提交</Submit>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

初始渲染时第一行的小计已经自动算出为 8；点击「添加一行」并调整新行的单价或数量，只有新行会触发重算，最终提交时每行都会带上计算好的 `total`。

<Aside type="tip" title="基本类型数组不会展开遍历">
`reaction.each` 只会继续递归进入「元素是对象」的嵌套数组。如果行内包含像 `tags: string[]` 这样的基本类型数组，它不会被拆开遍历；只有当你直接把 `d.tags` 传给选择器时，回调才会在 `depth === 0` 访问其中的每一项字符串。
</Aside>
