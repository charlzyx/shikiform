# 数组与树

## 嵌套对象与只读行

场景：一张客户资料里有嵌套的地址和一组订单；整张表可以切成只读，已发货的订单行无论如何都不能改数量；地址放在抽屉里编辑。

```tsx preview play=nested
import { useState } from 'react';
import { Button, Drawer } from 'antd';
import { ArrayField, Field, Form, ObjectField, Watch, defineEffects, useForm, type Draft } from 'shikiform';
import { FormItem, FormLayout, Input, InputNumber, Switch } from 'shikiform/antd';

type Order = { id: string; title: string; qty: number; shipped: boolean };
type Values = { editable: boolean; profile: { name: string; address: { city: string; street: string } }; orders: Order[] };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    const pattern = d.editable.$value ? undefined : 'readPretty'; // undefined = 继承上级
    d.profile.$pattern = pattern;
    d.orders.$pattern = pattern;
  });
  reaction.each((d) => d.orders, (row) => {
    row.qty.$pattern = row.shipped.$value ? 'readPretty' : undefined;
  });
});

export default function App() {
  const [open, setOpen] = useState(false);
  const form = useForm<Values>({
    initialValues: {
      editable: true,
      profile: { name: 'Ada', address: { city: '伦敦', street: '贝克街 221B' } },
      orders: [{ id: 'o1', title: '未发货', qty: 1, shipped: false }, { id: 'o2', title: '已发货', qty: 2, shipped: true }],
    },
    fields: { editable: { virtual: true } },
    effects: [effects],
  });
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="editable" title="可编辑" decorator={[FormItem]} component={[Switch]} />
        <ObjectField name="profile">
          <Field name="name" title="姓名" decorator={[FormItem]} component={[Input]} />
          <FormItem label="地址">
            <Watch select={(d: Draft<Values>) => d.profile.address.$value}>{(address) => <span>{address.city} · {address.street} </span>}</Watch>
            <Button size="small" onClick={() => setOpen(true)}>编辑</Button>
          </FormItem>
          <Drawer title="地址" open={open} onClose={() => setOpen(false)}>
            <ObjectField name="address">
              <Field name="city" title="城市" decorator={[FormItem]} component={[Input]} />
              <Field name="street" title="街道" decorator={[FormItem]} component={[Input]} />
            </ObjectField>
          </Drawer>
        </ObjectField>
      </FormLayout>
      <ArrayField name="orders" rowKey="id">
        {() => (
          <FormLayout layout="inline" feedbackLayout="terse" style={{ marginBottom: 8 }}>
            <Field name="title" pattern="readPretty" component={[Input]} />
            <Field name="qty" title="数量" decorator={[FormItem]} component={[InputNumber, { min: 1 }]} />
            <Field name="shipped" title="已发货" decorator={[FormItem]} component={[Switch]} />
          </FormLayout>
        )}
      </ArrayField>
    </Form>
  );
}
```

- `$pattern` 从父级往下传：只写 `d.profile` 和 `d.orders`，下面所有字段一起变；`undefined` 表示「跟随上级」。
- 行里的 `qty` 自己写了 `readPretty`，所以表格可编辑时它也只读；打开「已发货」开关试试。
- 抽屉里的 `<ObjectField name="address">` 仍在 `profile` 作用域里：React context 能穿过 portal。抽屉关掉，值和字段状态都还在引擎里。
- 「地址」那一行不是字段：`FormItem` 放在字段外就是纯布局，标签和列宽跟随 `FormLayout`，见 [一个标签放几个字段](/guide/layout#一个标签放几个字段)。

## 树：跨层移动

场景：菜单编辑器。节点可以拖到别的父节点下，节点上的错误和输入状态要跟着节点走；不能把节点拖进它自己的子孙。

```tsx preview play=headless
import { useState } from 'react';
import { Form, RowScope, TreeField, useField, useForm, useTreeField, useTreeNode } from 'shikiform';

type Node = { id: string; name: string; children: Node[] };
type DragProps = ReturnType<typeof useTreeField>['dragProps'];

function NodeRow({ dragProps }: { dragProps: DragProps }) {
  const { pos, path, record } = useTreeNode<Node>();
  const name = useField<Node, 'name'>('name', { required: true });
  return (
    <div {...dragProps(pos)} style={{ cursor: 'grab', padding: '2px 0' }}>
      ⠿ <input aria-label="名称" value={name.value} onChange={(event) => name.onChange(event.target.value)} onBlur={name.onBlur} />
      <small> id {record.id} · pos [{pos.join(',')}] · {path}</small>
      {name.errors[0] && <small style={{ color: 'crimson' }}> {name.errors[0]}</small>}
    </div>
  );
}

function Branch({ path, nodes, pos, dragProps }: { path: string; nodes: Node[]; pos: number[]; dragProps: DragProps }) {
  return (
    <ul style={{ paddingLeft: pos.length ? 20 : 0, listStyle: 'none', margin: 0 }}>
      {nodes.map((node, index) => (
        <li key={node.id}>
          <RowScope path={`${path}.${index}`} pos={[...pos, index]}>
            <NodeRow dragProps={dragProps} />
            <Branch path={`${path}.${index}.children`} nodes={node.children} pos={[...pos, index]} dragProps={dragProps} />
          </RowScope>
        </li>
      ))}
    </ul>
  );
}

function Menu() {
  const [result, setResult] = useState('');
  return (
    <TreeField name="menu" rowKey="id">
      {(tree) => (
        <>
          <Branch path={tree.path} nodes={tree.value as Node[]} pos={[]} dragProps={tree.dragProps} />
          <button type="button" onClick={() => setResult(JSON.stringify(tree.move([1, 0], [0, 0])))}>「撤销」移到「文件」最前</button>{' '}
          <button type="button" onClick={() => setResult(JSON.stringify(tree.move([0], [0, 0])))}>「文件」移进自己的子节点</button>
          <pre>{result}</pre>
        </>
      )}
    </TreeField>
  );
}

export default function App() {
  const form = useForm({
    initialValues: {
      menu: [
        { id: 'file', name: '文件', children: [{ id: 'new', name: '', children: [] }, { id: 'open', name: '打开', children: [] }] },
        { id: 'edit', name: '编辑', children: [{ id: 'undo', name: '撤销', children: [] }] },
      ] as Node[],
    },
  });
  return (
    <Form form={form}>
      <Menu />
      <button type="button" onClick={() => void form.validate()}>校验</button>
    </Form>
  );
}
```

- 先点「校验」，空名称的节点报错；再把它拖到别处：错误跟着 `id` 走，`pos` 和 `path` 随位置变化。
- `tree.move(from, to)`（即 `form.moveTree`）返回 `{ ok, reason? }`，拒绝移进自己的子孙。
- 每个节点包一层 `<RowScope path pos>`，节点组件里用 `useTreeNode()` 拿 `pos` / `path` / `record`，不需要知道树叫什么。见 [Headless Hooks](/guide/headless)。
- 完整版把数组拖动和树拖动放在一页，并显示每行的渲染次数。

## 长列表：只挂载可见行

场景：2000 行的名单，只渲染滚动窗口里的几行，但每行的必填规则都要生效。

```tsx preview play=virtual
import { useState } from 'react';
import { ArrayField, Field, Form, useForm } from 'shikiform';
import { Input } from 'shikiform/antd';

type Row = { id: string; name: string };

export default function App() {
  const [errors, setErrors] = useState('');
  const form = useForm<{ rows: Row[] }>({
    initialValues: { rows: Array.from({ length: 2000 }, (_, index) => ({ id: `v${index}`, name: index % 500 === 499 ? '' : `第 ${index} 行` })) },
    fields: { 'rows.*.name': { required: true } }, // 行模板：每一行都有，挂没挂载都查
  });
  const validate = async () => {
    const result = await form.validate();
    setErrors(result.map((error) => error.path).join('、') || '无');
  };
  return (
    <Form form={form}>
      <ArrayField name="rows" rowKey="id" virtualScroll={{ height: 240, rowHeight: 40, overscan: 4 }}>
        {({ index }) => (
          <div style={{ display: 'flex', gap: 8, alignItems: 'center', height: 40 }}>
            <code style={{ width: 48 }}>#{index}</code>
            <Field name="name" component={[Input, { style: { width: 200 } }]} />
          </div>
        )}
      </ArrayField>
      <button type="button" onClick={validate}>校验全部 2000 行</button>
      <p>错误：{errors}</p>
    </Form>
  );
}
```

- 第 499、999、1499、1999 行是空的，它们都不在可见区域，校验照样报出来：规则在 `fields` 的行模板 `rows.*.name` 上，不在组件上。
- `<ArrayField virtualScroll>` 和 `<VirtualRows>` 是同一个虚拟滚动，只是把行作用域也一并提供了；它只用于普通行，不和容器 `component` 一起用。
