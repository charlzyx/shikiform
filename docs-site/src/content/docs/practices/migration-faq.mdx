## 从 display / pattern 迁到四个布尔

`display`、`pattern`、`readPretty`、`virtual`、`$hidden`、`$display`、`$pattern` 已经删除，没有兼容别名。

| 旧写法 | 现在 |
|---|---|
| `display: 'visible'` | 默认。`visible` 默认为 `true` |
| `display: 'hidden'` / `$hidden = true` | 不渲染写 `visible: false`（同时跳过校验，值仍提交） |
| `display: 'none'`（旧语义：不提交） | `visible: false`，不提交再加 `omit: true` |
| `display: 'virtual'` | `omit: true`（仍渲染、仍校验、不提交、不计入 dirty） |
| `pattern: 'disabled'` | `disabled: true`（置灰，仍提交） |
| `pattern: 'readOnly'` / `'readPretty'` | `readOnly: true`（直接渲染预览） |
| `mapProps({ readPretty })` | `mapProps({ preview })` |
| 计算字段默认 `readPretty` | 不再自动只读；要预览再写 `readOnly`，不提交再写 `omit` |

## 从 Formily / react-hook-form 迁移

| 常见概念 | ShikiForm 对应写法 |
|---|---|
| Formily `reactions` / `x-reactions` | 在 `defineEffects` 中编写 `reaction((d) => ...)`，直接给 `$` 状态赋值 |
| Formily `onFieldValueChange` 清空关联字段 | 使用 `watch(source, effect)` 监听变化后执行一次性重置 |
| Formily 数组行内 `map` 联动 | 使用 `reaction.each(draft.items, fn)`（只接收两个参数；selector 仍可用） |
| RHF `watch('email')` | 组件中用 `useWatch((d) => d.email.$value)`，联动中直接读 `d.email.$value` |
| RHF `setValue('city', '')` | 外部调用 `form.setValue('city', '')`，联动中赋值 `d.city.$value = ''` |
| RHF `resolver`（如 Zod） | 直接传给 `useForm({ validate: schema })`（支持 Standard Schema） |

## 常见问答（FAQ）

### 计算字段会自动变成只读吗？

不会。`reaction` 写入 `$value` 只表示这是计算字段：仍然可以编辑，也仍然提交，不计入 dirty。要展示成预览，再写 `readOnly`；不要交给后端时再声明 `omit: true`。

### 隐藏的字段还会出现在提交结果里吗？

会。`$visible = false` 不渲染、跳过校验并清掉已有错误，值仍然提交。不进提交结果要再写 `$omit = true`。重新显示时，引擎里的值还在。`disabled` 同样照常提交，这和 react-hook-form 相反。

### 确认密码等辅助字段怎么从提交数据中剔除？

给辅助字段声明 `omit: true` 即可：输入框依然正常显示并参与校验，在调用 `getSubmitValues()` 或 `onSubmit` 时会被自动剔除，此时 `$visible` 依然为 `true`。

### 可以不引入 React 单独使用表单引擎吗？

可以。安装 `@shikiform/core` 后直接调用 `createForm` 即可，所有联动、校验、路径读写和数组操作都不依赖 React。使用 React 时直接安装 `@shikiform/react`，其中已经重导出了核心 API。

### 如何让字段名获得 TypeScript 类型检查？

通过 `const F = typed(form)` 获取绑定当前表单类型的组件集合，然后使用 `<F.Field name="..." />`、`F.useWatch(...)` 即可。对于需要动态拼接路径的场景，继续使用普通的 `<Field>`。

### 自定义组件怎么接入表单的值和错误提示？

- 仅负责输入部分时，用 `connect(Control, mapProps({ ... }))` 包装，外部再套 `decorator={[FormItem]}`。
- 在自定义渲染函数或独立组件内部接线时，直接调用 `useField()` 读写 `value`、`onChange`、`onBlur`。注意 `useFieldDecorator().control` 只包含标签、无障碍属性和错误信息，**不包含 `value` 与 `onChange`**。

### 查询列表和弹窗草稿表单在哪个包？

无 UI 的状态 Hook（`useQueryTable`、`useShadowForm`、`useArrayTable`、`useColumnSettings`、`useSuggestion`、`useLazyCascader`）位于 `@shikiform/react`，可搭配原生 HTML 或任意 UI 组件库渲染，见 [查询列表与 Pro Hooks](/guide/pro)。
