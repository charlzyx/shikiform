---
title: 从 Formily 或 react-hook-form 迁移
description: 字段仍是 Field 加装饰器。显隐用四种 display。联动写成 reaction，而不是 schema 上的 reactions。
---

迁移时先保住数据形状和提交结果，再换联动的写法。

## Formily

字段仍是一个路径的主人：`decorator` 包住 `component`。`FormItem`、`FormLayout`、`ArrayTable` 这些名字能对上。

| Formily | ShikiForm |
|---|---|
| `reactions` / `x-reactions` | `defineEffects` 里的 `reaction`，对 `$` 状态赋值 |
| `visible: false` | `$visible = false`，也就是 `display: 'none'` |
| `hidden`（不校验） | 这里的 `hidden` 仍校验、仍提交。要不校验，用 `none` |
| 单独的 virtual 标记 | `display: 'virtual'`：渲染、校验、不提交 |
| `onFieldValueChange` 里做清空 | `watch` |
| 数组的 `map` | `reaction.each`，两个参数 |

计算字段默认会提交。Formily 里靠不注册来丢掉的字段，这里声明 `virtual` 或 `none`。

## react-hook-form

`register` / `Controller` 换成 `Field`。值不在组件的 state 里，在引擎里。

| react-hook-form | ShikiForm |
|---|---|
| `watch('email')` | `useWatch((d) => d.email.$value)`，或在 reaction 里读 `$value` |
| `setValue('city', '')` | `form.setValue('city', '')`，联动里写 `d.city.$value = ''` |
| `resolver` | `useForm({ validate: schema })`。schema 实现 Standard Schema 即可，例如 Zod |
| 条件渲染卸载输入框 | 优先 `$visible` / `$hidden`，这样规则还在引擎里 |

`setValue` 的路径可以用下标：`orders[0].lines[2].qty`。
