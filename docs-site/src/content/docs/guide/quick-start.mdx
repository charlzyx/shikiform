从安装到一张会校验、会提交的表单。字段只有一种写法：`<Field>`，装饰器包住控件。

## 安装

```bash
npm i @shikiform/react
```

用 Ant Design 再执行 `npm i @shikiform/antd`。查询列表、影子表单再执行 `npm i @shikiform/hooks`。`react` / `react-dom` 为 `^18 || ^19`。`antd`（`^5.18`）和 `dayjs`（`^1`）只在使用 `@shikiform/antd` 时需要。

## 第一张表单

`useForm` 创建引擎，`<Form>` 把它交给字段并渲染原生 `<form>`。`<Field>` 拥有一个路径：`decorator={[FormItem]}` 显示标签、星号和错误，`component={[Input]}` 是 connect 过的 antd 控件，二者都从字段上下文读字段，不再写 `name`。`typed(form)` 返回同一组组件，只是 `name` 按表单值类型检查。

```tsx preview
import { useState } from 'react';
import { Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormItem, FormLayout, Input, InputNumber, Reset, Submit } from '@shikiform/antd';

type Values = { name: string; email: string; age: number | null };

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm<Values>({ initialValues: { name: '', email: '', age: 18 } });
  const F = typed(form);
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <F.Field name="name" title="姓名" required decorator={[FormItem]} component={[Input, { placeholder: 'Ada' }]} />
        <F.Field name="email" title="邮箱" required rules={{ format: 'email', message: '邮箱格式不对' }}
          decorator={[FormItem]} component={[Input]} />
        <F.Field name="age" title="年龄" rules={{ min: 0, max: 150 }} decorator={[FormItem]} component={[InputNumber]} />
        <FormButtonGroup.FormItem>
          <Submit>提交</Submit>
          <Reset afterReset={() => setResult('还没有提交')} />
        </FormButtonGroup.FormItem>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

直接点提交，必填项报错；失焦时也会校验。全部通过后 `onSubmit` 才收到值。

- `title`、`required`、`rules` 写在 `Field` 上；`component` / `decorator` 的第二项是传给控件 / 装饰器的属性。
- `<Submit>` 在已经有错误、或正在提交时不可点（`$canSubmit` 为 false）。还没校验过的空必填项不挡住它，第一次点击仍会跑校验。`<Reset>` 回到初始值。
- `FormButtonGroup.FormItem` 让按钮跟随 `FormLayout` 对齐到控件列，不用再写一遍偏移。
- `<Form>` 自己就是 `<form>`，不要再套一层。组件外创建引擎用 `createForm`，选项和 `useForm` 相同。

## 不用 antd

自己的输入组件用不带参数的 `useField()` 读当前字段，放进 `component`（或作为 `<Field>` 的子元素）。完整的一页在 [不用 UI 库](/start/native)。

```tsx preview
import { useState } from 'react';
import { Field, Form, useField, useForm } from '@shikiform/react';

function TextInput({ label }: { label: string }) {
  const field = useField<string>();
  return (
    <p>
      <label htmlFor={field.id}>{label} </label>
      <input id={field.id} value={field.value ?? ''} onChange={(event) => field.onChange(event.target.value)} onBlur={field.onBlur} />
      {field.errors[0] && <small role="alert" style={{ color: 'crimson' }}> {field.errors[0]}</small>}
    </p>
  );
}

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm({ initialValues: { username: '' } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <Field name="username" required component={[TextInput, { label: '姓名' }]} />
      <button type="submit">提交</button>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

不带参数的 `useField()` 必须写在 `<Field>` 的 `component` / `decorator` / 子元素里，否则抛错并提示修法。输入组件自己把 `value` / `onChange` / `onBlur` 接到控件上；要套用同一套映射，用 [`connect`](/reference/antd-adapter#connect)（从 `@shikiform/react` 导入，不必装 antd）。标签、错误和提交按钮见 [接自己的组件库](/guide/headless#接自己的组件库)。

## 复用一段字段

片段就是普通组件：名字相对外层 `<ObjectField>` / 行作用域解析，`typed<Address>()` 按片段自己的值类型检查。

```tsx preview
import { Form, ObjectField, typed, useForm } from '@shikiform/react';
import { FormItem, Input } from '@shikiform/antd';

type Address = { city: string; street: string };
const A = typed<Address>();

function AddressFields() {
  return (
    <>
      <A.Field name="city" title="城市" decorator={[FormItem]} component={[Input]} />
      <A.Field name="street" title="街道" decorator={[FormItem]} component={[Input]} />
    </>
  );
}

export default function App() {
  const form = useForm({ initialValues: { home: { city: '杭州', street: '' }, office: { city: '上海', street: '' } } });
  return (
    <Form form={form}>
      <ObjectField name="home"><AddressFields /></ObjectField>
      <ObjectField name="office"><AddressFields /></ObjectField>
    </Form>
  );
}
```

装饰器和控件的四种写法、UI 属性分层见 [Field、装饰器与组件](/guide/field)。只要绑定、不要组件时用 `useField`，见 [Headless Hooks](/guide/headless)。
