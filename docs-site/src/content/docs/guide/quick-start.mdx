## 安装

```bash
npm i @shikiform/react
```

`@shikiform/react` 已内置核心表单引擎（`@shikiform/core`）、Headless React 绑定，以及查询列表、草稿表单、数组表格、列配置等无 UI 业务 Hooks。仅在非 React 环境使用表单引擎时，可单独安装 `@shikiform/core`。

版本要求：`react` 与 `react-dom` 为 `^16.8.0 || ^17 || ^18 || ^19`（支持 React 16.8+、17、18、19）。React 18+ 下未传 `<Form id>` 时自动通过 `useId()` 生成水合安全的字段 ID；React 16.8 / 17 的 SSR 应用请显式传入 `<Form id="…">` 以避免水合不一致。ShikiForm 零 UI 库依赖，可搭配原生 HTML 控件或任意 React UI 组件库使用。

## 第一张表单

`useForm` 创建表单实例，`<Form>` 提供上下文并渲染原生 `<form>` 元素，`<Field>` 绑定数据路径。

在 `<Field>` 上，`decorator`（如 `FormItem`）展示标签、必填标记与错误信息，`component`（如 `FieldInput`）渲染输入控件；通过 `<Form kit={siteKit}>` 传入默认装饰器后，不必在每个 `<Field>` 上重复书写 `decorator`。`typed(form)` 返回的 `F.Field` 与 `<Field>` 运行时相同，额外按表单值类型校验 `name`。

> 示例中的 `@site/ui` 是本文档站基于 `@ui-sdk/react` 封装的内部演示包（不对外发布）。业务项目接入公开组件库见 [接入 Ant Design](/guide/headless#接入-ant-design)、[接入 TDesign React](/guide/headless#接入-tdesign-react) 或 [接入组件库](/guide/headless#接自己的组件库)。

```tsx preview
import { useState } from 'react';
import { Form, Reset, Submit, typed, useForm } from '@shikiform/react';
import { Button, FieldInput, FieldNumber, siteKit } from '@site/ui';

type Values = { name: string; email: string; age: number | null };

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm<Values>({ initialValues: { name: '', email: '', age: 18 } });
  const F = typed(form);
  return (
    <Form form={form} kit={siteKit} onSubmit={(values) => setResult(JSON.stringify(values))} style={{ maxWidth: 420 }}>
      <F.Field name="name" title="姓名" required component={[FieldInput, { placeholder: 'Ada' }]} />
      <F.Field
        name="email"
        title="邮箱"
        required
        rules={{ format: 'email', message: '邮箱格式不对' }}
        component={[FieldInput, { placeholder: 'ada@example.com' }]}
      />
      <F.Field name="age" title="年龄" rules={{ min: 0, max: 150 }} component={[FieldNumber, { min: 0, max: 150 }]} />
      <div style={{ display: 'flex', gap: 8 }}>
        <Submit asChild><Button variant="primary">提交</Button></Submit>
        <Reset asChild afterReset={() => setResult('还没有提交')}><Button variant="outline">重置</Button></Reset>
      </div>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

点击「提交」或输入框失焦时会触发校验；全部规则通过后，`<Form onSubmit>` 收到表单值。

几点约定：

- `title`、`required`、`rules` 直接写在 `<Field>` 上；传给控件或装饰器的属性放在元组第二项，如 `component={[FieldInput, props]}`、`decorator={[FormItem, props]}`。
- 存在已触发的错误或正在提交（`$canSubmit` 为 `false`）时，`<Submit>` 自动禁用。尚未校验过的空必填项不会在初始渲染时禁用按钮，首次点击仍会触发校验。`<Reset>` 将表单恢复到 `initialValues`。
- `<Form>` 已渲染原生 `<form>`，不要再嵌套一层 `<form>`。在组件外创建实例可使用 `createForm`，参数与 `useForm` 相同。

## 直接用 `useField()`

最简场景下，不需要拆分装饰器与控件，直接在组件内部调用无参 `useField()` 读取当前字段绑定（`value`、`onChange`、`onBlur`、`errors`、`id`），再将该组件传给 `component`。需要接入外部组件库时详见 [接入组件库](/guide/headless)。

```tsx preview
import { useState } from 'react';
import { Field, Form, useField, useForm } from '@shikiform/react';
import { Button, Input } from '@site/ui';

function TextInput({ label }: { label: string }) {
  const field = useField<string>();
  return (
    <div className="sf-ui-form-item">
      <label htmlFor={field.id} className="sf-ui-form-label">{label}</label>
      <Input
        id={field.id}
        value={field.value ?? ''}
        invalid={field.errors.length > 0}
        onChange={(event) => field.onChange(event.target.value)}
        onBlur={field.onBlur}
      />
      {field.errors[0] && <p role="alert" className="sf-ui-form-error">{field.errors[0]}</p>}
    </div>
  );
}

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm({ initialValues: { username: '' } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))} style={{ maxWidth: 360 }}>
      <Field name="username" required component={[TextInput, { label: '姓名' }]} />
      <div><Button variant="primary" type="submit">提交</Button></div>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

无参 `useField()` 只能在 `<Field>` 渲染的 `component`、`decorator` 或 `children` 内调用。封装第三方组件库（如 [Ant Design](/guide/headless#接入-ant-design) / [TDesign React](/guide/headless#接入-tdesign-react) / shadcn/ui）可使用 `@shikiform/react` 导出的 `connect` 与 `useFieldDecorator`，见 [接入组件库](/guide/headless#接自己的组件库)。

## 复用一段字段

收货地址、联系人等子表单片段可写成普通组件。放在 `<ObjectField>` 或数组行作用域内时，内部字段名按相对路径解析；配合 `typed<Address>()` 可按片段自身类型检查字段名。

```tsx preview
import { Form, ObjectField, typed, useForm } from '@shikiform/react';
import { Card, FieldInput, siteKit } from '@site/ui';

type Address = { city: string; street: string };
const A = typed<Address>();

function AddressFields() {
  return (
    <div style={{ display: 'grid', gap: 12 }}>
      <A.Field name="city" title="城市" component={FieldInput} />
      <A.Field name="street" title="街道" component={[FieldInput, { placeholder: '路名与门牌号' }]} />
    </div>
  );
}

export default function App() {
  const form = useForm({
    initialValues: { home: { city: '杭州', street: '' }, office: { city: '上海', street: '' } },
  });
  return (
    <Form form={form} kit={siteKit}>
      <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(220px, 1fr))', gap: 12 }}>
        <Card title="家庭地址" padding="sm">
          <ObjectField name="home"><AddressFields /></ObjectField>
        </Card>
        <Card title="公司地址" padding="sm">
          <ObjectField name="office"><AddressFields /></ObjectField>
        </Card>
      </div>
    </Form>
  );
}
```

装饰器、控件及 UI 属性合并规则见 [表单与字段](/guide/field)；不经 `<Field>` 直接用 Hooks 绑定控件见 [接入组件库](/guide/headless)。继续阅读：[教程](/tutorial/)、[核心概念](/guide/concepts)。
