## 安装

安装 React 绑定包：

```bash
npm i @shikiform/react
```

按需安装无 UI 业务 Hooks 包（查询表格、草稿表单、列设置等）：

```bash
npm i @shikiform/react
```

版本要求：`react` 与 `react-dom` 为 `^18 || ^19`。ShikiForm 零 UI 库依赖，可搭配原生 HTML 控件或任意 React UI 组件库使用。

## 第一张表单

`useForm` 创建表单实例，`<Form>` 提供上下文并渲染原生 `<form>` 元素，`<Field>` 绑定数据路径。

在 `<Field>` 上，`decorator`（如自定义的 `FieldItem`）展示标签、必填标记与错误信息，`component`（如自定义的 `TextInput`）渲染输入控件。两者通过上下文调用 `useField()` / `useFieldDecorator()` 读取外层 `<Field>` 的绑定状态，不需再传 `name`。`typed(form)` 返回的 `F.Field` 与 `<Field>` 运行时相同，额外按表单值类型校验 `name`。

```tsx preview
import { useState, type ReactNode } from 'react';
import { Form, Reset, Submit, typed, useField, useFieldDecorator, useForm } from '@shikiform/react';

type Values = { name: string; email: string; age: number | null };

function FieldItem({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <div style={{ marginBottom: 10 }}>
      <label {...d.labelProps} style={{ display: 'inline-block', width: 64 }}>
        {d.required && <span style={{ color: 'crimson' }}>* </span>}
        {d.label}
      </label>
      {children}
      {d.errorProps && <small {...d.errorProps} style={{ color: 'crimson', marginLeft: 8 }}>{d.errors[0]}</small>}
    </div>
  );
}

function TextInput({ placeholder }: { placeholder?: string }) {
  const field = useField<string>();
  return (
    <input id={field.id} value={field.value ?? ''} placeholder={placeholder}
      disabled={field.disabled} readOnly={field.readOnly}
      onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
  );
}

function NumberInput() {
  const field = useField<number | null>();
  return (
    <input id={field.id} type="number" value={field.value ?? ''}
      disabled={field.disabled} readOnly={field.readOnly}
      onChange={(e) => field.onChange(e.target.value === '' ? null : Number(e.target.value))}
      onBlur={field.onBlur} />
  );
}

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm<Values>({ initialValues: { name: '', email: '', age: 18 } });
  const F = typed(form);
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <F.Field name="name" title="姓名" required decorator={[FieldItem]} component={[TextInput, { placeholder: 'Ada' }]} />
      <F.Field name="email" title="邮箱" required rules={{ format: 'email', message: '邮箱格式不对' }}
        decorator={[FieldItem]} component={[TextInput]} />
      <F.Field name="age" title="年龄" rules={{ min: 0, max: 150 }} decorator={[FieldItem]} component={[NumberInput]} />
      <div style={{ display: 'flex', gap: 8, marginTop: 8 }}>
        <Submit>提交</Submit>
        <Reset afterReset={() => setResult('还没有提交')}>重置</Reset>
      </div>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

点击「提交」或输入框失焦时会触发校验；全部规则通过后，`<Form onSubmit>` 收到表单值。

几点约定：

- `title`、`required`、`rules` 直接写在 `<Field>` 上；传给控件或装饰器的属性放在元组第二项，如 `component={[TextInput, props]}`、`decorator={[FieldItem, props]}`。
- 存在已触发的错误或正在提交（`$canSubmit` 为 `false`）时，`<Submit>` 自动禁用。尚未校验过的空必填项不会在初始渲染时禁用按钮，首次点击仍会触发校验。`<Reset>` 将表单恢复到 `initialValues`。
- `<Form>` 已渲染原生 `<form>`，不要再嵌套一层 `<form>`。在组件外创建实例可使用 `createForm`，参数与 `useForm` 相同。

## 直接用 `useField()`

最简场景下，不需要拆分装饰器与控件，直接在组件内部调用无参 `useField()` 读取当前字段绑定（`value`、`onChange`、`onBlur`、`errors`、`id`），再将该组件传给 `component`。需要接入外部组件库时详见 [接入组件库](/guide/headless)。

```tsx preview
import { useState } from 'react';
import { Field, Form, useField, useForm } from '@shikiform/react';

function TextInput({ label }: { label: string }) {
  const field = useField<string>();
  return (
    <p>
      <label htmlFor={field.id}>{label} </label>
      <input id={field.id} value={field.value ?? ''} onChange={(event) => field.onChange(event.target.value)} onBlur={field.onBlur} />
      {field.errors[0] && <small role="alert" style={{ color: 'crimson' }}> {field.errors[0]}</small>}
    </p>
  );
}

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm({ initialValues: { username: '' } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <Field name="username" required component={[TextInput, { label: '姓名' }]} />
      <button type="submit">提交</button>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

无参 `useField()` 只能在 `<Field>` 渲染的 `component`、`decorator` 或 `children` 内调用。封装第三方组件库（如 Ant Design / Arco / Radix）可使用 `@shikiform/react` 导出的 `connect` 与 `useFieldDecorator`，见 [接入组件库](/guide/headless#接自己的组件库)。

## 复用一段字段

收货地址、联系人等子表单片段可写成普通组件。放在 `<ObjectField>` 或数组行作用域内时，内部字段名按相对路径解析；配合 `typed<Address>()` 可按片段自身类型检查字段名。

```tsx preview
import { Form, ObjectField, typed, useField, useForm } from '@shikiform/react';

type Address = { city: string; street: string };
const A = typed<Address>();

function LabeledInput() {
  const field = useField<string>();
  return (
    <div style={{ marginBottom: 6 }}>
      <label htmlFor={field.id} style={{ display: 'inline-block', width: 56 }}>{field.title}</label>
      <input id={field.id} value={field.value ?? ''} onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
    </div>
  );
}

function AddressFields() {
  return (
    <>
      <A.Field name="city" title="城市" component={[LabeledInput]} />
      <A.Field name="street" title="街道" component={[LabeledInput]} />
    </>
  );
}

export default function App() {
  const form = useForm({ initialValues: { home: { city: '杭州', street: '' }, office: { city: '上海', street: '' } } });
  return (
    <Form form={form}>
      <fieldset><legend>家庭地址</legend><ObjectField name="home"><AddressFields /></ObjectField></fieldset>
      <fieldset><legend>公司地址</legend><ObjectField name="office"><AddressFields /></ObjectField></fieldset>
    </Form>
  );
}
```

装饰器、控件及 UI 属性合并规则见 [表单与字段](/guide/field)；不经 `<Field>` 直接用 Hooks 绑定控件见 [接入组件库](/guide/headless)。继续阅读：[教程](/tutorial/)、[核心概念](/guide/concepts)。
