如果你不打算引入 Ant Design，或者需要封装自定义的表格与树形编辑器，可以直接使用 `@shikiform/react` 提供的无 UI Hooks（`<Field>` 和 `<ArrayField>` 本身也是构建在这些 Hook 之上的薄封装）：

- **基础绑定与订阅**：`useField(name)` 负责绑定单个字段，`useWatch(select)` / `<Watch>` 负责订阅任意 `$` 状态变化。
- **数组行内上下文**：`useArray()` 获取最近一层数组的操作句柄，`useIndex()` 获取当前行下标，`useRecord()` 获取当前行数据，调用时都不需要传数组名。如需展示数组路径自身的错误（不包含子字段），可以在容器或 `ArrayTable` 的 `footer` 中调用 `useArrayErrors()`（注意必须放在 `<ArrayField>` 子树内部，详见 [数组自身的错误](/guide/arrays#数组自身的错误)）。
- **树节点上下文**：`useTreeNode()` 返回当前节点的 `{ path, pos, index, key, record, dragProps }`。
- **拖拽排序**：数组句柄（`useArray()` / `useArrayField(name)`）的 `dragProps(index)` 与树节点（`useTreeNode().dragProps()`）或树句柄（`useTreeField(name).dragProps(pos)`）会直接返回所需的 HTML5 拖放事件属性，配合同一句柄的 `move` 即可完成排序。

`useArray`、`useIndex` 和 `useRecord` 在普通 `<ArrayField>` 渲染函数以及 `ArrayItems`、`ArrayCards`、`ArrayTable` 容器内均可通用。

## 数组行组件：免传路径名

```tsx preview
import { ArrayField, Form, Watch, useArray, useField, useForm, useIndex, useRecord, type Draft } from '@shikiform/react';

type Todo = { id: number; title: string; done: boolean };
type Values = { todos: Todo[] };
let nextId = 4;

function TitleInput() {
  const field = useField<Todo, 'title'>('title', { required: true });
  return (
    <span>
      <input aria-label="标题" value={field.value ?? ''} onChange={(event) => field.onChange(event.target.value)} onBlur={field.onBlur} />
      {field.errors[0] && <small style={{ color: 'crimson' }}> {field.errors[0]}</small>}
    </span>
  );
}

function DoneBox() {
  const field = useField<Todo, 'done'>('done');
  return <input type="checkbox" aria-label="完成" checked={field.value} onChange={(event) => field.onChange(event.target.checked)} />;
}

function Row() {
  const array = useArray<Todo>();
  const index = useIndex();
  const record = useRecord<Todo>();
  return (
    <li {...array.dragProps(index)} style={{ cursor: 'grab', opacity: record.done ? 0.5 : 1 }}>
      ⠿ <DoneBox /> <TitleInput /> <small>#{index} · id {record.id}</small>{' '}
      <button type="button" onClick={() => array.remove(index)}>删除</button>
    </li>
  );
}

function TodoList() {
  return (
    <ul style={{ paddingLeft: 0, listStyle: 'none' }}>
      <ArrayField name="todos" rowKey="id">{() => <Row />}</ArrayField>
    </ul>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: { todos: [{ id: 1, title: '读文档', done: true }, { id: 2, title: '写表单', done: false }, { id: 3, title: '拖动排序', done: false }] },
  });
  return (
    <Form form={form}>
      <TodoList />
      <button type="button" onClick={() => form.pushArray('todos', { id: nextId++, title: '', done: false })}>添加</button>
      <Watch select={(d: Draft<Values>) => d.todos.$value.filter((todo) => todo.done).length}>
        {(done) => <p>已完成 {done} 项</p>}
      </Watch>
    </Form>
  );
}
```

在 `Row` 组件中，`useArray()` 会自动解析到外层的 `todos` 数组，拖拽重排后 `#` 后面的行下标会同步变化，而业务 `id` 和焦点状态保持不变。

## 树形结构：TreeField 与 useTreeNode

渲染树形数据时，使用 `<TreeField name rowKey>` 遍历树并自动为每个节点建立作用域；子节点通过 `node.children` 递归传入（叶子节点为 `null`），内部的 `useField('name')` 会自动指向当前节点，`useTreeNode()` 则提供当前节点的坐标、数据与 `dragProps()`：

```tsx
function NodeRow() {
  const { record, dragProps } = useTreeNode<Node>()
  const field = useField<Node, 'name'>('name')
  return <div {...dragProps()}>⠿ <input value={field.value} onChange={(e) => field.onChange(e.target.value)} /> {record.children?.length ?? 0}</div>
}

<ul>
  <TreeField name="menu" rowKey="id">
    {(node) => (
      <li>
        <NodeRow />
        {node.children && <ul>{node.children}</ul>}
      </li>
    )}
  </TreeField>
</ul>
```

`useTreeNode().dragProps()`（以及 `useTreeField('menu')` 的 `tree.dragProps(pos)`）自带跨父级拖拽和「禁止拖入自身子节点」校验。完整可运行演示见 [示例库 · 树：跨层移动](/examples/arrays#树跨层移动)。

## 接自己的组件库

`connect` 和 `mapProps` 均直接由 `@shikiform/react` 导出，不依赖 `@shikiform/antd`（默认不传 Ant Design 专属的 `status`）。标签与错误提示使用 [`useFieldDecorator`](/reference/react-hooks#usefielddecorator)，提交和重置按钮可使用 headless 的 [`Submit` / `Reset`](/reference/react-hooks#usesubmit)（支持 `asChild` 或 render prop，其中 `Reset` 通过 `afterReset` 接收重置后的值）。下面以 shadcn/ui、Mantine 和 MUI 为例展示接入方式，原生 HTML 最小起步见 [不用 UI 库](/start/native)。

### 区分 `useFieldDecorator().control` 与 `connect`

`useFieldDecorator().control` 返回的是标签、说明、错误提示、`id`、`onBlur` 和无障碍 `aria-*` 属性，**里面不包含 `value` 和 `onChange`**：

```tsx
import { Field, connect, useField, useFieldDecorator } from '@shikiform/react'

// ✗ control 没有 value / onChange，不能单独接管受控值
function Bad() {
  const { control } = useFieldDecorator()
  return <TextInput {...control} />
}

// ✓ 适合自带 label 的控件（如 Mantine TextInput）：control 负责标签和报错，值单独用 useField 接入
function NameInput() {
  const field = useField<string>()
  const { control } = useFieldDecorator()
  return (
    <TextInput
      {...control}
      value={field.value ?? ''}
      onChange={(event) => field.onChange(event.currentTarget.value)}
    />
  )
}

// ✓ 适合纯输入控件（如 shadcn Input）：用 connect 接入输入绑定，外面再搭配 FormItem 装饰器
const Input = connect(ShadcnInput)
<Field name="name" title="姓名" decorator={[FormItem]} component={[Input]} />
```

像 `NameInput` 这样自身已经渲染了标签和报错的组件，不要再嵌套 `FormItem` 装饰器，也不要把 `control` 展开到已经用 `connect()` 包装过的组件上。

### 处理没有 `onBlur` 的组件

如果目标控件的属性类型里没有 `onBlur`（常见于下拉弹层或日期选择器），TypeScript 在调用 `connect()` 时会报错提示，避免失焦校验失效。你可以通过以下方式显式声明失焦时机：

| 写法 | 触发 `field.onBlur()` 的时机 |
|---|---|
| `mapProps({ blurOn: 'onOpenChange' })` | 弹层关闭时（回调首个参数为 `false`），且不再向下透传 `onBlur` |
| `mapProps({ blurOn: 'onChange' })` | 每次值变更写入后立即触发 |
| `mapProps({ blurOn: { prop, when? } })` | 指定的 `prop` 回调触发且 `when(...args)` 不返回 `false` 时（适用于如 MUI DatePicker 的 `onClose`） |
| `mapProps({ onBlur: false })` | 显式声明不处理失焦校验 |

```tsx
connect(SelectControl, mapProps({ options: 'options', onChange: 'onValueChange', blurOn: 'onOpenChange' }))
connect(Picker, mapProps({ onBlur: false }))
```

完整参数签名见 [mapProps](/reference/antd-adapter#mapprops)。

### shadcn/ui 接入模板

在 shadcn/ui 中，`Input` 本身支持标准 `value` / `onChange` / `onBlur`，可以直接 `connect`；`Select` 的选项由 `SelectItem` 渲染，通过 `onValueChange` 回调值并在弹层关闭时触发 `blurOn: 'onOpenChange'`；`Checkbox` 使用 `checked` 与 `onCheckedChange`；`DatePicker` 由 `Popover + Calendar` 组合而成，借助 `format` / `parse` 在表单存储的 `yyyy-MM-dd` 字符串与 `Date` 对象间双向转换；`FormItem` 装饰器基于 `useFieldDecorator()` 渲染标签和错误。

```tsx
import { format, parseISO } from 'date-fns'
import type { ReactNode } from 'react'
import { Field, Form, Reset, Submit, connect, mapProps, useFieldDecorator, useForm } from '@shikiform/react'
import { Button } from '@/components/ui/button'
import { Calendar } from '@/components/ui/calendar'
import { Checkbox as ShadcnCheckbox } from '@/components/ui/checkbox'
import { Input as ShadcnInput } from '@/components/ui/input'
import { Label } from '@/components/ui/label'
import { Popover, PopoverContent, PopoverTrigger } from '@/components/ui/popover'
import { Select as ShadcnSelect, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select'

const Input = connect(ShadcnInput, mapProps({ readPretty: ({ value }: { value?: string }) => <span>{value || '—'}</span> }))

function SelectControl(props: {
  id?: string
  value?: string
  disabled?: boolean
  options?: { label: string; value: string; disabled?: boolean }[]
  onValueChange?: (value: string) => void
  onOpenChange?: (open: boolean) => void
}) {
  return (
    <ShadcnSelect value={props.value || undefined} disabled={props.disabled} onValueChange={props.onValueChange} onOpenChange={props.onOpenChange}>
      <SelectTrigger id={props.id}><SelectValue /></SelectTrigger>
      <SelectContent>
        {(props.options ?? []).map((option) => (
          <SelectItem key={option.value} value={option.value} disabled={option.disabled}>{option.label}</SelectItem>
        ))}
      </SelectContent>
    </ShadcnSelect>
  )
}

const Select = connect(SelectControl, mapProps({ options: 'options', onChange: 'onValueChange', blurOn: 'onOpenChange' }))

function CheckboxControl(props: {
  id?: string
  checked?: boolean
  disabled?: boolean
  onCheckedChange?: (checked: boolean | 'indeterminate') => void
  onBlur?: () => void
}) {
  return <ShadcnCheckbox id={props.id} checked={!!props.checked} disabled={props.disabled} onCheckedChange={props.onCheckedChange} onBlur={props.onBlur} />
}

const Checkbox = connect(CheckboxControl, mapProps({
  value: 'checked',
  onChange: 'onCheckedChange',
  parse: (checked: boolean | 'indeterminate') => checked === true,
}))

function DatePickerControl(props: {
  id?: string
  value?: Date | null
  disabled?: boolean
  onChange?: (value: Date | null) => void
  onOpenChange?: (open: boolean) => void
}) {
  return (
    <Popover onOpenChange={props.onOpenChange}>
      <PopoverTrigger asChild>
        <Button type="button" id={props.id} variant="outline" disabled={props.disabled}>
          {props.value ? format(props.value, 'yyyy-MM-dd') : '选择日期'}
        </Button>
      </PopoverTrigger>
      <PopoverContent>
        <Calendar mode="single" selected={props.value ?? undefined} onSelect={(next) => props.onChange?.(next ?? null)} />
      </PopoverContent>
    </Popover>
  )
}

// 字段存 yyyy-MM-dd。format 传给 Calendar 的是 Date，parse 把选中的 Date 写回字符串。
const DatePicker = connect(DatePickerControl, mapProps({
  blurOn: 'onOpenChange',
  format: (value: string | undefined) => (value ? parseISO(value) : null),
  parse: (next: Date | null) => (next ? format(next, 'yyyy-MM-dd') : undefined),
}))

function FormItem({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator()
  return (
    <div className="grid gap-2" data-invalid={d.invalid || undefined}>
      {d.label ? <Label {...d.labelProps}>{d.label}{d.required ? <span aria-hidden="true"> *</span> : null}</Label> : null}
      {children}
      {d.descriptionProps ? <p {...d.descriptionProps} className="text-sm text-muted-foreground">{d.description}</p> : null}
      {d.errorProps ? <p {...d.errorProps} className="text-sm text-destructive">{d.errors.join('、')}</p> : null}
    </div>
  )
}

export default function App() {
  const form = useForm({ initialValues: { name: '', city: '', agree: false, birthday: '' } })
  return (
    <Form form={form} onSubmit={(values) => console.log(values)}>
      <Field name="name" title="姓名" required decorator={[FormItem]} component={[Input, { placeholder: 'Ada' }]} />
      <Field name="city" title="城市" required enum={[{ label: '杭州', value: 'hz' }, { label: '南京', value: 'nj' }]} decorator={[FormItem]} component={[Select]} />
      <Field name="agree" title="同意协议" rules={{ isTrue: true }} decorator={[FormItem]} component={[Checkbox]} />
      <Field name="birthday" title="生日" decorator={[FormItem]} component={[DatePicker]} />
      <Submit asChild><button type="submit">提交</button></Submit>{' '}
      <Reset asChild><button type="button">重置</button></Reset>
    </Form>
  )
}
```

接入时的几点细节：
- Radix Select 不允许传入空字符串作为 `value`，未选择时需转为 `undefined`。
- Checkbox 的 `required` 规则认为 `false` 也是有效值，强制勾选需使用 `rules={{ isTrue: true }}`。

### 在线最小可运行示例

下面是一个用原生 `<input>` / `<select>` / `<input type="date">` 模拟上述适配模式的完整示例，同时演示了 `kit` 注册默认装饰器和控件名称的写法：

```tsx preview
import { useState, type ReactNode } from 'react';
import { Field, Form, Reset, Submit, connect, mapProps, useFieldDecorator, useForm } from '@shikiform/react';

function TextControl(props: {
  id?: string;
  value?: string;
  placeholder?: string;
  disabled?: boolean;
  readOnly?: boolean;
  onChange?: (event: { target: { value: string } }) => void;
  onBlur?: () => void;
}) {
  return (
    <input
      id={props.id}
      placeholder={props.placeholder}
      disabled={props.disabled}
      readOnly={props.readOnly}
      value={props.value ?? ''}
      onChange={props.onChange}
      onBlur={props.onBlur}
    />
  );
}

function PopoverSelect(props: {
  id?: string;
  value?: string;
  disabled?: boolean;
  options?: { label: string; value: string; disabled?: boolean }[];
  onChange?: (value: string) => void;
  onOpenChange?: (open: boolean) => void;
}) {
  return (
    <select
      id={props.id}
      disabled={props.disabled}
      value={props.value ?? ''}
      onChange={(event) => {
        props.onChange?.(event.target.value);
        props.onOpenChange?.(false);
      }}
    >
      <option value="">请选择</option>
      {(props.options ?? []).map((option) => (
        <option key={String(option.value)} value={String(option.value)} disabled={option.disabled}>{option.label}</option>
      ))}
    </select>
  );
}

const Input = connect(TextControl, mapProps({ readPretty: ({ value }: { value?: string }) => <span>{value || '—'}</span> }));
const Select = connect(PopoverSelect, mapProps({ options: 'options', blurOn: 'onOpenChange' }));

function DateControl(props: {
  id?: string;
  value?: Date | null;
  onChange?: (value: Date | null) => void;
  onBlur?: () => void;
}) {
  const text = props.value && !Number.isNaN(props.value.getTime())
    ? `${props.value.getFullYear()}-${String(props.value.getMonth() + 1).padStart(2, '0')}-${String(props.value.getDate()).padStart(2, '0')}`
    : '';
  return (
    <input
      type="date"
      id={props.id}
      aria-label="生日"
      value={text}
      onChange={(event) => {
        const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(event.target.value);
        props.onChange?.(match ? new Date(Number(match[1]), Number(match[2]) - 1, Number(match[3])) : null);
      }}
      onBlur={props.onBlur}
    />
  );
}

const DatePicker = connect(DateControl, mapProps({
  format: (value: string | undefined) => {
    const match = value && /^(\d{4})-(\d{2})-(\d{2})$/.exec(value);
    return match ? new Date(Number(match[1]), Number(match[2]) - 1, Number(match[3])) : null;
  },
  parse: (next: Date | null) => {
    if (!next || Number.isNaN(next.getTime())) return undefined;
    const month = String(next.getMonth() + 1).padStart(2, '0');
    const day = String(next.getDate()).padStart(2, '0');
    return `${next.getFullYear()}-${month}-${day}`;
  },
}));

function FormItem({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <div style={{ display: 'grid', gap: 4, marginBottom: 12 }}>
      {d.label ? <label {...d.labelProps}>{d.label}{d.required ? <span aria-hidden="true"> *</span> : null}</label> : null}
      {children}
      {d.descriptionProps ? <p {...d.descriptionProps} style={{ margin: 0, color: '#666' }}>{d.description}</p> : null}
      {d.errorProps ? <p {...d.errorProps} style={{ margin: 0, color: 'crimson' }}>{d.errors.join('、')}</p> : null}
    </div>
  );
}

export default function App() {
  const [saved, setSaved] = useState('还没有提交');
  const form = useForm({ initialValues: { name: '', city: '', birthday: '' } });
  return (
    <Form form={form} kit={{ decorator: FormItem, components: { Input, Select, DatePicker } }} onSubmit={(values) => setSaved(JSON.stringify(values))}>
      <Field name="name" title="姓名" description="对外显示" required component={['Input', { placeholder: 'Ada' }]} />
      <Field name="city" title="城市" required enum={[{ label: '杭州', value: 'hz' }, { label: '南京', value: 'nj' }]} component="Select" />
      <Field name="birthday" title="生日" component="DatePicker" />
      <Submit asChild><button>提交</button></Submit>{' '}
      <Reset afterReset={() => setSaved('已重置')} asChild><button>重置</button></Reset>
      <pre aria-live="polite">{saved}</pre>
    </Form>
  );
}
```

### Mantine 接入要点

Mantine 的 `TextInput`、`Select`、`Checkbox` 均支持 `onBlur`，且 `error` 属性直接接收报错文本，因此自带标签的控件可以直接展开 `control` 并配合 `useField()` 接线；`Select` 的选项属性名为 `data`；`DatePickerInput` 则通过 `format` / `parse` 在 `Date | null` 与本地日期字符串 `YYYY-MM-DD` 之间转换（解析时手动拆年月日构造本地 `Date`，避免 `new Date('YYYY-MM-DD')` 被按 UTC 解析产生时区偏差）。

```tsx
import { Checkbox, Select, TextInput } from '@mantine/core'
import { DatePickerInput } from '@mantine/dates'
import { Field, connect, mapProps, useField, useFieldDecorator } from '@shikiform/react'

function MantineInput() {
  const field = useField<string>()
  const { control } = useFieldDecorator()
  return (
    <TextInput
      {...control}
      value={field.value ?? ''}
      onChange={(event) => field.onChange(event.currentTarget.value)}
    />
  )
}

const City = connect(Select, mapProps({ options: 'data' }))
const Agree = connect(Checkbox, mapProps({ value: 'checked' }))

function calendarDay(value: string | undefined): Date | null {
  const match = value && /^(\d{4})-(\d{2})-(\d{2})$/.exec(value)
  return match ? new Date(Number(match[1]), Number(match[2]) - 1, Number(match[3])) : null
}

const Birthday = connect(DatePickerInput, mapProps({
  format: (value: string | undefined) => calendarDay(value),
  parse: (next: Date | null) => {
    if (!next) return undefined
    const month = String(next.getMonth() + 1).padStart(2, '0')
    const day = String(next.getDate()).padStart(2, '0')
    return `${next.getFullYear()}-${month}-${day}`
  },
}))

<Field name="name" title="姓名" required component={[MantineInput]} />
<Field name="city" enum={[{ label: '杭州', value: 'hz' }]} component={[City]} />
<Field name="agree" rules={{ isTrue: true }} component={[Agree]} />
<Field name="birthday" component={[Birthday]} />
```

### MUI 接入要点

MUI 的 `TextField` 接收布尔型的 `error` 与提示文本 `helperText`，而 `control.error` 是字符串，因此不能直接展开 `control`，应当逐项读取 `useFieldDecorator()` 的字段并与 `useField()` 组合。`DatePicker`（dayjs 适配器）则通过 `slotProps.textField.id` 绑定标签 `id`，并用 `mapProps({ blurOn: { prop: 'onClose' } })` 触发失焦校验。

```tsx
import dayjs, { type Dayjs } from 'dayjs'
import Checkbox from '@mui/material/Checkbox'
import TextField from '@mui/material/TextField'
import { DatePicker } from '@mui/x-date-pickers/DatePicker'
import { Field, connect, mapProps, useField, useFieldDecorator } from '@shikiform/react'

// ✗ control 没有 value / onChange，而且 error 是文案不是布尔
function Bad() {
  const { control } = useFieldDecorator()
  return <TextField {...control} />
}

function MuiText() {
  const field = useField<string>()
  const d = useFieldDecorator()
  return (
    <TextField
      id={d.id}
      label={d.label}
      required={d.required}
      error={d.invalid}
      helperText={d.error ?? d.description}
      disabled={d.disabled}
      value={field.value ?? ''}
      onChange={(event) => field.onChange(event.target.value)}
      onBlur={field.onBlur}
    />
  )
}

const Agree = connect(Checkbox, mapProps({ value: 'checked' }))

function toDayjs(value: string | undefined): Dayjs | null {
  const match = value && /^(\d{4})-(\d{2})-(\d{2})$/.exec(value)
  if (!match) return null
  return dayjs(new Date(Number(match[1]), Number(match[2]) - 1, Number(match[3])))
}

// 字段是 YYYY-MM-DD 字符串，DatePicker 的 value 是 Dayjs。
// DatePicker 自己没有 id，标签的 htmlFor 要落到内部 TextField 上。
const Birthday = connect(DatePicker, mapProps({
  id: false,
  blurOn: { prop: 'onClose' },
  format: (value: string | undefined) => toDayjs(value),
  parse: (next: Dayjs | null) => (next?.isValid() ? next.format('YYYY-MM-DD') : undefined),
}, (props, field) => ({
  ...props,
  slotProps: { textField: { id: field.id } },
})))

<Field name="name" title="姓名" required component={[MuiText]} />
<Field name="agree" rules={{ isTrue: true }} component={[Agree]} />
<Field name="birthday" component={[Birthday]} />
```

MUI `Select` 自身支持 `onBlur` 且 `onChange` 遵循标准事件结构，无需配置 `blurOn`；如需配合 `<Field enum>`，可参照上文 shadcn/ui 的包装方式把选项映射成 `MenuItem`。

## 登记一次

如果不想在每个 `<Field>` 上重复写 `decorator={[FormItem]}`，可以通过 `<FieldKit>` 或 `<Form kit={{ ... }}>` 集中注册默认装饰器和常用控件。注册后，在 `<Field>` 上可以直接传字符串名称（或继续传组件引用）；不需要默认装饰器时（例如表格单元格），显式传入 `decorator={false}` 即可。

```tsx
import { Field, FieldKit, Form } from '@shikiform/react'

declare module '@shikiform/react' {
  interface FieldComponents { Input: typeof Input; Select: typeof Select; DatePicker: typeof DatePicker }
  interface FieldDecorators { FormItem: typeof FormItem }
}

<FieldKit components={{ Input, Select, DatePicker }} decorator={FormItem}>
  <Form form={form}>
    <Field name="name" title="姓名" component={['Input', { placeholder: 'Ada' }]} />
    <Field name="city" component="Select" />
    <Field name="qty" component={Input} decorator={false} />
  </Form>
</FieldKit>
```

扩展 `FieldComponents` / `FieldDecorators` 后，字符串名称即可获得完整的自动补全与元组 `props` 类型校验；使用组件引用时，即使不预先注册也能自动应用默认装饰器。

全部 Hook 签名与订阅范围请见 [React Hooks 参考](/reference/react-hooks)。
