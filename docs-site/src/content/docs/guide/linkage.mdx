---
title: 联动
description: 用 reaction 维护派生状态，用 watch 执行一次性动作，并通过 reaction.each 与 watch.each 深入多层数组和树结构。
---

像「金额 = 单价 × 数量」「切换省份后清空城市」这类表单联动规则，统一写在 `defineEffects` 中并传给 `useForm({ effects })`。联动直接读写引擎底层状态，无论目标字段此时是否已经挂载渲染，规则都能正常生效。

```ts
const effects = defineEffects<Values>(({ reaction, watch }) => {
  reaction((d) => { /* 派生计算：自动追踪内部读取的所有 $ 状态 */ })
  watch((d) => d.province.$value, (d) => { /* 动作响应：仅在监听源变化时触发 */ })
})
```

## reaction 与 watch

```tsx preview
import { useState, type ReactNode } from 'react';
import { Field, Form, defineEffects, useField, useFieldDecorator, useForm } from '@shikiform/react';

type Values = { price: number; qty: number; amount: number; province: string; city: string };

const CITIES: Record<string, { label: string; value: string }[]> = {
  zj: [{ label: '杭州', value: 'hz' }, { label: '宁波', value: 'nb' }],
  js: [{ label: '南京', value: 'nj' }, { label: '苏州', value: 'sz' }],
};

const effects = defineEffects<Values>(({ reaction, watch }) => {
  // 派生：一开始就运行，price / qty 变化时重算
  reaction((d) => {
    d.amount.$value = d.price.$value * d.qty.$value;
  });
  // 派生 UI：城市选项跟着省份
  reaction((d) => {
    // 没选省份时写 undefined 会回到 <Field enum> / fields 声明的选项；这里要空列表，所以写 []
    d.city.$enum = CITIES[d.province.$value] ?? [];
    d.city.$disabled = !d.province.$value;
  });
  // 动作：省份变了才清空城市；第一次不执行，初始的「杭州」保留
  watch((d) => d.province.$value, (d) => {
    d.city.$value = '';
  });
});

function FieldItem({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <div style={{ marginBottom: 8 }}>
      <label {...d.labelProps} style={{ display: 'inline-block', width: 56 }}>{d.label}</label>
      {children}
    </div>
  );
}

function NumberInput() {
  const field = useField<number>();
  return (
    <input id={field.id} type="number" value={field.value ?? 0} disabled={field.disabled}
      onChange={(e) => field.onChange(Number(e.target.value))} onBlur={field.onBlur} />
  );
}

function SelectInput() {
  const field = useField<string>();
  return (
    <select id={field.id} value={field.value ?? ''} disabled={field.disabled}
      onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur}>
      <option value="">请选择</option>
      {field.options.map((o) => <option key={String(o.value)} value={String(o.value)}>{o.label}</option>)}
    </select>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { price: 10, qty: 2, amount: 0, province: 'zj', city: 'hz' },
    effects: [effects],
  });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <Field name="price" title="单价" decorator={[FieldItem]} component={[NumberInput]} />
      <Field name="qty" title="数量" decorator={[FieldItem]} component={[NumberInput]} />
      <Field name="amount" title="金额" decorator={[FieldItem]} component={[NumberInput]} />
      <Field name="province" title="省" enum={[{ label: '浙江', value: 'zj' }, { label: '江苏', value: 'js' }]}
        decorator={[FieldItem]} component={[SelectInput]} />
      <Field name="city" title="市" decorator={[FieldItem]} component={[SelectInput]} />
      <pre>{result}</pre>
    </Form>
  );
}
```

| 特性 | `reaction(effect)` | `watch(source, effect)` |
|---|---|---|
| **定位** | **派生**：持续同步得出的一份结果 | **动作**：当 X 变化时执行一次 Y |
| **首次运行** | 初始化时立即运行一次 | 初始化时不运行 |
| **依赖追踪** | 自动收集 `effect` 内读取的所有 `$` 状态 | 仅追踪 `source` 内读取的状态，忽略 `effect` 中的读取 |
| **写入 `$value`** | 目标字段成为[计算字段](/guide/concepts#四个布尔)（仍可编辑、仍提交、不计入 dirty；预览再写 `readOnly`，不提交再写 `omit`） | 作为普通用户数据写入 |

编写联动时需遵守四条规则：
- 写入结果会在当前轮次结束后统一生效，因此不要在同一段 `reaction` 中读回刚赋值的 `$value`；需要复用中间结果时，请先存入局部变量（如 `const total = …; d.total.$value = total; d.tax.$value = total * 0.1`）。
- 同一个 `$` 状态只能由一个 `reaction` 负责写入；如果多个 `reaction` 同时写入同一个状态，引擎会在开发阶段报错提示。
- `reaction` 必须保持同步执行；异步请求等副作用应当放在 `watch` 中，拿到响应后再通过 `form.batch` 写回表单。
- 只有读取过的状态确实发生改变时，`reaction` 才会重新触发；如果写入的值与当前值相等，不会唤醒下游依赖。

## reaction.each：每一行一个实例

处理动态数组时，使用 `reaction.each(select, effect)` 可以为选中的数组元素逐一建立独立的联动实例。该函数只接收两个参数：第一个参数选中目标数组的 handle，第二个参数是每行执行的回调。修改某一行的数据时，只有对应那一行的回调会重新运行（包括尚未渲染到界面上的离线行）。

如果数组中包含嵌套的对象数组（例如订单下的明细 `lines`，或树节点的 `children`），`reaction.each` 会自动递归进入每一层对象数组；而嵌套在对象上的基本类型数组（如 `tags: string[]`）则不会自动展开，除非你直接对该数组本身调用 `reaction.each((d) => d.tags, fn)`（此时回调会在 `depth === 0` 时针对每个元素触发）。需要区分不同层级或字段时，可在回调中通过第二个参数 `ctx` 进行过滤。

```ts
reaction.each((d) => d.items, (row, ctx) => { … })
// ctx 提供：key、index、depth、parent、path、pos 以及根 draft `d`
```

- `key`：当前元素所属数组的字段名（如 `items`、`children`）。
- `index`：当前元素在所属数组中的下标。
- `depth`：当前遍历深度；直接选中的数组元素为 `0`，每深入一层对象数组加 `1`。
- `parent`：父级元素的 handle（`depth === 0` 时不存在）。
- `path`：当前元素此刻的路径（如 `items.2`、`nodes.0.children.1`）。
- `pos`：从选中数组根部算起的下标路径（如 `[0, 1]`；普通单层数组为 `[index]`）。

当发生行插入、删除或排序移动时，位置发生变动的行会自动以新数据重新计算，确保联动写入的状态跟随数据行一起迁移。

<Aside type="caution" title="不要在读取任何状态前直接 return">
如果回调在第一行就根据条件提前 `return` 且没有读取任何 `$` 状态，引擎会认为该实例不依赖任何数据变化，之后该节点再修改时也不会重新触发。如果需要随数据变化而恢复计算，请确保在 `return` 前已经读取过相关的 `$` 状态。
</Aside>

## 用 ctx 过滤

对于多层嵌套结构（例如 `orders: [{ lines: [{ sku, qty }] }]`），如果只是想读取某一个固定位置，直接按路径访问即可，不必动用 `each`（参见 [按路径读写](/basics/path)）：

```ts
d.orders[0].lines[2].qty.$value
form.getValue('orders[0].lines[2].qty')
```

如果需要为每个订单外层元素的特定位置设置逻辑，可以用 `ctx.depth` 过滤出外层元素：

```ts
reaction.each((d) => d.orders, (order, ctx) => {
  if (ctx.depth !== 0) return
  order.lines[2].qty.$required = true
})
```

如果希望直接定位到内层的 `lines` 节点，回调里的 `row` 会聚合选中数组及各嵌套对象数组的字段（同名字段取联合类型），而 `ctx.key` 和 `ctx.depth` 也会被精确推导为字面量联合（如 `'orders' | 'lines'` 和 `0 | 1`）：

```ts
reaction.each((d) => d.orders, (node, ctx) => {
  if (ctx.key !== 'lines' || ctx.index !== 2) return
  node.qty.$required = true
})
```

单层列表无需上述过滤；递归树结构（`children?: Node[]`）过滤掉非 `children` 的其他对象数组后即可读写 `node` 上的字段。

`watch.each` 采用相同的遍历规则，具备 `watch` 的触发时机：初始化时不执行，仅当某一行回调内读取的 `$` 状态变化时对该行运行一次（兄弟行增删或移动不会触发）。可用于「某行切换商品后将该行数量重置为 1」等动作：

```tsx preview play=sku
import { useState, type ReactNode } from 'react';
import { ArrayField, Field, Form, defineEffects, useArrayField, useField, useForm, useIndex } from '@shikiform/react';

type Item = { id: number; sku: string; price: number; qty: number; total: number };
type Values = { discount: number; items: Item[] };

const PRICES: Record<string, number> = { pen: 3, book: 25, bag: 80 };
let nextId = 3;

const effects = defineEffects<Values>(({ reaction, watch }) => {
  reaction.each((d) => d.items, (row, { d, index }) => {
    const price = PRICES[row.sku.$value] ?? 0;
    row.price.$value = price;
    row.total.$value = price * row.qty.$value * (1 - d.discount.$value / 100);
    row.sku.$required = index === 0; // 第一行必须选商品
  });
  // 换了商品，数量回到 1
  watch.each((d) => d.items, (row) => {
    if (row.sku.$value) row.qty.$value = 1;
  });
});

function InlineNumber({ min, max, width = 72 }: { min?: number; max?: number; width?: number }) {
  const field = useField<number>();
  return (
    <label style={{ display: 'inline-flex', alignItems: 'center', gap: 4 }}>
      <span>{field.title}</span>
      <input id={field.id} type="number" min={min} max={max} style={{ width }}
        value={field.value ?? 0} onChange={(e) => field.onChange(Number(e.target.value))} onBlur={field.onBlur} />
    </label>
  );
}

function InlineSelect() {
  const field = useField<string>();
  return (
    <label style={{ display: 'inline-flex', alignItems: 'center', gap: 4 }}>
      <span>{field.title}</span>
      <select id={field.id} value={field.value ?? ''} onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur}>
        <option value="">请选择</option>
        {field.options.map((o) => <option key={String(o.value)} value={String(o.value)}>{o.label}</option>)}
      </select>
    </label>
  );
}

function RemoveButton() {
  const array = useArrayField<Item>();
  const index = useIndex();
  return <button type="button" onClick={() => array.remove(index)}>删除</button>;
}

function ItemList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Item>();
  return (
    <div>
      {children}
      <button type="button" style={{ marginTop: 10 }}
        onClick={() => array.push({ id: nextId++, sku: '', price: 0, qty: 1, total: 0 })}>添加一行</button>
    </div>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { discount: 10, items: [{ id: 1, sku: 'pen', price: 0, qty: 4, total: 0 }, { id: 2, sku: 'book', price: 0, qty: 1, total: 0 }] },
    fields: { 'items.*.sku': { enum: Object.keys(PRICES).map((value) => ({ label: value, value })) } },
    effects: [effects],
  });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <div style={{ marginBottom: 10 }}>
        <Field name="discount" title="折扣 %" component={[InlineNumber, { min: 0, max: 100 }]} />
      </div>
      <ArrayField name="items" rowKey="id" component={ItemList}>
        {() => (
          <div style={{ display: 'flex', gap: 8, alignItems: 'center', marginBottom: 8, flexWrap: 'wrap' }}>
            <Field name="sku" title="商品" component={[InlineSelect]} />
            <Field name="price" title="单价" component={[InlineNumber]} />
            <Field name="qty" title="数量" component={[InlineNumber, { min: 1 }]} />
            <Field name="total" title="小计" component={[InlineNumber]} />
            <RemoveButton />
          </div>
        )}
      </ArrayField>
      <button style={{ marginTop: 10 }} type="submit">提交</button>
      <pre>{result}</pre>
    </Form>
  );
}
```

修改某一行的数量只触发该行重算；修改顶部的全局折扣时，所有行都读取了 `d.discount`，因此全部重算。`price` 和 `total` 由 `reaction` 写入，属于计算字段，默认仍可编辑且随表单提交（如需只读展示可加 `readOnly`）。

## 嵌套对象数组与树

对于包含 `children` 属性的树形数据，由于 `children` 本身也是对象数组，`reaction.each` 会自动遍历到树中的每一个节点。回调里的 `ctx.pos` 记录了节点当前的下标链（如 `[0, 1]`），适合用于生成大纲编号或判断层级；节点身份的稳定追踪依然依靠 `rowKey`。如果树节点上还挂载了其他对象数组字段，只需通过 `ctx.key === 'children'` 过滤一下即可。

```tsx preview
import { Field, Form, TreeField, defineEffects, useField, useForm, useTreeField } from '@shikiform/react';

type Node = { id: string; code: string; name: string; children?: Node[] };
type Values = { nodes: Node[] };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction.each((d) => d.nodes, (node, { pos, key, depth }) => {
    if (depth > 0 && key !== 'children') return;
    node.code.$value = pos.map((index) => index + 1).join('.'); // 大纲编号随位置变化
    node.name.$required = pos.length === 1; // 只有顶层节点必填
  });
});

function TextBox({ width }: { width?: number }) {
  const field = useField<string>();
  return (
    <input style={width ? { width } : undefined} value={field.value ?? ''}
      onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
  );
}

function NodeTree() {
  const tree = useTreeField('nodes', { rowKey: 'id' });
  return (
    <>
      <ul style={{ paddingLeft: 0, listStyle: 'none' }}>
        <TreeField name="nodes" rowKey="id">
          {(node) => (
            <li style={{ margin: '6px 0' }}>
              <span style={{ display: 'inline-flex', gap: 6 }}>
                <Field name="code" component={[TextBox, { width: 56 }]} />
                <Field name="name" component={[TextBox, { width: 180 }]} />
              </span>
              {node.children && <ul style={{ paddingLeft: 24, listStyle: 'none' }}>{node.children}</ul>}
            </li>
          )}
        </TreeField>
      </ul>
      <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
        <button type="button" onClick={() => tree.move([0, 1], [0, 0])}>把「洗菜」移到最前</button>
        <button type="button" onClick={() => tree.move([0, 0], [1, 0])}>把第一个子节点移到「下厨」下</button>
      </div>
    </>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: {
      nodes: [
        { id: 'a', code: '', name: '准备', children: [{ id: 'a1', code: '', name: '买菜' }, { id: 'a2', code: '', name: '洗菜' }] },
        { id: 'b', code: '', name: '下厨', children: [{ id: 'b1', code: '', name: '炒菜' }] },
      ],
    },
    trees: { nodes: { rowKey: 'id' } },
    effects: [effects],
  });
  return (
    <Form form={form}>
      <NodeTree />
    </Form>
  );
}
```

## 通过联动控制 UI 状态

字段的显隐、必填、下拉选项、标签和占位符同样是 `$` 状态，可以直接在 `reaction` 中赋值（完整示范见 [首页](/)）。

控制字段条件显隐使用 `$visible`：`$visible = false` 不渲染、跳过校验，值仍会提交（见 [四个布尔](/guide/concepts#四个布尔)）；不进入提交结果时再设置 `$omit = true`。撤销联动层对 `$title`、`$readOnly`、`$disabled` 或 `$enum` 的覆盖可赋 `undefined`，回退到 JSX 或 `fields` 声明；将选项置为空数组则赋 `$enum = []`。

不要在组件渲染期间调用 `form.getValue(...)` 计算控件属性，该写法不订阅状态变化。同一字段需要挂载第二个 UI（如回显文本、联动滑块），或需要控制无数据提示横幅时，使用命名 UI 节点 `d.x.$ui('echo')` / `d.$ui('tip')`，见 [命名 UI](/guide/ui)。

多维 SKU 选择、冲突清理、价格与库存联动见 [SKU 选择器](/play/sku-picker) 与 [联动示例](/examples/linkage)。
