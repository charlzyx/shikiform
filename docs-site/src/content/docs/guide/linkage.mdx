title: 联动
description: reaction 维持派生状态，watch 做一次性动作；reaction.each / watch.each 走进每一层对象数组。
---

「金额 = 单价 × 数量」「省份变了清空城市」这类规则写在 `defineEffects` 里，交给 `useForm({ effects })`。它们直接读写引擎，字段有没有挂载都生效。

```ts
const effects = defineEffects<Values>(({ reaction, watch }) => {
  reaction((d) => { /* 派生：读到的 $ 状态就是依赖 */ })
  watch((d) => d.province.$value, (d) => { /* 动作：来源变了才执行 */ })
})
```

## reaction 与 watch

```tsx preview
import { useState } from 'react';
import { Field, Form, defineEffects, useForm } from '@shikiform/react';
import { FormItem, FormLayout, InputNumber, Select } from '@shikiform/antd';

type Values = { price: number; qty: number; amount: number; province: string; city: string };

const CITIES: Record<string, { label: string; value: string }[]> = {
  zj: [{ label: '杭州', value: 'hz' }, { label: '宁波', value: 'nb' }],
  js: [{ label: '南京', value: 'nj' }, { label: '苏州', value: 'sz' }],
};

const effects = defineEffects<Values>(({ reaction, watch }) => {
  // 派生：一开始就运行，price / qty 变化时重算
  reaction((d) => {
    d.amount.$value = d.price.$value * d.qty.$value;
  });
  // 派生 UI：城市选项跟着省份
  reaction((d) => {
    // 没选省份时写 undefined 会回到 <Field enum> / fields 声明的选项；这里要空列表，所以写 []
    d.city.$enum = CITIES[d.province.$value] ?? [];
    d.city.$disabled = !d.province.$value;
  });
  // 动作：省份变了才清空城市；第一次不执行，初始的「杭州」保留
  watch((d) => d.province.$value, (d) => {
    d.city.$value = '';
  });
});

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { price: 10, qty: 2, amount: 0, province: 'zj', city: 'hz' },
    effects: [effects],
  });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="price" title="单价" decorator={[FormItem]} component={[InputNumber]} />
        <Field name="qty" title="数量" decorator={[FormItem]} component={[InputNumber]} />
        <Field name="amount" title="金额" decorator={[FormItem]} component={[InputNumber]} />
        <Field name="province" title="省" enum={[{ label: '浙江', value: 'zj' }, { label: '江苏', value: 'js' }]}
          decorator={[FormItem]} component={[Select, { style: { width: 160 } }]} />
        <Field name="city" title="市" decorator={[FormItem]} component={[Select, { style: { width: 160 } }]} />
      </FormLayout>
      <pre>{result}</pre>
    </Form>
  );
}
```

| | `reaction(effect)` | `watch(source, effect)` |
|---|---|---|
| 用途 | **派生**：维持一份结果 | **动作**：X 变了就做一次 Y |
| 首次 | 立即运行 | 不运行 |
| 依赖 | `effect` 里读到的所有 `$` 状态 | 只有 `source` 读到的；`effect` 里的读取不算 |
| 写 `$value` | 字段成为[计算字段](/guide/concepts#显隐pattern-与提交)，默认仍提交；不想提交就声明 `display: 'virtual'` | 普通写入 |

规则：

- 写入在本轮结束才生效。刚写的值不要在同一轮读回，先放进局部变量：`const total = …; d.total.$value = total; d.tax.$value = total * 0.1`。
- 一个 `$` 状态只能由一个 reaction 写；两个 reaction 写同一个状态会报错。
- reaction 必须同步；请求放在 `watch` 里，结果用 `form.batch` 写回。
- 只有读过的键变了，reaction 才重跑；相等的写入不会唤醒下游。

## reaction.each：每一行一个实例

`reaction.each(select, effect)` 只有两个参数。选择器返回数组的 **handle**。每一行一个 reaction 实例，单元格改了只重算那一行（包括没有渲染出来的行）。

遇到**元素是对象的数组**会继续走进去（嵌套 `lines`、树的 `children`）。嵌套在对象上的**基本类型数组**（行里的 `tags: string[]`）不进。直接对这个数组调用 `each` 是例外：`reaction.each((d) => d.tags, fn)` 会在 `depth === 0` 访问每个元素。没有第三个参数。回调自己按 `ctx` 过滤。

```ts
reaction.each((d) => d.items, (row, ctx) => { … })
// ctx：key、index、depth、parent、path、pos，外加根 draft `d`
```

- `key`：这一元素所在数组的字段名（`items`、`children`）
- `index`：它在那个数组里的下标
- `depth`：选中数组的直接元素是 `0`，每进一层对象数组加 1
- `parent`：父元素的 handle；`depth === 0` 时没有
- `path`：此刻的路径（`items.2`、`nodes.0.children.1`）
- `pos`：从选中数组数下来的下标链（`[0, 1]`）；普通行是 `[index]`

只要某一层的逻辑不一样，在回调里返回。插入、删除、移动之后，换了元素的位置会用新的元素重跑，所以写下的状态跟着走。

<Aside type="caution" title="提前 return 且什么都没读">
这样的实例跑过一次之后就停着。那个节点的数据再变，也不会重跑。要跟着变，就在 return 之前读到相关的 `$` 状态，或者不要在那一层 return。
</Aside>

## 用 ctx 过滤

数据是 `orders: [{ lines: [{ sku, qty }] }]`。只取一个位置时不要用 `each`，直接写路径。细节见 [按路径读写](/basics/path)。

```ts
d.orders[0].lines[2].qty.$value
form.getValue('orders[0].lines[2].qty')
```

没有下标时，`get(d, 'user.name').$value` 也行：draft 上 `get` 返回子 handle。带下标的 `get(d, 'orders[0].lines[2].qty')` 过不了类型检查，用上面两种写法。

每个外层元素都取里面的同一项：

```ts
reaction.each((d) => d.orders, (order, ctx) => {
  if (ctx.depth !== 0) return
  const qty = order.lines[2].qty.$value
})
```

要改里面某一项，仍在外层回调里走 handle。`depth === 0` 时 `order` 的类型就是订单，`order.lines[2].qty` 能过类型检查：

```ts
reaction.each((d) => d.orders, (order, ctx) => {
  if (ctx.depth !== 0) return
  order.lines[2].qty.$required = true
})
```

<Aside type="caution" title="回调参数的类型停在选中的那一层">
`each` 把回调的第一个参数类型定成选择器选中的元素（这里是 `{ lines }`）。运行时走进 `lines` 仍会调用它，但类型不会变成行。用 `ctx.key !== 'lines' || ctx.index !== 2` 可以在运行时只处理最里层的第 2 项，接着写 `node.qty` 却是 `TS2339`。那样运行时会把 `orders.0.lines.2` 设成必填，只是不能当能过 tsc 的写法。要改这个字段，用上面的 `order.lines[2].qty`。
</Aside>

平铺表格的回调里不用这些判断。树的子节点如果和当前节点是同一个类型（`children?: Node[]`），`ctx.key` / `ctx.depth` 滤完之后仍可以写 `node.name`。子元素是另一种形状时，用上面的外层 handle。

`watch.each` 是同样的遍历，语义是 `watch`：回调里读到的 `$` 状态就是来源，来源变了才执行，首次不写入。某个元素变化只触发它自己，兄弟和别处的移动不触发。适合「这个节点的 X 变了就做一次动作」。

```tsx preview play=sku
import { useState } from 'react';
import { Button } from 'antd';
import { ArrayField, Field, Form, defineEffects, useForm } from '@shikiform/react';
import { FormItem, FormLayout, InputNumber, Select } from '@shikiform/antd';

type Item = { id: number; sku: string; price: number; qty: number; total: number };
type Values = { discount: number; items: Item[] };

const PRICES: Record<string, number> = { pen: 3, book: 25, bag: 80 };
let nextId = 3;

const effects = defineEffects<Values>(({ reaction, watch }) => {
  reaction.each((d) => d.items, (row, { d, index }) => {
    const price = PRICES[row.sku.$value] ?? 0;
    row.price.$value = price;
    row.total.$value = price * row.qty.$value * (1 - d.discount.$value / 100);
    row.sku.$required = index === 0; // 第一行必须选商品
  });
  // 换了商品，数量回到 1
  watch.each((d) => d.items, (row) => {
    if (row.sku.$value) row.qty.$value = 1;
  });
});

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { discount: 10, items: [{ id: 1, sku: 'pen', price: 0, qty: 4, total: 0 }, { id: 2, sku: 'book', price: 0, qty: 1, total: 0 }] },
    fields: { 'items.*.sku': { enum: Object.keys(PRICES).map((value) => ({ label: value, value })) } },
    effects: [effects],
  });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout layout="inline" feedbackLayout="terse">
        <Field name="discount" title="折扣 %" decorator={[FormItem]} component={[InputNumber, { min: 0, max: 100 }]} />
      </FormLayout>
      <ArrayField name="items" rowKey="id">
        {({ index }) => (
          <FormLayout layout="inline" feedbackLayout="terse" style={{ marginTop: 12 }}>
            <Field name="sku" title="商品" decorator={[FormItem]} component={[Select, { style: { width: 100 } }]} />
            <Field name="price" title="单价" decorator={[FormItem]} component={[InputNumber]} />
            <Field name="qty" title="数量" decorator={[FormItem]} component={[InputNumber, { min: 1 }]} />
            <Field name="total" title="小计" decorator={[FormItem]} component={[InputNumber]} />
            <Button danger onClick={() => form.removeArray('items', index)}>删除</Button>
          </FormLayout>
        )}
      </ArrayField>
      <Button style={{ marginTop: 12 }} onClick={() => form.pushArray('items', { id: nextId++, sku: '', price: 0, qty: 1, total: 0 })}>添加一行</Button>
      <Button style={{ marginTop: 12, marginLeft: 8 }} type="primary" htmlType="submit">提交</Button>
      <pre>{result}</pre>
    </Form>
  );
}
```

改某一行的数量，只有那一行重算；改折扣，所有行重算（它们都读了 `d.discount`）。`price` 和 `total` 是计算字段，仍在提交结果里。

## 嵌套对象数组与树

`children` 是对象数组，所以同一个 `reaction.each` 会走到每个节点。`ctx.pos` 是下标链（`[0, 1]`），移动后变；稳定身份用 `rowKey`。节点上如果还有别的对象数组，用 `ctx.key === 'children'` 滤掉。

```tsx preview
import { Button, Space } from 'antd';
import { Field, Form, RowScope, TreeField, defineEffects, useForm } from '@shikiform/react';
import { Input } from '@shikiform/antd';

type Node = { id: string; code: string; name: string; children?: Node[] };
type Values = { nodes: Node[] };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction.each((d) => d.nodes, (node, { pos, key, depth }) => {
    if (depth > 0 && key !== 'children') return;
    node.code.$value = pos.map((index) => index + 1).join('.'); // 大纲编号随位置变化
    node.name.$required = pos.length === 1; // 只有顶层节点必填
  });
});

function Nodes({ path, nodes, pos }: { path: string; nodes: Node[]; pos: number[] }) {
  return (
    <ul style={{ paddingLeft: pos.length ? 24 : 0, listStyle: 'none' }}>
      {nodes.map((node, index) => {
        const at = [...pos, index];
        return (
          <li key={node.id} style={{ margin: '6px 0' }}>
            <RowScope path={`${path}.${index}`} pos={at}>
              <Space.Compact>
                <Field name="code" component={[Input, { style: { width: 64 } }]} />
                <Field name="name" component={[Input, { style: { width: 200 } }]} />
              </Space.Compact>
              {node.children?.length ? <Nodes path={`${path}.${index}.children`} nodes={node.children} pos={at} /> : null}
            </RowScope>
          </li>
        );
      })}
    </ul>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: {
      nodes: [
        { id: 'a', code: '', name: '准备', children: [{ id: 'a1', code: '', name: '买菜' }, { id: 'a2', code: '', name: '洗菜' }] },
        { id: 'b', code: '', name: '下厨', children: [{ id: 'b1', code: '', name: '炒菜' }] },
      ],
    },
    trees: { nodes: { rowKey: 'id' } },
    effects: [effects],
  });
  return (
    <Form form={form}>
      <TreeField name="nodes" rowKey="id">
        {(tree) => (
          <>
            <Nodes path={tree.path} nodes={tree.value as Node[]} pos={[]} />
            <Button onClick={() => tree.move([0, 1], [0, 0])}>把「洗菜」移到最前</Button>{' '}
            <Button onClick={() => tree.move([0, 0], [1, 0])}>把第一个子节点移到「下厨」下</Button>
          </>
        )}
      </TreeField>
    </Form>
  );
}
```

## UI 也是状态

显隐、必填、选项、标签、占位符都是 `$` 状态，在 reaction 里赋值即可（完整例子见 [首页](/)）。条件显示的字段写 `$visible`：`$visible = false` 等价于 `display: 'none'`，不是 `hidden`（不渲染、不校验、不提交，值留在 store；与 Formily 的 `visible` 一致）。只藏 UI、仍校验仍提交，写 `$hidden = true` / `$display = 'hidden'`。见 [显隐、pattern 与提交](/guide/concepts#显隐pattern-与提交)。赋 `undefined` 撤销 reaction 写的这一层（`$title`、`$pattern`、`$enum` 都一样），`$enum = undefined` 回到 `<Field enum>` / `fields` 声明的选项，`$enum = []` 才是清空。不要在渲染时根据 `form.getValue(...)` 算 props：那不是响应式的。同一字段的第二个 UI（回显、滑块）和没有值的提示条用命名 UI 节点 `d.x.$ui('echo')` / `d.$ui('tip')`，见 [UI 节点](/guide/ui)。
