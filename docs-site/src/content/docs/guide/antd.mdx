Ant Design 控件通常接收 `value`、`onChange`、`status`、`disabled` 等属性。`@shikiform/antd` 负责将 ShikiForm 引擎里的字段状态映射成这些属性，数据本身依然统一存储在 ShikiForm 引擎中——因此请**不要同时使用 Ant Design 原生 `Form` 的 `name`、`rules` 或 `initialValues`**，以免两套状态互相冲突。

## 开箱即用的控件

`@shikiform/antd` 提供了全套常用控件的适配版本，包括：`Input`（含 `TextArea`、`Password`）、`InputNumber`、`Select`、`AutoComplete`、`TreeSelect`、`Cascader`、`Switch`、`Checkbox`（含 `Group`）、`Radio`（直接作为单选组使用，等同于 `Radio.Group`）、`DatePicker` / `TimePicker`（含 `RangePicker`）、`Slider`、`Rate`、`Transfer`、`Upload`（含 `Dragger`）和 `ColorPicker`。完整清单与阅读态效果见 [控件与阅读态](/guide/controls)。

这些适配控件具备以下统一特性：
- **自动读取枚举**：选择类控件的 `options`（以及 `TreeSelect` 的 `treeData`、`Transfer` 的 `dataSource`）会自动对接字段配置的枚举（JSX `enum`、`fields.x.enum` 或 `$enum`），使用异步数据源时还会自动传入 `loading` 状态。
- **自动响应交互态**：当 `pattern` 为 `disabled` 或 `readOnly` 时自动禁用输入；设为 `readPretty` 时自动切换为阅读态文本（选择类控件可配置 `prettyType="badge" | "tag"`）。
- **日期存储字符串**：`DatePicker` 与 `TimePicker` 自动完成字符串与 `dayjs` 对象之间的转换，表单引擎中只保留格式化后的纯字符串（默认 `YYYY-MM-DD` / `HH:mm:ss`）。

```tsx preview
import { Radio as AntRadio } from 'antd';
import { Field, Form, ObjectField, useForm, type Pattern } from '@shikiform/react';
import { Checkbox, DatePicker, FormItem, FormLayout, Input, InputNumber, Radio, Select, Switch } from '@shikiform/antd';

type Profile = { name: string; age: number; level: string; tags: string[]; gender: string; vip: boolean; birthday: string };

const PATTERNS: Pattern[] = ['editable', 'disabled', 'readOnly', 'readPretty'];

export default function App() {
  const form = useForm<{ profile: Profile }>({
    initialValues: { profile: { name: 'Ada', age: 36, level: 'gold', tags: ['math'], gender: 'f', vip: true, birthday: '1815-12-10' } },
  });
  return (
    <Form form={form}>
      <AntRadio.Group style={{ marginBottom: 16 }} optionType="button" options={PATTERNS} defaultValue="editable"
        onChange={(event) => form.batch((d) => { d.profile.$pattern = event.target.value; })} />
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        {/* 子字段都继承 profile 的 pattern */}
        <ObjectField name="profile">
          <Field name="name" title="Input" decorator={[FormItem]} component={[Input]} />
          <Field name="age" title="InputNumber" decorator={[FormItem]} component={[InputNumber]} />
          <Field name="level" title="Select" enum={[{ label: '黄金', value: 'gold', color: 'gold' }, { label: '白银', value: 'silver' }]}
            decorator={[FormItem]} component={[Select, { prettyType: 'tag', style: { width: 160 } }]} />
          <Field name="tags" title="Checkbox.Group" enum={[{ label: '数学', value: 'math' }, { label: '诗歌', value: 'poetry' }]}
            decorator={[FormItem]} component={[Checkbox.Group]} />
          <Field name="gender" title="Radio" enum={[{ label: '女', value: 'f' }, { label: '男', value: 'm' }]}
            decorator={[FormItem]} component={[Radio]} />
          <Field name="vip" title="Switch" decorator={[FormItem]} component={[Switch]} />
          <Field name="birthday" title="DatePicker" decorator={[FormItem]} component={[DatePicker]} />
        </ObjectField>
      </FormLayout>
    </Form>
  );
}
```

演示中切换顶部按钮时只修改了 `d.profile.$pattern`，内部的七个子字段通过继承自动同步切换状态。

## 封装自己的控件

任何遵循受控值/回调约定（如 `value` / `onChange`）的第三方或业务组件，都可以通过 `connect(Component, ...enhancers)` 接入 ShikiForm：

| 增强器（enhancer） | 作用说明 |
|---|---|
| `mapProps({ value: 'checked' })` | 重命名绑定属性；传 `false` 可屏蔽某个属性（如 `{ onBlur: false }`）。注意无 UI 的 `connect` 默认不传 Ant Design 专属的 `status`，需要校验红框时写 `{ status: 'status' }` |
| `mapProps({ title: 'placeholder' })` | 将其他字段状态映射到指定 prop（支持 `title`、`description`、`required`、`validating`、`componentProps.x` 等）；调用方显式传入同名 prop 时以调用方为准 |
| `mapProps({ format, parse })` | 双向数据转换：`format` 将引擎里的可序列化值转成控件所需的类型（如字符串转 Date），`parse` 将控件 `onChange` 回调参数转回字段值 |
| `mapProps((props, field) => props)` | 使用函数对最终 props 做自定义变换（在 `format` 之前执行） |
| `mapProps({ blurOn: 'onOpenChange' })` | 当控件自身没有 `onBlur` 回调时（例如弹出层选择器），指定通过关闭弹层或变更事件（`'onChange'`）来触发失焦校验 |
| `mapProps({ readPretty: View })` | 指定字段处于 `readPretty` 状态时渲染的只读视图（组件或 `[Component, props]`，接收 `value` 和 `options`）；未配置时则按 `readOnly` 降级 |

```tsx preview
import { Segmented as AntSegmented } from 'antd';
import { Field, Form, useForm } from '@shikiform/react';
import { FormItem, FormLayout, Switch, connect, mapProps } from '@shikiform/antd';

// Segmented 的 onChange 直接给值。headless connect 默认不传 status；这里再丢掉 id。阅读态显示带圆点的文字。
// connect 也从 '@shikiform/react' 导入，不必经过 antd。
const Segmented = connect(
  AntSegmented,
  mapProps({
    id: false,
    readOnly: 'disabled',
    readPretty: ({ value }: { value?: string }) => <span>● {value}</span>,
  }),
);

export default function App() {
  const form = useForm({ initialValues: { pretty: false, size: '中' } });
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="pretty" title="阅读态" decorator={[FormItem]}>
          <Switch onChange={(checked: boolean) => form.batch((d) => { d.size.$pattern = checked ? 'readPretty' : undefined; })} />
        </Field>
        <Field name="size" title="尺寸" decorator={[FormItem]} component={[Segmented, { options: ['小', '中', '大'] }]} />
      </FormLayout>
    </Form>
  );
}
```

经 `connect` 包装后的组件会自动转发 `ref`，并保留原组件的静态成员（如 `Select.Option`、`Input.Search`）。当控件触发 `onChange` 或 `onBlur` 时，会先通知引擎更新字段，再透传原始参数调用外部传入的回调；如果将该组件直接渲染在 `<Field>` 之外且未传入 `name` / `field`，它会自动退化为普通非绑定组件。

如果只是临时写一个业务专用控件，也可以跳过 `connect`，直接在组件内调用无参数的 `useField()` 手动接线：

```tsx
import { useField } from '@shikiform/react';

function Percent() {
  const field = useField<number>();
  return <AntSlider value={field.value} onChange={field.onChange} disabled={field.disabled} />;
}
<Field name="volume" title="音量" decorator={[FormItem]} component={[Percent]} />
```

## 提交与重置按钮

`@shikiform/antd` 导出的 `Submit` 和 `Reset` 会自动关联外层的 `<Form>`：`Submit` 在 `$canSubmit` 为 `false` 时自动禁用并在提交过程中展示 loading 状态；`Reset` 则在点击时调用 `form.reset()`，并支持通过 `afterReset` 拿到重置后的值（常用于清空查询条件后重新发起请求）。两个按钮的默认文本跟随表单的 `messages` 配置。如果不需要 Ant Design 按钮样式，可使用 `@shikiform/react` 提供的无样式版本或 `useSubmit()` / `useReset()`。

```tsx
<Form form={form} onSubmit={save}>
  <Field name="email" title="邮箱" required decorator={[FormItem]} component={[Input]} />
  <Submit />                                         {/* 触发原生 submit，交由 <Form onSubmit> 处理 */}
  <Reset />
  <Submit onSubmit={saveDraft}>存草稿</Submit>        {/* 绑定独立提交逻辑，内部直接调用 form.submit(saveDraft) */}
</Form>
```

如果需要对字段名开启 TypeScript 编译检查，配合 [`typed(form)`](/reference/react-hooks#typed) 使用即可。更多参数细节见 [Ant Design 参考](/reference/antd#submit)。
