# Ant Design 适配

antd 控件要的是 `value`、`onChange`、`status`、`disabled` 这些 props。`shikiform/antd` 把字段绑定映射成这些 props，值仍在 ShikiForm 引擎里，所以**不要再把同一份值交给 antd `Form` 的 `name` / `rules` / `initialValues`**。

## 接好的控件

`Input`（含 `TextArea`、`Password`）、`InputNumber`、`Select`、`AutoComplete`、`TreeSelect`、`Cascader`、`Switch`、`Checkbox`（含 `Group`）、`Radio`（就是单选组，`Radio.Group` 同一个）、`DatePicker` / `TimePicker`（含 `RangePicker`）、`Slider`、`Rate`、`Transfer`、`Upload`（含 `Dragger`）、`ColorPicker` 可以直接放进 `component`。全表和每个控件的阅读态见 [控件与阅读态](/guide/controls)。

- 选择类控件的 `options`（`TreeSelect` 的 `treeData`、`Transfer` 的 `dataSource`）默认取字段枚举（`<Field enum>`、`fields.x.enum` 或 `$enum`），异步枚举时自动带 `loading`。
- `pattern` 自动生效：`disabled` / `readOnly` 禁用控件，`readPretty` 换成阅读态视图（选择类显示标签，可加 `prettyType="badge" | "tag"`）。
- `DatePicker` / `TimePicker` 的字段值是格式化后的字符串（默认 `YYYY-MM-DD` / `HH:mm:ss`），不是 dayjs 对象。

```tsx preview
import { Radio as AntRadio } from 'antd';
import { Field, Form, ObjectField, useForm, type Pattern } from 'shikiform';
import { Checkbox, DatePicker, FormItem, FormLayout, Input, InputNumber, Radio, Select, Switch } from 'shikiform/antd';

type Profile = { name: string; age: number; level: string; tags: string[]; gender: string; vip: boolean; birthday: string };

const PATTERNS: Pattern[] = ['editable', 'disabled', 'readOnly', 'readPretty'];

export default function App() {
  const form = useForm<{ profile: Profile }>({
    initialValues: { profile: { name: 'Ada', age: 36, level: 'gold', tags: ['math'], gender: 'f', vip: true, birthday: '1815-12-10' } },
  });
  return (
    <Form form={form}>
      <AntRadio.Group style={{ marginBottom: 16 }} optionType="button" options={PATTERNS} defaultValue="editable"
        onChange={(event) => form.batch((d) => { d.profile.$pattern = event.target.value; })} />
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        {/* 子字段都继承 profile 的 pattern */}
        <ObjectField name="profile">
          <Field name="name" title="Input" decorator={[FormItem]} component={[Input]} />
          <Field name="age" title="InputNumber" decorator={[FormItem]} component={[InputNumber]} />
          <Field name="level" title="Select" enum={[{ label: '黄金', value: 'gold', color: 'gold' }, { label: '白银', value: 'silver' }]}
            decorator={[FormItem]} component={[Select, { prettyType: 'tag', style: { width: 160 } }]} />
          <Field name="tags" title="Checkbox.Group" enum={[{ label: '数学', value: 'math' }, { label: '诗歌', value: 'poetry' }]}
            decorator={[FormItem]} component={[Checkbox.Group]} />
          <Field name="gender" title="Radio" enum={[{ label: '女', value: 'f' }, { label: '男', value: 'm' }]}
            decorator={[FormItem]} component={[Radio]} />
          <Field name="vip" title="Switch" decorator={[FormItem]} component={[Switch]} />
          <Field name="birthday" title="DatePicker" decorator={[FormItem]} component={[DatePicker]} />
        </ObjectField>
      </FormLayout>
    </Form>
  );
}
```

切换上面的按钮只写了 `d.profile.$pattern`，下面的字段靠继承一起切换。选项直接写在 `<Field enum>` 上，见 [选项写在 JSX 里](/guide/field#选项写在-jsx-里)。

## 封装自己的控件

任何 `value` / `onChange` 控件经 `connect(Component, ...enhancers)` 都能当 `component` 用：

| enhancer | 作用 |
|---|---|
| `mapProps({ value: 'checked' })` | 重命名绑定属性；`false` 丢弃（`{ status: false }`）；`getValueFromEvent` 自定义取值 |
| `mapProps({ title: 'placeholder' })` | 把其他字段状态交给某个 prop：`title`、`description`、`required`、`validating`、`componentProps.x` …；调用方显式传的 prop 优先 |
| `mapProps((props, field) => props)` | 最后一步变换 props |
| `mapReadPretty(View)` | `readPretty` 时渲染 `View`（收到 `value` 和 `options`）；没有它时按 `readOnly` 处理 |

```tsx preview
import { Segmented as AntSegmented } from 'antd';
import { Field, Form, useForm } from 'shikiform';
import { FormItem, FormLayout, Switch, connect, mapProps, mapReadPretty } from 'shikiform/antd';

// Segmented 的 onChange 直接给值，默认取值逻辑就能处理；没有 status / id；阅读态显示带圆点的文字
const Segmented = connect(
  AntSegmented,
  mapProps({ status: false, id: false, readOnly: 'disabled' }),
  mapReadPretty(({ value }: { value?: string }) => <span>● {value}</span>),
);

export default function App() {
  const form = useForm({ initialValues: { pretty: false, size: '中' } });
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="pretty" title="阅读态" decorator={[FormItem]}>
          <Switch onChange={(checked: boolean) => form.batch((d) => { d.size.$pattern = checked ? 'readPretty' : undefined; })} />
        </Field>
        <Field name="size" title="尺寸" decorator={[FormItem]} component={[Segmented, { options: ['小', '中', '大'] }]} />
      </FormLayout>
    </Form>
  );
}
```

控件的 `onChange` 先写字段，再用原始参数调用你传的 `onChange`；`onBlur` 同理。

和 Formily 一样，`ref` 转发给原控件，静态成员（`Select.Option`、`Input.Search`）保留。接好的控件放在 `<Field>` 外、也没给 `name` 时，就是普通控件：只用你传的 props，开发环境警告一次。

不想经过 `connect` 时，组件里用不带参数的 `useField()` 读当前字段，自己接线。`<Field>` 的 `component`、子元素、表格单元格里的 `<Field>` 都一样：

```tsx
import { useField } from 'shikiform';

function Percent() {
  const field = useField<number>();
  return <AntSlider value={field.value} onChange={field.onChange} disabled={field.disabled} />;
}
<Field name="volume" title="音量" decorator={[FormItem]} component={[Percent]} />
```

在任何 `<Field>` 之外调用会抛 `ShikiUsageError`，消息里写明怎么改。

## 提交与重置按钮

`Submit` / `Reset` 读最近的 `<Form>`：`Submit` 在 `$canSubmit` 为 false 时不可点、提交中显示 loading；`Reset` 调 `form.reset()`。按钮文字跟随表单的 `messages`。

```tsx
<Form form={form} onSubmit={save}>
  <Field name="email" title="邮箱" required decorator={[FormItem]} component={[Input]} />
  <Submit />                                         {/* 原生 submit，交给 <Form onSubmit> */}
  <Reset />
  <Submit onSubmit={saveDraft}>存草稿</Submit>        {/* 自己调用 form.submit(saveDraft) */}
</Form>
```

按表单值类型检查字段名用 [`typed(form)`](/reference/react-hooks#typed)。细节见 [antd 参考](/reference/antd#submit)。
