title: 动态数组与表格
description: 使用 ArrayField、useArrayField、useIndex 与 useArrayTable 构建支持增删、排序、拖拽、数组级校验与分页勾选的动态列表。
---

[`<ArrayField>`](/guide/structures) 负责建立行作用域与追踪行身份。搭配 `@shikiform/react` 提供的 `useArrayField` / `useIndex` / `useRecord` 与 `useArrayTable`，可以用原生 HTML 或任意 UI 组件库搭建行列表、卡片列表和可编辑表格。

| 能力 | API | 说明 |
|---|---|---|
| 行作用域与身份追踪 | `<ArrayField name rowKey>` | 仅订阅数组结构变化，修改单元格不会重渲染整张列表 |
| 增删排序与原生拖拽 | `useArrayField()` / `useIndex()` / `useRecord()` | `push`、`insert`、`remove`、`move`、`swap`、`replace` 与 `dragProps(index)` |
| 表格分页 / 勾选 / 展开 / 复制 | `useArrayTable` | 无 UI 的数组表格状态管理，适合搭配原生 `<table>` 或项目表格组件 |

## 行列表与拖拽排序

```tsx preview
import type { ReactNode } from 'react';
import { Checkbox, CheckboxIndicator } from '@ui-sdk/react/checkbox';
import { Form, typed, useArrayField, useField, useForm, useIndex, useWatch, type Draft } from '@shikiform/react';

type Contact = { name: string; phone: string };
type Values = { contacts: Contact[] };

function TextInput({ placeholder }: { placeholder?: string }) {
  const field = useField<string>();
  if (field.readOnly) return <span>{field.value || '-'}</span>;
  return (
    <span>
      <input id={field.id} value={field.value ?? ''} placeholder={placeholder}
        disabled={field.disabled} onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
      {field.errors[0] && <small role="alert" style={{ color: 'crimson', marginLeft: 4 }}>{field.errors[0]}</small>}
    </span>
  );
}

const selectContactsEditable = (d: Draft<Values>) => !d.contacts.$readOnly && !d.contacts.$disabled;

function ContactRow({ children }: { children?: ReactNode }) {
  const array = useArrayField<Contact>();
  const index = useIndex();
  const editable = useWatch(selectContactsEditable);
  return (
    <div {...(editable ? array.dragProps(index) : {})}
      style={{ display: 'flex', gap: 8, alignItems: 'center', marginBottom: 8 }}>
      {editable && <span style={{ cursor: 'grab' }} title="拖动排序">⋮⋮</span>}
      <span>#{index + 1}</span>
      {children}
      {editable && (
        <>
          <button type="button" disabled={index === 0} onClick={() => array.move(index, index - 1)}>上移</button>
          <button type="button" disabled={index === array.keys.length - 1} onClick={() => array.move(index, index + 1)}>下移</button>
          <button type="button" onClick={() => array.remove(index)}>删除</button>
        </>
      )}
    </div>
  );
}

function ContactList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Contact>();
  const editable = useWatch(selectContactsEditable);
  return (
    <div>
      {children}
      {editable && <button type="button" onClick={() => array.push({ name: '', phone: '' })}>添加联系人</button>}
    </div>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: { contacts: [{ name: 'Ada', phone: '100' }, { name: 'Charles', phone: '200' }] },
    fields: { 'contacts.*.name': { required: true } },
  });
  const F = typed(form);
  return (
    <Form form={form}>
      <p>
        <label style={{ display: 'inline-flex', alignItems: 'center', gap: 6, cursor: 'pointer' }}>
          <Checkbox onCheckedChange={(checked) => form.batch((d) => { d.$readOnly = checked ? true : undefined; })}>
            <CheckboxIndicator>✓</CheckboxIndicator>
          </Checkbox>
          阅读态
        </label>
      </p>
      <F.ArrayField name="contacts" component={ContactList}>
        {(row) => (
          <ContactRow>
            <row.Field name="name" component={[TextInput, { placeholder: '姓名' }]} />
            <row.Field name="phone" component={[TextInput, { placeholder: '电话' }]} />
          </ContactRow>
        )}
      </F.ArrayField>
      <F.Watch select={(d) => d.contacts.$value}>{(rows) => <pre>{JSON.stringify(rows, null, 2)}</pre>}</F.Watch>
    </Form>
  );
}
```

- `F = typed(form)` 返回的 `F.ArrayField` 向子函数传入按行类型约束的 `row.Field`；自定义行组件内可用 `useIndex()` 与 `useRecord<Contact>()` 读取行号和行数据。
- 没有业务主键的对象行会自动按对象引用追踪身份，重排后报错和 `touched` 状态仍跟着原行走，正在编辑的输入框也不会失焦；数据本身带唯一 ID 时再传 `rowKey`。在同一次 `batch` 里混用数组句柄方法（`move` / `swap` / `remove` 等）和草稿数组方法（`push`、`splice`、`sort`、`reverse`）时，会按代码调用顺序生效：改过的单元格跟着行移动，删掉的行不会复活，含重复值的普通数组和 `reverse()` 也按顺序作用在最新数据上。
- `array.dragProps(index)` 提供原生 HTML5 拖放属性（不同数组之间互不响应），拖放到目标行自动调用 `move`。
- **非数组值保护**：如果字段当前值被外部改成了非数组（例如字符串、数字或 `BigInt`），继续调用旧数组句柄上的 `push` / `insert` / `remove` / `move` / `swap` / `replace` 时，仅 `null` / `undefined` 允许初始化为空数组；其它非数组值在开发环境会抛出带修复指引的 `ShikiUsageError`，生产环境则忽略该次操作以保护原数据不被覆盖。

## 不可编辑状态控制

表单或数组处于 `readOnly` / `disabled` 时，行内字段与数组路径都会继承对应状态：

```ts
useForm({ initialValues, readOnly: true })          // 详情页：整张表单初始化为阅读态
form.batch((d) => { d.$disabled = true })           // 运行时全局禁用（赋 undefined 恢复）
form.batch((d) => { d.contacts.$readOnly = true })  // 仅将当前数组设为只读
```

自定义数组操作按钮时，根据当前字段的 `readOnly` / `disabled`（本例用 `useWatch(selectContactsEditable)` 订阅数组状态）决定是否渲染增删排序控件。

## 数组自身的错误

当校验规则写在数组路径本身上时（例如 `fields` 中的 `members.*.phones` 或表单根的 `tags`），校验的是整个数组（如「至少添加一项」），而不是数组内部某个单元格。

在 `<ArrayField>` 的容器组件中调用 `useArrayField()`，读取句柄上的 `errors` 和 `warnings`（仅包含这一层数组自身的消息，不含子字段；要连子字段一起看，读 draft 的 `$errors`）。一旦报错显示出来，之后每次增删、移动或替换行都会立即重检该层数组，方便用户改对后即时消错（修改单个单元格不会触发整组重检）。

`useArrayField()` 必须在 `<ArrayField>` 里面（容器或子组件内），与 `<ArrayField>` 平级会抛错；不要把数组级错误写在每一行的渲染函数里（数组为空时行函数不跑，有多行时又会重复画）。

```tsx preview
import type { ReactNode } from 'react';
import { Form, Submit, typed, useArrayField, useField, useForm, useIndex } from '@shikiform/react';

type Phone = { no: string };
type Member = { name: string; phones: Phone[] };
type Values = { members: Member[] };

function TextInput({ placeholder }: { placeholder?: string }) {
  const field = useField<string>();
  return <input value={field.value ?? ''} placeholder={placeholder}
    onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />;
}

function PhoneList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Phone>();
  return (
    <div>
      {children}
      {array.errors.length > 0 && <p role="alert" style={{ color: 'crimson', margin: '4px 0' }}>{array.errors.join('、')}</p>}
      <button type="button" onClick={() => array.push({ no: '' })}>添加电话</button>
    </div>
  );
}

function RemovePhone() {
  const array = useArrayField<Phone>();
  const index = useIndex();
  return <button type="button" onClick={() => array.remove(index)}>删除</button>;
}

export default function App() {
  const form = useForm<Values>({
    initialValues: { members: [{ name: 'Ada', phones: [] }] },
    fields: {
      'members.*.phones': {
        rules: { validator: (phones) => (Array.isArray(phones) && phones.length ? null : '至少一个电话') },
      },
    },
  });
  const F = typed(form);
  return (
    <Form form={form}>
      <F.ArrayField name="members">
        {(member) => (
          <div style={{ border: '1px solid #ddd', padding: 10, marginBottom: 10 }}>
            <div style={{ marginBottom: 8 }}>
              <member.Field name="name" component={[TextInput, { placeholder: '姓名' }]} />
            </div>
            <member.ArrayField name="phones" component={PhoneList}>
              {(phone) => (
                <div style={{ display: 'flex', gap: 6, marginBottom: 6 }}>
                  <phone.Field name="no" component={[TextInput, { placeholder: '电话' }]} />
                  <RemovePhone />
                </div>
              )}
            </member.ArrayField>
          </div>
        )}
      </F.ArrayField>
      <Submit>提交</Submit>
    </Form>
  );
}
```

直接点击「提交」，空的电话列表下方会出现「至少一个电话」提示；点击「添加电话」新增一行后，提示随即消失。

## 可编辑表格：`useArrayTable`

需要分页切片、行勾选、单行复制（含 `createRowKey`）与展开子表时，使用 `@shikiform/react` 的 `useArrayTable` 配合 `<ArrayField.Row>` 提供行作用域：

```tsx preview play=array-table
import { ArrayField, Field, Form, useArrayTable, useField, useForm, useRecord } from '@shikiform/react';

type Row = { id: string; name: string; price: number; qty: number };
let nextId = 4;
const createRow = (): Row => ({ id: String(nextId++), name: '', price: 0, qty: 1 });

function CellText() {
  const field = useField<string>();
  return <input value={field.value ?? ''} onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />;
}

function CellNumber() {
  const field = useField<number>();
  return <input type="number" style={{ width: 72 }} value={field.value ?? 0}
    onChange={(e) => field.onChange(Number(e.target.value))} onBlur={field.onBlur} />;
}

function Subtotal() {
  const row = useRecord<Row>();
  return <span>{((row.price ?? 0) * (row.qty ?? 0)).toFixed(2)}</span>;
}

function PurchaseTable() {
  const table = useArrayTable<Row>('list', {
    rowKey: 'id',
    createRowKey: () => String(nextId++),
    pagination: { pageSize: 5 },
  });
  return (
    <div>
      <div style={{ marginBottom: 8 }}>
        <button type="button" onClick={() => table.add(createRow())}>新增一行</button>
      </div>
      <table>
        <thead>
          <tr><th>#</th><th>名称</th><th>单价</th><th>数量</th><th>小计</th><th>操作</th></tr>
        </thead>
        <tbody>
          {table.pageRows.map(({ key, index, position }) => (
            <ArrayField.Row key={key} path={`list.${index}`} index={index} itemKey={key}>
              <tr>
                <td>{position}</td>
                <td><Field name="name" required component={[CellText]} /></td>
                <td><Field name="price" component={[CellNumber]} /></td>
                <td><Field name="qty" component={[CellNumber]} /></td>
                <td><Subtotal /></td>
                <td>
                  <button type="button" onClick={() => table.copy(index)}>复制</button>{' '}
                  <button type="button" onClick={() => void table.remove(index)}>删除</button>
                </td>
              </tr>
            </ArrayField.Row>
          ))}
        </tbody>
      </table>
    </div>
  );
}

export default function App() {
  const form = useForm<{ list: Row[] }>({
    initialValues: { list: [
      { id: '1', name: '钢笔', price: 12, qty: 2 },
      { id: '2', name: '笔记本', price: 8.5, qty: 3 },
      { id: '3', name: '墨水', price: 20, qty: 1 },
    ] },
  });
  return <Form form={form}><PurchaseTable /></Form>;
}
```

分页、勾选、展开状态不进入表单值；如需列显隐、列宽和密度设置，搭配 `@shikiform/react` 的 [`useColumnSettings`](/reference/pro-hooks#usecolumnsettings)。

## 其他数组方案的选择

- 自定义行布局与按钮：直接使用 `<ArrayField>` 配合 `useArrayField()` / `useIndex()`，见 [字段路径与结构](/guide/structures)。
- 带筛选条件的分页表格：使用 [`useQueryTable`](/guide/pro#查询列表)。
- 大行数虚拟列表：使用 `<ArrayField name virtualScroll={{ height }}>`，只渲染可视区域内的行，并用稳定行 key 维护组件状态——在可视窗口里重排行时，行组件的本地状态不会错位，见 [数组示例 · 长列表](/examples/arrays)。
- API 参考：[useArrayField](/reference/react-hooks#usearrayfield)、[useArrayTable](/reference/pro-hooks#usearraytable)。
