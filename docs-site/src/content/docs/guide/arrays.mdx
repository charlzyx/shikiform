---
title: 数组容器 ArrayItems / ArrayCards / ArrayTable
description: 给 ArrayField 一个容器组件，就有添加、删除、上下移、拖拽排序、序号和空状态；ArrayTable 是带分页、选择、列配置的 antd 表格。
---

[`<ArrayField>`](/guide/structures) 只管作用域和行身份，按钮要自己写：`useArray()` + `useIndex()` 拼删除、上移、下移，再判断数组是不是可编辑。`@shikiform/antd` 把这些写成了 Formily 式的容器：

| 容器 | 每一行 | 内置 |
|---|---|---|
| `ArrayItems` | 你写 `ArrayItems.Item`（一行横排） | `SortHandle`、`Index`、`Remove`、`MoveUp`、`MoveDown`、`Addition`，空状态 |
| `ArrayCards` | 自动包成一张卡片，标题 `title #序号` | 卡片右上角默认 上移 / 下移 / 删除，可拖拽排序，空状态 |
| `ArrayTable` | antd 表格的一行，单元格来自 `columns` | 同一批行按钮 + `Copy` / `ShadowAddition`，分页、勾选、展开子表、列配置、列宽 |

容器是 `<ArrayField>` 的 `component`，和 `<Field component>` 一样可以写 `[组件, props]`（props 按容器检查类型）。它渲染在数组的作用域里，所以按钮不需要数组名和行号。三个容器只有这一种接法。

## ArrayItems

```tsx preview
import { Switch } from 'antd';
import { Form, typed, useForm } from '@shikiform/react';
import { ArrayItems, FormItem, Input } from '@shikiform/antd';

type Contact = { name: string; phone: string };
type Values = { contacts: Contact[] };

export default function App() {
  const form = useForm<Values>({
    initialValues: { contacts: [{ name: 'Ada', phone: '100' }, { name: 'Charles', phone: '200' }] },
    fields: { 'contacts.*.name': { required: true } },
  });
  const F = typed(form);
  return (
    <Form form={form}>
      <p>
        阅读态 <Switch aria-label="阅读态" onChange={(on) => form.batch((d) => { d.$pattern = on ? 'readPretty' : undefined; })} />
      </p>
      <F.ArrayField name="contacts" component={[ArrayItems, { addition: <ArrayItems.Addition title="添加联系人" /> }]}>
        {(row) => (
          <ArrayItems.Item>
            <ArrayItems.SortHandle />
            <ArrayItems.Index />
            <row.Field name="name" decorator={[FormItem]} component={[Input, { placeholder: '姓名' }]} />
            <row.Field name="phone" decorator={[FormItem]} component={[Input, { placeholder: '电话' }]} />
            <ArrayItems.MoveUp />
            <ArrayItems.MoveDown />
            <ArrayItems.Remove />
          </ArrayItems.Item>
        )}
      </F.ArrayField>
      <F.Watch select={(d) => d.contacts.$value}>{(rows) => <pre>{JSON.stringify(rows, null, 2)}</pre>}</F.Watch>
    </Form>
  );
}
```

- `F = typed(form)`：`F.ArrayField` 的 `row.Field` 按一行（`Contact`）检查名字；行里的自定义组件用 `useIndex()` / `useRecord<Contact>()` 读这一行。
- 行**不需要 id**。没有 `rowKey` / `id` 的对象行用对象身份当 key，移动后错误、touched 跟着行走；单元格编辑不会换 key。只有行里本来就有业务 id 时才传 `rowKey`。
- 拖拽：按住 `⋮⋮` 拖到另一行上松开，等于 `array.move(from, to)`（HTML5 拖放，没有额外依赖）。拖放载荷带源数组路径，跨数组（或跨树）放置会被忽略。`MoveUp` / `MoveDown` 是键盘可用的同一操作，首行 / 末行禁用。
- `Addition` 默认追加 `{}`；`defaultValue` 可以是值（每次克隆）或函数，`method="unshift"` 插到最前。
- 没有行时显示 antd `Empty`；`empty={<span>还没有联系人</span>}` 换内容，`empty={false}` 不显示。

## 不可编辑时按钮自动消失

`Addition`、`Remove`、`MoveUp`、`MoveDown`、`SortHandle` 只在数组的**有效 pattern** 是 `editable` 时渲染；`Index` 一直显示。有效 pattern 沿祖先继承到根，所以这些写法都会让按钮消失：

```ts
useForm({ initialValues, pattern: 'readPretty' })        // 整张表从阅读态开始（详情页）
form.batch((d) => { d.$pattern = 'disabled' })            // 运行时切整张表；undefined 恢复
form.batch((d) => { d.contacts.$pattern = 'readOnly' })   // 只锁这个数组
```

`ArrayTable` 的行操作（`SortHandle`、`Remove`、`MoveUp`、`MoveDown`、`Copy`、`Addition`、`ShadowAddition`）遵守同一条规则。自己写的行操作用 `useArrayEditable()` 做同样的判断。

## ArrayCards

```tsx preview
import { Form, typed, useForm } from '@shikiform/react';
import { ArrayCards, FormItem, FormLayout, Input, InputNumber } from '@shikiform/antd';

type Item = { sku: string; qty: number };

export default function App() {
  const form = useForm<{ items: Item[] }>({ initialValues: { items: [{ sku: 'A-1', qty: 2 }] } });
  const F = typed(form);
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <F.ArrayField
          name="items"
          component={[ArrayCards, { title: '商品', addition: <ArrayCards.Addition defaultValue={() => ({ sku: '', qty: 1 })} /> }]}
        >
          {(row) => (
            <>
              <row.Field name="sku" title="SKU" required decorator={[FormItem]} component={[Input]} />
              <row.Field name="qty" title="数量" decorator={[FormItem]} component={[InputNumber, { min: 1 }]} />
            </>
          )}
        </F.ArrayField>
      </FormLayout>
    </Form>
  );
}
```

行的字段就是卡片内容，不需要包装组件。`extra` 换掉右上角的默认按钮（`extra={<ArrayCards.Remove confirm />}`）。

## 数组自身的错误

规则写在数组路径上时，校验的是这一层数组，不是某一格。`fields` 里的 `members.*.phones`、根上的 `tags`，都是这种规则。`ArrayItems` 和 `ArrayCards` 把**这一层自己的**错误和警告画在各行与添加按钮之间，样式与 `FormItem` 的反馈行相同（错误色 / 警告色）。行里字段的消息仍在各自的 `FormItem` 上，不会在这里再出现一次。

第一次出现仍要等到提交，或该字段自己的校验时机。已经显示之后，增删、移动或替换一行会立刻重跑这一层（和改一个已经报错的输入一样），不用再提交一次。改某一格不会重跑数组这一层。新行上的 `required` 不会因此提前冒出来。

`feedback={false}` 关掉这块。外层 `<FormLayout feedbackLayout="none">` 同样不显示。

自己画列表时用 [`useArrayErrors()`](/reference/react-hooks#usearrayerrors)。它只返回这一层路径上的 `errors` / `warnings`。子字段的合计是 draft 上的 `$errors`，两者不是一回事。

调用它的组件必须渲染在 `<ArrayField>` 的子树里：作为 `component` 容器（容器包住各行，数组为空也会挂上），或放进容器仍会渲染的位置。`ArrayTable` 不画这条反馈；要画在表格下方时，把组件交给 `footer`。`footer` 由 `ArrayTable` 渲染，而 `ArrayTable` 在这个数组的作用域里。和 `<ArrayField>` 平级再挂一个兄弟节点（表格下面另写一个组件）会抛错。开发构建抛 `ShikiUsageError`，消息是 `useArrayErrors() must render inside an <ArrayField> (its container, or a row).`。生产构建抛 `Error`，消息是 `useArrayErrors() must render inside an <ArrayField>`。

行 children 里调用也在作用域内，但数组为空时行函数不会执行，这条错误就出不来；有多行时每一行都会画一次。数组这一层的提示放在容器或 `footer`，不要放进行回调。

```tsx
import type { ReactNode } from 'react'
import { ArrayField, useArrayErrors } from '@shikiform/react'
import { ArrayTable, type ArrayTableColumn } from '@shikiform/antd'

function ArrayMessage() {
  const { errors } = useArrayErrors()
  if (!errors.length) return null
  return <p role="alert">{errors.join('、')}</p>
}

function MyList({ children }: { children?: ReactNode }) {
  return (
    <div>
      {children}
      <ArrayMessage />
    </div>
  )
}

const columns: ArrayTableColumn[] = [{ key: 'name', title: '名称', render: () => null }]

// ✓ 容器、footer 都在 <ArrayField> 里面
function Correct() {
  return (
    <>
      <ArrayField name="tags" component={[MyList]}>{() => <span />}</ArrayField>
      <ArrayField name="list" component={[ArrayTable, { columns, footer: <ArrayMessage /> }]} />
    </>
  )
}

// ✗ 和 <ArrayField> 平级，渲染时抛上面的 ShikiUsageError
function Wrong() {
  return (
    <>
      <ArrayField name="list" component={[ArrayTable, { columns }]} />
      <ArrayMessage />
    </>
  )
}
```

```tsx preview
import { Form, typed, useForm } from '@shikiform/react';
import { ArrayItems, FormItem, Input, Submit } from '@shikiform/antd';

type Phone = { no: string };
type Member = { name: string; phones: Phone[] };
type Values = { members: Member[] };

export default function App() {
  const form = useForm<Values>({
    initialValues: { members: [{ name: 'Ada', phones: [] }] },
    fields: {
      'members.*.phones': {
        rules: { validator: (phones) => (Array.isArray(phones) && phones.length ? null : '至少一个电话') },
      },
    },
  });
  const F = typed(form);
  return (
    <Form form={form}>
      <F.ArrayField name="members" component={[ArrayItems]}>
        {(member) => (
          <ArrayItems.Item>
            <member.Field name="name" decorator={[FormItem]} component={[Input, { placeholder: '姓名' }]} />
            <div style={{ flex: 1 }}>
              <member.ArrayField
                name="phones"
                component={[ArrayItems, { addition: <ArrayItems.Addition title="添加电话" defaultValue={{ no: '' }} /> }]}
              >
                {(phone) => (
                  <ArrayItems.Item>
                    <phone.Field name="no" decorator={[FormItem]} component={[Input, { placeholder: '电话' }]} />
                    <ArrayItems.Remove />
                  </ArrayItems.Item>
                )}
              </member.ArrayField>
            </div>
          </ArrayItems.Item>
        )}
      </F.ArrayField>
      <Submit />
    </Form>
  );
}
```

点「提交」：空的电话列表下面出现「至少一个电话」。点「添加电话」后这条消失。姓名字段如果再加 `required`，它的「必填」只出现在姓名的 `FormItem` 下。

## ArrayTable

一张 antd 表格。单元格来自 `columns`，所以 `<ArrayField>` 不写行 children；列的 `render` 运行在**行作用域**里：`<Field name="name">` 就是 `list.N.name`，单元格可以不要装饰器。行内用 `ArrayTable.useRow()`（`{ key, index, position, record }`），或直接用 `useArray()` / `useIndex()` / `useRecord()`。

```tsx preview play=array-table
import { Field, Form, typed, useForm } from '@shikiform/react';
import { ArrayTable, FormItem, Input, InputNumber, type ArrayTableColumn } from '@shikiform/antd';

type Row = { id: string; name: string; price: number; qty: number };
let nextId = 4;
const createRow = (): Row => ({ id: String(nextId++), name: '', price: 0, qty: 1 });

function Subtotal() {
  const { record } = ArrayTable.useRow();
  return <span>{((record.price ?? 0) * (record.qty ?? 0)).toFixed(2)}</span>;
}

const columns: ArrayTableColumn<Row>[] = [
  { key: 'sort', width: 48, render: () => <ArrayTable.SortHandle /> },
  { key: 'index', title: '#', width: 48, render: () => <ArrayTable.Index /> },
  { key: 'name', title: '名称', width: 200, render: () => <Field name="name" required decorator={[FormItem, { feedbackLayout: 'terse' }]} component={[Input]} /> },
  { key: 'price', title: '单价', width: 120, render: () => <Field name="price" component={[InputNumber, { min: 0 }]} /> },
  { key: 'qty', title: '数量', width: 100, render: () => <Field name="qty" component={[InputNumber, { min: 1 }]} /> },
  { key: 'subtotal', title: '小计', width: 100, align: 'right', render: () => <Subtotal /> },
  { key: 'actions', title: '操作', width: 140, render: () => <><ArrayTable.Copy /><ArrayTable.Remove confirm /></> },
];

export default function App() {
  const form = useForm<{ list: Row[] }>({
    initialValues: { list: [
      { id: '1', name: '钢笔', price: 12, qty: 2 },
      { id: '2', name: '笔记本', price: 8.5, qty: 3 },
      { id: '3', name: '墨水', price: 20, qty: 1 },
    ] },
  });
  const F = typed(form);
  return (
    <Form form={form}>
      <F.ArrayField name="list" rowKey="id" component={[ArrayTable, {
        title: '采购清单',
        rowSelection: true,
        pagination: { pageSize: 5 },
        columns,
        extra: (
          <>
            <ArrayTable.Addition defaultValue={createRow} />
            <ArrayTable.ShadowAddition<Row> title="弹窗添加" onOk={(values, table) => { table.add({ ...createRow(), ...values }); return false; }}>
              <Field name="name" title="名称" required decorator={[FormItem]} component={[Input]} />
              <Field name="price" title="单价" decorator={[FormItem]} component={[InputNumber, { min: 0 }]} />
            </ArrayTable.ShadowAddition>
          </>
        ),
      }]} />
    </Form>
  );
}
```

拖动 ⋮⋮ 排序、勾选行、在弹窗里添加（先校验再写回）、复制和删除。展开子表、列宽拖拽、异步删除、10 万行见 [/play/array-table](/play/array-table)。表格状态（分页、勾选、展开、列配置）不进表单值；无 UI 的同一套状态是 `useArrayTable`（`@shikiform/hooks`）。

## 和其他数组组件的关系

- 只要作用域、按钮自己画：`<ArrayField>` + `useArray()` / `useIndex()`，见 [数组、树与嵌套对象](/guide/structures)。数组自身的错误用 [`useArrayErrors()`](/reference/react-hooks#usearrayerrors)，写在 `<ArrayField>` 的容器或 `footer` 里，不要和 `<ArrayField>` 平级。
- 查询条件 + 服务端分页的表格：[`QueryList`](/guide/pro#查询列表)，它内部就是一张 `ArrayTable`。
- 很长的名单只渲染可见行：`<ArrayField name virtualScroll={{ height }}>`（普通行，不和容器同用），见 [示例 · 虚拟滚动](/examples/arrays)。
- 参数表：[ArrayItems](/reference/antd#arrayitems)、[ArrayCards](/reference/antd#arraycards)、[ArrayTable](/reference/antd#arraytable)、[useArrayEditable](/reference/antd#usearrayeditable)。
