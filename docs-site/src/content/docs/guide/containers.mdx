---
title: 分组容器 FormTab / FormCollapse / FormStep
description: 将大型表单拆分为标签页、折叠面板或分步向导，保持所有字段挂载和校验有效，并在提交失败时自动定位到出错面板。
---

当表单字段较多时，通常需要拆分成标签页、折叠面板或分步向导来组织界面。但如果直接用原生的 Ant Design `Tabs` 或 `Collapse`，未激活的面板默认不会渲染，导致里面的 `<Field>` 规则无法注册生效，切换面板后也无法直观看出哪一页存在校验报错。

`@shikiform/antd` 提供的 `FormTab`、`FormCollapse` 和 `FormStep` 专门解决了这些问题：
- **保持字段挂载**：所有面板都会保持渲染（非当前面板仅做视觉隐藏），用户输入的数据、JSX 校验规则和报错状态始终保留，提交时自动校验全部面板。
- **错误角标提示**：标签页或折叠面板的标题上会自动显示内部出错字段的数量，分步条上也会把包含错误的步骤标记为异常状态。
- **自动定位报错**：点击提交或调用 `form.validate()` 发现错误时，容器会自动切换到包含错误字段的面板或步骤，随后表单将焦点定位到第一个出错控件。
- **纯视图容器**：这些容器不对应任何数据路径，内部字段名按正常规则书写即可；外层的 `$pattern` 与 `$display` 状态也会照常继承下去。

所有面板组件必须作为对应容器的直接子元素（支持包裹在 Fragment 中或使用条件表达式）。

## FormTab

```tsx preview
import { useState } from 'react';
import { Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormItem, FormLayout, FormTab, Input, Submit } from '@shikiform/antd';

type Values = { name: string; email: string; phone: string; note: string };

export default function App() {
  const form = useForm<Values>({ initialValues: { name: '', email: '', phone: '', note: '' } });
  const F = typed(form);
  const [saved, setSaved] = useState<Values>();
  return (
    <Form form={form} onSubmit={setSaved} data-form-tab-demo="">
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 16 }}>
        <FormTab>
          <FormTab.Pane name="base" tab="基本信息">
            <F.Field name="name" title="姓名" required decorator={[FormItem]} component={[Input]} />
          </FormTab.Pane>
          <FormTab.Pane name="contact" tab="联系方式">
            <F.Field name="email" title="邮箱" required rules={{ format: 'email' }} decorator={[FormItem]} component={[Input]} />
            <F.Field name="phone" title="电话" required decorator={[FormItem]} component={[Input]} />
          </FormTab.Pane>
          <FormTab.Pane name="more" tab="其他">
            <F.Field name="note" title="备注" decorator={[FormItem]} component={[Input.TextArea]} />
          </FormTab.Pane>
        </FormTab>
        <FormButtonGroup.FormItem>
          <Submit />
        </FormButtonGroup.FormItem>
      </FormLayout>
      {saved && <pre>{JSON.stringify(saved, null, 2)}</pre>}
    </Form>
  );
}
```

直接点击「提交」可以看到，即使「联系方式」标签页从未被点开过，里面的两个必填项依然参与了校验，并在标签头上显示错误计数 `2`。如果先填好「姓名」再提交，容器会自动切到「联系方式」并将焦点移至「邮箱」输入框（存在错误时提交按钮处于禁用状态，改对后会重新启用）。

`FormTab` 支持透传 Ant Design `Tabs` 的其余属性（如 `type`、`size`、`tabPosition` 等）；非受控模式用 `defaultActiveKey`，受控模式用 `activeKey` 与 `onChange(key)`（`key` 对应 `Pane` 的 `name`，未指定时默认取下标字符串）。`FormTab.Pane` 接收 `name?`、`tab`、`disabled?`。

## FormCollapse

```tsx preview
import { useState } from 'react';
import { Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormCollapse, FormItem, FormLayout, Input, InputNumber, Submit } from '@shikiform/antd';

type Values = { title: string; price: number | null; stock: number | null };

export default function App() {
  const form = useForm<Values>({ initialValues: { title: '', price: null, stock: null } });
  const F = typed(form);
  const [saved, setSaved] = useState<Values>();
  return (
    <Form form={form} onSubmit={setSaved}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 16 }}>
        <FormCollapse defaultActiveKey={['base']}>
          <FormCollapse.Panel name="base" header="商品">
            <F.Field name="title" title="标题" required decorator={[FormItem]} component={[Input]} />
          </FormCollapse.Panel>
          <FormCollapse.Panel name="sale" header="价格与库存">
            <F.Field name="price" title="价格" required decorator={[FormItem]} component={[InputNumber, { min: 0 }]} />
            <F.Field name="stock" title="库存" required decorator={[FormItem]} component={[InputNumber, { min: 0 }]} />
          </FormCollapse.Panel>
        </FormCollapse>
        <FormButtonGroup.FormItem>
          <Submit />
        </FormButtonGroup.FormItem>
      </FormLayout>
      {saved && <pre>{JSON.stringify(saved, null, 2)}</pre>}
    </Form>
  );
}
```

`FormCollapse` 默认展开全部面板（若开启手风琴模式 `accordion`，则默认只展开第一个）。支持传入 `defaultActiveKey` 或受控的 `activeKey` + `onChange(keys)`（类型为 `string[]`），其余 props 透传给 Ant Design `Collapse`；`FormCollapse.Panel` 支持 `name?`、`header`、`extra?`、`collapsible?`。

## FormStep

分步表单的状态通过 `useFormStep()` 创建，通常在按钮所在的父组件中初始化后传给 `<FormStep step={step}>`：

| 成员 | 说明 |
|---|---|
| `current` / `count` | 当前步骤下标（从 0 开始）以及总步数 |
| `isFirst` / `isLast` | 是否处于第一步或最后一步 |
| `next(): Promise<boolean>` | **仅校验当前步骤**内的可编辑字段（单次调用 `form.validate(paths)`），校验失败时停留在当前步并返回 `false` |
| `back()` / `goTo(i)` | 直接切换步骤，不触发校验 |

最后一步直接使用普通的 `<Submit />` 按钮，提交时会完整校验所有步骤的字段，如有错误会在步骤条上高亮标红。

```tsx preview
import { Button } from 'antd';
import { useState } from 'react';
import { Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormItem, FormLayout, FormStep, Input, Submit, useFormStep } from '@shikiform/antd';

type Values = { account: string; password: string; nickname: string; bio: string };

export default function App() {
  const form = useForm<Values>({ initialValues: { account: '', password: '', nickname: '', bio: '' } });
  const step = useFormStep();
  const F = typed(form);
  const [saved, setSaved] = useState<Values>();
  return (
    <Form form={form} onSubmit={setSaved} data-form-step-demo="">
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 16 }}>
        <FormStep step={step}>
          <FormStep.Step title="账号">
            <F.Field name="account" title="账号邮箱" required rules={{ format: 'email' }} decorator={[FormItem]} component={[Input]} />
            <F.Field name="password" title="密码" required rules={{ minLength: 6 }} decorator={[FormItem]} component={[Input.Password]} />
          </FormStep.Step>
          <FormStep.Step title="资料">
            <F.Field name="nickname" title="昵称" required decorator={[FormItem]} component={[Input]} />
          </FormStep.Step>
          <FormStep.Step title="完成">
            <F.Field name="bio" title="简介" decorator={[FormItem]} component={[Input.TextArea]} />
          </FormStep.Step>
        </FormStep>
        <FormButtonGroup.FormItem>
          <Button disabled={step.isFirst} onClick={step.back}>上一步</Button>
          {step.isLast ? <Submit /> : <Button type="primary" onClick={step.next}>下一步</Button>}
        </FormButtonGroup.FormItem>
      </FormLayout>
      {saved && <pre data-step-result="">{JSON.stringify(saved, null, 2)}</pre>}
    </Form>
  );
}
```

- 在步骤切换过程中，非当前步骤的字段处于 `hidden` 状态但依然挂载，返回上一步时输入内容完整保留。
- `next()` 会自动跳过不可编辑的字段（`readPretty` / `readOnly` / `disabled`），因此全表单处于阅读态的详情页也能顺畅点击下一步；而最终提交依然会校验全部字段。
- 需要受控管理步骤时，可使用 `useFormStep({ current, onChange })`（此时 `next` / `back` / `goTo` 仅触发 `onChange` 回调）；非受控模式下可通过 `defaultCurrent` 指定初始步。`next()` 不会 reject，若表单级校验抛错则停留在原步骤并在控制台输出错误。
- `FormStep` 其余 props 透传至 Ant Design `Steps`；`FormStep.Step` 支持 `name?`、`title`、`description?`、`subTitle?`、`icon?`。

## 提交失败时的自动展开与聚焦

无论是点击 `<Submit />`、表单内回车、调用 `form.submit()` 还是手动执行 `form.validate()`，只要发现校验错误，三个容器都会自动执行定位（无需额外配置）：

| 容器 | 自动展开行为 |
|---|---|
| `FormTab` | 自动切换到**第一个**包含出错字段的标签页 |
| `FormCollapse` | 自动展开**所有**包含出错字段的面板（手风琴模式下则展开第一个） |
| `FormStep` | 自动跳转至**最早**包含出错字段的步骤 |

面板切换完毕后，`<Form>` 会按页面 DOM 顺序将焦点定位到第一个出错的控件（控件 `id` 由 `<Form id>` 或 `useId()` 前缀加上字段路径生成，如果目标元素不可聚焦则会滚动至可视区域）。需要注意，输入或失焦触发的常规校验不会自动切页；使用受控模式时容器只会触发 `onChange`，是否切换由外部状态决定。如果存在容器嵌套（如折叠面板中嵌标签页），内外层会协同切换到目标面板。

如果需要为自定义容器接入同款定位能力，可以通过 `form.subscribeValidateFailed((errors) => …)` 订阅校验失败事件。

## 自定义区域

分组、徽标和「只校验这一步」由 `FormTab` / `FormCollapse` / `FormStep` 完成。字段分组原语不从 `@shikiform/react` 的公开入口导出。自己要在校验失败时切到某一块，用 `form.subscribeValidateFailed((errors) => …)`，再对那一块字段调用一次 `form.validate(paths)`。
