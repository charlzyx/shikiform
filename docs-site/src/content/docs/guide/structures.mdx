title: 字段路径与结构
description: 使用 ObjectField、ArrayField 和 TreeField 建立相对路径作用域，通过 rowKey 或行模板保持行状态随数据移动。
---

当表单数据结构包含多层嵌套对象、动态列表或树形结构时，把所有 `<Field>` 都写成 `profile.address.city`、`contacts.2.phone` 这样的绝对路径既繁琐，又难以应对数组行的增删和排序。ShikiForm 提供了三个结构组件，用来为子字段划定路径作用域：

| 结构组件 | 提供的路径作用域 | 常用操作方式 |
|---|---|---|
| `<ObjectField name="profile">` | `profile.*` | — |
| `<ArrayField name="items" rowKey="id">` | 每行内为 `items.N.*` | `useArrayField(name?)`：`push` / `insert` / `remove` / `move` / `swap` / `replace`。不传 name 取最近一层 |
| `<TreeField name="nodes">` | 每个树节点内为对应节点路径，子节点传入 `node.children` | `useTreeField(name)` 是整棵树，`path` 与 `treePath` 都是树根。节点里 `useTreeField()` 是当前节点：`path` 是句柄指向的字段路径，`treePath` 是这棵树的根路径，并带上 `pos`、`index` 和树的 `push` / `insert` / `remove` / `replace` / `move` / `dragProps` |

## 对象与数组示例

```tsx preview
import { type ReactNode } from 'react';
import { Button, Space } from 'antd';
import { ArrayField, Field, Form, ObjectField, Watch, useArrayField, useIndex, useForm, type Draft } from '@shikiform/react';
import { FormItem, FormLayout, Input } from '@shikiform/antd';

type Contact = { id: number; name: string; phone: string };
type Values = { profile: { name: string; address: { city: string } }; contacts: Contact[] };

let nextId = 3;

/** 行内操作：不需要知道数组名和行号，从作用域里拿。 */
function RowActions() {
  const array = useArrayField<Contact>();
  const index = useIndex();
  return (
    <Space.Compact>
      <Button disabled={index === 0} onClick={() => array.move(index, index - 1)}>上移</Button>
      <Button disabled={index === array.keys.length - 1} onClick={() => array.move(index, index + 1)}>下移</Button>
      <Button danger onClick={() => array.remove(index)}>删除</Button>
    </Space.Compact>
  );
}

/** 添加按钮放在 `<ArrayField component>` 里，这样 `useArrayField()` 能拿到这一层数组。 */
function ContactList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Contact>();
  return (
    <>
      {children}
      <Button onClick={() => array.push({ id: nextId++, name: '', phone: '' })}>添加联系人</Button>
    </>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: {
      profile: { name: 'Ada', address: { city: '伦敦' } },
      contacts: [{ id: 1, name: 'Charles', phone: '100' }, { id: 2, name: 'Mary', phone: '200' }],
    },
    fields: { 'contacts.*.name': { required: true } },
  });
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <ObjectField name="profile">
          <Field name="name" title="姓名" decorator={[FormItem]} component={[Input]} />
          <ObjectField name="address">
            <Field name="city" title="城市" description="path 是 profile.address.city" decorator={[FormItem]} component={[Input]} />
          </ObjectField>
        </ObjectField>
      </FormLayout>
      <ArrayField name="contacts" rowKey="id" component={ContactList}>
        {() => (
          <FormLayout layout="inline" feedbackLayout="terse" style={{ marginBottom: 8 }}>
            <Field name="name" title="联系人" decorator={[FormItem]} component={[Input, { style: { width: 120 } }]} />
            <Field name="phone" title="电话" decorator={[FormItem]} component={[Input, { style: { width: 120 } }]} />
            <RowActions />
          </FormLayout>
        )}
      </ArrayField>
      <Watch select={(d: Draft<Values>) => d.$value}>{(values) => <pre>{JSON.stringify(values, null, 2)}</pre>}</Watch>
    </Form>
  );
}
```

使用数组和结构组件时，有几个关键机制需要留意：
- **行身份与状态跟随**：指定 `rowKey="id"` 后，每一行在引擎中都会绑定一个稳定的身份标识；如果行数据本身没有业务主键，引擎也会自动以对象引用作为唯一标识，因此通常无需刻意伪造 id。当发生上移、下移或删除操作时，错误提示和 `touched` 等字段状态会跟着数据行一起移动。
- **行模板与固定下标的区别**：在 `fields` 中使用 `'contacts.*.name'` 声明的是行模板，它会自动应用到当前及未来新增的所有行上；而写死下标的配置（如 `'contacts.0.name'`）绑定的是「第 0 个位置」本身，行顺序变化后会作用于新的第 0 行。需要让配置跟随具体数据行移动时，请使用行模板或 [`reaction.each`](/guide/linkage#reactioneach每一行一个实例)。
- **使用数组句柄**：增删或调整行顺序时调用 `useArrayField()` / `useArrayField(name)` 上的 `push` / `remove` / `move` 等方法，不要直接原地修改 `getValue` 返回的数组引用，也不要调用 `form.pushArray`。`<ArrayField>` 只订阅数组的长度与行键变化，修改某个单元格不会导致整张列表重渲染。

如果需要现成的添加、删除、上下移动和拖拽排序按钮，可以使用 [数组容器 ArrayItems / ArrayCards](/guide/arrays)。

### 作用域内的字段名不要重复前缀

由于 `<ObjectField>` 和 `<ArrayField>` 会自动为内部字段拼接外层路径前缀，内部的子字段只能写相对路径。如果在一个 `<F.ObjectField name="group">` 内部，不小心又使用了表单根上解构出来的 `F.Field` 并写了 `name="group.inner"`，TypeScript 虽然能通过类型检查（因为根表单确实存在 `group.inner`），但运行时路径会被重复拼接成 `group.group.inner`。开发模式下，当拼接后的路径没有值而根路径存在值时，引擎会抛出 `ShikiUsageError` 提示。

```tsx
const F = typed(form)

// ✗ 类型检查能过，但运行时会被拼接成 group.group.inner 并报错
<F.ObjectField name="group">
  <F.Field name="group.inner" />
</F.ObjectField>

// ✓ 使用函数子节点提供的 obj.Field，在享受类型检查的同时写相对路径
<F.ObjectField name="group">
  {(obj) => <obj.Field name="inner" />}
</F.ObjectField>
```

同理，在数组行内也应直接写 `name` 而不是 `items.0.name`。关于作用域类型推导的详细说明见 [typed](/reference/react-hooks#typed)。

对于树形数据，使用 `<TreeField name rowKey>` 为每个节点自动建立作用域并传入 `node.children` 递归渲染，同时在创建表单时通过 `trees` 选项注册树根路径，以便联动在挂载前就能识别树结构。具体示例见 [联动 · 嵌套对象数组与树](/guide/linkage#嵌套对象数组与树) 和 [Headless Hooks](/guide/headless)。

## 按路径精准更新嵌套值

在 `reaction` 中更新嵌套对象中的某个字段时，应当直接赋值到目标字段路径，这样只有订阅了该字段的组件和联动会重新执行；如果给父对象整体赋一个新对象，则所有读取父对象的订阅都会被唤醒：

```ts
d.user.name.$value = 'x'                              // ✓ 精准修改单个字段，影响范围最小
d.user.$value = { ...d.user.$value, name: 'x' }       // 整体替换对象，会触发所有 user 读取者重跑
d.user.$value.name = 'x'                              // ✗ 直接修改不可变快照，开发环境会报错
d.items.$value = [...d.items.$value, row]             // 联动里整体替换数组。组件里用 useArrayField().push(row)
```

与表单值不同，`$componentProps` 这类对象型的 UI 状态支持按键深合并，具体规则见 [UI 状态三层叠加](/guide/field#ui-状态三层叠加)。
