title: 字段路径与结构
description: 使用 ObjectField、ArrayField 和 TreeField 建立相对路径作用域，通过 rowKey 或行模板保持行状态随数据移动。
---

表单包含嵌套对象、动态数组或树结构时，使用以下三个结构组件为内部字段建立相对路径作用域，避免手写 `profile.address.city`、`contacts.2.phone` 这类绝对路径：

| 结构组件 | 提供的路径作用域 | 常用操作方式 |
|---|---|---|
| `<ObjectField name="profile">` | `profile.*` | — |
| `<ArrayField name="items" rowKey="id">` | 每行内为 `items.N.*` | `useArrayField(name?)`：`push` / `insert` / `remove` / `move` / `swap` / `replace`。不传 name 取最近一层 |
| `<TreeField name="nodes">` | 每个树节点内为对应节点路径，子节点传入 `node.children` | `useTreeField(name)` 是整棵树，`path` 与 `treePath` 都是树根。节点里 `useTreeField()` 是当前节点：`path` 是句柄指向的字段路径，`treePath` 是这棵树的根路径，并带上 `pos`、`index` 和树的 `push` / `insert` / `remove` / `replace` / `move` / `dragProps` |

## 对象与数组示例

```tsx preview
import { type ReactNode } from 'react';
import { ArrayField, Field, Form, ObjectField, Watch, useArrayField, useField, useIndex, useForm, type Draft } from '@shikiform/react';

type Contact = { id: number; name: string; phone: string };
type Values = { profile: { name: string; address: { city: string } }; contacts: Contact[] };

let nextId = 3;

function TextInput({ width }: { width?: number }) {
  const field = useField<string>();
  return (
    <label style={{ display: 'inline-flex', alignItems: 'center', gap: 4 }}>
      <span>{field.title}</span>
      <input id={field.id} style={width ? { width } : undefined} value={field.value ?? ''}
        onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
      {field.description && <small style={{ opacity: 0.7 }}>{field.description}</small>}
      {field.errors[0] && <small role="alert" style={{ color: 'crimson' }}>{field.errors[0]}</small>}
    </label>
  );
}

/** 行内操作：不需要知道数组名和行号，从作用域里拿。 */
function RowActions() {
  const array = useArrayField<Contact>();
  const index = useIndex();
  return (
    <span style={{ display: 'inline-flex', gap: 4 }}>
      <button type="button" disabled={index === 0} onClick={() => array.move(index, index - 1)}>上移</button>
      <button type="button" disabled={index === array.keys.length - 1} onClick={() => array.move(index, index + 1)}>下移</button>
      <button type="button" onClick={() => array.remove(index)}>删除</button>
    </span>
  );
}

/** 添加按钮放在 `<ArrayField component>` 里，这样 `useArrayField()` 能拿到这一层数组。 */
function ContactList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Contact>();
  return (
    <div>
      {children}
      <button type="button" onClick={() => array.push({ id: nextId++, name: '', phone: '' })}>添加联系人</button>
    </div>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: {
      profile: { name: 'Ada', address: { city: '伦敦' } },
      contacts: [{ id: 1, name: 'Charles', phone: '100' }, { id: 2, name: 'Mary', phone: '200' }],
    },
    fields: { 'contacts.*.name': { required: true } },
  });
  return (
    <Form form={form}>
      <ObjectField name="profile">
        <div style={{ marginBottom: 6 }}><Field name="name" title="姓名" component={[TextInput]} /></div>
        <ObjectField name="address">
          <div style={{ marginBottom: 10 }}>
            <Field name="city" title="城市" description="path 是 profile.address.city" component={[TextInput]} />
          </div>
        </ObjectField>
      </ObjectField>
      <ArrayField name="contacts" rowKey="id" component={ContactList}>
        {() => (
          <div style={{ display: 'flex', gap: 8, alignItems: 'center', marginBottom: 8, flexWrap: 'wrap' }}>
            <Field name="name" title="联系人" component={[TextInput, { width: 110 }]} />
            <Field name="phone" title="电话" component={[TextInput, { width: 110 }]} />
            <RowActions />
          </div>
        )}
      </ArrayField>
      <Watch select={(d: Draft<Values>) => d.$value}>{(values) => <pre>{JSON.stringify(values, null, 2)}</pre>}</Watch>
    </Form>
  );
}
```

数组与作用域的几个规则：

- 指定 `rowKey="id"` 后，每行的字段状态绑定到该主键；若行对象没有业务主键，引擎以对象引用作为稳定标识，无需额外构造临时 id。上移、下移或删除行时，`errors`、`touched` 等状态随数据行一起移动。
- `fields` 中的 `'contacts.*.name'` 是行模板，作用于当前及后续新增的所有行；固定下标 `'contacts.0.name'` 绑定第 0 个位置，行重排后作用于新的第 0 行。需要状态跟随数据行移动时使用行模板或 [`reaction.each`](/guide/linkage#reactioneach每一行一个实例)。
- 数组增删改序请调用 `useArrayField()` / `useArrayField(name)` 的 `push` / `remove` / `move` 等方法。开发环境里原地修改 `getValue` / `form.values` 返回的数组会抛 `ShikiUsageError`，不会通知订阅者；`FormInstance` 上没有 `pushArray` / `moveTree`。`<ArrayField>` 仅订阅数组长度与行键列表，修改单元格值不会重渲染整张列表。

现成的可编辑表格与拖拽排序写法见 [动态数组与表格](/guide/arrays)。

### 作用域内的字段名不要重复前缀

`<ObjectField>` 与 `<ArrayField>` 会为内部字段自动拼上当前作用域前缀，子字段必须写相对路径。如果在 `<F.ObjectField name="group">` 内误用根表单的 `F.Field` 写 `name="group.inner"`，TypeScript 按根类型检查能够通过，但运行时路径会被拼成 `group.group.inner`。开发环境下，当拼接路径无值而根路径有值时，引擎会抛出 `ShikiUsageError`。

```tsx
const F = typed(form)

// ✗ 类型检查通过，但运行时拼成 group.group.inner 并抛错
<F.ObjectField name="group">
  <F.Field name="group.inner" />
</F.ObjectField>

// ✓ 使用函数子节点提供的 obj.Field，按当前对象类型检查相对路径
<F.ObjectField name="group">
  {(obj) => <obj.Field name="inner" />}
</F.ObjectField>
```

数组行内同样直接写 `name` 而非 `items.0.name`，详见 [typed](/reference/react-hooks#typed)。

树形数据使用 `<TreeField name rowKey>` 为每个节点建立作用域并传入 `node.children` 递归渲染；若联动需在组件挂载前识别树结构，在创建表单时传入 `trees` 选项。示例见 [联动 · 嵌套对象数组与树](/guide/linkage#嵌套对象数组与树) 与 [Headless Hooks](/guide/headless)。

## 按路径精准更新嵌套值

在 `reaction` 中修改嵌套对象内的某个属性时，直接写入目标子路径，这样只唤醒订阅了该子路径的联动和组件；若对父对象整体赋新引用，所有读取父对象的订阅都会重跑：

```ts
d.user.name.$value = 'Ada'           // 写一个字段
d.extra[key].$value = amount         // 动态键也能直接写，无需读取 extra.$value
delete d.extra.$value[key]           // 删除对象属性
d.items.$value.push(row)             // 追加一行
d.items.$value.splice(index, 1)      // 删除一行，后续行前移
```

如果需要根据全部选中项重新生成列表，可以整体赋值，例如 `d.items.$value = selectedIds.map(makeRow)`。只追加一行时用 `push`，会保留已有行，并走与 `useArrayField().push` 相同的行操作。数组草稿上 `delete items[i]` 会留下空位，长度不变。已注册的树使用树操作。

`$componentProps` 等对象型 UI 状态支持按键深合并，见 [UI 状态三层叠加](/guide/field#ui-状态三层叠加)。
