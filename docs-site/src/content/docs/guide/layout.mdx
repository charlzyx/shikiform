description: 使用 FormLayout 统一表单尺寸与标签宽度，通过 FormGrid 实现响应式多列栅格，并用 FormButtonGroup 对齐操作按钮。
---

如果在每个 `FormItem` 上逐一配置 `labelCol` 和 `size`，代码会非常冗长。`@shikiform/antd` 提供的 `FormLayout` 可以统一控制内部所有 `FormItem` 的布局样式。`FormLayout` 本身不绑定任何字段路径，也支持多层嵌套——内层会与外层逐键合并，并以最近的一层为准。

```tsx preview
import { useState } from 'react';
import { Radio as AntRadio, Space } from 'antd';
import { Field, Form, useForm } from '@shikiform/react';
import { FormItem, FormLayout, Input, Select, type FeedbackLayout } from '@shikiform/antd';

type Layout = 'horizontal' | 'vertical' | 'inline';
type Size = 'small' | 'middle' | 'large';

export default function App() {
  const [layout, setLayout] = useState<Layout>('horizontal');
  const [size, setSize] = useState<Size>('middle');
  const [feedback, setFeedback] = useState<FeedbackLayout>('loose');
  const form = useForm({ initialValues: { name: '', city: undefined, remark: '' } });
  return (
    <>
      <Space wrap style={{ marginBottom: 16 }}>
        <AntRadio.Group size="small" value={layout} onChange={(event) => setLayout(event.target.value)}
          options={['horizontal', 'vertical', 'inline']} optionType="button" />
        <AntRadio.Group size="small" value={size} onChange={(event) => setSize(event.target.value)}
          options={['small', 'middle', 'large']} optionType="button" />
        <AntRadio.Group size="small" value={feedback} onChange={(event) => setFeedback(event.target.value)}
          options={['loose', 'terse', 'popover', 'none']} optionType="button" />
      </Space>
      <Form form={form}>
        <FormLayout layout={layout} size={size} feedbackLayout={feedback} labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
          <Field name="name" title="姓名" required decorator={[FormItem]} component={[Input]} />
          <Field name="city" title="城市" required enum={[{ label: '上海', value: 'sh' }, { label: '北京', value: 'bj' }]}
            decorator={[FormItem]} component={[Select, { style: { minWidth: 120 } }]} />
          {/* 局部覆盖：这一项的标签放到上方 */}
          <FormLayout layout="vertical" labelCol={{ span: 24 }} wrapperCol={{ span: 24 }}>
            <Field name="remark" title="备注（嵌套的 vertical 布局）" decorator={[FormItem]} component={[Input.TextArea]} />
          </FormLayout>
          <button type="button" onClick={() => void form.validate()}>校验，看反馈方式</button>
        </FormLayout>
      </Form>
    </>
  );
}
```

| 属性 | 说明 |
|---|---|
| `layout` | 排列方式：`horizontal`（标签在左）、`vertical`（标签在上）或 `inline`（行内流式排列） |
| `labelCol` / `wrapperCol` / `labelAlign` / `colon` | 与 Ant Design `Form.Item` 一致 |
| `labelWidth` / `wrapperWidth` | 固定列宽（传数字时单位为 `px`），优先级高于 `labelCol` / `wrapperCol` |
| `labelWrap` | 允许过长的标签文本自动换行 |
| `requiredMark` | `true` 显示必填星号、`false` 不显示，或设为 `'optional'` 在非必填项后附加「（可选）」 |
| `tooltipLayout` | 提示显示形式：`icon`（显示 ⓘ 图标）或 `text`（紧跟在标签后的说明文字） |
| `size` | 统一控制内部控件的尺寸（对应 Ant Design `componentSize`） |
| `feedbackLayout` | 错误提示布局：`loose`（默认，始终保留提示行占位）、`terse`（无错误时不留底部空白，适合紧凑表单和表格）、`popover`（悬浮气泡提示）、`none`（仅保留状态边框颜色，不显示文字） |
| `breakpoints` | 配合响应式数组使用的容器宽度断点，默认为 `[720, 1280, 1920]` |
| `className` / `style` | 外层容器样式 |

布局配置的优先级从低到高依次为：`FormLayout` → 字段自身的 `decoratorProps`（含 `fields` 声明、JSX 与 `$decoratorProps`）→ `FormItem` 组件上直接传入的 props。在自定义组件中可通过 `useFormLayout()` 读取当前继承到的布局上下文。

在表格单元格中，通常直接省略 `decorator`，或传入紧凑模式 `decorator={[FormItem, { feedbackLayout: 'terse' }]}`。完整签名见 [FormLayout 参考](/reference/antd-adapter#formlayout)。

## 响应式断点：窄屏自动切换标签位置

`layout`、`labelCol`、`wrapperCol`、`labelWidth`、`wrapperWidth` 和 `labelAlign` 均支持传入数组，根据 `FormLayout` 自身容器的实际宽度（即使嵌在弹窗或侧边栏抽屉里也能准确响应）自动匹配对应档位：

```tsx
<FormLayout layout={['vertical', 'horizontal']} labelWidth={[undefined, 96]} breakpoints={[600]}>
  …
</FormLayout>
```

## 栅格布局：FormGrid

`FormGrid` 用于快速构建自适应的多列表单。它会根据容器宽度自动计算能容纳多少个 `minWidth` 宽度的列（并限制在 `minColumns` 与 `maxColumns` 之间）。需要让某个字段横跨多列时，在装饰器属性中设置 `gridSpan`（例如 `decorator={[FormItem, { gridSpan: 2 }]}`）；普通内容则可用 `GridColumn` 包裹。

```tsx preview
import { useState } from 'react';
import { Field, Form, useForm } from '@shikiform/react';
import { FormButtonGroup, FormGrid, FormItem, FormLayout, GridColumn, Input, Reset, Submit } from '@shikiform/antd';

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm({ initialValues: { keyword: '', owner: '', status: '', from: '', to: '', note: '' } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelWidth={72}>
        <FormGrid maxColumns={3} minWidth={220}>
          <Field name="keyword" title="关键词" decorator={[FormItem]} component={[Input]} />
          <Field name="owner" title="负责人" decorator={[FormItem]} component={[Input]} />
          <Field name="status" title="状态" decorator={[FormItem]} component={[Input]} />
          <Field name="note" title="备注" decorator={[FormItem, { gridSpan: 2 }]} component={[Input]} />
          <GridColumn>
            <FormButtonGroup align="right"><Submit>查询</Submit><Reset /></FormButtonGroup>
          </GridColumn>
        </FormGrid>
      </FormLayout>
      <pre>{result}</pre>
    </Form>
  );
}
```

## 在一个标签下组合多个字段

当 `FormItem` 脱离 `<Field>` 直接在 JSX 中使用时，它就是一个纯布局容器，可以为内部的多个控件提供统一的标签和对齐列宽：

```tsx
<FormItem label="地址" asterisk>
  <Space>
    <Field name="province" required decorator={[FormItem]} component={[Select]} />
    <Field name="city" required decorator={[FormItem]} component={[Select]} />
  </Space>
</FormItem>
```

上面的写法中，内部每个字段各自带有无标签的 `FormItem`，错误信息会分别显示在各自控件下方。与 Formily 一致，没有传入 `label` 的 `FormItem` 不会继承外层 `FormLayout` 的 `labelCol` / `wrapperCol` / `labelWidth`，避免在一行内部产生二次缩进。

### 省略内部装饰器，将错误汇总到外层

对于区号加号码（`Space.Compact`）或日期范围这类紧挨在一起的组合控件，如果每个子字段都各自占一行显示报错，会把版面撑开。此时可以去掉内部 `<Field>` 的 `decorator`，外层的纯布局 `FormItem` 会自动收集并展示它们未被消化的错误信息：

```tsx preview
import { useState } from 'react';
import { Space } from 'antd';
import { Form, typed, useForm } from '@shikiform/react';
import { FormButtonGroup, FormItem, FormLayout, Input, InputNumber, Submit } from '@shikiform/antd';

type Values = { areaCode: string; phoneNumber: string; minAge: number | null; maxAge: number | null };

export default function App() {
  const form = useForm<Values>({ initialValues: { areaCode: '', phoneNumber: '', minAge: null, maxAge: null } });
  const F = typed(form);
  const [result, setResult] = useState('');
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))} data-layout-errors-demo="">
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 16 }}>
        <FormItem label="电话" asterisk>
          <Space.Compact>
            <F.Field name="areaCode" required component={[Input, { placeholder: '区号', style: { width: 80 } }]} />
            <F.Field name="phoneNumber" required rules={{ pattern: /^\d{7,8}$/, message: '号码是 7–8 位数字' }} component={[Input, { placeholder: '号码' }]} />
          </Space.Compact>
        </FormItem>
        <FormItem label="年龄段">
          <Space>
            <F.Field name="minAge" required decorator={[FormItem]} component={[InputNumber, { placeholder: '最小' }]} />
            <F.Field name="maxAge" required decorator={[FormItem]} component={[InputNumber, { placeholder: '最大' }]} />
          </Space>
        </FormItem>
        <FormButtonGroup.FormItem><Submit /></FormButtonGroup.FormItem>
      </FormLayout>
      <pre>{result}</pre>
    </Form>
  );
}
```

汇总规则如下：
- 内部字段自己带有 `FormItem`（如上例「年龄段」）时，错误由内层各自展示，外层不重复。
- 内部字段没有装饰器（如上例「电话」），或者其 `FormItem` 设了 `feedbackLayout: 'none'` 时，错误会自动汇总到外层 `FormItem` 展示，且相同的提示文案会自动去重。
- 多个纯布局 `FormItem` 嵌套时，错误仅由最内层的那一个展示。
- 外层错误汇总只展示错误文案并添加 `ant-form-item-has-error` 样式类，不会强行设置全局 `validateStatus`，因此只有真正出错的那个输入框边框会变红。外层自身的 `feedbackLayout`（如 `terse` / `popover` / `none`）同样正常生效。

## 按钮对齐

使用 `FormButtonGroup.FormItem` 可以自动用空的标签列占位，使操作按钮精确对齐上方表单控件的起始位置（同时兼容 `labelCol` 和 `labelWidth`）；长表单还可以使用 `FormButtonGroup.Sticky` 让操作栏吸底展示。

```tsx
<FormLayout labelWidth={96}>
  …
  <FormButtonGroup.FormItem><Submit /><Reset /></FormButtonGroup.FormItem>
</FormLayout>
```
