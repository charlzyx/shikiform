查询列表、弹窗/抽屉草稿表单以及远程异步输入控件的状态逻辑位于 `@shikiform/hooks`（无 UI 依赖），对应的 Ant Design 视图组件位于 `@shikiform/antd`。行内可编辑表格 `ArrayTable` 属于数组容器，见 [数组容器](/guide/arrays#arraytable)。

| Ant Design 组件（`@shikiform/antd`） | 底层 Hook（`@shikiform/hooks`） | 职责 |
|---|---|---|
| `ShadowModal` / `ShadowDrawer` / `ShadowPopconfirm` / `ShadowForm` | `useShadowForm` | 在独立临时表单中编辑副本，确认并校验通过后再写回宿主表单 |
| `QueryList` | `useQueryTable` | 可折叠筛选栅格 + 服务端分页 `ArrayTable` |
| 选择控件 `prettyType` / `Suggestion` / `CascaderPlus` | `enumItems` / `useSuggestion` / `useLazyCascader` | 枚举阅读态徽标与标签、防抖远程联想、按需懒加载级联 |

## 草稿表单（ShadowForm）

在弹窗或抽屉中编辑单条记录或表格行时，取消操作不应修改主表单的值或 `dirty` 状态。

`ShadowModal`、`ShadowDrawer` 等草稿组件在打开时创建一个独立的 `FormInstance`；点击确认时先校验草稿内部字段，通过后将草稿值交给 `onOk`（或写回绑定路径）；点击取消则直接丢弃该实例，主表单保持不变。

```tsx preview play=shadow-form
import { Button, Descriptions } from 'antd';
import { Field, Form, Watch, useForm, type Draft } from '@shikiform/react';
import { FormItem, Input, Select, ShadowDrawer, ShadowModal } from '@shikiform/antd';

type Info = { domain: string; owner: string; env: string };
type Values = { info: Info };

export default function App() {
  const form = useForm<Values>({
    initialValues: { info: { domain: 'shikiform.dev', owner: 'Ada', env: 'prod' } },
    fields: {
      'info.domain': { title: '域名', required: true, rules: { pattern: /^[a-z0-9.-]+$/, message: '只能包含小写字母、数字、点和横线' } },
      'info.owner': { title: '负责人', required: true },
      'info.env': { title: '环境', enum: [{ label: '生产', value: 'prod' }, { label: '预发', value: 'staging' }] },
    },
  });
  const fields = (
    <>
      <Field name="domain" decorator={[FormItem]} component={[Input]} />
      <Field name="owner" decorator={[FormItem]} component={[Input]} />
      <Field name="env" decorator={[FormItem]} component={[Select]} />
    </>
  );
  return (
    <Form form={form}>
      <Watch select={(d: Draft<Values>) => d.info.$value}>
        {(info) => (
          <Descriptions size="small" column={3} bordered items={[
            { key: 'domain', label: '域名', children: info.domain },
            { key: 'owner', label: '负责人', children: info.owner },
            { key: 'env', label: '环境', children: info.env },
          ]} />
        )}
      </Watch>
      <div style={{ marginTop: 12, display: 'flex', gap: 8 }}>
        <ShadowModal<Info> name="info" title="编辑（弹窗）" trigger={<Button>弹窗编辑</Button>}>
          {fields}
        </ShadowModal>
        <ShadowDrawer<Info> name="info" title="编辑（抽屉）" trigger={<Button>抽屉编辑</Button>}>
          {fields}
        </ShadowDrawer>
      </div>
    </Form>
  );
}
```

需要注意：由于草稿内部是独立表单（`ShadowBody` 会隔离宿主表单、作用域、字段、分组与栅格上下文，仅保留 `FieldKit` 与 `FormLayout`），里面 `<Field>` 的 `name` 是相对于草稿根路径解析的。通过 `name="info"`（或把 `<ShadowModal>` 直接放在表格行内）绑定宿主路径后，打开草稿时会自动复制当前值并继承对应前缀的 `fields` 规则与有效 `readOnly` / `disabled`，确认时自动写回原路径，参见 [/play/array-table-shadow](/play/array-table-shadow)。

## 查询列表

`useQueryTable` 统一管理查询条件、分页状态、表头排序、列筛选、请求竞态以及批量勾选；配套的 `QueryList` 则渲染顶部的可折叠筛选栏和下方的受控分页 `ArrayTable`。由于请求返回的每页列表会直接写入 `rows` 指定的数组字段，因此表格里的单元格同样支持直接行内编辑。

```tsx
const table = useQueryTable({ initialValues: { query: {}, list: [] }, params: 'query', rows: 'list', request })
<QueryList table={table} columns={columns}>
  <Field name="query.domain" title="域名" decorator={[FormItem]} component={[Input]} />
</QueryList>
```

顶部筛选区基于 [`FormGrid`](/guide/layout#栅格布局formgrid) 布局，列数随容器宽度变化。收起时只保留第一行并将「重置 / 查询」置于行末，仅在筛选字段超出单行时展示「展开 / 收起」按钮；列数与跨列通过 `grid` 和 `gridSpan` 配置。

列定义配置 `sorter: true` 或 `filters` 后，操作表头排序与列筛选会携带参数重新请求并回到第 1 页；触发列筛选或点击「查询」会清空已勾选项，单纯翻页或排序则保留勾选。

协议与返回值见 [查询 Hooks](/reference/query-hooks)，在线演示见 [/play/query-list](/play/query-list) 与无 Ant Design 依赖的 [/play/query-native](/play/query-native)。

## 枚举展示、远程联想与懒加载级联

- 枚举阅读态：选择类控件在 `readOnly` 下将值反显为 `label`，传 `prettyType="badge" | "tag"` 可渲染为徽标或彩色标签；表单外使用 `PreviewText.Select`（[/play/pro-enum](/play/pro-enum)、[控件与阅读态](/guide/controls)）。
- `Suggestion`：输入防抖并丢弃过期的并发响应，支持单选、多选与 `labelInValue`（[/play/suggestion](/play/suggestion)）。
- `CascaderPlus`：传入 `loadData(path)` 按需加载各级选项，已有值回显时自动逐级拉取并拼接路径标签（[/play/cascader-plus](/play/cascader-plus)）。

上述输入组件均提供不绑定字段的受控版本（`SuggestionView`、`CascaderPlusView`）。参数说明见 [Pro 组件参考](/reference/pro-components) 与 [Pro Hooks 参考](/reference/pro-hooks)，示例见 [Pro 示例](/examples/pro)。
