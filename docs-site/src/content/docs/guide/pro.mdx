后台表单常见的弹窗编辑、查询列表，不必每次从头搭起（可编辑表格 `ArrayTable` 是数组容器，见 [数组容器](/guide/arrays#arraytable)）。`@shikiform/hooks` 提供无 UI 的 Hooks，`@shikiform/antd` 里的同名组件是它们的薄封装。

| 组件（`@shikiform/antd`） | Hook（`@shikiform/hooks`） | 用途 |
|---|---|---|
| `ShadowModal` / `ShadowDrawer` / `ShadowPopconfirm` / `ShadowForm` | `useShadowForm` / `useArrayShadow` | 影子草稿：在独立引擎里编辑，确认后才写回 |
| `QueryList` | `useQueryTable` | 查询条件 + 服务端分页列表（一张 `ArrayTable`） |
| 选择控件 `prettyType` / `Suggestion` / `CascaderPlus` | `enumItems` / `useSuggestion` / `useLazyCascader` + `useCascaderLabels` | 枚举阅读态（徽标 / 标签）、远程联想、懒加载级联 |

## 影子草稿

编辑到一半想取消，宿主表单不能被改脏。影子表单每次打开都建一个**独立的引擎**：确认时先校验，通过后把值交给 `onOk`，由你决定怎么写回；取消什么都不写。

```tsx preview play=shadow-form
import { Button, Descriptions } from 'antd';
import { Field, Form, Watch, useForm, type Draft } from '@shikiform/react';
import { FormItem, Input, Select, ShadowDrawer, ShadowModal } from '@shikiform/antd';

type Info = { domain: string; owner: string; env: string };
type Values = { info: Info };

export default function App() {
  const form = useForm<Values>({ initialValues: { info: { domain: 'shikiform.dev', owner: 'Ada', env: 'prod' } } });
  const fields = (
    <>
      <Field name="domain" title="域名" required rules={{ pattern: /^[a-z0-9.-]+$/, message: '只能包含小写字母、数字、点和横线' }}
        decorator={[FormItem]} component={[Input]} />
      <Field name="owner" title="负责人" required decorator={[FormItem]} component={[Input]} />
      <Field name="env" title="环境" decorator={[FormItem]} component={[Select]} />
    </>
  );
  const shadowFields = { env: { enum: [{ label: '生产', value: 'prod' }, { label: '预发', value: 'staging' }] } };
  return (
    <Form form={form}>
      <Watch select={(d: Draft<Values>) => d.info.$value}>
        {(info) => (
          <Descriptions size="small" column={3} bordered items={[
            { key: 'domain', label: '域名', children: info.domain },
            { key: 'owner', label: '负责人', children: info.owner },
            { key: 'env', label: '环境', children: info.env },
          ]} />
        )}
      </Watch>
      <div style={{ marginTop: 12, display: 'flex', gap: 8 }}>
        <ShadowModal<Info> title="编辑（弹窗）" fields={shadowFields} record={() => form.getValue('info')}
          onOk={(values) => form.setValue('info', values)} trigger={<Button>弹窗编辑</Button>}>
          {fields}
        </ShadowModal>
        <ShadowDrawer<Info> title="编辑（抽屉）" fields={shadowFields} record={() => form.getValue('info')}
          onOk={(values) => form.setValue('info', values)} trigger={<Button>抽屉编辑</Button>}>
          {fields}
        </ShadowDrawer>
      </div>
    </Form>
  );
}
```

- 草稿里的字段名从草稿的根开始解析，不继承所在行的作用域。
- 表格行编辑用 `useArrayShadow`：它在 `useShadowForm` 上加了「编辑这一行 / 追加一行」的默认写回，见 [/play/array-table-shadow](/play/array-table-shadow)。
- 草稿是一份编辑副本，不是并发事务，也不会替你调用后端。

## 查询列表

`useQueryTable` 管查询条件、分页、表头排序和列筛选、请求竞态和选择；`QueryList` 渲染可折叠的条件栅格加一张受控分页的 `ArrayTable`。每页结果写进 `rows` 指定的数组字段，所以单元格同样可以编辑。

```tsx
const table = useQueryTable({ initialValues: { query: {}, list: [] }, params: 'query', rows: 'list', request })
<QueryList table={table} columns={columns}>
  <Field name="query.domain" title="域名" decorator={[FormItem]} component={[Input]} />
</QueryList>
```

条件栅格就是 [`FormGrid`](/guide/layout#栅格formgrid)：列数随宽度变，收起时只留第一行，重置 / 查询排在行末（像 antd Pro 的 `QueryFilter`），放不下才出现「展开 / 收起」；`grid` 改列数，宽的条件用 `gridSpan`。

列上写 `sorter: true` / `filters`，表头排序和列筛选会随请求发给服务端（`request` 的 `sorter` / `filters`）并回到第 1 页。列筛选和点「查询」一样会清空选择，免得批量操作碰到已经看不见的行；只翻页或排序时选择保留。

请求协议和返回值见 [查询 Hooks](/reference/query-hooks)；完整页面见 [/play/query-list](/play/query-list) 和不依赖 antd 的 [/play/query-native](/play/query-native)。

## 枚举、联想与级联

- 枚举阅读态：选择类控件在 `readPretty` 下显示 label，`prettyType="badge" | "tag"` 画成徽标 / 彩色标签；只显示的字段写 `pattern="readPretty"`，表单外用 `PreviewText.Select`（[/play/pro-enum](/play/pro-enum)，[控件与阅读态](/guide/controls)）。
- `Suggestion`：远程联想下拉，防抖并丢弃过期结果，支持多选和 `labelInValue`（[/play/suggestion](/play/suggestion)）。
- `CascaderPlus`：一个 `loadData(path)` 服务所有层级的懒加载级联，打开已有值时逐级反显；阅读态显示标签，没有 `labelInValue` 的裸编码也会经同一个 `loadData` 解析成标签（[/play/cascader-plus](/play/cascader-plus)）。

每个组件还有不绑定字段的 `…View` / `SuggestionView` 版本。签名见 [Pro 组件参考](/reference/pro-components) 与 [Pro Hooks 参考](/reference/pro-hooks)，更多场景在 [Pro 示例](/examples/pro)。
