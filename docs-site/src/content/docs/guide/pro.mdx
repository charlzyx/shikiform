`@shikiform/react` 提供零 UI 依赖的业务表单与表格 Hooks，可自由搭配原生 HTML 或任意 React UI 组件库。

| Hook | 职责 |
|---|---|
| `useShadowForm` | 在独立临时表单中编辑副本，确认并校验通过后再写回宿主表单 |
| `useQueryTable` | 统一管理查询条件、分页状态、表头排序、列筛选、请求竞态与跨页勾选 |
| `useArrayTable` | 数组字段的分页切片、勾选、展开与行操作（`add` / `copy` / `remove` / `move`） |
| `useColumnSettings` | 无 UI 表格列显隐、拖拽排序、列宽与密度管理 |
| `enumItems` / `useSuggestion` / `useLazyCascader` | 枚举标签与颜色解析、防抖远程联想、按需懒加载级联 |

## 草稿表单（`useShadowForm`）

在弹窗或抽屉中编辑单条记录或表格行时，取消操作不应修改主表单的值或 `dirty` 状态。

`useShadowForm` 在打开时创建一个独立的 `FormInstance`；点击确认时先校验草稿内部字段，通过后将草稿值交给 `onOk`（或写回绑定路径）；点击取消则直接丢弃该实例，主表单保持不变。

```tsx preview play=shadow-form
import { Dialog, DialogBackdrop, DialogContent, DialogTitle } from '@ui-sdk/react/dialog';
import { Select, SelectContent, SelectItem, SelectItemIndicator, SelectTrigger, SelectValue } from '@ui-sdk/react/select';
import { Field, Form, Watch, useField, useForm, useShadowForm, type Draft } from '@shikiform/react';

type Info = { domain: string; owner: string; env: string };
type Values = { info: Info };

function TextInput() {
  const field = useField<string>();
  return (
    <div style={{ marginBottom: 8 }}>
      <label htmlFor={field.id} style={{ display: 'inline-block', width: 64 }}>{field.title}</label>
      <input id={field.id} value={field.value ?? ''} onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
      {field.errors[0] && <small role="alert" style={{ color: 'crimson', marginLeft: 6 }}>{field.errors[0]}</small>}
    </div>
  );
}

function SelectInput() {
  const field = useField<string>();
  const items = field.options.map((o) => ({ value: String(o.value), label: o.label }));
  return (
    <div style={{ marginBottom: 8 }}>
      <label htmlFor={field.id} style={{ display: 'inline-block', width: 64 }}>{field.title}</label>
      <Select items={items} value={field.value || null} onValueChange={(v) => field.onChange(v ?? '')}>
        <SelectTrigger id={field.id}><SelectValue placeholder="请选择" /></SelectTrigger>
        <SelectContent>
          {items.map((item) => (
            <SelectItem key={item.value} value={item.value}>
              {item.label}
              <SelectItemIndicator>✓</SelectItemIndicator>
            </SelectItem>
          ))}
        </SelectContent>
      </Select>
    </div>
  );
}

function EditPanel() {
  const shadow = useShadowForm<Info>({ name: 'info' });
  return (
    <div style={{ marginTop: 12 }}>
      <button type="button" onClick={() => void shadow.open()}>编辑草稿</button>
      <Dialog open={shadow.visible} onOpenChange={(open) => { if (!open) shadow.cancel(); }}>
        <DialogBackdrop />
        <DialogContent>
          <DialogTitle>编辑草稿</DialogTitle>
          <Form form={shadow.form} onSubmit={() => void shadow.confirm()}>
            <Field name="domain" component={[TextInput]} />
            <Field name="owner" component={[TextInput]} />
            <Field name="env" component={[SelectInput]} />
            <div style={{ display: 'flex', gap: 8, marginTop: 12 }}>
              <button type="submit" disabled={shadow.submitting}>确定</button>
              <button type="button" onClick={shadow.cancel}>取消</button>
            </div>
          </Form>
        </DialogContent>
      </Dialog>
    </div>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: { info: { domain: 'shikiform.dev', owner: 'Ada', env: 'prod' } },
    fields: {
      'info.domain': { title: '域名', required: true, rules: { pattern: /^[a-z0-9.-]+$/, message: '只能包含小写字母、数字、点和横线' } },
      'info.owner': { title: '负责人', required: true },
      'info.env': { title: '环境', enum: [{ label: '生产', value: 'prod' }, { label: '预发', value: 'staging' }] },
    },
  });
  return (
    <Form form={form}>
      <Watch select={(d: Draft<Values>) => d.info.$value}>
        {(info) => <pre>{JSON.stringify(info, null, 2)}</pre>}
      </Watch>
      <EditPanel />
    </Form>
  );
}
```

需要注意：由于草稿内部是独立表单，里面 `<Field>` 的 `name` 是相对于草稿根路径解析的。通过 `name="info"`（或在表格行作用域内调用 `useShadowForm()`）绑定宿主路径后，打开草稿时会自动复制当前值并继承对应前缀的 `fields` 规则与有效 `readOnly` / `disabled`，确认时自动写回原路径。

## 查询列表

`useQueryTable` 统一管理查询条件、分页状态、表头排序、列筛选、请求竞态以及跨页勾选。请求返回的每页列表会直接写入 `rows` 指定的数组字段，因此表格单元格可以直接通过 `<ArrayField.Row>` 进行行内编辑。

```tsx
const table = useQueryTable({
  initialValues: { query: { domain: '' }, list: [] },
  params: 'query',
  rows: 'list',
  request,
})
```

调用 `table.setSorter(...)` 或 `table.setFilters(...)`（或把 `table.onTableChange` 传给表格组件）会携带参数重新请求并回到第 1 页；触发列筛选或点击「查询」会清空已勾选项，单纯翻页或排序则保留勾选。

协议与完整可运行示例见 [查询 Hooks 参考](/reference/query-hooks)，在线演示见 [/play/query-native](/play/query-native)。

## 枚举展示、远程联想与懒加载级联

- `enumItems(value, options, { colorful })`：按枚举解析字段值的显示标签和语义色（`ENUM_COLORS`），适合渲染阅读态徽标或标签（[/play/pro-enum](/play/pro-enum)）。
- `useSuggestion`：输入防抖、中止过期请求并保留已选项标签（`remember` / `labelOf`）。
- `useLazyCascader`：传入 `load(path)` 按需加载各级选项，已有值回显时自动逐级拉取祖先并用 `labelsOf(path)` 拼接路径标签。

完整签名与参数说明见 [Pro Hooks 参考](/reference/pro-hooks)，场景示例见 [Pro 示例](/examples/pro)。
