在复杂后台页面中常见的查询列表、弹窗/抽屉编辑以及远程异步输入控件，无 UI 的状态逻辑都封装在 `@shikiform/hooks` 中，`@shikiform/antd` 则提供了对应的 Ant Design 视图组件。至于行内可编辑表格 `ArrayTable`，它属于数组容器，详情请参考 [数组容器](/guide/arrays#arraytable)。

| Ant Design 组件（`@shikiform/antd`） | 底层 Hook（`@shikiform/hooks`） | 适用场景 |
|---|---|---|
| `ShadowModal` / `ShadowDrawer` / `ShadowPopconfirm` / `ShadowForm` | `useShadowForm` | **草稿表单**：在独立的临时表单实例中编辑，确认校验通过后再写回主表单 |
| `QueryList` | `useQueryTable` | **查询列表**：上方可折叠筛选区 + 下方服务端分页 `ArrayTable` |
| 选择控件 `prettyType` / `Suggestion` / `CascaderPlus` | `enumItems` / `useSuggestion` / `useLazyCascader` + `useCascaderLabels` | 枚举阅读态徽标/标签、防抖远程联想、按需懒加载级联 |

## 草稿表单（ShadowForm）

很多业务需要在弹窗或抽屉里编辑一条数据或数组中的某一行：如果用户改到一半点「取消」，主表单的数据和 `dirty` 状态不能受到任何影响。

草稿表单（对应 API 为 `ShadowModal` / `ShadowDrawer` 等）会在打开时创建一个**完全独立的表单引擎实例**，并在确认提交时先执行草稿内部的校验，全部通过后把值交给 `onOk` 回调，由你决定如何更新主表单或调用接口；点击取消则会直接丢弃这份草稿，不会污染原表单。

```tsx preview play=shadow-form
import { Button, Descriptions } from 'antd';
import { Field, Form, Watch, useForm, type Draft } from '@shikiform/react';
import { FormItem, Input, Select, ShadowDrawer, ShadowModal } from '@shikiform/antd';

type Info = { domain: string; owner: string; env: string };
type Values = { info: Info };

export default function App() {
  const form = useForm<Values>({
    initialValues: { info: { domain: 'shikiform.dev', owner: 'Ada', env: 'prod' } },
    fields: {
      'info.domain': { title: '域名', required: true, rules: { pattern: /^[a-z0-9.-]+$/, message: '只能包含小写字母、数字、点和横线' } },
      'info.owner': { title: '负责人', required: true },
      'info.env': { title: '环境', enum: [{ label: '生产', value: 'prod' }, { label: '预发', value: 'staging' }] },
    },
  });
  const fields = (
    <>
      <Field name="domain" decorator={[FormItem]} component={[Input]} />
      <Field name="owner" decorator={[FormItem]} component={[Input]} />
      <Field name="env" decorator={[FormItem]} component={[Select]} />
    </>
  );
  return (
    <Form form={form}>
      <Watch select={(d: Draft<Values>) => d.info.$value}>
        {(info) => (
          <Descriptions size="small" column={3} bordered items={[
            { key: 'domain', label: '域名', children: info.domain },
            { key: 'owner', label: '负责人', children: info.owner },
            { key: 'env', label: '环境', children: info.env },
          ]} />
        )}
      </Watch>
      <div style={{ marginTop: 12, display: 'flex', gap: 8 }}>
        <ShadowModal<Info> name="info" title="编辑（弹窗）" trigger={<Button>弹窗编辑</Button>}>
          {fields}
        </ShadowModal>
        <ShadowDrawer<Info> name="info" title="编辑（抽屉）" trigger={<Button>抽屉编辑</Button>}>
          {fields}
        </ShadowDrawer>
      </div>
    </Form>
  );
}
```

需要注意：由于草稿内部是独立表单（`ShadowBody` 会隔离宿主表单、作用域、字段、分组与栅格上下文，仅保留 `FieldKit` 与 `FormLayout`），里面 `<Field>` 的 `name` 是相对于草稿根路径解析的。通过 `name="info"`（或把 `<ShadowModal>` 直接放在表格行内）绑定宿主路径后，打开草稿时会自动复制当前值并继承对应前缀的 `fields` 规则与有效 `readOnly` / `disabled`，确认时自动写回原路径，参见 [/play/array-table-shadow](/play/array-table-shadow)。

## 查询列表

`useQueryTable` 统一管理查询条件、分页状态、表头排序、列筛选、请求竞态以及批量勾选；配套的 `QueryList` 则渲染顶部的可折叠筛选栏和下方的受控分页 `ArrayTable`。由于请求返回的每页列表会直接写入 `rows` 指定的数组字段，因此表格里的单元格同样支持直接行内编辑。

```tsx
const table = useQueryTable({ initialValues: { query: {}, list: [] }, params: 'query', rows: 'list', request })
<QueryList table={table} columns={columns}>
  <Field name="query.domain" title="域名" decorator={[FormItem]} component={[Input]} />
</QueryList>
```

顶部的筛选栏底层使用 [`FormGrid`](/guide/layout#栅格formgrid)，列数随容器宽度自动调整。收起状态下只保留第一行，并将「重置 / 查询」按钮放在行末，只有筛选条件放不下时才会出现「展开 / 收起」开关；需要自定义列数或横跨多列时，可以配置 `grid` 和 `gridSpan`。

如果在列定义中开启了 `sorter: true` 或 `filters`，操作表头排序和列筛选时会自动携带参数重新请求并重置到第 1 页；为防止批量操作误触已被过滤掉的数据，触发列筛选或点击「查询」时会自动清空当前勾选（仅翻页或排序时保留勾选）。

完整的协议定义与返回值说明见 [查询 Hooks](/reference/query-hooks)，完整可交互示例见 [/play/query-list](/play/query-list) 以及无 Ant Design 依赖的 [/play/query-native](/play/query-native)。

## 枚举展示、远程联想与懒加载级联

- **枚举阅读态标签**：选择类控件在 `readOnly` 时把值反显为标签，`prettyType="badge" | "tag"` 画成徽标或彩色标签。表单外用 `PreviewText.Select`（[/play/pro-enum](/play/pro-enum)、[控件与阅读态](/guide/controls)）。
- **远程搜索联想（`Suggestion`）**：自带输入防抖并自动丢弃过期的并发响应，支持单选、多选以及 `labelInValue` 等多种值格式（[/play/suggestion](/play/suggestion)）。
- **懒加载级联（`CascaderPlus`）**：只需提供一个 `loadData(path)` 函数即可按需加载每一级选项，回显已有数据时支持逐级自动拉取并翻译为完整路径标签（[/play/cascader-plus](/play/cascader-plus)）。

上述输入组件均提供不绑定表单的 `…View`（如 `SuggestionView`）独立版本。详细参数见 [Pro 组件参考](/reference/pro-components) 与 [Pro Hooks 参考](/reference/pro-hooks)，更多业务案例见 [Pro 示例](/examples/pro)。
