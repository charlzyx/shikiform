---

`@shikiform/antd` 内置了全套常用 Ant Design 控件的适配版本，可以直接传给 `<Field>` 的 `component` 属性。当某个字段、父级对象或整张表单的 `pattern` 设为 `readPretty` 时，这些控件会自动切换为只读的「阅读态」文本：选项自动反显为 `label`、日期按格式展示、密码打码、多选展示为标签，空值则统一显示为空值占位符。

| 控件 | 字段值类型 | 枚举来源（`<Field enum>`） | 阅读态表现 |
|---|---|---|---|
| `Input`（`.TextArea` `.Password`）、`AutoComplete` | 字符串 | `AutoComplete` 的补全项 | 文本展示（保留前后缀与换行）；密码显示为 `******` |
| `InputNumber` | 数字（清空时为 `null`） | — | 数字文本（自动应用 `formatter`） |
| `Select`、`Radio`、`Checkbox.Group` | 单值或数组 | `options` | 展示对应的 `label`；多选呈标签组，支持 `prettyType` 设徽标或彩色标签 |
| `TreeSelect` | 单值或数组 | `treeData`（带 `children` 的树） | 从树节点中匹配并显示 `label` |
| `Cascader` | 路径数组（如 `['zj', 'hz']`） | `options`（带 `children` 的树） | 拼接为 `浙江 / 杭州` |
| `Transfer` | 目标 key 数组 | `dataSource` | 展示选中项的标签 |
| `Switch`、`Checkbox` | 布尔值 | — | 显示「是 / 否」（`Switch` 若配了 `checkedChildren` 则优先显示它） |
| `DatePicker`、`TimePicker`（`.RangePicker`） | 格式化字符串或 `[start, end]` | — | 格式化文本；范围显示为 `start ~ end` |
| `Slider`、`Rate` | 数字（`Slider range` 为 `[from, to]`） | — | 数字文本 / 只读星级 |
| `Upload`（`.Dragger`） | 文件列表 `UploadFile[]` | — | 文件下载链接或缩略图 |
| `ColorPicker` | 颜色字符串（如 `#1677ff`） | — | 色块加颜色值文本 |

## 控件总览与交互态切换

在下面的演示中，切换顶部状态只需修改根节点一处 `d.$pattern`，所有子字段都会自动继承生效；如果有个别字段需要例外，只需单独设置该字段的 `pattern`。

```tsx preview
import { Button, Segmented } from 'antd';
import { Form, typed, useForm, Watch, type Draft, type Pattern } from '@shikiform/react';
import {
  AutoComplete, Cascader, Checkbox, ColorPicker, DatePicker, FormItem, FormLayout, Input, InputNumber, Radio, Rate,
  Select, Slider, Switch, TimePicker, Transfer, TreeSelect, Upload,
} from '@shikiform/antd';

const AREA = [
  { label: '浙江', value: 'zj', children: [{ label: '杭州', value: 'hz', children: [{ label: '西湖', value: 'xh' }, { label: '滨江', value: 'bj' }] }] },
  { label: '江苏', value: 'js', children: [{ label: '南京', value: 'nj', children: [{ label: '玄武', value: 'xw' }] }] },
];
const DEPTS = [
  { label: '研发', value: 'rd', children: [{ label: '前端', value: 'fe' }, { label: '后端', value: 'be' }] },
  { label: '设计', value: 'ux' },
];
const SKILLS = [{ label: 'React', value: 'react', color: 'processing' }, { label: 'Rust', value: 'rust', color: 'warning' }, { label: 'Go', value: 'go' }];
const MEMBERS = [{ label: '小林', value: 'lin' }, { label: '小周', value: 'zhou' }, { label: '小吴', value: 'wu' }];

type Values = {
  nickname: string; bio: string; token: string; salary: number | null; city: string;
  skills: string[]; level: string; remote: boolean; dept: string; area: string[]; team: string[];
  joined: string; shift: [string, string]; focus: number; stars: number; avatar: { uid: string; name: string; url?: string }[];
  theme: string;
};

export default function App() {
  const form = useForm<Values>({
    initialValues: {
      nickname: 'Ada', bio: '写代码\n也写诗', token: 'secret', salary: 32000, city: '杭州',
      skills: ['react', 'rust'], level: 'p7', remote: true, dept: 'fe', area: ['zj', 'hz', 'xh'], team: ['lin'],
      joined: '2024-03-01', shift: ['09:30', '18:30'], focus: 70, stars: 4,
      avatar: [{ uid: '1', name: 'logo.svg', url: 'https://gw.alipayobjects.com/zos/rmsportal/KDpgvguMpGfqaHPjicRK.svg' }],
      theme: '#1677ff',
    },
  });
  const F = typed(form);
  return (
    <Form form={form} data-controls-demo="">
      <Segmented<Pattern> style={{ marginBottom: 16 }} options={['editable', 'readPretty', 'readOnly', 'disabled']}
        onChange={(pattern) => form.batch((d) => { d.$pattern = pattern; })} />
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 17 }}>
        <F.Field name="nickname" title="昵称" decorator={[FormItem]} component={[Input, { prefix: '@' }]} />
        <F.Field name="bio" title="简介" decorator={[FormItem]} component={[Input.TextArea]} />
        <F.Field name="token" title="令牌" decorator={[FormItem]} component={[Input.Password]} />
        <F.Field name="salary" title="月薪" decorator={[FormItem]} component={[InputNumber, { prefix: '¥', style: { width: 160 } }]} />
        <F.Field name="city" title="城市" enum={['杭州', '南京', '上海']} decorator={[FormItem]} component={[AutoComplete]} />
        <F.Field name="skills" title="技能" enum={SKILLS} decorator={[FormItem]} component={[Select, { mode: 'multiple', prettyType: 'tag' }]} />
        <F.Field name="level" title="职级" enum={[{ label: 'P6', value: 'p6' }, { label: 'P7', value: 'p7' }]} decorator={[FormItem]} component={[Radio]} />
        <F.Field name="remote" title="远程" decorator={[FormItem]} component={[Switch]} />
        <F.Field name="dept" title="部门" enum={DEPTS} decorator={[FormItem]} component={[TreeSelect, { treeDefaultExpandAll: true }]} />
        <F.Field name="area" title="地区" enum={AREA} decorator={[FormItem]} component={[Cascader]} />
        <F.Field name="team" title="组员" enum={MEMBERS} decorator={[FormItem]} component={[Transfer]} />
        <F.Field name="joined" title="入职" decorator={[FormItem]} component={[DatePicker]} />
        <F.Field name="shift" title="班次" decorator={[FormItem]} component={[TimePicker.RangePicker, { format: 'HH:mm' }]} />
        <F.Field name="focus" title="专注度" decorator={[FormItem]} component={[Slider]} />
        <F.Field name="stars" title="评分" decorator={[FormItem]} component={[Rate]} />
        <F.Field name="avatar" title="头像" decorator={[FormItem]}
          component={[Upload, { listType: 'picture', beforeUpload: () => false, maxCount: 1, children: <Button>选择文件</Button> }]} />
        <F.Field name="theme" title="主题色" decorator={[FormItem]} component={[ColorPicker, { showText: true }]} />
      </FormLayout>
      <Watch select={(d: Draft<Values>) => d.$value}>
        {(values) => <pre data-controls-values>{JSON.stringify({ ...values, avatar: values.avatar.map((file) => file.name) }, null, 2)}</pre>}
      </Watch>
    </Form>
  );
}
```

- **树形枚举**：`TreeSelect` 和 `Cascader` 同样通过 `<Field enum>` 传入带 `children` 的树形数据；在 `typed(form).Field` 中，选项值类型会与字段值（或路径/多选的元素类型）对齐检查。动态加载选项在 `reaction` 中给 `d.city.$enum` 赋值即可。
- **文件上传**：`Upload` 绑定的字段值就是 Ant Design 的 `fileList`。如果配了 `action` 自动上传，提交时可直接读取响应中的 `url`；上例设置 `beforeUpload: () => false`，文件会保留在本地 `originFileObj` 中随表单一起提交。
- **序列化日期**：`DatePicker` 和 `TimePicker` 在引擎中直接存储格式化后的字符串，避免引入 `dayjs` 实例，因此在设置 `initialValues`、调用 `reset()` 和提交数据时都非常干净。
- **异步大数据控件**：需要逐级异步加载的级联使用 [`CascaderPlus`](/reference/pro-components#cascaderplus)；需要远程搜索防抖的下拉框使用 [`Suggestion`](/reference/pro-components#suggestion)。

## 详情页：全表只读与空值占位

构建详情页时，只需在创建表单时传入 `useForm({ pattern: 'readPretty' })` 即可。对于 `undefined`、`null`、`''`、`[]` 等空值，所有控件在阅读态下都会统一显示 `messages.empty`（默认为 `-`），可以通过单表的 `messages` 或全局的 `setDefaultMessages({ empty: '…' })` 修改。

```tsx preview
import { Form, typed, useForm } from '@shikiform/react';
import { Cascader, DatePicker, FormItem, FormLayout, Input, Select, Upload } from '@shikiform/antd';

const STATUS = [{ label: '待审核', value: 0, color: 'default' }, { label: '已通过', value: 1, color: 'success' }, { label: '已驳回', value: 2, color: 'error' }];
const REGION = [{ label: '浙江', value: 'zj', children: [{ label: '宁波', value: 'nb' }] }];

type Detail = { title: string; state: number; region: string[]; due?: string; owner?: string; attachments: { uid: string; name: string; url: string }[] };

export default function App() {
  const form = useForm<Detail>({
    initialValues: { title: '采购申请 #1024', state: 1, region: ['zj', 'nb'], attachments: [] },
    pattern: 'readPretty',
    messages: { empty: '暂无' },
  });
  const F = typed(form);
  return (
    <Form form={form} data-detail-demo="">
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 17 }}>
        <F.Field name="title" title="标题" decorator={[FormItem]} component={[Input]} />
        <F.Field name="state" title="状态" enum={STATUS} decorator={[FormItem]} component={[Select, { prettyType: 'badge' }]} />
        <F.Field name="region" title="区域" enum={REGION} decorator={[FormItem]} component={[Cascader]} />
        <F.Field name="due" title="截止" decorator={[FormItem]} component={[DatePicker]} />
        <F.Field name="owner" title="负责人" decorator={[FormItem]} component={[Input]} />
        <F.Field name="attachments" title="附件" decorator={[FormItem]} component={[Upload]} />
      </FormLayout>
    </Form>
  );
}
```

- 如果在普通表格单元格或详情卡片等**表单外部**场景需要同款展示效果，可以直接渲染纯视图组件 `<PreviewText.Select value={row.state} options={STATUS} prettyType="badge" />`（还包括 `.Input`、`.TreeSelect`、`.Cascader`、`.DatePicker`、`.TimePicker` 等，完整列表见 [PreviewText](/reference/antd-adapter#previewtext)）。
- 封装自定义控件时，使用 `connect(MyPicker, mapProps({ readPretty: PreviewText.TreeSelect }))` 即可直接复用现成的阅读态视图。

关于每个控件具体的属性映射细节，请参考 [Ant Design 适配层参考](/reference/antd-adapter#previewtext)。
