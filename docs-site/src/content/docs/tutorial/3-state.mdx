练习代码里有一个「需要联系」开关，目前无论开或关，下方的邮箱输入框始终显示在界面上。

在联动函数中，字段的自身状态统一带有 `$` 前缀（例如 `$value` 读取当前值，`$required` 控制必填），不带 `$` 的属性名则代表子字段。

字段状态是四个布尔：

| 开关 | 界面 | 校验 | 提交 |
|---|---|---|---|
| `visible: false` | 不渲染 | 跳过 | 仍然提交 |
| `disabled: true` | 置灰 | 跳过 | 提交 |
| `readOnly: true` | 预览（同时 `disabled` 时预览优先） | 跳过 | 提交 |
| `omit: true` | 不影响 | 不影响 | 不提交 |

四个布尔都沿字段路径继承。`visible` / `disabled` / `readOnly` 这一层写了 `true` 或 `false` 就用这一层。`omit` 是任一祖先为 `true` 则子孙为 `true`：子级写 `omit: false` 不能单独把这一段提交回来，因为父级被删掉时整棵子树一起离开提交结果。校验只在 `visible && !disabled && !readOnly` 时运行。

**这一步：** 在 `reaction` 中补充 `d.email.$visible = d.contact.$value`。

完成后，关闭开关即可隐藏邮箱。清空邮箱再关闭开关，提交能够通过（不再校验），JSON 里仍然有 `email`。重新打开开关时，刚才的内容还在。

如果这份数据不该进提交结果，再写 `d.email.$omit = !d.contact.$value`。
