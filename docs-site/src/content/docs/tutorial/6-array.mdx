起始订单中有一行商品（贴纸，单价 2，数量 4），小计仍为 0，不会随单价或数量更新。

`<ArrayField>` 接收渲染函数作为子元素，函数内的字段名相对于当前行解析。指定 `rowKey="id"` 后，增删或排序时字段状态跟随行 `id` 移动。结构变更通过数组句柄完成：行内 `<RemoveButton>` 调用 `useArrayField().remove(useIndex())`，「添加一行」放在 `<ArrayField component>` 内调用 `useArrayField().push(row)`，不要调用 `form.pushArray` / `form.removeArray`。

数组每行的派生计算使用 `reaction.each(select, callback)`。引擎为每一行维护独立实例，修改某一行时只重算该行。

**这一步：** 在 `effects` 中补充按行计算：

```ts
reaction.each(
  (d) => d.items,
  (row) => {
    const total = (row.price.$value || 0) * (row.qty.$value || 0);
    row.total.$value = total;
  },
);
```

修改后，「贴纸」的小计变为 8；修改已有行或新增行时，对应行的小计随之更新并参与提交。若小计仅在前端展示、不随表单提交，可为 `total` 声明 `omit: true`。
