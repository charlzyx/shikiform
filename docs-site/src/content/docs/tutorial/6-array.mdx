当前订单中已经有一条商品数据（贴纸，单价 2，数量 4），但小计还停留在 0，也不会随数量变化。

`<ArrayField>` 接收一个渲染函数作为子元素，函数内部渲染的字段名会自动相对于当前行解析。通过设置 `rowKey="id"`，引擎会在增删或拖拽排序时保留每行的状态。增删行可以调用 `form.pushArray` 和 `form.removeArray`。

在联动逻辑中，数组每一行的派生计算应当使用 `reaction.each(select, callback)`。其中第一个参数选中数组字段的 handle，第二个参数是每行对应的回调。引擎会为数组中的每一行建立独立的联动实例，编辑某一行时只会触发那一行的重算。

**这一步：** 在 `effects` 中补充按行计算的逻辑：

```ts
reaction.each(
  (d) => d.items,
  (row) => {
    const total = (row.price.$value || 0) * (row.qty.$value || 0);
    row.total.$value = total;
  },
);
```

保存后，「贴纸」的小计会立刻变为 8；修改某一行或新增行时，对应行的小计也会实时更新并随表单一起提交。如果小计只用于前端展示、不需要随表单提交，只需为 `total` 字段声明 `display: 'virtual'`。
