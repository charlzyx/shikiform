一张表单由三块拼成：`useForm` 创建引擎，`Form` 负责提交，`Field` 拥有一个路径。

每个输入都是同一种字段。`decorator={[FormItem]}` 显示标签和错误，`component={[Input]}` 是控件。它们从 `Field` 读字段，所以不用再写 `name`。`FormItem`、`Input`、`Submit` 来自 `@shikiform/antd`。

数据形状决定你用哪一种字段：一个值用 `Field`，对象用 `ObjectField`，数组用 `ArrayField`，树用 `TreeField`。标题和按钮不是字段。

**这一步：** 加上邮箱。`initialValues` 里写上 `email`，再放一个 `name="email"` 的 `Field`。提交之后，JSON 里同时有 `name` 和 `email`。
