# 最小表单

<div className="tutorial-step">
<div className="tutorial-copy">

右边有一个姓名框。填上字，点提交，下面会出现 JSON。

这几块就够了：`useForm` 创建表单，`Form` 处理提交，`Field` 的 `name` 是路径。

一个字段分三层：`<Field>` 拥有路径和状态，`decorator={[FormItem]}` 显示标签（`title`）和错误，`component={[Input, props]}` 是输入框。`FormItem`、`Input`、`Submit` 都来自 `shikiform/antd`，它们从 `Field` 读字段，所以不用再写 `name`。改字的时候，值写回 ShikiForm，不进 antd 的表单状态。

**这一步：** 加上邮箱。`initialValues` 里写上 `email`，再放一个 `name="email"` 的 `Field`。提交之后，JSON 里同时有 `name` 和 `email`。
