你已经会写一份表单：字段、嵌套 path、选项 `enum`、`$` 状态、`pattern`、`reaction`、`reaction.each` 和 `watch`。

## 理解设计，再查 API

[核心概念](/guide/concepts) 把引擎、React 绑定和 UI 适配连起来。项目里接 antd 从 [快速开始](/guide/quick-start) 的 `<Field decorator={[FormItem]} component={[Input]}>` 入手；装饰器、控件的细节看 [Field、装饰器与组件](/guide/field)。四个入口、引擎方法和联动 API 列在 [API](/api)。要让拼错的字段名编译不过，用 [`typed(form)`](/reference/react-hooks#typed)（第 8 步的 `F.Field` 就是它）。

## 把概念放进业务里

- [SKU 选择器](/play/sku-picker)：可选范围、最新选择、价格与库存怎样联动。
- [供应商和产品](/play/merged)：数据保持嵌套，合并显示不改变字段路径。
- [查询表](/play/query)：条件、筛选、分页与勾选共用状态。
- [订单行](/play/orders)：逐行计算、父级状态与展开/收起。
- [抽屉行编辑](/play/row-edit)：什么时候直接写值，什么时候先装载到临时 editor 再确认。

全部 23 个场景见 [示例库](/examples)。继续深挖时，看 [联动](/guide/linkage)、[数组、树与嵌套对象](/guide/structures) 和 [校验](/guide/validation)；封装控件前先看 [Ant Design 适配](/guide/antd)。
