## 4.1 裁剪提交字段与表单重置

将密码和确认密码都填成 `secret123` 后点击提交，`confirmPassword` 会一并出现在提交结果中。

「确认密码」需要正常渲染和校验，但不应提交给后端。声明 `omit` 后，字段照常渲染与校验（`$visible` 仍为 `true`），在提交和 `getSubmitValues()` 时被剔除。

`Reset` 按钮将表单恢复到 `initialValues`，随后触发 `afterReset` 回调（本例用于清空已展示的提交结果）。表单内的「重置表单」用于恢复表单值，工具栏右侧的「重置」用于恢复练习代码。

**这一步：** 为 `confirmPassword` 加上 `omit`，并在 `rules` 中添加校验：当值不等于 `ctx.record.password` 时返回 `'两次密码不一致'`。
