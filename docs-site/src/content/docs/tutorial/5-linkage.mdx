第一段练习中，单价和数量已有初始值，金额不会随输入自动重算。

派生值使用 `reaction`：初始化时立即运行一次，自动追踪内部读取的所有 `$` 状态，依赖变化时重算。同一轮计算中若后续还要复用刚算出的值（如先算小计再算税费），请先存入局部变量，不要在同一轮内读回刚赋值的 `$value`。

被 `reaction` 写入 `$value` 的字段为计算字段：默认仍可编辑、仍参与提交、不计入 `dirty`。如需展示为预览态，再设置 `$readOnly = true`（或在 `<Field readOnly>` 上声明）；不需要提交则声明 `omit: true`。

**这一步：** 用 `defineEffects` 注册一条 `reaction`：

```ts
const amount = (d.price.$value || 0) * (d.qty.$value || 0);
d.amount.$value = amount;
```

将 `effects` 传给 `useForm` 后，修改单价或数量时金额随之重算，提交输出的 JSON 中包含 `amount`。

第二段练习中，初始省份为「浙江」、初始城市为「杭州」，但起始代码把清空城市写进了 `reaction`，导致表单初始化时就把「杭州」清空了。

字段变更后触发一次性动作应使用 `watch`：首次渲染时不执行，仅在第一个参数读取的状态变化后运行回调。

代码中同时使用了 `typed(form)` 返回的 `F.Field`：运行时行为与 `<Field>` 一致，额外在编译期检查字段名拼写。

**这一步：** `reaction` 中只保留 `d.city.$disabled = !d.province.$value`，将清空城市移入 `watch`：

```ts
watch(
  (d) => d.province.$value,
  (d) => {
    d.city.$value = '';
  },
);
```

修改后，初始打开时保留「杭州」，切换省份后清空城市；清空省份时城市选择器变为禁用。
