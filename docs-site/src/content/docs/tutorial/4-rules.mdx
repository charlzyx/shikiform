<div className="tutorial-copy">

起始表单有姓名、邮箱、年龄三个字段，尚未绑定校验规则。

单字段规则写在 `<Field rules>` 上；整表校验可将实现 Standard Schema 的校验器（如 Zod）传给 `useForm` 的 `validate`。默认在失焦（`onBlur`）与提交时执行校验。

内置规则中，空值（`''`、`null`、`undefined`）只由 `required` 拦截，`minLength`、`format`、`min` 等规则遇到空值直接放行。起始代码中的 Zod Schema 同样放过了空值（邮箱包含 `z.literal('')`，年龄使用 `.nullable()` 兼容数字框清空后的 `null`）。

**这一步：** 给 `useForm` 传入 `validate: schema`，为三个字段加上 `required`，并为姓名加上 `rules={{ minLength: 2, message: '至少 2 个字' }}`。

修改后，任意字段留空失焦会提示必填，姓名少于 2 个字提示「至少 2 个字」，邮箱格式错误或年龄小于 18 显示 Zod 报错；全部合法后提交会输出 JSON。
