## 深入原理与专题

- [核心概念](/guide/concepts)：理解表单引擎、draft handle 以及 `$` 状态的设计。
- [按路径读写](/basics/path)：使用 `get` / `set` 和 `d.orders[0].lines[2].qty` 精准操作深层路径。
- [字段状态](/basics/state)：完整对比 `visible`、`hidden`、`virtual`、`none` 四种模式及 `pattern` 继承规则。
- [联动](/guide/linkage)：学习在多层嵌套数组和树形结构中使用 `ctx` 进行局部联动。
- [常见的坑](/practices/pitfalls)：常见误用（如解构 handle、同轮回读等）的正误对照。
- [API 总览](/api)：查阅四个包提供的完整组件、Hooks 和工具函数。
