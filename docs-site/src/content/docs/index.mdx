## 30 秒在线体验

联动在 `defineEffects` 内通过 `reaction` 和 `watch` 直接读写字段的 `$` 状态，React 组件只负责声明字段路径与界面结构。切换下方「账号类型」观察必填校验、占位符与「公司」字段显隐联动：

```tsx preview
import { useEffect, useRef, useState, type ReactNode } from 'react';
import { defineEffects, Form, Submit, typed, useField, useFieldDecorator, useForm, useWatch, type Draft } from '@shikiform/react';

type Values = { kind: 'personal' | 'work'; email: string; company: string };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    const work = d.kind.$value === 'work';
    d.email.$required = work;
    d.email.$componentProps.placeholder = work ? 'name@company.com' : 'name@example.com';
    d.company.$visible = work;
  });
});

function FieldItem({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <div style={{ marginBottom: 10 }}>
      <label {...d.labelProps} style={{ display: 'inline-block', width: 72 }}>
        {d.required && <span style={{ color: 'crimson' }}>* </span>}
        {d.label}
      </label>
      {children}
      {d.errorProps && <small {...d.errorProps} style={{ color: 'crimson', marginLeft: 8 }}>{d.errors[0]}</small>}
    </div>
  );
}

function TextInput({ placeholder }: { placeholder?: string }) {
  const field = useField<string>();
  return (
    <input id={field.id} value={field.value ?? ''} placeholder={placeholder}
      onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
  );
}

function RadioGroup() {
  const field = useField<string>();
  return (
    <span style={{ display: 'inline-flex', gap: 12 }}>
      {field.options.map((o) => (
        <label key={String(o.value)}>
          <input type="radio" name={field.id} checked={field.value === o.value}
            onChange={() => field.onChange(String(o.value))} />
          {' '}{o.label}
        </label>
      ))}
    </span>
  );
}

function ForgetResult({ clear }: { clear: () => void }) {
  const kind = useWatch((d: Draft<Values>) => d.kind.$value);
  const clearRef = useRef(clear);
  clearRef.current = clear;
  const ready = useRef(false);
  useEffect(() => {
    if (!ready.current) {
      ready.current = true;
      return;
    }
    clearRef.current();
  }, [kind]);
  return null;
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { kind: 'personal', email: '', company: '' },
    effects: [effects],
  });
  const F = typed(form);
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))} onInvalid={() => setResult('')}>
      <ForgetResult clear={() => setResult('')} />
      <F.Field name="kind" title="账号类型" enum={[{ label: '个人', value: 'personal' }, { label: '工作', value: 'work' }]}
        decorator={[FieldItem]} component={[RadioGroup]} />
      <F.Field name="email" title="邮箱" rules={{ format: 'email' }} decorator={[FieldItem]} component={[TextInput]} />
      <F.Field name="company" title="公司" required decorator={[FieldItem]} component={[TextInput]} />
      <Submit>提交</Submit>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

账号类型为「个人」时，邮箱可留空提交，「公司」字段隐藏并跳过必填校验；切到「工作」后，`reaction` 将邮箱设为必填、替换占位文本并显示「公司」。注意 `$visible = false` 只跳过渲染和校验，字段值默认仍包含在提交结果中；如需从提交数据中剔除，再设置 `d.company.$omit = !work`。

`typed(form)` 返回绑定了 `Values` 类型的 `Field` 组件。`decorator` 渲染标签与错误信息，`component` 渲染输入控件，详见 [表单与字段](/guide/field) 与 [核心概念](/guide/concepts)。

## 与常见表单方案的差异

| 维度 | ShikiForm | react-hook-form | Formily |
|---|---|---|---|
| 状态与联动 | 集中在引擎内，在 `reaction` 中对 `$` 状态直接赋值 | 多在组件内调用 `watch` / `setValue` | 使用 `reactions`，常与 Schema 配合 |
| UI 绑定 | 引擎零 UI 依赖，通过 `useField` / `connect` / `useFieldDecorator` 接入任意组件库 | 无 UI，受控组件通过 `Controller` 桥接 | 提供独立 UI 适配包 |
| 显隐与提交 | `visible: false` 不渲染、跳过校验，值仍提交；是否提交只看 `omit`。`disabled` 置灰但仍提交 | 由组件挂载状态决定；`disabled` 默认不提交 | `hidden` 默认跳过校验并保留值，`none` 不提交 |

## 安装与模块划分

React 项目默认安装 `@shikiform/react`，再按需安装无 UI 业务 Hooks 包：

```bash
npm i @shikiform/react
# 查询列表、草稿表单、数组表格等无 UI Hooks
npm i @shikiform/hooks
```

| 包名 | 职责 |
|---|---|
| `@shikiform/core` | 纯 TypeScript 表单引擎：状态存储、draft、`reaction` / `watch` 与校验，不依赖 React |
| `@shikiform/react` | `Form`、`Field`、`useField`、`connect`、`useFieldDecorator` 等 React 绑定，并重导出 `@shikiform/core` |
| `@shikiform/hooks` | `useQueryTable`、`useShadowForm`、`useArrayTable`、`useColumnSettings` 等无 UI 业务 Hooks |

完整导出清单见 [API 总览](/api)。使用 AI 编程工具时可将 [/llms.txt](/llms.txt) 作为上下文传入。
