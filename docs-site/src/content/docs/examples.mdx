先看五个高频基础场景（已按主题聚合到对应专题页，每个示例均可在线编辑代码并提交验证）：

| 场景 | 核心用法 |
|---|---|
| [登录校验](/examples/forms#登录校验) | `required`、`format`、`minLength` 等基础规则组合 |
| [跨字段与异步校验](/examples/forms#跨字段与异步校验) | 读取同记录密码比对，以及配合 `AbortSignal` 处理异步请求 |
| [联动计算](/examples/linkage#联动计算) | 使用 `reaction` 派生计算字段的值 |
| [条件显隐](/examples/linkage#条件显隐) | `$visible = false` 跳过校验；不提交再写 `$omit` |
| [动态行按行计算](/examples/arrays#动态行按行计算) | 使用 `reaction.each` 为订单每一行独立计算小计 |

下方按主题列出完整场景示例（代码支持在线编辑，独立页面汇总在 [示例目录](/play)，异步请求均为本地模拟）。
