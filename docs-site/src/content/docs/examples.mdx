先看五个基础场景，每个示例均可在线编辑代码并提交验证：

| 场景 | 核心用法 |
|---|---|
| [登录校验](/examples/login) | `required`、`format`、`minLength` 等基础规则组合 |
| [联动计算](/examples/computed) | 使用 `reaction` 派生计算字段的值 |
| [条件显隐](/examples/visibility) | `$visible = false` 跳过校验；不提交再写 `$omit` |
| [动态表格](/examples/dynamic-table) | 使用 `reaction.each` 为订单每一行独立计算小计 |
| [跨字段与异步校验](/examples/async-rules) | 读取同记录密码比对，以及配合 `AbortSignal` 处理异步请求 |

下方按主题列出完整场景示例（代码支持在线编辑，独立页面汇总在 [示例目录](/play)，异步请求均为本地模拟）。
