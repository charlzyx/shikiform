从 `@shikiform/hooks` 导入，没有 antd 依赖。`@shikiform/antd` 里的 [ArrayTable](/reference/antd#arraytable) 和 [ShadowModal、Suggestion、CascaderPlus](/reference/pro-components) 是它们的渲染层。可点的例子：[/play/array-table](/play/array-table)、[/play/shadow-form](/play/shadow-form)、[/play/pro-enum](/play/pro-enum)。

## useArrayTable

```ts
useArrayTable<TRow>(name: string, options?: UseArrayTableOptions<TRow>): ArrayTableApi<TRow>
// options: rowKey, createRowKey?(row), pagination (false | { pageSize, current, total, hideOnSinglePage, onChange }),
//          preserveSelection, selectedKeys / onSelectionChange, defaultExpandAll, rowExpandable, onRemove
// 行操作: remove(i), add(row, { jump? }), copy(i, transform?(copy, source)), moveUp(i), moveDown(i), move(from, to)
```

数组字段的表格状态，不含 UI：分页切片（给了 `pagination.total` 就是受控的服务端分页，数组只放一页）、行选择（`selectPage` / `invertPage` / `clearSelection`，默认翻页清空，`preserveSelection` 保留）、展开（`defaultExpandAll` 每页重新展开）、行操作（`remove` 先跑异步 `onRemove`，失败保留；`add` 追加并翻到新行所在页；`copy`、`moveUp`、`moveDown`）。只订阅数组结构，单元格改值不会让表格重渲染。`pageRows[i].position` 是跨页的 1 起序号。

**复制行与行 id。** `copy(i)` 在第 `i` 行后插入一份深拷贝。设了 `rowKey` 时，复制行的 id 这样处理：

- 传了 `createRowKey(row)`：复制行的 id 是它的返回值（`row` 是去掉 id 的拷贝），内部 key 也随之变成这个 id；`add(row)` 遇到 `row[rowKey]` 为 `undefined` / `null` 时同样调用它补 id，已有 id 不动。
- 没传：默认删掉 id 字段，复制行按对象身份做 key，提交结果里这行没有 id，需要自己补。
- `copy(i, (copy, source) => …)` 的返回值就是要插入的行，最后执行，可以改 id 或其他字段。

```ts
let seq = 1000
const table = useArrayTable<Row>('rows', { rowKey: 'id', createRowKey: () => ++seq })
table.copy(0)                                                   // { id: 1001, sku: 'a' }
table.copy(0, (row, source) => ({ ...row, sku: `${source.sku} (副本)` }))
```

`ArrayTable` 同样接受 `createRowKey`（`rowKey` 来自外层 `<ArrayField rowKey>`），`ArrayTable.Copy` 按钮会用它。

## useColumnSettings

```ts
useColumnSettings(columns: { key: string; title?: unknown; width?: number; hidden?: boolean }[]): ColumnSettingsApi
// items, visibleKeys, toggle(key), move(from, to), moveKey(fromKey, toKey), setWidth(key, width),
// density, setDensity, reset(), dragProps(key), drag: { from, over }
```

列配置状态（Pro.formily `ProSettings`）：显示 / 隐藏、排序、列宽（拖拽表头时调用 `setWidth`）、密度（large / middle / small）。后来新增的列追加在末尾，被删掉的列自动消失；`reset()` 恢复初始顺序、可见性、列宽和密度。

拖拽排序不依赖任何库：`dragProps(key)` 返回一组 HTML5 拖放属性（`draggable`、`onDragStart`、`onDragOver`、`onDragLeave`、`onDrop`、`onDragEnd`，以及拖动中 / 悬停目标的 `data-dragging` / `data-drag-over`），展开到每一行上，把一行放到另一行上就移到那一行的位置（`moveKey`）。只接受从列表里开始的拖动，拖进来的文件之类不会改顺序。拖放不能用键盘操作，所以保留 `move(from, to)` 做 ↑ ↓ 按钮。

```tsx
const settings = useColumnSettings(columns)
settings.items.map((item, index) => (
  <div key={item.key} {...settings.dragProps(item.key)}>
    ⋮⋮ {item.title}
    <button aria-label="上移" onClick={() => settings.move(index, index - 1)}>↑</button>
  </div>
))
```

## useShadowForm

```ts
useShadowForm<TValues = Record<string, any>, TContext = unknown>(options?: {
  name?: string
  form?: FormInstance<any>
  add?: boolean
  rowKey?: string | ((row: any) => string | number)
  merge?: (current: TValues, values: TValues) => TValues
  initialValues?: TValues
  fields?, trees?, effects?, formOptions?,
  onOk?: (values: TValues, context?: TContext) => void | false | Promise<void | false>,
  onCancel?: (context?: TContext) => void,
}): ShadowFormApi<TValues, TContext>
// { form, visible, loading, submitting, context, open(init?, context?), confirm(onOk?), cancel() }
```

草稿表单（`ShadowForm`）：在独立的临时表单实例中编辑一份副本，只有用户确认且校验通过后，才会写回宿主或交给 `onOk`，取消则直接丢弃草稿，绝不修改宿主表单。每次调用 `open()` 都会创建全新的表单引擎，因此 `reset`、`dirty`、错误状态与联动都会从干净基线开始。`open` 支持直接传入对象或异步加载函数（连续触发时，新的 `open` 会自动作废尚在加载中的旧请求）。若 `confirm` 校验失败，会返回 `{ ok: false, errors }` 并保持弹窗/草稿打开。

- **路径绑定（`name` / `form`）**：传入 `name`（或在 `<Form>` / 数组行 / 对象作用域内省略 `name` 或传相对路径）时，草稿会自动绑定到宿主表单的对应路径：
  - **自动继承**：打开草稿时自动从宿主复制当前路径的 `initialValues`，剥离路径前缀后继承 `fields` / `trees` 声明（含数组通配符模板如 `list.*`），并继承宿主的 `messages`、`validateTrigger`、`asyncDebounceMs`、`enumPolicy` 以及该路径当前生效的 `pattern`（如 `readPretty` / `readOnly`）。
  - **默认写回**：确认且校验通过后自动写回宿主路径——对象默认按 `{ ...current, ...values }` 浅合并（可通过 `merge` 自定义）；当绑定到数组且 `add: true` 时追加到数组末尾；当绑定到数组行时按 `rowKey`（或对象引用）定位原行写回，行被移动后仍能准确落回原行。若 `onOk` 返回 `false`，则跳过默认写回，适合自行调接口提交后刷新列表的场景。

## useSuggestion

```ts
useSuggestion({ fetch: (keyword, { signal }) => Promise<EnumOption[]>, debounce?: number, minLength?: number }): SuggestionApi
// { keyword, options, loading, error, search(keyword), remember(options), labelOf(value) }
```

远程联想（Pro.formily `Suggestion`）：防抖，新关键字中止旧请求，迟到的结果按序号丢弃（最后一次请求胜出）。`remember` 记住用户选中的选项，下一次搜索后它们的标签仍能显示。

## useLazyCascader

```ts
useLazyCascader({ load: (path: (string | number)[]) => Promise<CascaderOption[]>, paths?: (string | number)[][], enabled?: boolean }): LazyCascaderApi
// { options, loading, loadChildren(path), ensure(paths), labelsOf(path) }
```

懒加载级联（Pro.formily `CascaderPlus`）：挂载时 `load([])` 取根，展开时 `load(path)` 取子级；同一路径并发只请求一次。`paths` 是已有值，打开时逐级加载每一层祖先，标签就能反显。已带 `children` 的节点不再加载（`load([])` 直接返回整棵树也可以）。`enabled: false` 时什么都不加载。

## useCascaderLabels

```ts
useCascaderLabels({ value: unknown, multiple?: boolean, load?: CascaderLoader }): CascaderLabelsApi
// { labels: string[][], loading }
```

级联值的标签，给阅读态用（`CascaderPlus` 的 `readPretty` 就是它）。`labelInValue` 的值自带标签，不发请求；裸值（`['410000', '410600']`）用同一个 `load` 逐级加载祖先后解析成标签，加载完成前或找不到的层级显示原值。没有 `load` 时只能显示原值。每条路径一组标签，`multiple` 时有多组。

```tsx
const { labels } = useCascaderLabels({ value: ['410000', '410600', '410621'], load: loadArea })
labels[0].join('/') // '河南省/鹤壁市/浚县'
```

## enumItems

```ts
enumItems(value: unknown, options?: EnumOption[], config?: { colorful?: boolean }): EnumDisplayItem[]
// → [{ value, label, color, matched }]
```

把字段值（单个或数组，`{ label, value }` 项也行）按枚举解析成显示项：标签和颜色。宽松匹配（`1` 等于 `'1'`，与 Pro.formily 一致）；选项没写 `color` 时按位置取调色板颜色，`colorful: false` 关闭。找不到的值保留，`label` 是它自己（`labelInValue` 项用自己的 `label`），`matched: false`。`PreviewText.Select`（选择类控件的阅读态）就是它的渲染。

## ENUM_COLORS

```ts
const ENUM_COLORS: { success: 'green'; processing: 'blue'; error: 'red'; warning: 'gold'; default: '#d9d9d9'; … }
```

枚举选项 `color` 可以写的语义色名（`success`、`processing`、`error`、`warning`、`default`）和 antd 预设色名；其他字符串（如 `#1677ff`）原样使用。`enumItems` 和 `PreviewText` 都按这张表把名字换成颜色。
