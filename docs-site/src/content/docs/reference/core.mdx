`@shikiform/core` 是纯 TypeScript 表单引擎，不依赖 React 或任何 UI 库。`@shikiform/react` 重新导出了本页中常用的运行时 API，因此在 React 组件中也可以直接从 `@shikiform/react` 导入。

相关指南：[按路径读写](/basics/path)、[联动](/guide/linkage)、[核心概念](/guide/concepts)。

## createForm

```ts
function createForm<T, TSubmit = T>(options?: FormOptions<T>): FormInstance<T, TSubmit>

// @shikiform/react。V 写在 typed<V>() 上。
typed<V>().createForm<TSubmit = DefaultSubmit, const F extends FieldsInput<V> = {}>(
  options?: Omit<FormOptions<V>, 'fields'> & { fields?: F & FieldsInput<V> },
): FormInstance<V, ResolveSubmit<V, TSubmit, F>>

typed<V>().useForm<TSubmit = DefaultSubmit, const F extends FieldsInput<V> = {}>(
  options?: Omit<UseFormOptions<V>, 'fields'> & { fields?: F & FieldsInput<V> },
): FormInstance<V, ResolveSubmit<V, TSubmit, F>>
```

用于在组件外部创建表单引擎实例，配置项与 `useForm` 完全一致（包括 `initialValues`、`effects`、`fields`、`validate`、`pattern`、`messages`）。返回的 `FormInstance` 提供 `getValue`、`setValue`、`batch`、`submit`、`validate`、`reset` 等方法。无参调用 `createForm()` 或传入 `undefined` 与传入 `{}` 等价。

在类型推导上：不传泛型参数时，`fields` 中声明了 `display: 'virtual'` 或 `display: 'none'` 的路径在提交类型里会自动变为可选；显式传入 `createForm<V>(options)` 时提交类型固定为 `V`；如果既想显式指定原始值类型 `V`，又想根据 `fields` 自动剔除虚拟/隐藏字段，请使用 `typed<V>().createForm({ fields })`（或 `typed<V>().useForm({ fields })`）；需要手动列举可选路径时，可以通过第二个泛型参数传 `SubmitValues<V, 'tmp'>`。`DefaultSubmit`、`FieldsInput` 和 `ResolveSubmit` 为内部推导辅助类型，不作为公开类型导出。

```ts
import { createForm } from '@shikiform/core'

const form = createForm<{ name: string }>({ initialValues: { name: '' } })
form.setValue('name', 'Ada')
```

```ts
import { typed } from '@shikiform/react'

type Values = { name: string; confirm: string }
const fields = { confirm: { display: 'virtual' as const } }

const form = typed<Values>().createForm({ initialValues: { name: '', confirm: '' }, fields })

form.submit((values) => {
  values.name // string
  values.confirm // string | undefined
})

function Demo() {
  const live = typed<Values>().useForm({ initialValues: { name: '', confirm: '' }, fields })
  live.submit((values) => {
    values.name // string
    values.confirm // string | undefined
  })
  return null
}
```

## get

```ts
function get<T, P extends FieldPath<T>>(data: T, path: P): PathValue<T, P>
```

从普通数据上按路径读取。`a.b[0].c`、`a.b.0.c`、`a['name']` 都可以。缺的段落是 `undefined`。不改入参。

在 draft 上，`get` 沿属性走，返回子 handle，读值再写 `.$value`。带下标同样可以。

```ts
get(order, 'items[0].sku')
get(d, 'user.name').$value
get(d, 'orders[0].lines[2].qty').$value
d.orders[0].lines[2].qty.$value
form.getValue('orders[0].lines[2].qty')
```

## set

```ts
function set<T, P extends FieldPath<T>>(data: T, path: P, value: PathValue<T, P>): T
```

返回一棵把 `path` 设成 `value` 的新树，不改入参。缺的中间对象和数组会建出来。

```ts
const next = set(order, 'items[0].qty', 2)
```

写进表单用 `form.setValue('items[0].qty', 2)`，或在 reaction 里给 handle 的 `$value` 赋值。不要对 draft 调用 `set`。

## defineEffects

`defineEffects<T>(factory)` 用于定义一组可复用的联动模块。`factory` 会收到 `reaction`、`watch` 和 `query`：`reaction` 用于声明派生状态，`watch` 用于响应变化执行一次性动作，两者均提供仅接收两个参数的 `each(select, fn)` 方法。详见 [联动](/guide/linkage)。

```ts
import { defineEffects } from '@shikiform/core'

const effects = defineEffects<{ qty: number; total: number }>(({ reaction }) => {
  reaction((d) => {
    d.total.$value = (d.qty.$value ?? 0) * 2
  })
})
```

## EnumSource

用于定义异步选项源，通过 `EnumSource.with(params)` 绑定到字段的 `enum` 或 `$enum`。在请求尚未完成前，读取 `$enum` 会返回空数组 `[]`。

## 错误类

引擎会导出 `ShikiUsageError`、`ShikiConflictError` 和 `ShikiCycleError`，均可使用 `instanceof` 捕获判断。其中用法误用和反应式写冲突仅在开发环境校验，而循环依赖错误在生产环境也会抛出。

## 文案

内置文案默认使用中文 `zhCN`，同时也提供了英文 `enUS`。调用 `setDefaultMessages(enUS)` 会修改此后创建的所有表单的默认文案，单个表单可通过 `messages` 选项进行局部覆盖，`getDefaultMessages()` 用于读取当前生效的全局默认文案。

## 树坐标

提供 `moveNode`、`pathOf` 和 `posOf` 工具函数用于操作树形节点的坐标路径（`pos` 为下标数组，如 `[0, 2]`）。普通数组操作请直接使用 `form.moveArray`。
