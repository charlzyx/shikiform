普通 `<Field>` 从 React 上下文读取表单实例，编译期不知道表单类型，`name` 默认接受任意字符串（适用于动态路径）。`typed(form)` 返回同一组组件和 Hook 的带类型版本，不增加运行时开销：

```tsx
const form = useForm<Values>({ initialValues })
const F = typed(form)
const email = F.useWatch((d) => d.email.$value)

<F.Field name="email" decorator={[FormItem]} component={[Input]} />
```

在作用域组件中，`F.ArrayField` 的渲染函数会传入按单行类型约束的 `row.Field`，`F.ObjectField` 的函数子节点会传入按该对象类型约束的 `obj.Field`，字段名始终相对于当前作用域书写。

对于可复用的独立子表单组件，只需通过 `const A = typed<Address>()` 定义一组绑定到该片段类型的组件，再挂载到对应的 `<ObjectField>` 下面即可。

## 注册控件与默认装饰器

使用 `<FieldKit>` 或 `<Form kit>` 可以集中注册常用控件和默认装饰器（省略 `decorator` 属性的字段会自动套用默认装饰器，不需要时可传 `decorator={false}`）。配合 TypeScript 模块扩展声明后，使用字符串名称也能获得完整的属性提示与校验：

```tsx
import { Field, FieldKit, Form } from '@shikiform/react'

declare module '@shikiform/react' {
  interface FieldComponents {
    Input: typeof Input
  }
  interface FieldDecorators {
    FormItem: typeof FormItem
  }
}

<FieldKit components={{ Input }} decorator={FormItem}>
  <Form form={form}>
    <Field name="name" title="姓名" component="Input" />
    <Field name="qty" component={[Input, { placeholder: '数量' }]} decorator={false} />
  </Form>
</FieldKit>
```

在传入 `[Component, props]` 元组时，引擎会校验 `props` 与组件属性的类型匹配（`data-*` 自定义属性默认放行）。当组件本身是泛型控件（例如 `InputNumber`）时，元组中会按最宽泛的类型参数推断，回调参数通常无需手动标注类型。

## 推导提交值类型

`submit`、`getSubmitValues` 与 `onSubmit` 的值类型按以下规则推导：

- 不传泛型调用 `createForm({ fields })` / `useForm({ fields })`，或通过 `typed<Values>().createForm({ fields })` / `typed<Values>().useForm({ fields })` 指定原始值类型时，`fields` 中声明了 `omit: true` 的路径在提交类型中变为可选属性。仅设置 `visible: false` 的字段仍参与提交，类型保持不变，除非同时声明 `omit: true`。
- 调用 `createForm<Values>(options)` / `useForm<Values>(options)` 时，提交类型固定为 `Values`，不读取 `fields`。
- JSX 或 `reaction` 中动态设置的 `omit` 无法在编译期推断，可通过第二个泛型参数配合 `SubmitValues` 显式列出路径：

```ts
import { createForm, type SubmitValues } from '@shikiform/react'

type Values = { name: string; confirm: string; rows: { total: number }[] }

createForm<Values, SubmitValues<Values, 'confirm' | 'rows.*.total'>>({
  initialValues: { name: '', confirm: '', rows: [] },
})
```

上述写法中，`confirm` 和数组每行的 `total` 在提交值类型中都会被自动推导为可选属性。另外，无参数调用 `createForm()` / `useForm()` 或传入 `undefined` 均等价于传入 `{}`。
