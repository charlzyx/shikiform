## Package entry points

`@shikiform/core` is independent of React. `@shikiform/react` re-exports common engine APIs and supplies field components, hooks and adapters. `@shikiform/react` supplies higher-level headless hooks.

## Create a form

```ts
useForm<T, TSubmit = T>(options?: UseFormOptions<T>): FormInstance<T, TSubmit>  // Stable across renders. Options default to an empty object.
createForm<T, TSubmit = T>(options?: FormOptions<T>): FormInstance<T, TSubmit>  // Outside React. Options default to an empty object.
```

| Option | Behavior |
|---|---|
| `initialValues` | Initial data and reset baseline. Defaults to an empty object. |
| `fields` | Persistent field rules, flags, presentation and options. Wildcard paths apply to each row. |
| `effects` | Install effect modules in array order. |
| `validate` | Whole-form Standard Schema or a function returning errors by path. |
| `validateTrigger` | Defaults to blur and submit. May also include change. |
| `asyncDebounceMs` | Delay asynchronous rules. Defaults to zero and can be overridden per field. |
| `enumPolicy` | Ignore an out-of-range value by default, clear it or report an error. |
| `readOnly`, `disabled` | Set root state inherited by descendants. |
| `trees` | Declare tree roots, children keys and row keys before mounting. |
| `messages` | Override all or part of the built-in Chinese messages. |

### Read, write and submit

| Method | Contract |
|---|---|
| `getValue`, `setValue` | Read or update a single dot or bracket path. Path writes reject quoted keys containing `.`, `[`, or `]` in both development and production (replace the parent object instead); invalid array indices throw `ShikiUsageError` in development and are ignored in production. In development an object result is a read-only view (not `===` to the stored value; production returns the stored value). `indexOf` / `includes` still find a raw row. Copy with `snapshot(value)` for `structuredClone`, `postMessage`, or IndexedDB. `getSubmitValues()` is the submit payload. |
| `patchValues` | Deep-merge partial plain objects in one flush; arrays and primitives replace whole. |
| `batch(fn)` | Write multiple paths on one draft with one reaction pass and one notification. Nested `batch` buffers each layer independently: an inner batch merges into the outer batch on success and rolls back only its own layer if `fn` throws. |
| `validate()` / `validate(path)` / `validate([paths])` | Validate the whole form, one subtree, or several paths in one pass (what a step validates; bracket and dot path aliases normalize identically at runtime). On success, resolves a clone: no path is `getSubmitValues()` (`TSubmit`; root `$omit: true` yields `{}`); one path is that value (`PathValue`; the path itself is returned even when omitted or under a root omit, and descendants omitted only because of that path stay — a descendant's own `omit` is removed); an array is a nested object of only those paths (`ValidatePick`). A literal list keeps each value. An array index is a numeric key (`{ rows: { 0: { name } } }`). The array returned at runtime is dense, and an index that was not selected is `undefined`, so `result.rows[0]` reads that property. Rejects `FieldError[]`. A form-level `validate` throw rejects as-is. |
| `submit(onValid?)` | Validate and return the callback result or submit values. A later attempt immediately rejects an earlier call still in validation with `SubmitSupersededError`, while an already-started `onValid` continues counting toward `submitting`. |
| `getSubmitValues` | Return values with omitted subtrees removed. Root `$omit: true` returns `{}` and excludes the whole form from `dirty`. |
| `reset(path?)`, `reset(record)` | Restore initial values or install a new record and baseline. `reset(path)` normalizes bracket and dot paths and cancels queued debounced validation and overlapping in-flight validation only for that subtree. |
| `setInitialValues` | Replace the baseline while preserving current values. |
| `setErrors`, `clearErrors` | Set external errors or clear errors at a path or across the form (bracket and dot path aliases normalize identically). |
| `message` | Resolve a message using form, application and library defaults in order. |
| `subscribePath`, `subscribeStructure`, `subscribeMeta` | Observe paths, array or tree structure (bracket and dot paths normalize on registration), and form state. Each returns an unsubscribe function. |
| `subscribeValidateFailed` | Observe validation failures from explicit validate and submit calls. |

Three overloads. The resolved type follows the argument:

```ts
validate(): Promise<TSubmit>
validate<P extends FieldPath<T>>(path: P): Promise<PathValue<T, P>>
validate<const Paths extends readonly FieldPath<T>[]>(paths: Paths): Promise<ValidatePick<T, Paths>>
```

Success resolves a copy of the values current when the call finishes, with `omit` removed for that scope. Plain objects, arrays, `Date`, `Map`, and `Set` are copied. Class instances, functions, and React elements keep the same reference. Editing the copy does not write back to the form. In development, `getValue` and `form.values` are the read-only view that throws `ShikiUsageError` on mutation. Rules read the snapshot from the start of the pass. `validate()` does not rerun when values change during that pass, so the result can be newer than the snapshot. `submit()` reruns until the values settle, then resolves the values that were just checked. A missing path resolves `undefined`. Failure still rejects `FieldError[]`. A throw from a form-level `validate` rejects as-is.

```ts
const values = await form.validate()
const city = await form.validate('user.city')
const picked = await form.validate(['name', 'user.city'])
values.name = 'Grace' // Edits the copy only.
```

### Array and tree handles

Use the scoped hooks for structural edits and native drag props.

```ts
useArrayField<TRow = unknown>(): ArrayHandle<TRow>
useArrayField(name, opts?: { rowKey?: string }): ArrayHandle<Row>
useTreeField<TNode = unknown>(): TreeNodeHandle<TNode>   // Inside a node, path targets that node.
useTreeField(name, opts?: { childrenKey?: string; rowKey?: string }): TreeHandle<unknown>   // Both paths identify the tree root.

interface ArrayHandle<TRow> {
  path: string
  keys: { key: string; index: number }[]
  push(row: TRow): void
  insert(index: number, row: TRow): void
  remove(index: number): void
  move(from: number, to: number): void   // to is the final index.
  swap(indexA: number, indexB: number): void
  replace(index: number, row: TRow): void
  dragProps(index: number): DragProps
}

interface TreeHandle<TNode> {
  path: string            // The root handle targets the tree. A node handle targets its node.
  treePath: string        // Always points to the root. Equals path on the root handle.
  errors: readonly string[]     // Messages for the array itself, excluding descendants.
  warnings: readonly string[]
  value: TNode[]
  push(node: TNode, parentPos?: Pos): void  // Append to the root or as the last child of parentPos.
  insert(pos: Pos, node: TNode): void
  remove(pos: Pos): void
  replace(pos: Pos, node: TNode): void
  move(from: Pos, to: Pos): MoveResult   // Use final coordinates. A rejected move into a descendant returns a reason.
  dragProps(pos: Pos): DragProps
}
```

### Edit an existing record

```ts
const form = useForm<Values>({ values: query.data })            // Reset when the record arrives or reloads.
const dirty = useWatch((d: Draft<Values>) => d.$dirty)          // Restoring the initial value clears dirty.

<Button disabled={!dirty} onClick={() => form.submit(save)}>Save</Button>
```

### Submit value types

Inferred `fields` make statically omitted paths optional. Use `typed<V>()` to fix the value type while preserving field inference. For dynamic omissions, specify the submit type explicitly.

```ts
import { createForm, type SubmitValues } from '@shikiform/react'

type V = { a: string; tmp: string; b: string; rows: { qty: number; total: number }[] }
const form = createForm<V, SubmitValues<V, 'tmp' | 'b' | 'rows.*.total'>>({
  initialValues: { a: '1', tmp: 'x', b: '', rows: [] },
  fields: { tmp: { omit: true }, 'rows.*.total': { omit: true } },
})
await form.submit((values) => {
  values.tmp   // string | undefined
  values.rows[0]?.total // number | undefined
})
```

## React components

| Component | Behavior |
|---|---|
| `<Form form onSubmit onInvalid onSubmitError …>` | Provides engine context and renders a native `<form>`. Calls `form.submit(onSubmit)`, routes validation errors to `onInvalid(errors)`, and sends `onSubmit` / `SubmitUnstableError` errors to `onSubmitError` (defaults to `console.error`). Focuses the first invalid field in document order on submit or `validate()` failure. Control `id` is `<prefix>-<sanitized-path>`. |
| `<Field name …>` | Owns a path and renders its decorator and control. See the [field guide](/en/guide/field). |
| `<ObjectField name visible? disabled? readOnly? omit?>` | Object scope. `visible`, `disabled`, and `readOnly` inherit unless overridden (`false` exits). `omit` removes the whole subtree from submit (`omit: false` on a child cannot opt back in). |
| `<ArrayField name rowKey? component? virtualScroll?>{({ index, key }) => …}` | Per-row scope; parent subscribes only to array structure. `component` wraps rows; `virtualScroll={{ height }}` mounts visible plain rows only. |
| `<TreeField name childrenKey? rowKey?>{(node) => …}` | Registers the tree root and renders nodes recursively (`node` has `{ path, pos, index, key, depth, children }`). Use `useTreeField()` inside nodes or `useTreeField(name)` outside. |
| `<Field name ui="echo">` / `<UI name component decorator …>` | Secondary UI for a field (`d.x.$ui('echo')`) or value-free UI node (`d.$ui(name)`). See [named UI nodes](/en/guide/ui). |
| `<Watch select>{(value) => …}` | Render-prop form of `useWatch`. |

Plain `<Field>`, `<ObjectField>`, `<ArrayField>`, and `useField` accept any string as an escape hatch for dynamic paths. Use [`typed(form)`](/en/reference/react-hooks#typed) for type-checked names and scoped `row.Field` / `obj.Field` helpers. Names are always relative to the current scope.

## Effects

```ts
const effects = defineEffects<Values>(({ reaction, watch, draft, query }) => {
  reaction((d) => { … })
  reaction.each(draft.items, (row, ctx) => { … }) // Path handle. (d) => d.items still works.
  watch(draft.city, (d) => { … })                 // Watches city.$value.
  watch([draft.a, draft.b], (d) => { … })         // Watches either $value.
  watch.each(draft.items, (row, ctx) => { … })
  query(pathOf('menus', pos)).$disabled = true    // Escape hatch when the path is already a string.
})
```

| API | Trigger | Notes |
|---|---|---|
| `reaction(effect)` | Immediately on install, then whenever a `$` state read during `effect` changes | Synchronous derivation. A field whose `$value` is written by a reaction becomes computed and still submits unless `omit`. |
| `reaction.each(draft.items, effect)` | Per own enumerable string key for plain objects; per element (and nested object arrays) for arrays | Path is read once at registration; selector `(d) => …` still works and re-reads every pass to follow changing keys. Takes two arguments only; filter with `ctx.key` / `ctx.depth`. |
| `watch(draft.city, effect)` / `watch(fn, effect)` | After a watched `$` state changes; skips the initial pass | `watch(draft.city, …)` equals `watch((d) => d.city.$value, …)`; `watch([draft.a, draft.b], …)` watches each `$value`. `watch(fn, effect)` triggers whenever **any `$` state read by `fn` changes** (it does **not** compare or deduplicate by `fn`'s return value — e.g. `d.amount.$value > 100` still triggers when `amount` goes from `10` to `20`), and re-tracks `fn`'s reads on each trigger so changing keys (`d.extra[d.activeKey.$value].$value`) are followed. |
| `watch.each(draft.rows, effect)` | Visits array elements and nested object arrays; `$` reads in the callback are its source | Changes to one element trigger only that element. Selector form still works. |
| `query(path)` | — | Untyped handle when the path is already a string (`pathOf`, config, or props such as `rowsPath`). Prefer `d.a.b`, `d.items[i]`, or `d.extra[key]` when the path can be written on `draft`. |

Row callbacks receive `(row, ctx)` where `ctx` includes `d`, `key`, `index`, `depth`, `parent`, `path`, and `pos`. See [reactions and watches](/en/guide/linkage).

## Engine utilities

Tree positions are arrays of indices. Use `pathOf` and `posOf` to translate between a data path and position. SKU helpers match value combinations and available options.

```ts
// Tree positions are index paths. [0, 2] is the third child of the first node.
pathOf(root: string, pos: Pos, childrenKey = 'children'): string          // pathOf('menus', [0, 2]) → 'menus.0.children.2'
posOf(root: string, path: string, childrenKey = 'children'): Pos | undefined
moveNode(nodes: any[], from: Pos, to: Pos, childrenKey?, canMove?, messages?): TreeMoveResult  // Returns a new array. The destination is the final position.

// Combination selection
comboMatch(table, selection): boolean                                     // Check whether any combination matches every selected dimension.
comboOptions(table, selection, dim, { disabledWhen? }?): ComboOption[]    // Available values for dim given the other selections.
```

## Errors and messages

```ts
class ShikiUsageError extends Error      // Development errors include mutating read-only views, rereading a flag just written, treating handles as arrays, misspelled states,
                                         // unknown rule keys, undefined components or an ArrayField on a non-array. The error suggests a correction.
class ShikiCycleError extends Error      // Effects did not converge in ten passes. The cycle lists the chain.
class ShikiConflictError extends Error   // Two reactions write the same state. Inspect state, first and second.
class SubmitSupersededError extends Error // A later submit replaced this one (code = 'superseded').
class SubmitUnstableError extends Error   // Values failed to settle for three passes (code = 'unstable').
function isFieldErrors(value): value is FieldError[]  // Validation failures reject with this array.

zhCN / enUS: FormMessages                // Built-in messages default to zhCN.
setDefaultMessages(messages: Partial<FormMessages>): void   // Partial application-wide message overrides.
getDefaultMessages(): FormMessages       // Current application defaults after setDefaultMessages.
```

`@shikiform/core` exports form, field, enum, rule, draft and path types. `@shikiform/react` adds typed components, bindings, scopes, array handles and form props. `@shikiform/react` exports option, result and handle types alongside its hooks. See the [TypeScript guide](/en/advanced/typescript).
