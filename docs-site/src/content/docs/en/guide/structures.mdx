## Object and array scopes

Use `ObjectField` for a group of related properties and `ArrayField` for repeated records. The render function receives components typed to that scope. Use stable row keys for moves and insertions.

```tsx preview
import { type ReactNode } from 'react';
import { enUS, ArrayField, Field, Form, ObjectField, Watch, useArrayField, useIndex, useForm, type Draft } from '@shikiform/react';
import { Button, Card, FieldInput, FormItem, PlusIcon, siteKit, TrashIcon } from '@site/ui';

type Contact = { id: number; name: string; phone: string };
type Values = { profile: { name: string; address: { city: string } }; contacts: Contact[] };

let nextId = 3;

/** Read the array and row position from scope. */
function RowActions() {
  const array = useArrayField<Contact>();
  const index = useIndex();
  return (
    <span style={{ display: 'inline-flex', gap: 4, marginInlineStart: 'auto' }}>
      <Button variant="ghost" size="sm" disabled={index === 0} onClick={() => array.move(index, index - 1)}>Move up</Button>
      <Button variant="ghost" size="sm" disabled={index === array.keys.length - 1} onClick={() => array.move(index, index + 1)}>Move down</Button>
      <Button variant="danger" size="sm" icon={<TrashIcon size={13} />} onClick={() => array.remove(index)}>Delete</Button>
    </span>
  );
}

/** Put the add button in the ArrayField container to access its array handle. */
function ContactList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Contact>();
  return (
    <Card
      title="Contacts"
      padding="sm"
      extra={
        <Button
          variant="outline"
          size="sm"
          icon={<PlusIcon size={13} />}
          onClick={() => array.push({ id: nextId++, name: '', phone: '' })}
        >
          Add contact
        </Button>
      }
    >
      <div style={{ display: 'grid', gap: 8 }}>{children}</div>
    </Card>
  );
}

export default function App() {
  const form = useForm<Values>({
    messages: enUS,
    initialValues: {
      profile: { name: 'Ada', address: { city: "London" } },
      contacts: [{ id: 1, name: 'Charles', phone: '100' }, { id: 2, name: 'Mary', phone: '200' }],
    },
    fields: { 'contacts.*.name': { required: true } },
  });
  return (
    <Form form={form} kit={siteKit}>
      <Card title="Profile" padding="sm">
        <ObjectField name="profile">
          <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(200px, 1fr))', gap: 12 }}>
            <Field name="name" title="Name" component={FieldInput} />
            <ObjectField name="address">
              <Field name="city" title="City" description="Path: profile.address.city" component={FieldInput} />
            </ObjectField>
          </div>
        </ObjectField>
      </Card>
      <ArrayField name="contacts" rowKey="id" component={ContactList}>
        {() => (
          <div style={{ display: 'flex', gap: 8, alignItems: 'center', flexWrap: 'wrap' }}>
            <Field name="name" decorator={[FormItem, { compact: true }]} component={[FieldInput, { size: 'sm', placeholder: "Contact", style: { width: 140 } }]} />
            <Field name="phone" decorator={[FormItem, { compact: true }]} component={[FieldInput, { size: 'sm', placeholder: "Phone", style: { width: 140 } }]} />
            <RowActions />
          </div>
        )}
      </ArrayField>
      <Watch select={(d: Draft<Values>) => d.$value}>{(values) => <pre>{JSON.stringify(values, null, 2)}</pre>}</Watch>
    </Form>
  );
}
```

### Use relative field names

A child of `address` uses `city`. Including the parent prefix again produces the wrong path and throws in development.

```tsx
const F = typed(form)

// ✗ Resolves to group.group.inner and throws at runtime
<F.ObjectField name="group">
  <F.Field name="group.inner" />
</F.ObjectField>

// ✓ obj.Field checks relative paths against this object
<F.ObjectField name="group">
  {(obj) => <obj.Field name="inner" />}
</F.ObjectField>
```

## Update a nested value

Assign to the field's own `$value` to notify its readers. Replacing an entire object updates all readers of that object. Outside effects, use `form.setValue(path, value)`.

```ts
d.user.name.$value = 'Ada'           // Write one path
d.extra[key].$value = amount         // Write a dynamic path without reading extra.$value
delete d.extra.$value[key]           // Remove an object property
d.items.$value.push(row)             // Append a row
d.items.$value.splice(index, 1)      // Remove a row and shift the following indexes
```

Assign a whole value when the result itself is a new collection, for example `d.items.$value = selectedIds.map(makeRow)`. To append one row, `push` retains the existing rows and uses the same row operation as `useArrayField().push`. On an array draft, `delete items[i]` leaves a hole and keeps the length. Use tree operations for registered trees.

See [dynamic arrays and tables](/en/guide/arrays) for row operations, drag handles and array-level rules.
