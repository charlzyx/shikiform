`@shikiform/react` provides table and editor state. Render it with a native table, dialog or your project's components.

## Draft editors with useShadowForm

Open an independent form to edit a copy. Cancel discards it, and confirm validates before writing back. The host keeps its original value and dirty state while the draft is open.

```tsx preview play=shadow-form
import { enUS, Field, Form, Watch, useForm, useShadowForm, type Draft } from '@shikiform/react';
import { Button, Card, Dialog, FieldInput, FieldSelect, siteKit } from '@site/ui';

type Info = { domain: string; owner: string; env: string };
type Values = { info: Info };

function EditPanel() {
  const shadow = useShadowForm<Info>({ name: 'info' });
  return (
    <div>
      <Button variant="primary" size="sm" onClick={() => void shadow.open()}>Edit draft</Button>
      <Dialog
        open={shadow.visible}
        onOpenChange={(open) => { if (!open) shadow.cancel(); }}
        title="Edit draft"
        description="Canceling leaves the host form untouched; confirming validates before writing back."
        footer={
          <>
            <Button variant="outline" onClick={shadow.cancel}>Cancel</Button>
            <Button variant="primary" loading={shadow.submitting} onClick={() => void shadow.confirm()}>Confirm</Button>
          </>
        }
      >
        <Form form={shadow.form} kit={siteKit} onSubmit={() => void shadow.confirm()}>
          <Field name="domain" component={FieldInput} />
          <Field name="owner" component={FieldInput} />
          <Field name="env" component={FieldSelect} />
        </Form>
      </Dialog>
    </div>
  );
}

export default function App() {
  const form = useForm<Values>({
    messages: enUS,
    initialValues: { info: { domain: 'shikiform.dev', owner: 'Ada', env: 'prod' } },
    fields: {
      'info.domain': { title: "Domain", required: true, rules: { pattern: /^[a-z0-9.-]+$/, message: "Use lowercase letters, numbers, dots and hyphens" } },
      'info.owner': { title: "Owner", required: true },
      'info.env': { title: "Environment", enum: [{ label: "Production", value: 'prod' }, { label: "Staging", value: 'staging' }] },
    },
  });
  return (
    <Form form={form} style={{ maxWidth: 460 }}>
      <Card title="Host form value" padding="sm" extra={<EditPanel />}>
        <Watch select={(d: Draft<Values>) => d.info.$value}>
          {(info) => <pre style={{ margin: 0 }}>{JSON.stringify(info, null, 2)}</pre>}
        </Watch>
      </Card>
    </Form>
  );
}
```

With a bound `name`, fields in the draft use paths relative to the copied object. The draft inherits the host path's declared rules and effective read-only and disabled state.

## Query tables

Map filter values into request parameters. The hook manages requests, pagination, column filters, sorting and selection. Setting a sorter or filter resets the page. Searching and filtering clear selection, while sorting and paging preserve it.

```tsx
const table = useQueryTable({
  initialValues: { query: { domain: '' }, list: [] },
  params: 'query',
  rows: 'list',
  request,
})
```

See the [query hooks reference](/en/reference/query-hooks) and try the [native query table](/en/play/query-native).
