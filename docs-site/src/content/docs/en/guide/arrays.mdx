`<ArrayField>` creates a scope for each row and tracks its identity. A change to the array structure updates the list. Editing one cell only updates its subscribers.

## Reorder a list

Drag a contact or use the move buttons. `ContactRow` and `ContactList` both call `useWatch(selectContactsEditable)` so their actions follow the effective state of the contacts array. Toggle read-only mode to try it.

```tsx preview
import type { ReactNode } from 'react';
import { enUS, Form, typed, useArrayField, useForm, useIndex, useWatch, type Draft } from '@shikiform/react';
import {
  Badge,
  Button,
  Checkbox,
  FieldInput,
  FormItem,
  GripVerticalIcon,
  PlusIcon,
  TrashIcon,
} from '@site/ui';

type Contact = { name: string; phone: string };
type Values = { contacts: Contact[] };

const selectContactsEditable = (d: Draft<Values>) => !d.contacts.$readOnly && !d.contacts.$disabled;

function ContactRow({ children }: { children?: ReactNode }) {
  const array = useArrayField<Contact>();
  const index = useIndex();
  const editable = useWatch(selectContactsEditable);
  return (
    <div
      {...(editable ? array.dragProps(index) : {})}
      style={{
        display: 'flex',
        gap: 8,
        alignItems: 'center',
        flexWrap: 'wrap',
        padding: '8px 10px',
        border: '1px solid var(--sf-ui-border)',
        borderRadius: 'var(--sf-ui-radius)',
        background: 'var(--sf-ui-surface)',
      }}
    >
      {editable && (
        <span style={{ cursor: 'grab', color: 'var(--sf-ui-fg-muted)', display: 'inline-flex' }} title="Drag to reorder">
          <GripVerticalIcon size={14} />
        </span>
      )}
      <Badge variant="outline">#{index + 1}</Badge>
      {children}
      {editable && (
        <span style={{ display: 'inline-flex', gap: 4, marginInlineStart: 'auto' }}>
          <Button variant="ghost" size="sm" disabled={index === 0} onClick={() => array.move(index, index - 1)}>Move up</Button>
          <Button variant="ghost" size="sm" disabled={index === array.keys.length - 1} onClick={() => array.move(index, index + 1)}>Move down</Button>
          <Button variant="danger" size="sm" icon={<TrashIcon size={13} />} onClick={() => array.remove(index)}>Delete</Button>
        </span>
      )}
    </div>
  );
}

function ContactList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Contact>();
  const editable = useWatch(selectContactsEditable);
  return (
    <div style={{ display: 'grid', gap: 8 }}>
      {children}
      {editable && (
        <div>
          <Button variant="outline" size="sm" icon={<PlusIcon size={13} />} onClick={() => array.push({ name: '', phone: '' })}>
            Add contact
          </Button>
        </div>
      )}
    </div>
  );
}

export default function App() {
  const form = useForm<Values>({
    messages: enUS,
    initialValues: { contacts: [{ name: 'Ada', phone: '100' }, { name: 'Charles', phone: '200' }] },
    fields: { 'contacts.*.name': { required: true } },
  });
  const F = typed(form);
  return (
    <Form form={form}>
      <div>
        <Checkbox onCheckedChange={(checked) => form.batch((d) => { d.$readOnly = checked ? true : undefined; })}>
          Read only
        </Checkbox>
      </div>
      <F.ArrayField name="contacts" component={ContactList}>
        {(row) => (
          <ContactRow>
            <row.Field name="name" decorator={[FormItem, { compact: true }]} component={[FieldInput, { size: 'sm', placeholder: "Name", style: { width: 140 } }]} />
            <row.Field name="phone" decorator={[FormItem, { compact: true }]} component={[FieldInput, { size: 'sm', placeholder: "Phone", style: { width: 140 } }]} />
          </ContactRow>
        )}
      </F.ArrayField>
      <F.Watch select={(d) => d.contacts.$value}>{(rows) => <pre>{JSON.stringify(rows, null, 2)}</pre>}</F.Watch>
    </Form>
  );
}
```

- `typed(form).ArrayField` gives you a `row.Field` typed to one contact; inside a row, use `useIndex()` for the row position and `useRecord<Contact>()` for its data.
- Object rows without IDs track identity by object reference, so moving a row keeps its errors, touched state, and input focus intact; pass `rowKey` when your data already has a stable ID. Dropping a row calls `move` within the same array.
- In a single batch, array handle operations (`move`, `swap`, `remove`, etc.) and draft array methods (`push`, `splice`, `sort`, `reverse`) run in call order: edited cells move with their row, deleted rows stay deleted, and plain arrays with duplicate values or `reverse()` work on the latest data.
- With `virtualScroll`, visible rows reuse stable row keys so reordering rows inside the viewport preserves local component state.
- **Non-array guard**: calling row edits (`push`, `insert`, `remove`, `move`, `swap`, `replace`) on an array handle whose value is no longer an array initializes `null` / `undefined` to `[]`; for any other non-array value it throws `ShikiUsageError` in development and does nothing in production so existing data isn't overwritten.

## Read-only and disabled arrays

Rows inherit these states from the form or array. Apply them to editing buttons and drag handles as well as inputs.

```ts
useForm({ initialValues, readOnly: true })          // Start the whole form in read-only mode.
form.batch((d) => { d.$disabled = true })           // Disable the whole form. Assign undefined to restore the lower layer.
form.batch((d) => { d.contacts.$readOnly = true })  // Make just this array read-only.
```

## Array-level errors

A rule declared on `members.*.phones` validates each phone list as a whole. Render its messages once in the array container, where they remain visible even when the list is empty. `useArrayField().errors` and `warnings` belong to that array. The draft's `$errors` also includes descendant fields.

```tsx preview
import type { ReactNode } from 'react';
import { enUS, Form, Submit, typed, useArrayField, useForm, useIndex } from '@shikiform/react';
import { Alert, Button, Card, FieldInput, PlusIcon, TrashIcon } from '@site/ui';

type Phone = { no: string };
type Member = { name: string; phones: Phone[] };
type Values = { members: Member[] };

function PhoneList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Phone>();
  return (
    <div style={{ display: 'grid', gap: 8 }}>
      {children}
      {array.errors.length > 0 && <Alert variant="danger">{array.errors.join(', ')}</Alert>}
      <div>
        <Button variant="outline" size="sm" icon={<PlusIcon size={13} />} onClick={() => array.push({ no: '' })}>
          Add phone
        </Button>
      </div>
    </div>
  );
}

function RemovePhone() {
  const array = useArrayField<Phone>();
  const index = useIndex();
  return (
    <Button variant="ghost" size="sm" icon={<TrashIcon size={13} />} onClick={() => array.remove(index)}>
      Delete
    </Button>
  );
}

export default function App() {
  const form = useForm<Values>({
    messages: enUS,
    initialValues: { members: [{ name: 'Ada', phones: [] }] },
    fields: {
      'members.*.phones': {
        rules: { validator: (phones) => (Array.isArray(phones) && phones.length ? null : "Add at least one phone") },
      },
    },
  });
  const F = typed(form);
  return (
    <Form form={form} style={{ maxWidth: 420 }}>
      <F.ArrayField name="members">
        {(member) => (
          <Card padding="sm">
            <div style={{ display: 'grid', gap: 10 }}>
              <member.Field name="name" component={[FieldInput, { size: 'sm', placeholder: "Name" }]} />
              <member.ArrayField name="phones" component={PhoneList}>
                {(phone) => (
                  <div style={{ display: 'flex', gap: 8, alignItems: 'center' }}>
                    <phone.Field name="no" component={[FieldInput, { size: 'sm', placeholder: "Phone" }]} />
                    <RemovePhone />
                  </div>
                )}
              </member.ArrayField>
            </div>
          </Card>
        )}
      </F.ArrayField>
      <div><Submit asChild><Button variant="primary">Submit</Button></Submit></div>
    </Form>
  );
}
```

Submit the form with an empty list, then add a phone. Once a structural error is visible, an insert, removal, move or replacement revalidates the array. Mount the container inside `<ArrayField>` to provide its context.

## Editable tables with useArrayTable

Use `useArrayTable` for pagination, selection, expansion and row operations. `<ArrayField.Row>` establishes the correct scope for each visible row. Table presentation state stays outside submitted values.

```tsx preview play=array-table
import { enUS, ArrayField, Field, Form, useArrayTable, useForm, useRecord } from '@shikiform/react';
import {
  Badge,
  Button,
  FieldInput,
  FieldNumber,
  PlusIcon,
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
  Toolbar,
  TrashIcon,
} from '@site/ui';

type Row = { id: string; name: string; price: number; qty: number };
let nextId = 4;
const createRow = (): Row => ({ id: String(nextId++), name: '', price: 0, qty: 1 });

function Subtotal() {
  const row = useRecord<Row>();
  return <span style={{ fontWeight: 500 }}>¥ {((row.price ?? 0) * (row.qty ?? 0)).toFixed(2)}</span>;
}

function PurchaseTable() {
  const table = useArrayTable<Row>('list', {
    rowKey: 'id',
    createRowKey: () => String(nextId++),
    pagination: { pageSize: 5 },
  });
  return (
    <div style={{ display: 'grid', gap: 10 }}>
      <Toolbar ariaLabel="Table toolbar">
        <Button variant="primary" size="sm" icon={<PlusIcon size={13} />} onClick={() => table.add(createRow())}>
          Add row
        </Button>
        <Badge variant="outline" style={{ marginInlineStart: 'auto' }}>{table.total} rows</Badge>
      </Toolbar>
      <Table compact>
        <TableHead>
          <TableRow>
            <TableHeader style={{ width: 44 }}>#</TableHeader>
            <TableHeader>Name</TableHeader>
            <TableHeader style={{ width: 120 }}>Unit price</TableHeader>
            <TableHeader style={{ width: 110 }}>Quantity</TableHeader>
            <TableHeader style={{ width: 96 }}>Subtotal</TableHeader>
            <TableHeader style={{ width: 140 }}>Actions</TableHeader>
          </TableRow>
        </TableHead>
        <TableBody>
          {table.pageRows.map(({ key, index, position }) => (
            <ArrayField.Row key={key} path={`list.${index}`} index={index} itemKey={key}>
              <TableRow>
                <TableCell>{position}</TableCell>
                <TableCell><Field name="name" required component={[FieldInput, { size: 'sm', placeholder: 'Item name' }]} /></TableCell>
                <TableCell><Field name="price" component={[FieldNumber, { size: 'sm', min: 0, step: 0.5, prefix: '¥', showControls: false }]} /></TableCell>
                <TableCell><Field name="qty" component={[FieldNumber, { size: 'sm', min: 1 }]} /></TableCell>
                <TableCell><Subtotal /></TableCell>
                <TableCell>
                  <span style={{ display: 'inline-flex', gap: 4 }}>
                    <Button variant="ghost" size="sm" onClick={() => table.copy(index)}>Copy</Button>
                    <Button variant="danger" size="sm" icon={<TrashIcon size={13} />} onClick={() => void table.remove(index)}>Delete</Button>
                  </span>
                </TableCell>
              </TableRow>
            </ArrayField.Row>
          ))}
        </TableBody>
      </Table>
    </div>
  );
}

export default function App() {
  const form = useForm<{ list: Row[] }>({
    messages: enUS,
    initialValues: {
      list: [
        { id: '1', name: "Pen", price: 12, qty: 2 },
        { id: '2', name: "Notebook", price: 8.5, qty: 3 },
        { id: '3', name: "Ink", price: 20, qty: 1 },
      ],
    },
  });
  return <Form form={form}><PurchaseTable /></Form>;
}
```
