Use `defineEffects` to group related effects. In a draft, plain properties select a path and `$` properties access state.

```ts
const effects = defineEffects<Values>(({ reaction, watch, draft }) => {
  reaction((d) => { /* Track the states read during derivation. */ })
  watch(draft.province, (d) => { /* Watches province.$value. watch((d) => d.province.$value, …) is the same source. */ })
})
```

`draft` is the same root handle the callbacks receive as `d`. Use it to name a path at registration. Walking `draft.a.b` does not read a value. A `$` read in the factory body returns the current value and is not a dependency; in development, objects and arrays are read-only views. A `$` write there throws in development. Write inside `reaction` or `watch`.

## Derive state and respond to changes

A `reaction` runs immediately and tracks every `$` state it reads. A `watch` skips its first pass and ignores reads inside its `effect` callback. Passing `draft.city` or `[draft.a, draft.b]` watches those `$value` paths; passing a function `watch(fn, effect)` triggers whenever **any `$` state read by `fn` changes** (it does **not** compare or deduplicate by `fn`'s return value — for example, `d.amount.$value > 100` still triggers when `amount` changes from `10` to `20`), and re-tracks `fn`'s reads on each trigger so changing keys (`d.extra[d.activeKey.$value].$value`) are followed. To act only when a threshold crosses, check the condition inside `effect` or derive a boolean field in `reaction` and watch that field.

Keep reactions synchronous and side-effect free:
- Within a batch or effect pass, `getValue` and draft reads reflect all value and structural edits made so far in call order (array/tree handles and draft array mutators apply sequentially so edited cell values move with their row or node, removed rows do not reappear, plain arrays with duplicate values follow call order, and `reverse()` reverses the already-edited array); reading `$rules` and UI state also returns the latest value, while boolean flags (`$visible`, `$required`, etc.) should be kept in a local variable.
- If one `reaction` throws, sibling derivations in the same wave still settle before the first error is rethrown, preventing half-computed state.
- A draft handle from a rejected async `reaction` expires as soon as the pass ends (writing through it after `await` throws `ShikiUsageError` in development and is ignored in production). Do not call `form.setValue`, `form.reset`, or `form.submit` synchronously inside a `reaction` (development throws `ShikiUsageError`; in production `setValue` buffers with the current pass). Perform async work in `watch` and write back with `form.setValue` or `form.batch`.
- `$enum` accepts an option array, an `EnumSource` binding, or `undefined`. Invalid shapes throw `ShikiUsageError` in development and are ignored in production (preserving existing options, selected value, and in-flight load). Reading `$enum` back in the same pass returns normalized `{ label, value }[]` options; clearing an override with `$enum = undefined` immediately reads the fallback layer's options (including a cached `EnumSource`), or `[]` when no fallback options are available.

For dependent dropdowns, derive the available cities in a `reaction` and reset the selected city in a `watch` only after the province changes.

```tsx preview
import { useState, type ReactNode } from 'react';
import { Select, SelectContent, SelectItem, SelectItemIndicator, SelectTrigger, SelectValue } from '@ui-sdk/react/select';
import { enUS, Field, Form, defineEffects, useField, useFieldDecorator, useForm } from '@shikiform/react';

type Values = { price: number; qty: number; amount: number; province: string; city: string };

const CITIES: Record<string, { label: string; value: string }[]> = {
  zj: [{ label: "Hangzhou", value: 'hz' }, { label: "Ningbo", value: 'nb' }],
  js: [{ label: "Nanjing", value: 'nj' }, { label: "Suzhou", value: 'sz' }],
};

const effects = defineEffects<Values>(({ reaction, watch, draft }) => {
  // Run immediately and recalculate when price or quantity changes.
  reaction((d) => {
    d.amount.$value = d.price.$value * d.qty.$value;
  });
  // City options depend on province.
  reaction((d) => {
    // Use an empty list here. Undefined would restore the options declared in JSX or fields.
    d.city.$enum = CITIES[d.province.$value] ?? [];
    d.city.$disabled = !d.province.$value;
  });
  // Clear the city after a province change. Keep the initial selection on mount.
  watch(draft.province, (d) => {
    d.city.$value = '';
  });
});

function FieldItem({ children }: { children?: ReactNode }) {
  const d = useFieldDecorator();
  return (
    <div style={{ marginBottom: 8 }}>
      <label {...d.labelProps} style={{ display: 'inline-block', width: 56 }}>{d.label}</label>
      {children}
    </div>
  );
}

function NumberInput() {
  const field = useField<number>();
  return (
    <input id={field.id} type="number" value={field.value ?? 0} disabled={field.disabled}
      onChange={(e) => field.onChange(Number(e.target.value))} onBlur={field.onBlur} />
  );
}

function SelectInput() {
  const field = useField<string>();
  const items = field.options.map((o) => ({ value: String(o.value), label: o.label }));
  return (
    <Select items={items} value={field.value || null} disabled={field.disabled} onValueChange={(next) => field.onChange(next ?? '')} onOpenChange={(open) => { if (!open) field.onBlur(); }}>
      <SelectTrigger id={field.id}><SelectValue placeholder="Choose an option" /></SelectTrigger>
      <SelectContent>
        {items.map((o) => (
          <SelectItem key={o.value} value={o.value}>{o.label}<SelectItemIndicator aria-hidden="true">✓</SelectItemIndicator></SelectItem>
        ))}
      </SelectContent>
    </Select>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    messages: enUS,
    initialValues: { price: 10, qty: 2, amount: 0, province: 'zj', city: 'hz' },
    effects: [effects],
  });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <Field name="price" title="Unit price" decorator={[FieldItem]} component={[NumberInput]} />
      <Field name="qty" title="Quantity" decorator={[FieldItem]} component={[NumberInput]} />
      <Field name="amount" title="Amount" decorator={[FieldItem]} component={[NumberInput]} />
      <Field name="province" title="Province" enum={[{ label: "Zhejiang", value: 'zj' }, { label: "Jiangsu", value: 'js' }]}
        decorator={[FieldItem]} component={[SelectInput]} />
      <Field name="city" title="City" decorator={[FieldItem]} component={[SelectInput]} />
      <pre>{result}</pre>
    </Form>
  );
}
```

## One reaction per row

`reaction.each(draft.items, callback)` creates a separate instance for each row. `draft` comes from `defineEffects`, and the path is taken once at registration. The selector `(d) => d.items` still works and is re-read every pass, which is how a changing key is followed. Editing a quantity only recalculates that row's subtotal.

```ts
reaction.each(draft.items, (row, ctx) => { … })
// ctx includes key, index, depth, parent, path, pos and the root draft d.
```

### Dynamic object fields

For an `extra: Record<string, number | null>` field, select the object handle to create one reaction per own enumerable string key. Use nonempty field names without path delimiters (`.` or `[`). The callback receives the property's field handle. Its context includes the property name (`key`), full field path (`path`), root draft (`d`) and `depth: 0`.

Try adding two fees, editing one amount and removing one field.

```tsx preview
import { useRef } from 'react'
import { Form, defineEffects, typed, useForm } from '@shikiform/react'

type Values = { extra: Record<string, number | null> }
const effects = defineEffects<Values>(({ reaction, draft }) => {
  reaction.each(draft.extra, (fee) => {
    fee.$description = fee.$value === 0 ? 'Free' : undefined
  })
})

export default function App() {
  const form = useForm<Values>({ initialValues: { extra: { fee1: 0 } }, effects: [effects] })
  const F = typed(form)
  const nextId = useRef(2)
  return (
    <Form form={form} aria-label="Extra fees">
      <button type="button" onClick={() => {
        const key = `fee${nextId.current++}`
        form.batch((d) => { d.extra[key].$value = 0 })
      }}>Add fee</button>
      <F.Watch select={(d) => Object.keys(d.extra.$value)}>
        {(keys) => keys.map((key) => (
          <F.Field key={key} name={`extra.${key}`}>
            {(field) => (
              <div>
                <label htmlFor={field.id}>{key}</label>
                <input id={field.id} type="number" value={field.value ?? ''}
                  onChange={(e) => field.onChange(e.target.value === '' ? null : e.target.valueAsNumber)}
                  onBlur={field.onBlur} aria-describedby={field.description ? `${field.id}-hint` : undefined} />
                {field.description && <span id={`${field.id}-hint`}>{field.description}</span>}
                <button type="button" onClick={() => form.batch((d) => { delete d.extra.$value[key] })}>
                  Remove {key}
                </button>
              </div>
            )}
          </F.Field>
        ))}
      </F.Watch>
    </Form>
  )
}
```

Each new key runs its reaction once. Changing a fee runs the instance that read its value. Removing the key releases its subscriptions. Adding it again creates a fresh instance. Reading a shared flag on `d` also subscribes the instance to that flag. `watch.each` takes an array.

The list of inputs comes from `Object.keys(d.extra.$value)` in `<F.Watch>`. A fixed `<Field name="extra.fee1">` stays mounted when its value is deleted. The selector reads the entire object, so editing an existing amount can also reevaluate the key list. Assigning `undefined` to an existing optional property leaves its key in `Object.keys`; use `delete d.extra.$value[key]` to remove it.

For a derivation that follows **one selected key**, read `d.extra[d.activeKey.$value].$value` in a regular `reaction`. Each run collects the current dependencies. `watch((d) => d.extra[d.activeKey.$value].$value, action)` also re-tracks `fn`'s reads on each trigger, so switching `activeKey` follows edits to the newly selected key (keep derivations themselves in `reaction`).

## Filter using the context

`ctx` includes `key`, `index`, `depth`, `parent`, `path`, `pos` and the root draft `d`. Nested object arrays are traversed automatically. Filter the rows you need before reading state.

```ts
d.orders[0].lines[2].qty.$value
form.getValue('orders[0].lines[2].qty')
```

```ts
reaction.each(draft.orders, (order, ctx) => {
  if (ctx.depth !== 0) return
  order.lines[2].qty.$required = true
})
```

```ts
reaction.each(draft.orders, (node, ctx) => {
  if (ctx.key !== 'lines' || ctx.index !== 2) return
  node.qty.$required = true
})
```

Use `watch.each` to reset a row's quantity when its selected product changes, while `reaction.each` keeps prices, subtotals, and row-level `required` state in sync. `watch.each` refreshes a row's dependencies whenever that row's callback runs and migrates row subscriptions across array moves, inserts, and removals:

```tsx preview play=sku
import { useState, type ReactNode } from 'react';
import { Select, SelectContent, SelectItem, SelectItemIndicator, SelectTrigger, SelectValue } from '@ui-sdk/react/select';
import { enUS, ArrayField, Field, Form, defineEffects, useArrayField, useField, useForm, useIndex } from '@shikiform/react';

type Item = { id: number; sku: string; price: number; qty: number; total: number };
type Values = { discount: number; items: Item[] };

const PRICES: Record<string, number> = { pen: 3, book: 25, bag: 80 };
let nextId = 3;

const effects = defineEffects<Values>(({ reaction, watch, draft }) => {
  reaction.each(draft.items, (row, { d, index }) => {
    const price = PRICES[row.sku.$value] ?? 0;
    row.price.$value = price;
    row.total.$value = price * row.qty.$value * (1 - d.discount.$value / 100);
    row.sku.$required = index === 0; // The first row requires a product.
  });
  // Reset quantity when the product changes.
  watch.each(draft.items, (row) => {
    if (row.sku.$value) row.qty.$value = 1;
  });
});

function InlineNumber({ min, max, width = 72 }: { min?: number; max?: number; width?: number }) {
  const field = useField<number>();
  return (
    <label style={{ display: 'inline-flex', alignItems: 'center', gap: 4 }}>
      <span>{field.title}</span>
      <input id={field.id} type="number" min={min} max={max} style={{ width }}
        value={field.value ?? 0} onChange={(e) => field.onChange(Number(e.target.value))} onBlur={field.onBlur} />
    </label>
  );
}

function InlineSelect() {
  const field = useField<string>();
  const items = field.options.map((o) => ({ value: String(o.value), label: o.label }));
  return (
    <span style={{ display: 'inline-flex', alignItems: 'center', gap: 4 }}>
      <label htmlFor={field.id}>{field.title}</label>
      <Select items={items} value={field.value || null} onValueChange={(next) => field.onChange(next ?? '')} onOpenChange={(open) => { if (!open) field.onBlur(); }}>
        <SelectTrigger id={field.id}><SelectValue placeholder="Choose an option" /></SelectTrigger>
        <SelectContent>
          {items.map((o) => (
            <SelectItem key={o.value} value={o.value}>{o.label}<SelectItemIndicator aria-hidden="true">✓</SelectItemIndicator></SelectItem>
          ))}
        </SelectContent>
      </Select>
    </span>
  );
}

function RemoveButton() {
  const array = useArrayField<Item>();
  const index = useIndex();
  return <button type="button" onClick={() => array.remove(index)}>Delete</button>;
}

function ItemList({ children }: { children?: ReactNode }) {
  const array = useArrayField<Item>();
  return (
    <div>
      {children}
      <button type="button" style={{ marginTop: 10 }}
        onClick={() => array.push({ id: nextId++, sku: '', price: 0, qty: 1, total: 0 })}>Add row</button>
    </div>
  );
}

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    messages: enUS,
    initialValues: { discount: 10, items: [{ id: 1, sku: 'pen', price: 0, qty: 4, total: 0 }, { id: 2, sku: 'book', price: 0, qty: 1, total: 0 }] },
    fields: { 'items.*.sku': { enum: Object.keys(PRICES).map((value) => ({ label: value, value })) } },
    effects: [effects],
  });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <div style={{ marginBottom: 10 }}>
        <Field name="discount" title="Discount (%)" component={[InlineNumber, { min: 0, max: 100 }]} />
      </div>
      <ArrayField name="items" rowKey="id" component={ItemList}>
        {() => (
          <div style={{ display: 'flex', gap: 8, alignItems: 'center', marginBottom: 8, flexWrap: 'wrap' }}>
            <Field name="sku" title="Product" component={[InlineSelect]} />
            <Field name="price" title="Unit price" component={[InlineNumber]} />
            <Field name="qty" title="Quantity" component={[InlineNumber, { min: 1 }]} />
            <Field name="total" title="Subtotal" component={[InlineNumber]} />
            <RemoveButton />
          </div>
        )}
      </ArrayField>
      <button style={{ marginTop: 10 }} type="submit">Submit</button>
      <pre>{result}</pre>
    </Form>
  );
}
```

## Nested arrays and trees

`each` also visits descendants in a tree. Nested primitive arrays are skipped during object traversal. Selecting a primitive array itself visits its elements at depth zero.

```tsx preview
import { enUS, Field, Form, TreeField, defineEffects, useField, useForm, useTreeField } from '@shikiform/react';

type Node = { id: string; code: string; name: string; children?: Node[] };
type Values = { nodes: Node[] };

const effects = defineEffects<Values>(({ reaction, draft }) => {
  reaction.each(draft.nodes, (node, { pos, key, depth }) => {
    if (depth > 0 && key !== 'children') return;
    node.code.$value = pos.map((index) => index + 1).join('.'); // Outline numbering follows node positions.
    node.name.$required = pos.length === 1; // Only top-level nodes are required.
  });
});

function TextBox({ width }: { width?: number }) {
  const field = useField<string>();
  return (
    <input style={width ? { width } : undefined} value={field.value ?? ''}
      onChange={(e) => field.onChange(e.target.value)} onBlur={field.onBlur} />
  );
}

function NodeTree() {
  const tree = useTreeField('nodes', { rowKey: 'id' });
  return (
    <>
      <ul style={{ paddingLeft: 0, listStyle: 'none' }}>
        <TreeField name="nodes" rowKey="id">
          {(node) => (
            <li style={{ margin: '6px 0' }}>
              <span style={{ display: 'inline-flex', gap: 6 }}>
                <Field name="code" component={[TextBox, { width: 56 }]} />
                <Field name="name" component={[TextBox, { width: 180 }]} />
              </span>
              {node.children && <ul style={{ paddingLeft: 24, listStyle: 'none' }}>{node.children}</ul>}
            </li>
          )}
        </TreeField>
      </ul>
      <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
        <button type="button" onClick={() => tree.move([0, 1], [0, 0])}>Move Wash to the top</button>
        <button type="button" onClick={() => tree.move([0, 0], [1, 0])}>Move the first child under Cook</button>
      </div>
    </>
  );
}

export default function App() {
  const form = useForm<Values>({
    messages: enUS,
    initialValues: {
      nodes: [
        { id: 'a', code: '', name: "Prepare", children: [{ id: 'a1', code: '', name: "Buy vegetables" }, { id: 'a2', code: '', name: "Wash" }] },
        { id: 'b', code: '', name: "Cook", children: [{ id: 'b1', code: '', name: "Stir fry" }] },
      ],
    },
    trees: { nodes: { rowKey: 'id' } },
    effects: [effects],
  });
  return (
    <Form form={form}>
      <NodeTree />
    </Form>
  );
}
```

## UI state in effects

Write `$visible`, `$disabled`, `$readOnly`, `$omit`, `$required`, `$title`, `$enum`, or a leaf of `$componentProps` / `$decoratorProps` on the relevant path. Setting `$visible = false` hides the field and skips validation, while keeping its value in submit unless `$omit = true` is also set (see [Field state](/en/basics/state)). Assigning `undefined` drops the reaction override and restores the JSX or `fields` layer; assign `$enum = []` to clear options explicitly.

Do not call `form.getValue(...)` during component render to compute props — it does not subscribe to changes. To mount a second UI for the same field or control a value-free banner, use named UI nodes (`d.x.$ui('echo')` / `d.$ui('tip')`). See [named UI nodes](/en/guide/ui).
