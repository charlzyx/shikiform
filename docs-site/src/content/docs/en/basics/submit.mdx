title: "Submit and reset"
description: "Validate a form, handle submission failures and restore the baseline."
---
`form.submit()` returns a promise. It validates before calling `onValid` and resolves to the callback result, or the submitted values when that result is undefined. Validation failures reject with `FieldError[]`. A later submit supersedes an earlier one (`SubmitSupersededError`), values that fail to settle after 3 passes reject with `SubmitUnstableError`, and other callback errors propagate.

```ts
try {
  const values = await form.submit()
  save(values)
} catch (error) {
  if (error instanceof SubmitSupersededError) return // The newer attempt will produce the result.
  if (error instanceof SubmitUnstableError) return report(error)
  if (isFieldErrors(error)) showErrors(error)
  else report(error)
}

form.submit(async (values) => {
  const saved = await api.save(values)
  return saved.id
}).then((id) => setId(id)).catch((error) => {
  if (isFieldErrors(error)) scrollTo(error[0]?.path)
  else report(error)
})
```

## Submit and Reset buttons

`<Form onSubmit>` handles native submission, including Enter. `<Submit>` tracks whether submission is available and in progress. `<Reset>` restores the baseline and calls `afterReset` with the restored values. Use `asChild` or a render prop to supply your own button.

```tsx preview
import { useState } from 'react';
import { enUS, Form, Reset, Submit, typed, useForm } from '@shikiform/react';
import { Button, FieldInput, siteKit } from '@site/ui';

type Values = { name: string };

export default function App() {
  const [log, setLog] = useState('');
  const form = useForm<Values>({ messages: enUS, initialValues: { name: 'Ada' } });
  const F = typed(form);
  return (
    <Form
      form={form}
      kit={siteKit}
      onSubmit={(values) => setLog(`Submitted ${JSON.stringify(values)}`)}
      onInvalid={() => setLog("Validation failed")}
      style={{ maxWidth: 380 }}
    >
      <F.Field name="name" title="Name" required component={FieldInput} />
      <div style={{ display: 'flex', gap: 8 }}>
        <Submit asChild><Button variant="primary">Submit</Button></Submit>
        <Reset asChild afterReset={(values) => setLog(`Reset ${JSON.stringify(values)}`)}>
          <Button variant="outline">Reset</Button>
        </Reset>
      </div>
      {log && <pre aria-live="polite">{log}</pre>}
    </Form>
  );
}
```

For an edit screen, `form.reset(record)` replaces both the current values and the initial baseline. After saving, call `form.setInitialValues(form.values)` to clear `dirty` without touching current values. Inside `batch` or `watch`, `reset` and `setInitialValues` apply in order so a later `reset(path)` restores from the updated baseline; if a nested `batch` throws, both value and baseline changes roll back together.
