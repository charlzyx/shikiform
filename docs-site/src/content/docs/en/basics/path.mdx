## Read and write a nested field

Use `form.getValue` and `form.setValue` outside an effect. Inside a reaction, watch or batch, follow the draft to the target path. Numeric segments can be written as `items.0.qty` or `items[0].qty`. Bracket paths are also equivalent to canonical dot paths at runtime (`a[0].b` ≡ `a.0.b`) in `fields` / `trees` declarations and `query(path)`; in TypeScript, `fields` (`FieldPath<T> | TemplatePath<T>`) and `trees` (`ArrayPath<T>`) constrain keys to canonical dot paths (`a.0.b`, `a.*.b`), while `query(path)` takes an untyped string.

```ts
// Inside reaction, watch, or batch, walk a draft handle. Indexes and runtime keys are handles too.
d.orders[0].lines[2].qty.$value
d.orders[0].lines[2].qty.$value = 4
d.items[i].qty.$value
d.extra[key].$value

// query is only for a path that is already a string (pathOf, config, or a prop such as rowsPath).
query(pathOf('menus', pos)).$disabled = true

// Read and write the form directly outside effects.
form.getValue('orders[0].lines[2].qty')
form.setValue('orders[0].lines[2].qty', 4)
form.getValue('orders.0.lines.2.qty')
```

Updating `d.user.name.$value` notifies readers of that field. Inside an effect, `d.user.$value.name = 'x'` is that same write. Replacing `d.user.$value` replaces the whole record. A path you can spell on the draft stays a handle, including `d.items[i].qty` and `d.extra[key]`. `query(path)` is untyped and is the escape hatch for a string, for example `query(pathOf('menus', pos)).$disabled = true` inside an effect. `getValue` and `form.values` stay read-only in development.

```tsx preview
import { enUS, Field, Form, useForm } from '@shikiform/react';

type Values = { orders: { lines: { sku: string; qty: number }[] }[] };

export default function App() {
  const form = useForm<Values>({
    messages: enUS,
    initialValues: { orders: [{ lines: [{ sku: 'pen', qty: 1 }, { sku: 'book', qty: 2 }] }] },
  });
  return (
    <Form form={form}>
      <Field<Values, 'orders.0.lines.0.qty'> name="orders.0.lines.0.qty" title="First row quantity">
        {(f) => (
          <p>
            <label htmlFor={f.id}>{f.title}：</label>
            <input
              id={f.id}
              type="number"
              value={f.value ?? 0}
              onChange={(e) => f.onChange(Number(e.target.value))}
              onBlur={f.onBlur}
            />
          </p>
        )}
      </Field>
      <button
        type="button"
        onClick={() => {
          const qty = form.getValue('orders[0].lines[0].qty');
          form.setValue('orders[0].lines[0].qty', (qty ?? 0) + 1);
        }}
      >
        Increment by path
      </button>
    </Form>
  );
}
```
