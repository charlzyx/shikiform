## Read and write a nested field

Use `form.getValue` and `form.setValue` outside effects, or walk the `d` draft inside `reaction`, `watch`, or `batch`:

- Array indices can use dots (`items.0.qty`) or brackets (`items[0].qty`). Both refer to the exact same field at runtime (including in `fields`, `trees`, and `query(path)`).
- In TypeScript, prefer dot paths (`a.0.b`, `a.*.b`) in `fields` and `trees` so path types check cleanly. `query(path)` accepts any untyped string.
- If a middle segment is missing, `getValue` returns `undefined` and `setValue` creates the missing objects or arrays automatically.

```ts
// Inside reaction, watch, or batch, walk a draft handle. Indexes and runtime keys are handles too.
d.orders[0].lines[2].qty.$value
d.orders[0].lines[2].qty.$value = 4
d.items[i].qty.$value
d.extra[key].$value

// query is only for a path that is already a string (pathOf, config, or a prop such as rowsPath).
query(pathOf('menus', pos)).$disabled = true

// Read and write the form directly outside effects.
form.getValue('orders[0].lines[2].qty')
form.setValue('orders[0].lines[2].qty', 4)
form.getValue('orders.0.lines.2.qty')
```

Writing `d.user.name.$value = 'x'` (or `d.user.$value.name = 'x'` inside an effect) only updates `user.name` and only notifies readers of that field. Replacing the whole object (`d.user.$value = { ... }`) notifies every reader under `user`.

Whenever you can spell a path on `d`—including `d.items[i].qty` and `d.extra[key]`—prefer `d` for type safety; keep `query(path)` for paths that already arrive as strings (such as `pathOf('menus', pos)`). In development, objects returned by `getValue` and `form.values` are read-only so accidental direct mutation throws immediately.

```tsx preview
import { enUS, Field, Form, useForm } from '@shikiform/react';

type Values = { orders: { lines: { sku: string; qty: number }[] }[] };

export default function App() {
  const form = useForm<Values>({
    messages: enUS,
    initialValues: { orders: [{ lines: [{ sku: 'pen', qty: 1 }, { sku: 'book', qty: 2 }] }] },
  });
  return (
    <Form form={form}>
      <Field<Values, 'orders.0.lines.0.qty'> name="orders.0.lines.0.qty" title="First row quantity">
        {(f) => (
          <p>
            <label htmlFor={f.id}>{f.title}: </label>
            <input
              id={f.id}
              type="number"
              value={f.value ?? 0}
              onChange={(e) => f.onChange(Number(e.target.value))}
              onBlur={f.onBlur}
            />
          </p>
        )}
      </Field>
      <button
        type="button"
        onClick={() => {
          const qty = form.getValue('orders[0].lines[0].qty');
          form.setValue('orders[0].lines[0].qty', (qty ?? 0) + 1);
        }}
      >
        Increment by path
      </button>
    </Form>
  );
}
```
