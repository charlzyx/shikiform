## Test a form

Use the engine directly to test calculations, validation and submit values. For a React integration, render the form and drive its controls as a user would.

```tsx
import { fireEvent, render, screen } from '@testing-library/react'
import { expect, test, vi } from 'vitest'
import { Form, Submit, typed, useField, useForm } from '@shikiform/react'

function EmailInput() {
  const field = useField<string>()
  return (
    <div>
      <label htmlFor={field.id}>{field.title}</label>
      <input
        id={field.id}
        value={field.value ?? ''}
        onChange={(e) => field.onChange(e.target.value)}
        onBlur={field.onBlur}
      />
      {field.errors[0] && <span role="alert">{field.errors[0]}</span>}
    </div>
  )
}

function Login({ onSubmit }: { onSubmit: (values: { email: string }) => void }) {
  const form = useForm({ initialValues: { email: '' } })
  const F = typed(form)
  return (
    <Form form={form} onSubmit={onSubmit}>
      <F.Field name="email" title="Email" required rules={{ format: 'email' }} component={[EmailInput]} />
      <Submit>Submit</Submit>
    </Form>
  )
}

test("Submit after validating email", async () => {
  const onSubmit = vi.fn()
  render(<Login onSubmit={onSubmit} />)
  const email = screen.getByRole('textbox', { name: "Email" })
  fireEvent.change(email, { target: { value: 'ada@example.com' } })
  fireEvent.blur(email)
  fireEvent.click(screen.getByRole('button', { name: "Submit" }))
  expect(onSubmit).toHaveBeenCalledWith({ email: 'ada@example.com' })
})
```

## Large lists

Subscribe to the specific state the view needs. Use `reaction.each` for row calculations, preserve stable row keys and use `virtualScroll` when mounting every row is expensive. Declare rules in `fields` so offscreen rows still validate. The [large form example](/en/play/large) exposes render counts.

## Server rendering

Create one engine per form or request. Keep the initial state deterministic so hydration matches the server output. Start browser-dependent requests in client effects.
