Common engine functions are also exported from `@shikiform/react`.

## createForm

```ts
function createForm<T, TSubmit = T>(options?: FormOptions<T>): FormInstance<T, TSubmit>

// From @shikiform/react. Set V on typed<V>().
typed<V>().createForm<TSubmit = DefaultSubmit, const F extends FieldsInput<V> = {}>(
  options?: Omit<FormOptions<V>, 'fields'> & { fields?: F & FieldsInput<V> },
): FormInstance<V, ResolveSubmit<V, TSubmit, F>>

typed<V>().useForm<TSubmit = DefaultSubmit, const F extends FieldsInput<V> = {}>(
  options?: Omit<UseFormOptions<V>, 'fields'> & { fields?: F & FieldsInput<V> },
): FormInstance<V, ResolveSubmit<V, TSubmit, F>>
```

Instantiate an engine outside React with the same model options used by `useForm`. In development `getValue` and `values` are read-only views. `snapshot(form.values)` is a plain copy for `structuredClone`, `postMessage`, and IndexedDB. `getSubmitValues()` is the submit payload. `toRaw(value)` is the live stored object. `patchValues` recursively merges plain objects and replaces arrays. `setReadOnly` and `setDisabled` change root-level state. Omitting options or passing undefined is equivalent to an empty object.

```ts
import { createForm } from '@shikiform/core'

const form = createForm<{ name: string }>({ initialValues: { name: '' } })
form.setValue('name', 'Ada')
```

Use `typed<V>().createForm` to specify the shape while inferring omissions from declared fields. `createForm<V>(options)` fixes the submit type to `V`.

`validate` has three overloads:

```ts
validate(): Promise<TSubmit>
validate<P extends FieldPath<T>>(path: P): Promise<PathValue<T, P>>
validate<const Paths extends readonly FieldPath<T>[]>(paths: Paths): Promise<ValidatePick<T, Paths>>
```

On success it resolves the values current when the call finishes. No path is `getSubmitValues()` (that submit type). One path is its `PathValue` (returned even when that path is omitted; descendants omitted only by that path stay, and a descendant's own `omit` is removed). An array of paths is a nested object of only those paths (`ValidatePick`). The result is a copy: plain objects, arrays, `Date`, `Map`, and `Set` are copied, while class instances, functions, and React elements keep the same reference. Editing it does not write back. In development, mutating the `getValue` view throws `ShikiUsageError`. It rejects `FieldError[]`, and a form-level `validate` throw rejects as-is. See the [API overview](/en/api).

```ts
const values = await form.validate()
```

```ts
import { typed } from '@shikiform/react'

type Values = { name: string; confirm: string }
const fields = { confirm: { omit: true as const } }

const form = typed<Values>().createForm({ initialValues: { name: '', confirm: '' }, fields })

form.submit((values) => {
  values.name // string
  values.confirm // string | undefined
})

function Demo() {
  const live = typed<Values>().useForm({ initialValues: { name: '', confirm: '' }, fields })
  live.submit((values) => {
    values.name // string
    values.confirm // string | undefined
  })
  return null
}
```

## defineEffects

Register reactions for derived state and watches for one-time actions after a change. The factory receives `draft`, the root path handle: `reaction.each(draft.items, …)`, `watch(draft.city, …)` (that field's `$value`), `watch([draft.a, draft.b], …)`. The selector form of `each` still works. `query(path)` is for a path that is already a string.

```ts
import { defineEffects } from '@shikiform/core'

const effects = defineEffects<{ qty: number; total: number }>(({ reaction }) => {
  reaction((d) => {
    d.total.$value = (d.qty.$value ?? 0) * 2
  })
})
```

## Value copying and equality

Form values must be acyclic: passing cyclic references to `createForm` or write APIs throws `ShikiUsageError` in both development and production.

- **Initial values and baselines**: `initialValues`, `reset(values)`, and `validate()` share the same form-value copy semantics — plain objects (preserving own keys such as `__proto__` without mutating prototypes), arrays, `Date`, `Map`, and `Set` are deep-copied, while `File`, `Blob`, custom class instances, functions, symbols, and React elements keep their references. Use `snapshot(value)` when you need a `structuredClone`-compatible copy for `postMessage` or IndexedDB.
- **Deep equality and `dirty`**: Change detection and `dirty` compare `Map` and `Set` by contents, compare `Date` timestamps with `Object.is`, and compare `File`, `Blob`, and other non-plain class instances by reference.
- **Sparse array holes**: Array comparison distinguishes a sparse hole from an explicit `undefined` slot; writing `undefined` into a hole counts as a change and updates `dirty`.

## EnumSource

Use a static option list or bind a reusable source with `source.with(params)` (a parameterless `EnumSource<void>` can also be passed directly without `.with()`). The engine manages loading, cancels obsolete requests and exposes the effective options on `$enum` (`[]` before loading finishes). Shared loads for the same source and params key are reference-counted across consumers: removing an array row or tree node cancels its consumer without interrupting other active consumers, while surviving nodes moved to a new position keep reusing the in-flight load for the same key.

## Errors

`ShikiUsageError` reports invalid draft operations. `ShikiConflictError` and `ShikiCycleError` identify conflicting or cyclic reactions. `isFieldErrors` recognizes validation failures (`FieldError[]`). `SubmitSupersededError` (`code: 'superseded'`) and `SubmitUnstableError` (`code: 'unstable'`) report superseded and non-converging submits.

## Messages

Use `zhCN`, `enUS`, `setDefaultMessages` and `getDefaultMessages` to configure application defaults. `form.message(key)` reads the effective text for one form.

## Tree coordinates

`pathOf` and `posOf` convert coordinates. `moveNode` returns the move result without mutating the original array.
