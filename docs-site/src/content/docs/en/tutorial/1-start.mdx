## 1.1 Bind your first field

`useForm` creates the form state. `<Form>` shares it with child components and handles submit events, while `<Field>` connects a field to your input. A field render function gives you `id`, `title`, `value`, `onChange`, `onBlur`, and `errors` (or you can pass a `useField()` component via `component`). `<Submit>` from `@shikiform/react` disables itself automatically while submitting or when errors exist. Use `ObjectField` for nested objects, `ArrayField` for repeated rows, and `TreeField` for trees.

**Try it.** Add `email: ''` to `initialValues` and render a field named `email`. Submit and check that the JSON contains both `name` and `email`.

## 1.2 Use relative paths

The form has a top-level name and an address with a city. Inside `<ObjectField name="address">`, names resolve relative to the scope, so `city` maps to `address.city` (repeating `address.city` would resolve to `address.address.city`).

**Try it.** Add `street` to the initial address and render the corresponding field inside the object scope. Submit and inspect both address properties.
