## 4.1 Choose which fields to submit

Enter `secret123` in both password fields and submit. The starter includes the confirmation in the payload.

**Try it.** Set `omit` on `confirmPassword`. Add a validator that compares it with `ctx.record.password` and returns an error if the two differ. Submit again and check the payload. The form's reset button restores field values and clears the displayed result through `afterReset`. The toolbar reset restores the exercise code.
