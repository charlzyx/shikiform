Start with five common form patterns (each opens an editable live preview):

| Scenario | Highlights |
|---|---|
| [Login validation](/en/examples/forms#login-validation) | Combining `required`, `format`, and `minLength` rules |
| [Cross-field and asynchronous validation](/en/examples/forms#cross-field-and-asynchronous-validation) | Comparing sibling fields via `ctx.record` and aborting stale async requests with `AbortSignal` |
| [Calculated values](/en/examples/linkage#calculated-values) | Deriving computed field values with `reaction` |
| [Conditional visibility](/en/examples/linkage#conditional-visibility) | `$visible = false` skips validation; add `$omit` to exclude from submit |
| [Calculate each row](/en/examples/arrays#calculate-each-row) | Per-row subtotals with `reaction.each` |
