每一步左边是说明，右边是可以直接改的代码和运行结果。工具栏里点 **看答案** 换成参考写法，点重置按钮回到这一步开始时的代码。

教程运行的就是正式库：`useForm` / `Field` 从 `@shikiform/react` 导入，`FormItem`、输入控件和 `Submit` 从 `@shikiform/antd` 导入，Zod 从 `zod` 导入。右侧只有一个 **App.tsx**，可以整段复制到项目里。
