本教程采用「讲解 + 在线沙盒」的形式：上方是本节目标说明，中间是实时预览区域，下方可以直接修改代码。点击工具栏中的 **看答案** 可以对照参考实现，点击 **重置** 则能恢复到初始练习代码。

这八个练习围绕注册与下单中最常见的业务需求设计，涵盖字段声明、嵌套路径、状态与显隐、表单校验、联动计算、动态数组以及提交重置。每一步都是独立可运行的完整表单，可以直接复制到项目里使用。

示例中使用的 `useForm`、`Field` 等核心 API 来自 `@shikiform/react`，`FormItem`、输入控件和 `Submit` 来自 `@shikiform/antd`。
