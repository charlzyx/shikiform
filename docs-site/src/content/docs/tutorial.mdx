每节上方为任务说明，中间为实时预览，下方可直接编辑代码。工具栏中的 **看答案** 可切换参考写法，**重置** 可恢复起始代码。

八个练习覆盖字段声明、相对路径、四个状态布尔、校验规则、`reaction` / `watch` 联动、动态数组与提交重置。示例中 `useForm`、`Field`、`useField`、`Submit` 等均来自 `@shikiform/react`，零 UI 库依赖。
