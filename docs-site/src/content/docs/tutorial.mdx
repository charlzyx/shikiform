每一步上面是说明，中间是预览，下面可以改代码。点 **看答案** 换成参考写法，点重置回到这一步开始时的代码。

这八步都来自同一次注册或下单会碰到的事：先放字段，再写路径、显隐、校验、单价联动、订单行，最后提交。每一步是一张可以单独跑的表，不是把上一步的文件接着改。

`useForm` / `Field` 从 `@shikiform/react` 导入，`FormItem`、输入控件和 `Submit` 从 `@shikiform/antd` 导入。只有一个 **App.tsx**，可以整段复制到项目里。
