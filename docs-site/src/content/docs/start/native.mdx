---
title: 不用 UI 库
description: 只安装 @shikiform/react，配合原生表单元素实现数据绑定、校验与提交。
---

```bash
npm i @shikiform/react
```

如果项目不需要第三方组件库，只安装 `@shikiform/react` 即可使用。控件使用原生 HTML 元素，字段值、校验和联动状态依然由 ShikiForm 引擎统一维护。

在自定义的输入组件中调用无参数的 `useField()`，就能拿到外层 `<Field>` 提供的字段绑定对象（包含 `id`、`value`、`onChange`、`onBlur`、`required` 和 `errors`），把它们直接接到原生 `<input>` 上即可。

```tsx preview
import { useState } from 'react';
import { Field, Form, useField, useForm } from '@shikiform/react';

function TextInput({ label }: { label: string }) {
  const field = useField<string>();
  return (
    <p>
      <label htmlFor={field.id}>
        {label}
        {field.required ? ' *' : ''}
      </label>
      <input
        id={field.id}
        value={field.value ?? ''}
        onChange={(event) => field.onChange(event.target.value)}
        onBlur={field.onBlur}
      />
      {field.errors[0] ? <small role="alert"> {field.errors[0]}</small> : null}
    </p>
  );
}

type Values = { name: string; email: string };

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm<Values>({ initialValues: { name: '', email: '' } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <Field name="name" required component={[TextInput, { label: '姓名' }]} />
      <Field name="email" required rules={{ format: 'email', message: '邮箱格式不对' }} component={[TextInput, { label: '邮箱' }]} />
      <button type="submit">提交</button>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

直接点击提交时，姓名和邮箱都会提示必填；将邮箱改为 `ada@example.com` 并填好姓名后，即可正常输出提交的 JSON 数据。

<Aside type="tip" title="关于 useField() 的调用位置">
不传参数的 `useField()` 依赖外层 `<Field>` 提供的上下文，只能在 `component`、`decorator` 或 `<Field>` 的子元素中使用。如果在字段组件之外读取某个字段状态，请传入路径（如 `useField('email')`）或使用 `useWatch`。
</Aside>

如果要封装一整套自己的组件库（包含标签、错误提示和属性映射），请参考 [接入组件库](/guide/headless#接自己的组件库)；如需配合 Ant Design 使用，请参考 [快速开始](/guide/quick-start)。
