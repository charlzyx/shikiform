---
title: 不用 UI 库
description: 只安装 @shikiform/react，配合原生表单元素实现数据绑定、校验与提交。
---

```bash
npm i @shikiform/react
```

不引入第三方 UI 库时只需安装 `@shikiform/react`。输入元素使用原生 HTML，表单值、校验规则与联动状态由引擎管理。

自定义输入组件内调用无参 `useField()` 可读取外层 `<Field>` 的绑定对象（`id`、`value`、`onChange`、`onBlur`、`required`、`errors`），直接传给原生 `<input>` 即可。

```tsx preview
import { useState } from 'react';
import { Field, Form, useField, useForm } from '@shikiform/react';

function TextInput({ label }: { label: string }) {
  const field = useField<string>();
  return (
    <p>
      <label htmlFor={field.id}>
        {label}
        {field.required ? ' *' : ''}
      </label>
      <input
        id={field.id}
        value={field.value ?? ''}
        onChange={(event) => field.onChange(event.target.value)}
        onBlur={field.onBlur}
      />
      {field.errors[0] ? <small role="alert"> {field.errors[0]}</small> : null}
    </p>
  );
}

type Values = { name: string; email: string };

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm<Values>({ initialValues: { name: '', email: '' } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <Field name="name" required component={[TextInput, { label: '姓名' }]} />
      <Field name="email" required rules={{ format: 'email', message: '邮箱格式不对' }} component={[TextInput, { label: '邮箱' }]} />
      <button type="submit">提交</button>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

直接点击提交会触发姓名与邮箱的必填报错；将邮箱改为 `ada@example.com` 并填入姓名后提交，下方会输出表单值 JSON。

<Aside type="tip" title="useField() 的调用位置">
无参 `useField()` 读取外层 `<Field>` 的上下文，只能在 `component`、`decorator` 或 `<Field>` 子元素内调用。在字段组件外读取指定路径请传入字段名（如 `useField('email')`）或使用 `useWatch`。
</Aside>

封装完整的自定义组件集见 [接入组件库](/guide/headless#接自己的组件库)；配合 Ant Design 使用见 [快速开始](/guide/quick-start)。
