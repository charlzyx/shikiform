title: 按路径读写
description: 通过 draft handle 链以及 form.getValue / form.setValue 读写深层嵌套路径。
---

读写深层嵌套的数据（例如 `orders[0].lines[2].qty`）有两种方式：在联动（`reaction` / `watch`）或 `batch` 里直接顺着 `d` 往下点；在组件或普通事件回调里调用 `form.getValue` / `form.setValue`。

路径写法有几点规则：
- 支持点号（`a.b.0.c`）、方括号（`a.b[0].c`）以及带特殊字符的引号键（`a['b-c']`）。运行中 `a[0].b` 和 `a.0.b` 指向同一个字段，在 `fields` / `trees` 声明和 `query(path)` 里也等价。
- 写 TypeScript 的 `fields` / `trees` 配置时，优先用点号（`a.0.b`、`a.*.b`）以便类型检查；`query(path)` 接受任意字符串，不做静态路径检查。
- 路径中间缺一层时，`getValue` 返回 `undefined`，`setValue` 会自动补上缺失的对象或数组。开发环境里 `getValue` 返回的对象是只读的，不要原地修改，改用 `setValue` 或联动里的 `d.x.$value = …`。

## 读写单个嵌套路径

只操作某一个位置时，不必用 `reaction.each` 遍历整个数组，直接按路径访问即可：

```ts
// reaction / watch / batch 里走 draft handle。下标和运行时的键也是 handle。
d.orders[0].lines[2].qty.$value
d.orders[0].lines[2].qty.$value = 4
d.items[i].qty.$value
d.extra[key].$value

// 路径只以字符串存在时（pathOf、配置、组件 props，例如 rowsPath）才用 query
query(pathOf('menus', pos)).$disabled = true

// 组件或普通逻辑里直接读写表单实例
form.getValue('orders[0].lines[2].qty')
form.setValue('orders[0].lines[2].qty', 4)
form.getValue('orders.0.lines.2.qty')
```

在联动函数里，`d.orders[0].lines[2].qty` 只是指向这个字段的路径引用，直到读写 `.$value` 才会真正访问数据并自动建立依赖。只要路径能在 `d` 上直接写出来，就优先这样写（固定下标 `d.orders[0].lines[2].qty`、动态下标 `d.items[i].qty`、动态键 `d.extra[key]` 都可以）。只有手里拿到的已经是字符串路径时（比如 `pathOf('menus', pos)` 拼出来的路径），才用 `query(path)`。

```tsx preview
import { Field, Form, useForm } from '@shikiform/react';

type Values = { orders: { lines: { sku: string; qty: number }[] }[] };

export default function App() {
  const form = useForm<Values>({
    initialValues: { orders: [{ lines: [{ sku: 'pen', qty: 1 }, { sku: 'book', qty: 2 }] }] },
  });
  return (
    <Form form={form}>
      <Field<Values, 'orders.0.lines.0.qty'> name="orders.0.lines.0.qty" title="第一行数量">
        {(f) => (
          <p>
            <label htmlFor={f.id}>{f.title}：</label>
            <input
              id={f.id}
              type="number"
              value={f.value ?? 0}
              onChange={(e) => f.onChange(Number(e.target.value))}
              onBlur={f.onBlur}
            />
          </p>
        )}
      </Field>
      <button
        type="button"
        onClick={() => {
          const qty = form.getValue('orders[0].lines[0].qty');
          form.setValue('orders[0].lines[0].qty', (qty ?? 0) + 1);
        }}
      >
        路径加一
      </button>
    </Form>
  );
}
```

点击「路径加一」时，`form.getValue` 读出当前数量，`form.setValue` 写回同一路径。`orders[0].lines[0].qty` 与 `orders.0.lines.0.qty` 指向同一个字段。在 `reaction` 或 `batch` 中则直接赋值 `d.orders[0].lines[2].qty.$value = 4`。

需要对数组或嵌套集合中的每一项建立联动时使用 `reaction.each`，过滤方式见 [用 ctx 过滤](/guide/linkage#用-ctx-过滤)。
