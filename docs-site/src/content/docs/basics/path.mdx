title: 按路径读写
description: 通过 draft handle 链以及 form.getValue / form.setValue 读写深层嵌套路径。
---

读写深层嵌套的数据（例如 `orders[0].lines[2].qty`）有两种写法：在联动回调里顺着 draft handle 逐层访问，在组件或外部逻辑里调用 `form.getValue` / `form.setValue`。

路径字符串支持 `a.b.c`、`a.b[0].c`、`a.b.0.c` 以及带特殊字符的 `a['b-c']`。`a.b[0].c` 与 `a.b.0.c` 是同一个字段。路径中间缺一层时，`getValue` 返回 `undefined`；`setValue` 写入表单，并补上沿途缺失的对象或数组。

## 读写单个嵌套路径

只操作某一个位置时，不必用 `reaction.each` 遍历整个数组，直接按路径访问即可：

```ts
// 在 reaction / watch / batch 中使用 draft handle；动态路径在 reaction / watch 里用 query
d.orders[0].lines[2].qty.$value
d.orders[0].lines[2].qty.$value = 4
query('orders.0.lines.2.qty').$value

// 在组件或普通逻辑中直接读写表单实例
form.getValue('orders[0].lines[2].qty')
form.setValue('orders[0].lines[2].qty', 4)
form.getValue('orders.0.lines.2.qty')
```

在联动函数中，`d.orders[0].lines[2].qty` 依然是一个 handle，只有读取或赋值其 `$value` 时，才会真正获取数值并被追踪为联动依赖。动态路径在联动里用 `query('orders.0.lines.2.qty').$value`（没有类型）；平时写 `d.orders[0].lines[2].qty`。

```tsx preview
import { Button } from 'antd';
import { Field, Form, useForm } from '@shikiform/react';
import { FormItem, InputNumber } from '@shikiform/antd';

type Values = { orders: { lines: { sku: string; qty: number }[] }[] };

export default function App() {
  const form = useForm<Values>({
    initialValues: { orders: [{ lines: [{ sku: 'pen', qty: 1 }, { sku: 'book', qty: 2 }] }] },
  });
  return (
    <Form form={form}>
      <Field name="orders.0.lines.0.qty" title="第一行数量" decorator={[FormItem]} component={[InputNumber]} />
      <Button
        htmlType="button"
        onClick={() => {
          const qty = form.getValue('orders[0].lines[0].qty');
          form.setValue('orders[0].lines[0].qty', (qty ?? 0) + 1);
        }}
      >
        路径加一
      </Button>
    </Form>
  );
}
```

点击「路径加一」时，程序用 `form.getValue` 读出当前数量，再用 `form.setValue` 写回同一字段。`orders[0].lines[0].qty` 与字段名 `orders.0.lines.0.qty` 指向同一个值，输入框中的数值会同步递增。在 `reaction` 或 `batch` 中更新值，直接对目标路径的 `$value` 赋值（如 `d.orders[0].lines[2].qty.$value = 4`）。

当需要对多层嵌套结构中的「每一项的某个字段」批量建立联动时，才需要用到 `reaction.each`，具体过滤方式见 [用 ctx 过滤](/guide/linkage#用-ctx-过滤)。
