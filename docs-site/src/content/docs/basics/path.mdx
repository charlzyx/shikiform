title: 按路径读写
description: 通过 draft handle 链以及 form.getValue / form.setValue 读写深层嵌套路径。
---

读写深层嵌套的数据（例如 `orders[0].lines[2].qty`）有两种写法：在联动回调里顺着 draft handle 逐层访问，在组件或外部逻辑里调用 `form.getValue` / `form.setValue`。

路径字符串支持 `a.b.c`、`a.b[0].c`、`a.b.0.c` 以及带特殊字符的 `a['b-c']`。`a.b[0].c` 与 `a.b.0.c` 是同一个字段，这一运行时等价关系同样适用于 `fields` / `trees` 声明以及 `query(path)`（`a[0].b` ≡ `a.0.b`）；不过在 TypeScript 中，`fields`（`FieldPath<T> | TemplatePath<T>`）和 `trees`（`ArrayPath<T>`）的键类型约束为点分规范路径（`a.0.b`、`a.*.b`），手写配置优先使用点分写法，`query(path)` 则接收无静态类型约束的字符串。路径中间缺一层时，`getValue` 返回 `undefined`；`setValue` 写入表单，并补上沿途缺失的对象或数组。开发环境里 `getValue` 读到的对象不要原地改，改用 `setValue` 或联动里的 `d.x.$value = …`。

## 读写单个嵌套路径

只操作某一个位置时，不必用 `reaction.each` 遍历整个数组，直接按路径访问即可：

```ts
// reaction / watch / batch 里走 draft handle。下标和运行时的键也是 handle。
d.orders[0].lines[2].qty.$value
d.orders[0].lines[2].qty.$value = 4
d.items[i].qty.$value
d.extra[key].$value

// 路径只以字符串存在时（pathOf、配置、组件 props，例如 useQueryTable 的 rowsPath）才用 query
query(pathOf('menus', pos)).$disabled = true

// 组件或普通逻辑里直接读写表单实例
form.getValue('orders[0].lines[2].qty')
form.setValue('orders[0].lines[2].qty', 4)
form.getValue('orders.0.lines.2.qty')
```

在联动函数中，`d.orders[0].lines[2].qty` 是路径 handle，读写其 `$value` 时才访问数据并登记依赖。能写在 draft 上的路径就用 handle：固定位置 `d.orders[0].lines[2].qty`，变化的下标 `d.items[i].qty`，变化的键 `d.extra[key]`。`query(path)` 没有静态类型，只留给手里已经是字符串的路径，例如在 effect 里 `query(pathOf('menus', pos)).$disabled = true`。

```tsx preview
import { Field, Form, useForm } from '@shikiform/react';

type Values = { orders: { lines: { sku: string; qty: number }[] }[] };

export default function App() {
  const form = useForm<Values>({
    initialValues: { orders: [{ lines: [{ sku: 'pen', qty: 1 }, { sku: 'book', qty: 2 }] }] },
  });
  return (
    <Form form={form}>
      <Field<Values, 'orders.0.lines.0.qty'> name="orders.0.lines.0.qty" title="第一行数量">
        {(f) => (
          <p>
            <label htmlFor={f.id}>{f.title}：</label>
            <input
              id={f.id}
              type="number"
              value={f.value ?? 0}
              onChange={(e) => f.onChange(Number(e.target.value))}
              onBlur={f.onBlur}
            />
          </p>
        )}
      </Field>
      <button
        type="button"
        onClick={() => {
          const qty = form.getValue('orders[0].lines[0].qty');
          form.setValue('orders[0].lines[0].qty', (qty ?? 0) + 1);
        }}
      >
        路径加一
      </button>
    </Form>
  );
}
```

点击「路径加一」时，`form.getValue` 读出当前数量，`form.setValue` 写回同一路径。`orders[0].lines[0].qty` 与 `orders.0.lines.0.qty` 指向同一个字段。在 `reaction` 或 `batch` 中则直接赋值 `d.orders[0].lines[2].qty.$value = 4`。

需要对数组或嵌套集合中的每一项建立联动时使用 `reaction.each`，过滤方式见 [用 ctx 过滤](/guide/linkage#用-ctx-过滤)。
