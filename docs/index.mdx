# ShikiForm

ShikiForm 按数据形状管理字段，用 `reaction` / `watch` 写联动。值和校验留在表单里。输入框只负责显示。

## 从这里开始

1. **[教程](/tutorial)**：先看字段和联动，再改能跑的例子。
2. **[用例](/usage/01-basic-form)**：员工表单、数组、树、表格、SKU 这些场景的完整写法。
3. **[API](/api)**：`useForm`、`Field`、`defineEffects`，以及 `shikiform/ui`。
4. **[约定](/decisions)**：已经定下的行为，以及仍待拍板的几项。
5. **[案例补全清单](/coverage-checklist)**：对照 Formily / Pro / SKU 还要补的 demo。
