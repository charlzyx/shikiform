# ShikiForm

一个表单 = 一个引擎。值、字段状态、校验和联动都在引擎里；联动写成 `reaction` / `watch`，读写的是 **draft**（`d.email.$required = …`）。React 层只订阅和渲染，Ant Design 适配层只把字段映射成控件。

```tsx preview
import { useState } from 'react';
import { Button, Form as AntdForm } from 'antd';
import { Field, Form, defineEffects, useForm } from 'shikiform';
import { FormItem, FormLayout, Input, Radio } from 'shikiform/antd';

type Values = { kind: 'personal' | 'work'; email: string; company: string };

const effects = defineEffects<Values>(({ reaction }) => {
  reaction((d) => {
    const work = d.kind.$value === 'work';
    d.email.$required = work;
    d.email.$componentProps.placeholder = work ? 'name@company.com' : 'name@example.com';
    d.company.$display = work ? 'visible' : 'none';
  });
});

export default function App() {
  const [result, setResult] = useState('');
  const form = useForm<Values>({
    initialValues: { kind: 'personal', email: '', company: '' },
    fields: { kind: { enum: [{ label: '个人', value: 'personal' }, { label: '工作', value: 'work' }] } },
    effects: [effects],
  });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 5 }} wrapperCol={{ span: 19 }}>
        <Field name="kind" title="账号类型" decorator={[FormItem]} component={[Radio.Group]} />
        <Field name="email" title="邮箱" rules={{ format: 'email' }} decorator={[FormItem]} component={[Input]} />
        <Field name="company" title="公司" required decorator={[FormItem]} component={[Input]} />
        <AntdForm.Item wrapperCol={{ offset: 5, span: 19 }}>
          <Button type="primary" htmlType="submit">提交</Button>
        </AntdForm.Item>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

切到「工作」：邮箱变成必填、占位符换掉、公司出现；切回「个人」，公司既不显示、也不校验、不进提交结果（`display: 'none'`）。这些都写在一个 `reaction` 里，组件代码里没有一个 `if`。

## 四个入口

| 入口 | 内容 | 依赖 |
|---|---|---|
| `shikiform/core` | `createForm`、`defineEffects`、`EnumSource`、校验与树工具 | 无 |
| `shikiform` | core + React：`useForm`、`Form`、`Field`、`ObjectField`、`ArrayField`、`TreeField`、`useField`、`useWatch`、`useArray` … | React |
| `shikiform/pro` | 无 UI 的查询、数组表格、影子草稿、联想、懒加载级联 Hooks | React |
| `shikiform/antd` | `FormItem`、`FormLayout`、`connect`、接好的 antd 控件、`ProArrayTable`、`QueryList`、`ShadowModal` … | React + antd 5 |

依赖方向是 `antd → pro → react → core`。不用 antd 时，只用前两个入口加你自己的控件。
