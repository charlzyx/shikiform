# reaction.each

<div className="tutorial-step">
<div className="tutorial-copy">

右边是一行订单：贴纸，单价 2，数量 4。小计还是 0。可以再添加一行，也可以删掉。

`ArrayField` 的 children 是一个函数，收到当前 `{ index, key }`。函数里渲染的字段名相对当前行，`rowKey="id"` 保持行身份。添加按钮调用 `form.pushArray('items', createRow())`；删除按钮调用 `form.removeArray('items', index)`。这里的 `createRow` 是示例自己的函数，不是 `ArrayField` 的属性。

数组用 `reaction.each`：每一行一个实例。选择器要返回这一列的 handle。

**这一步：** 加上 effects：

```ts
reaction.each(
  (d) => d.items,
  (row) => {
    const total = (row.price.$value || 0) * (row.qty.$value || 0);
    row.total.$value = total;
  },
);
```

贴纸的小计变成 8。改某一行，只有这一行的小计变。提交时每一行带上算好的 `total`。不想提交，给这个字段声明 `virtual`。
