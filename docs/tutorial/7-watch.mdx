# watch 做动作

<div className="tutorial-step">
<div className="tutorial-copy">

`autorun` 用来保持一份派生状态，初始化就会跑。`watch` 用来做动作，初始化不跑，源变化之后才跑。

起始代码在 `autorun` 里写了 `d.city.$value = undefined`。`autorun` 初始化就会跑，所以一进来市是空的，杭州没有留下来。清空是切省之后才该发生的动作。

**这一步：** `autorun` 只留 `d.city.$disabled = !d.province.$value`。清空市改成：

```ts
watch(
  (d) => d.province,
  (d) => {
    d.city.$value = undefined;
  },
);
```

从 `watch` 的参数里取出 `watch`。一进来市仍是杭州，下拉可以改。切换省之后，市被清空。
