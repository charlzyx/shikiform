# autorun 写计算值

<div className="tutorial-step">
<div className="tutorial-copy">

计算值是普通字段，由 `autorun` 写入 `$value`。写过之后它变成计算字段：阅读态，并且默认 `virtual`，提交结果里没有它。

同一轮里用局部变量做乘法，再写回去。不要在同一轮读刚写上的 `$value`，否则依赖会把自己圈进去。

起始代码里金额是手填的，提交 JSON 里有 `amount`。

**这一步：** 用 `defineEffects` 包一个 `autorun`：

```ts
const amount = (d.price.$value || 0) * (d.qty.$value || 0);
d.amount.$value = amount;
```

把 `effects` 传给 `useForm`。改单价或数量，金额跟着变，而且不能手改。提交 JSON 里没有 `amount`。
