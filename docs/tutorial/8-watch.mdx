# watch

<div className="tutorial-step">
<div className="tutorial-copy">

省是浙江，市本来该是杭州。现在一打开，市是空的。

`reaction` 初始化就会跑，适合保持派生状态。清空市是一个动作，应该等省变了再做。这种用 `watch`：初始化不跑，源变化之后才跑。

起始代码在 `reaction` 里写了 `d.city.$value = undefined`，所以杭州被清掉了。

**这一步：** `reaction` 只留 `d.city.$disabled = !d.province.$value`。清空改成：

```ts
watch(
  (d) => d.province,
  (d) => {
    d.city.$value = undefined;
  },
);
```

从参数里取出 `watch`。一进来市仍是杭州。切换省之后，市被清空。没有省的时候，市是禁用的。
