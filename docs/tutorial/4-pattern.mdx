# pattern

<div className="tutorial-step">
<div className="tutorial-copy">

`pattern` 有四种：`editable`、`disabled`、`readOnly`、`readPretty`。

写在父字段上时，子字段跟着走。子字段自己写了 `$pattern`，就用自己的。这一步只改姓名一个字段。

起始代码读了模式下拉，没有把它写到姓名上，所以姓名一直能改。

**这一步：** 在 `autorun` 里，当 `mode` 有值时执行 `d.name.$pattern = mode`。

可编辑能打字。禁用不能改。只读能选中文字，不能改。阅读态变成纯文本（下拉的 label 也会显示出来）。
