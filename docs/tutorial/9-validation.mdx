# 规则和 Zod

<div className="tutorial-step">
<div className="tutorial-copy">

字段自己的规则写在 `rules`。整张表的结构用 Zod。`zodResolver` 从 `shikiform/zod` 来，和 [用例 11](/usage/11-validation-enum) 的 import 一样：把 `safeParse` 的问题收成 `{ [path]: message }`，交给 `useForm` 的 `resolver`。

起始代码已经写了 schema，调用了 `zodResolver`，但没有传进 `useForm`。姓名也没有规则。

**这一步：** `useForm` 加上 `resolver: zodResolver(schema)`。姓名的 `rules` 写成必填，以及 `minLength: 2`、文案「至少 2 个字」。

姓名一个字：失焦看到「至少 2 个字」。邮箱格式不对、年龄小于 18：看到 Zod 的文案。都合法之后，提交 JSON 里有三项。
