# 教程

每一步左边是说明，右边是可以直接改的代码和运行结果。工具栏里点 **看答案** 换成参考写法，点重置按钮回到这一步开始时的代码。

教程运行的就是正式库。`useForm` / `Field` 从 `shikiform` 导入，输入控件从 `antd` 导入，Zod 从 `zod` 导入。没有另一份教学 store。

右侧有 **App.tsx** 和 **fields.tsx** 两个文件。前者讲这一节，后者是可查看、修改和复制的控件绑定；它只使用正式 `Field` 和 hooks，不保存另一份表单值。复制示例时请带上两个文件。
