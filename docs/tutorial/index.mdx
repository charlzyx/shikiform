# 教程

教程分成三层。先认识字段有哪几种，再认识联动怎么写，然后每一步只改一个能跑的例子。右边可以直接改代码，预览会跟着变。点 **看答案** 换成参考写法，点 **重置** 回到这一步开始时的代码。

`FormItem` 和 `Input` 来自 `shikiform/ui`。这一层把 antd 的输入组件接成受控显示，值和校验仍由 `useForm` / `Field` 保存。应用自己的组件用 `connect` 接一次，见 [用例 00](/usage/00-ui-adapter)。

## 先看一个能跑的表单

```tsx preview
import { Form, Field, Submit, useForm } from 'shikiform';
import { FormItem, Input } from 'shikiform/ui';

export default function Welcome() {
  const form = useForm({ initialValues: { name: 'Ada' } });
  return (
    <Form form={form} onSubmit={() => undefined}>
      <Field name="name" decorator={<FormItem label="姓名" />}>
        <Input />
      </Field>
      <Submit>提交</Submit>
    </Form>
  );
}
```
