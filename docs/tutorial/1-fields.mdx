# 字段

字段只按数据形状分成四种。

| 类型 | 数据 | 例子 |
|---|---|---|
| `Field` | 一个值 | 姓名、邮箱 |
| `ObjectField` | 对象 | 地址 |
| `ArrayField` | 数组 | 订单行 |
| `TreeField` | 树 | 菜单 |

`name` 是 path 上的一段。写在 `ArrayField` 里面的 `name` 相对当前行。地址和 path 的差别就这一句：地址是你在 JSX 里写的相对名，path 是引擎拼出来的完整路径。

下面三样不是类型：

- **布局**是普通组件，不进 path。需要被联动控制时，用 `Region` 起名，例如 `d.ui('aside')`。
- **不提交**是 `virtual`。字段仍有值，仍参与校验和联动，提交结果里没有它。
- **计算值**是普通 `Field`。`reaction` 写入它的 `$value` 之后，它变成阅读态，并且默认 `virtual`。
