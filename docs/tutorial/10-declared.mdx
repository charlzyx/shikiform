# 没挂载的字段

<div className="tutorial-step">
<div className="tutorial-copy">

这一步对应 [待拍板](/decisions) 里的 **Q5**。Q5 还没有定。下面按草案里的提议演示：字段可以在 `fields` 里声明，不依赖有没有挂上输入框；`autorun` 写的 `$rules` 一直校验；JSX 的 `rules` 只在 `Field` 挂载时生效。

起始代码里，昵称和邀请码都写了 JSX `rules`，并且只有打开「填写更多」才渲染。开关关着，两个字段都不在树上，直接提交没有错误。

**这一步：**

1. `defineEffects` 里写 `d.code.$rules = [{ required: true, message: '邀请码必填' }]`，并把 effects 传给 `useForm`。
2. `useForm` 加上 `fields: { code: {} }`。
3. 邀请码的 `Field` 去掉 `rules`。昵称的 JSX 规则留着。

关掉开关，直接点提交。参考写法仍然列出 `code：邀请码必填`。昵称卸掉之后不再校验。
