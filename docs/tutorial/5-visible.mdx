# 显隐只看 $visible

<div className="tutorial-step">
<div className="tutorial-copy">

显隐只写 `$visible`。字段还在树上，只是不画出来：值留着，校验跳过，提交 JSON 里仍有这个键。

把 `Field` 从 JSX 里拿掉是另一件事，「没挂载的字段」再讲。

起始代码的 `reaction` 读了 `contact`，没有写邮箱的显隐，所以邮箱一直在。

**这一步：** 在 `reaction` 里写上 `d.email.$visible = d.contact.$value`。

关掉「需要联系」：邮箱消失。打开、把邮箱清空再失焦：出现「必填」。再关掉：错误消失，提交成功，JSON 里仍有 `email`。
