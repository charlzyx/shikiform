# 最小表单

<div className="tutorial-step">
<div className="tutorial-copy">

右边有一个姓名框。填上字，点提交，下面会出现 JSON。

这四块就够了：`useForm` 记住值，`Form` 包住它，`Field` 的 `name` 是路径，`Submit` 提交。`Input` 是 antd 的输入框，只负责显示。改字的时候，值写回 ShikiForm，不进 antd 的 `Form`。

标签是 `FormItem`。它读的是 ShikiForm 里的标题和错误，不是 antd 的 `Form.Item`。

**这一步：** 加上邮箱。`initialValues` 里写上 `email`，再放一个 `Field`。提交之后，JSON 里同时有 `name` 和 `email`。
