# 示例库

每个 `/play/...` 都是独立构建的完整页面，可以直接打开、刷新。它们使用和文档相同的正式库；源码在仓库 `playground/pages/`。页面内不能改代码，想边改边看，用文档里各页的示例（点工具栏的「编辑代码」）。

数据都是本地模拟，写回只改当前表单，不代表接好了后端。

## 数组、嵌套与树

| 示例 | 看什么 |
|---|---|
| [数组与树拖动](/play/headless) | headless Hooks 的拖动排序；树节点跨父级移动，`rowKey` 不变、`pos` 变化 |
| [嵌套字段](/play/nested) | 作用域、pattern 继承、抽屉里继续编辑嵌套对象 |
| [订单行](/play/orders) | 可展开的订单子表：行金额、订单合计、已发货行只读 |
| [供应商和产品](/play/merged) | 数据保持嵌套，合并单元格只是显示；跨层校验读父记录 |
