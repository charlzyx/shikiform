# 约定

## 已定行为

| | 行为 |
|---|---|
| D1 | 字段类型只有 `Field`、`ObjectField`、`ArrayField`、`TreeField`。布局是普通 React 组件。不提交用 `virtual`。计算值是普通 `Field`：`$value` 由 `reaction` 写入，阅读态，默认 `virtual`。 |
| D2 | 树节点有 `pos`，是索引路径。 |
| D3 | effects 是 draft 路径代理，加上 `reaction`、`reaction.each`、`watch`。字段状态用 `$` 前缀。没有 `./`、`../`。`when` 不对外。 |
| D4 | 只用精确 path。core 的命名 UI 句柄是 `d.x.$ui('summary')`；当前 React Field 尚未接通 `ui` 属性，不能当作完整 UI Brand 能力。 |
| D5 | `pattern` 取 `editable`、`disabled`、`readOnly`、`readPretty`。父级向下传，子级写了自己的值就用自己的。 |
| D6 | 表格列绑定数据路径；`readPretty` 显示文本，`readOnly` 保留不可编辑的输入框。 |
| D7 | effects 不使用额外的相对路径 scope DSL。逐行用 `reaction.each`；React 相对路径由结构字段提供。 |
| D8 | `virtual` 表示不进提交值。计算字段默认 `virtual`，要提交就写 `virtual={false}`。行编辑直接改正式值。 |

## 当前边界与待设计项

- `createForm` / `useForm` 已是公开入口；`enumPolicy` 已有 `none` / `clear` / `error`。当前签名见 [API](/api)，不再把已实现接口写成待定方案。
- JSX 规则只在字段挂载时生效；声明、模板和 reaction 规则不依赖挂载。`hidden` 仍校验和提交，`none` 才跳过。见 [没挂载的字段](/guide/unmounted)。
- `Field` 当前是 render-prop API。`component/decorator` 写法、JSON renderer 和完整 UI Brand 适配仍待设计，不是本教程可复制的接口。
- 跨模块规则怎样暴露 handle、重复 UI brand 的 React 生命周期、查看态 UI 适配仍需收敛成公开规范。
- `commit: 'blur'` 的类型/行为缺口和性能证据没有在教程迁移中补齐；ShadowForm 等明确延后特性也不在本轮。见 [案例补全清单](/coverage-checklist)。

旧的 `usage` 页面保留设计草稿的历史写法；不要把归档伪代码当成当前导出。入门和运行契约以 [教程](/tutorial)、[指南](/guide) 与 [API](/api) 为准。
