ShikiForm 核心是 headless 的。应用在自己的仓库里写一次适配层：`connect` 把 shadcn 组件的 `onValueChange` / `onCheckedChange` 等映射成统一的 `value / onChange`；`useDecorator` 让 `FormItem` 读 label、required、errors、validating。其他所有用例都从这里 import `Input / Select / FormItem / CellItem`。

**演示的特性：** Decorator vs Component 分工 · connect 适配
