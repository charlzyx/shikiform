同一个数据字段在编辑区和侧边摘要各有一个 UI：值 / 错误共享，visible / pattern / decorator 各自独立；没有 VoidField：Card / Grid 是普通布局，不产生 path 也不产生 address，需要被 effect 控制时才起名（`Region ui="aside"` → `d.ui('aside')`）；单独控制某个 UI = UI Brand（`ui="summary"` → `d.user.plan.ui('summary')`），#n 已删除。

**演示的特性：** 三棵树 · 一个字段多个 UI · 具名布局 Region
