# Pro 组件参考

从 `shikiform/antd` 导入。每个组件都是 [Pro Hooks](/reference/pro-hooks) 之上的薄封装，组件能做的 Hook 都能做。可点的例子见 [可点的例子](/examples)。

## ProArrayTable

```tsx
<ProArrayTable<Row>
  name="list" rowKey="id" pagination={{ pageSize: 10 }} rowSelection resizeable
  columns={[
    { key: 'sort', width: 50, render: () => <ProArrayTable.SortHandle /> },
    { key: 'a1', title: 'A1', render: () => <Field name="a1" component={[Input]} /> },   // 单元格可以不要装饰器
    { key: 'a2', title: 'A2', render: () => <Field name="a2" required decorator={[FormItem, { feedbackLayout: 'terse' }]} component={[Input]} /> },
    { key: 'act', title: '操作', render: () => <ProArrayTable.Remove confirm /> },
  ]}
  expandable={{ rowExpandable: (r) => !!r.children, render: () => <ProArrayTable name="children" pattern="readPretty" columns={…} /> }}
  toolbar={<MyToolbar />} extra={<ProArrayTable.Addition />} footer={<MyFooter />}
  onRemove={(index, record) => api.remove(record.id)}
/>
```

Pro.formily `ProArrayTable`：数组字段上的 antd 表格，建立在 `useArrayTable` + `useColumnSettings` 上。列是普通的 render 函数，渲染在行作用域里（`<Field name="a1">` 就是 `list.N.a1`；单元格可用不同的装饰器，或不要装饰器），所以展开行里可以再放一张子表。自带分页、选择条（选中 N 项 / 清空 / 全选 / 反选）、列配置和密度、表头拖拽改列宽、拖拽排序、异步删除。列配置弹层里拖动 ⋮⋮ 调整列顺序，↑ ↓ 按钮留给键盘操作。列可以写 `sorter`（`true` 只上报变化，比较函数则在本页内排序）、`sortOrder`、`filters`、`filterMultiple`、`filteredValue`，表头的排序 / 筛选变化经 `onTableChange(pagination, filters, sorter, extra)` 上报，参数与 antd `Table` `onChange` 一致（分页由底部分页器负责）。行操作：`SortHandle`、`Index`、`Remove`、`MoveUp`、`MoveDown`、`Copy`、`Addition`、`ProAddition`（影子表单添加，弹窗或抽屉）；上下文：`ProArrayTable.useTable()`（表格状态 + 列配置）、`ProArrayTable.useRow()`（`{ key, index, position, record }`，建立在无头的 [`useIndex`](/reference/react-hooks#useindex) / [`useRecord`](/reference/react-hooks#userecord) 之上，`record` 是响应式的）。单元格里同样可以直接用 [`useArray()`](/reference/react-hooks#usearray) / `useIndex()` / `useRecord()`。

## QueryList

```tsx
const table = useQueryTable({ initialValues: { query: {}, list: [] }, params: 'query', rows: 'list', request })
<QueryList table={table} list="list" columns={columns} collapseAfter={3}>
  <Field name="query.domain" title="域名" decorator={[FormItem, { layout: 'vertical' }]} component={[Input]} />
  …
</QueryList>
```

Pro.formily `QueryList` + `QueryForm` + `QueryTable`：可折叠的查询栅格（展开 / 收起、重置、查询）加一张受控服务端分页的 `ProArrayTable`，表头带刷新。状态全部在 `useQueryTable`；它的 `rows` 选项把每页结果写进 `list` 数组字段，单元格可以直接编辑。选择存在 Hook 里，翻页保留、新查询清空。列上写 `sorter: true` / `filters`，表头排序和列筛选会作为 `sorter` / `filters` 发给 `request` 并回到第 1 页；列筛选和新查询一样清空选择，排序保留选择；表头状态受 Hook 控制，`重置` 一并清空（见 [表头排序与列筛选](/reference/query-hooks#表头排序与列筛选)）。`ProQueryTable` 对普通 antd 列做同样的接线。

## ShadowModal

```tsx
<ShadowModal<Info> title="编辑" record={() => form.getValue('info')} onOk={(values) => form.setValue('info', values)} trigger={<Button>编辑</Button>}>
  <Field name="domain" title="域名" required decorator={[FormItem]} component={[Input]} />
</ShadowModal>
```

在 antd `Modal` 里编辑影子草稿（Pro.formily `ShadowModal`）。点 `trigger` 用 `record` 打开（值或加载函数）；确定先校验，再调 `onOk`，成功后关闭；取消什么都不写。传 `shadow`（来自 `useShadowForm` / `useArrayShadow`）时用外部草稿，否则组件自己持有一个。草稿字段从草稿的根开始解析，不继承所在行的作用域。

## ShadowDrawer

```tsx
<ShadowDrawer shadow={editor} title="编辑" okText="保存">
  <Field name="domain" title="域名" decorator={[FormItem]} component={[Input]} />
</ShadowDrawer>
```

与 `ShadowModal` 相同，换成 antd `Drawer`，底部是取消 / 确定。`ProArrayTable.ProAddition` 的 `popType="drawer"` 就是它。适合字段较多、需要更大编辑区域的行编辑。

## ShadowPopconfirm

```tsx
<ShadowPopconfirm record={() => ({ name: form.getValue('name') })} onOk={(v) => form.setValue('name', v.name)} trigger={<Button>改名</Button>}>
  <Field name="name" decorator={[FormItem]} component={[Input]} />
</ShadowPopconfirm>
```

把少量字段放进 antd `Popconfirm` 的气泡里编辑（Pro.formily `ShadowPopconfirm`）。打开气泡时用 `record` 初始化草稿，确认校验后调用 `onOk`，取消或点外面关闭都会丢弃草稿。

## ShadowForm

```tsx
<ShadowForm<Info> record={info} onOk={save}>
  {(shadow) => <>…fields… <Button onClick={() => shadow.confirm()}>提交</Button></>}
</ShadowForm>
```

内联的影子表单（Pro.formily 把 `ShadowForm` 用作 decorator / component 的两种写法）：挂载即用 `record` 打开，子节点渲染在草稿上。草稿通过 render prop 交给容器，或在任意子组件里用 `useShadow()` 取得，所以提交按钮可以放在任何位置。不渲染 `<form>` 元素，可以放在宿主 `<Form>` 里。

## useShadow

```ts
useShadow<TValues, TContext>(): ShadowFormApi<TValues, TContext>
```

读取外层 `ShadowForm` / `ShadowModal` / `ShadowDrawer` / `ShadowPopconfirm` 正在渲染的草稿：`form`、`visible`、`submitting`、`confirm()`、`cancel()`。不在这些组件里调用会抛错，提示需要的外层组件。

## EnumPretty

```tsx
<Field name="status" title="状态" decorator={[FormItem]} component={[EnumPretty, { showType: 'badge' }]} />
<Field name="tags" decorator={[FormItem]}><EnumPretty showType="tag" strict colorful={false} empty="无" /></Field>
```

只读的枚举显示（Pro.formily `ProEnumPretty`）：读字段值和字段枚举（`fields.x.enum`、`$enum`、`EnumSource`），按 `showType` 画成文字、徽标或标签；颜色来自选项的 `color`（可用 `success` / `processing` / `error` / `warning` 等语义名）或调色板。`Select`、`Radio.Group`、`Checkbox.Group` 的阅读态同样接受 `prettyType="badge" | "tag"`。

## EnumPrettyView

```tsx
<EnumPrettyView value={['a', 'o']} options={[{ label: '啊', value: 'a' }, { label: '哦', value: 'o', color: 'success' }]} showType="tag" />
```

`EnumPretty` 的纯视图版本，不绑定字段：直接传 `value` 和 `options`。适合表格单元格、详情页等不在表单里的地方，参数与 `EnumPretty` 相同（`showType`、`strict`、`colorful`、`empty`）。

## Suggestion

```tsx
<Field name="keyword" title="淘宝搜索" decorator={[FormItem]} component={[Suggestion, { fetch: search, debounce: 200, multiple: true, labelInValue: true }]} />
```

字段绑定的远程联想下拉（Pro.formily `Suggestion`），建立在 `useSuggestion` 上。值有四种形状：`string`、`{ label, value }`（`labelInValue`）、`string[]`（`multiple`）、`{ label, value }[]`（两者都开）。阅读态显示标签。

## SuggestionSelect

```tsx
<SuggestionSelect value={value} onChange={setValue} fetch={search} multiple />
```

`Suggestion` 的非字段版本：普通的受控 `value` / `onChange` 组件，其余属性透传给 antd `Select`。防抖、中止旧请求、记住已选标签的行为与 `Suggestion` 完全一样，可以在表单外单独使用。

## CascaderPlus

```tsx
<Field name="area" title="地区" decorator={[FormItem]} component={[CascaderPlus, { loadData: (path) => api.children(path), labelInValue: true }]} />
```

字段绑定的懒加载级联（Pro.formily `CascaderPlus`），建立在 `useLazyCascader` 上：一个 `loadData(path)` 服务所有层级，已有值打开时逐级加载以反显标签；`all` 表示整棵树一次返回；支持 `multiple` 和 `labelInValue`（每一级 `{ label, value }`）。默认 `changeOnSelect`。阅读态（`readPretty`）显示标签：`labelInValue` 的值自带标签；裸值（`['410000', '410600']`）用同一个 `loadData` 逐级加载后显示标签而不是编码（[`useCascaderLabels`](/reference/pro-hooks#usecascaderlabels)）。

## CascaderPlusView

```tsx
<CascaderPlusView value={['110000', '11000000', '110105']} onChange={setValue} loadData={loadArea} multiple={false} />
```

`CascaderPlus` 的非字段版本：受控 `value` / `onChange`，其余属性透传 antd `Cascader`。`/play/cascader-plus` 的三个例子（全量 / 懒加载切换、反显、labelInValue 反显）都直接用它。
