# Ant Design 适配层

从 `shikiform/antd` 导入。`<Field>` 拥有字段（`name`、`rules`、`title`、`decorator`、`component`），`FormItem` 只是装饰器，控件经 `connect` + `mapProps` + `mapReadPretty` 接线。适配层把 [useField](/reference/react-hooks#usefield) 的 `FieldBinding` 映射成 antd props，不保存自己的状态。用法见 [Ant Design 适配](/guide/antd)。

```tsx
import { createForm, Field, Form } from 'shikiform'
import { FormItem, FormLayout, Input, Select, Switch } from 'shikiform/antd'

const form = createForm({
  initialValues: { email: '', city: 'sh', vip: false },
  fields: {
    // 也可以在 fields 里声明 UI：<Field name="city" /> 就会渲染出来
    city: { title: '城市', decorator: [FormItem], component: [Select], enum: [{ label: '上海', value: 'sh' }, { label: '北京', value: 'bj' }] },
  },
})

export default function Profile() {
  return (
    <Form form={form} onSubmit={(values) => console.log(values)}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="email" title="邮箱" required rules={{ format: 'email' }}
          decorator={[FormItem, { tooltip: '工作邮箱' }]} component={[Input, { placeholder: 'name@example.com' }]} />
        <Field name="city" />
        <Field name="vip" title="会员" decorator={[FormItem]} component={[Switch]} />
      </FormLayout>
    </Form>
  )
}
```

- **`<Field>` 渲染 `decorator` 包住 `component`**（或包住 `children`），并把字段提供给子树（不带参数的 `useField()` 读到它），所以 `FormItem` 与 connect 控件都不需要 `name`。`children` 也可以是控件本身：`<Field name="x" decorator={[FormItem]}><Input /></Field>`；render prop `(field) => …` 照常可用。
- **UI 状态在字段模型上**：`title` → `label`，`description` → `extra`，`componentProps` 合并进控件 props，`decoratorProps` 合并进 `FormItem`。来源从低到高：`fields` 声明 → JSX（`title`、元组里的 props）→ reaction（`$title`、`$componentProps.placeholder = …`），对象深合并（数组、函数、React 元素整值替换）。
- **联动改 UI**：`reaction((d) => { d.city.$componentProps.disabled = d.vip.$value; d.city.$decoratorProps.tooltip = '…' })`。嵌套写 `d.x.$componentProps.style.color = 'red'` 只补这一处，JSX / 声明里 `style` 的其他键保留；缺失的中间对象不会自动创建，先 `style ??= {}`（只开一层，不清空下层）。整键赋值 `style = {...}` 替换这个键，整体赋值 `d.x.$componentProps = {...}` 替换所有下层，赋 `undefined` 撤销 reaction 层。
- **表格单元格**可以不要装饰器（`<Field name="a1" component={[Input]} />`），或换一个（`decorator={[FormItem, { feedbackLayout: 'terse' }]}`）。

控件找字段的顺序：`field` 属性 → `name` 属性（内部调用 `useField(name)`）→ 外层 `<Field>` 提供的字段（即不带参数的 `useField()`）。

## connect

```ts
connect<P>(target: ComponentType<P>, ...enhancers: ConnectEnhancer[]): ConnectedComponent<P>
// ConnectedComponent<P> = ComponentType<Partial<P> & { name?: string; field?: FieldBinding<any> }>
```

把任意 value/onChange 控件变成字段控件。`enhancers` 由 [mapProps](#mapprops) 与 [mapReadPretty](#mapreadpretty) 生成。返回的组件没有自己的状态：每次渲染都是对当前 `FieldBinding` 调一次 [mapFieldProps](#mapfieldprops)。字段的 `componentProps` 合并在调用方 props 之下（reaction 写的 `$componentProps` 因此能到达控件）。缺少 `name`、`field` 且不在 `<Field>` 内时抛错。

```tsx
const Rate = connect(AntRate, mapProps({ status: false }))
<Field name="score" title="评分" decorator={[FormItem]} component={[Rate, { count: 10 }]} />
```

## mapProps

```ts
mapProps(...args: Array<PropsMapping | PropsTransform>): ConnectEnhancer
type PropsMapping = Partial<Record<'value' | 'onChange' | 'onBlur' | 'disabled' | 'readOnly' | 'status' | 'id' | 'options' | 'loading', string | false>>
  & { getValueFromEvent?: (...args: any[]) => unknown }
type PropsTransform = (props: Record<string, any>, field: FieldBinding<any>) => Record<string, any>
```

对象参数重命名（`{ value: 'checked' }`）、合并（`{ readOnly: 'disabled' }`，与 `disabled` OR）或丢弃（`{ status: false }`）绑定属性；`options` / `loading` 默认不传，映射后才把字段枚举与加载状态交给控件。函数参数在最后变换 props。`getValueFromEvent` 把控件 `onChange` 的参数换成字段值，默认读取事件的 `target.checked`（checkbox）或 `target.value`，否则取第一个参数本身。

## mapReadPretty

```ts
mapReadPretty(component: ComponentType<any>, props?: Record<string, unknown>): ConnectEnhancer
```

字段 `pattern` 为 `readPretty` 时渲染 `component` 而不是控件。它收到调用方 props，加上 `value` 与 `options`（字段枚举）。没有 `mapReadPretty` 的控件在 `readPretty` 下按 `readOnly` 处理（例如 `Switch` 变为禁用）。默认的阅读态视图是 [PreviewText](#previewtext)。

## mapFieldProps

```ts
mapFieldProps(field: FieldBinding<any>, props: Record<string, any>, ...mappers: Array<PropsMapping | PropsTransform>): Record<string, any>
```

`connect` 的纯函数核心，给 Hook 用户直接使用：`value` 取字段值；`onChange` 先写字段再以原始参数调用调用方的 `onChange`，各一次；`onBlur` 先标记 touched 再调调用方；`disabled` / `readOnly` 与调用方 props 取 OR；`status` 有错误时为 `'error'`、只有警告时为 `'warning'`，调用方显式传入时以调用方为准；`id` 默认是字段 id；`field.componentProps` 合并在 `props` 之下。

```tsx
const field = useField('email', { required: true })
return <AntInput {...mapFieldProps(field, { placeholder: 'Email' })} />
```

## FormItem

```ts
FormItem(props: FormItemProps): ReactElement | null
interface FormItemProps
  extends Omit<antd.FormItemProps, 'name' | 'rules' | 'required' | 'children' | 'validateStatus' | 'help' | 'hidden' | 'layout' | …>,
    Pick<FormLayoutValue, 'layout' | 'size' | 'feedbackLayout'> {
  asterisk?: boolean   // 强制显示 / 隐藏必填星号
  children?: ReactNode
}
```

当前字段的装饰器（Formily `FormItem`），**不拥有字段**：没有 `name` / `rules` / `required` / `field` 属性，从外层 `<Field>` 的上下文读字段，在字段外使用会抛错。用法是 `<Field decorator={[FormItem, props]}>`，或放在 `<Field>` 的 children / render prop 里。

渲染 antd `Form.Item`（props 由 [mapFormItemProps](#mapformitemprops) 计算）：`label` 取字段 `title`，`extra` 取 `description`（显式传入时以显式为准）；必填星号跟随字段 `required`，`readPretty` 下隐藏；`validateStatus` 依次为 `error` → `validating` → `warning`；`help` 取第一条错误，否则第一条警告；继承外层 [FormLayout](#formlayout)。`display` 为 `hidden` / `none` 时不渲染。

```tsx
<Field name="email" title="邮箱" description="用于登录" required decorator={[FormItem, { tooltip: '工作邮箱' }]} component={[Input]} />
```

## mapFormItemProps

```ts
mapFormItemProps(field: FieldBinding<any>, props: Omit<FormItemProps, 'children'>, layout?: FormLayoutValue): antd.FormItemProps
```

`FormItem` 的纯函数核心。合并顺序（低 → 高）：`layout`（`FormLayout`）← `field.decoratorProps`（`fields` ← JSX ← `$decoratorProps`）← `props`。`feedbackLayout: 'none'` 去掉提示文字（状态颜色保留），`'terse'` 在没有提示时去掉底部间距。Hook 用户不用组件也能得到同样的装饰：

```tsx
const field = useField('email', { required: true, title: '邮箱' })
return <Form.Item {...mapFormItemProps(field, {})}><AntInput {...mapFieldProps(field, {})} /></Form.Item>
```

## FormLayout

```ts
FormLayout(props: FormLayoutProps): ReactElement
interface FormLayoutProps {
  layout?: 'horizontal' | 'vertical' | 'inline'
  labelCol?: ColProps
  wrapperCol?: ColProps
  labelAlign?: 'left' | 'right'
  colon?: boolean
  size?: 'small' | 'middle' | 'large'
  feedbackLayout?: 'loose' | 'terse' | 'none'
  className?: string
  style?: CSSProperties
  children?: ReactNode
}
```

Formily `FormLayout`：给内部所有 `FormItem` 一份布局。嵌套的 `FormLayout` 按键合并，近的优先；`FormItem` 自己的 props 与字段 `decoratorProps` 优先于布局。`size` 同时作用于内部控件（antd `componentSize`）；`inline` 让条目横向排布。

```tsx
<FormLayout layout="vertical" size="small">
  <Field name="a" title="A" decorator={[FormItem]} component={[Input]} />
  <FormLayout layout="horizontal" labelCol={{ span: 6 }}>
    <Field name="b" title="B" decorator={[FormItem]} component={[Input]} />
  </FormLayout>
</FormLayout>
```

## useFormLayout

```ts
useFormLayout(): FormLayoutValue   // FormLayoutProps 去掉 children / className / style
```

读取当前位置合并后的布局（所有外层 `FormLayout` 的合并结果）。自定义装饰器用它继承同一套布局，例如 `mapFormItemProps(field, props, useFormLayout())`；在任何 `FormLayout` 之外返回 `{}`。

## PreviewText

```ts
PreviewText(props: { value?: unknown; options?: { label: ReactNode; value: unknown }[]; empty?: ReactNode; format?: string }): ReactElement
```

阅读态文本：枚举值显示 `label`，数组用 `, ` 连接，布尔值显示 `是` / `否`，带 `format()` 方法的日期对象按 `format`（默认 `YYYY-MM-DD`）格式化；空值显示 `empty`（默认 `messages.empty`，空串）。控件编辑态的 `placeholder`（「请输入…」）不会出现在阅读态里。输出 `<span data-read-pretty>`。

## Input

```ts
const Input: ConnectedComponent<antd.InputProps> & {
  TextArea: ConnectedComponent<antd.TextAreaProps>
  Password: ConnectedComponent<antd.PasswordProps>
}
```

`connect(antd.Input, mapReadPretty(PreviewText))`。`onChange(event)` 写入 `event.target.value`。`readOnly` 字段传 `readOnly`；`readPretty` 显示文本。`Input.TextArea` 同理；`Input.Password` 的阅读态显示 `******`。

## InputNumber

```ts
const InputNumber: ConnectedComponent<antd.InputNumberProps>
```

`connect(antd.InputNumber, mapReadPretty(PreviewText))`。写入 antd 给出的原始值：数字，清空时为 `null`。`readPretty` 显示数字文本。

## Select

```ts
const Select: ConnectedComponent<antd.SelectProps>
```

`connect(antd.Select, mapProps({ options: 'options', loading: 'loading', readOnly: 'disabled' }), mapReadPretty(…))`，阅读态视图是 `PreviewText`，写了 `prettyType` 时换成 `EnumPrettyView`。未传 `options` 时使用字段枚举（`fields.x.enum`、`$enum`，含 `EnumSource` 异步加载的 `loading`）。`readOnly` 渲染为禁用；`readPretty` 显示选项的 `label`，多选用 `, ` 连接。

## Switch

```ts
const Switch: ConnectedComponent<antd.SwitchProps>
```

`connect(antd.Switch, mapProps({ value: 'checked', readOnly: 'disabled', status: false }))`。字段值对应 `checked`，`onChange(checked)` 写入布尔值。`readOnly` 与 `readPretty` 都渲染为禁用开关；没有阅读态文本视图。

## Checkbox

```ts
const Checkbox: ConnectedComponent<antd.CheckboxProps> & {
  Group: ConnectedComponent<antd.CheckboxGroupProps>
}
```

单个 `Checkbox` 的字段值对应 `checked`，`readOnly` / `readPretty` 渲染为禁用。`Checkbox.Group` 绑定数组值，未传 `options` 时使用字段枚举，`readPretty` 显示所选标签（`, ` 连接）。

## Radio

```ts
const Radio: { Group: ConnectedComponent<antd.RadioGroupProps> }
```

`Radio.Group` 绑定单值：`onChange(event)` 写入 `event.target.value`。未传 `options` 时使用字段枚举；`readOnly` 渲染为禁用；`readPretty` 显示所选标签。只导出 `Group`：单个 `Radio` 不是字段控件。

## DatePicker

```ts
const DatePicker: ConnectedComponent<antd.DatePickerProps> & {
  RangePicker: ConnectedComponent<antd.RangePickerProps>
}
```

与 Formily 一致，字段保存**格式化后的字符串**（按控件 `format`，默认 `YYYY-MM-DD`），只在交给 antd 时转成 dayjs，所以值能经受 `initialValues` 克隆、`reset` 和提交（核心用 `structuredClone`，会丢掉 dayjs 原型）。清空写入 `undefined`。`RangePicker` 保存 `[start, end]` 字符串元组，阅读态显示 `start ~ end`。需要 `dayjs`（antd 自带依赖）作为 peer dependency。
