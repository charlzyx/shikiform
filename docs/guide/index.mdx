# 指南

教程按一条路径把表单写完。这里把同一套概念再往下说一层：先看例子，再讲它在库里怎么走。

- [联动](/guide/effects)：`reaction` 保持结果，`watch` 做动作，`reaction.each` 管每一行。
- [pattern](/guide/pattern)：四种状态，父级往下传，子级可以自己定。
- [显隐](/guide/display)：`hidden` 和 `none` 不是一回事。
- [path 和提交](/guide/path)：嵌套名字、`virtual`、哪些值会进提交结果。
- [校验](/guide/validation)：什么时候查，卸掉输入框之后还查不查。
- [没挂载的字段](/guide/unmounted)：规则写在 JSX 上，还是写在 `reaction` 里。
- [可点的例子](/guide/demos)：SKU、合并表、查询表、订单行。

整站怎么排，看 [大纲](/OUTLINE)。组件和 effects 列在 [API](/api)。已经定下的行为在 [约定](/decisions)。还没做成可点 demo 的，在 [案例补全清单](/coverage-checklist)。
