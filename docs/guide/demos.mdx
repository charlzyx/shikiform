# 可点的例子

教程右边是一小步。下面这些是完整场景。

| 页面 | 在看什么 |
|---|---|
| [SKU 选择器](/play/sku-picker) | 三个维度任意顺序选。刚改的维度留下，和它冲突的被清掉。缺货置灰。价格是区间或唯一价，数量不超过库存。 |
| [SKU 表格](/play/sku-editor) | 和选择器同一份 SKU。改合并的颜色，整组一起变。再加一列时，价格留在原来的 `skuId` 上。 |
| [供应商和产品](/play/merged) | 数据保持嵌套。合并列改供应商，子列改产品。只看在售之后 rowspan 重算。C 级单价不能超过 1000。 |
| [查询表](/play/query) | 格子按宽度排。折叠之后值还在。空条件不进参数。列筛选和查询表单共用状态，一改就从第 1 页重新查，并清空选择。 |
| [订单行](/play/orders) | 展开编辑子表，收起再打开，数字还在。直接写正式值，没有草稿，没有取消回滚。已发货的行保持阅读态。 |
| [显隐](/play/display) | `hidden` 仍校验、仍提交。`none` 跳过校验，结果里没有这个字段。 |

### 对照 Pro.formily

Pro.formily 文档里的每个例子，在这里都有一页对应的 ShikiForm 版本。

| 页面 | Pro.formily 对应 | 在看什么 |
|---|---|---|
| [ProArrayTable](/play/pro-array-table) | ProArrayTable | 拖拽排序、序号、行内编辑、确认 + 异步删除、上下移、选择条、展开行（自定义 render + 只读子表）、列配置、列宽拖拽、分页、自定义 toolbar / footer、10 万行。 |
| [ProArrayTable + 影子表单](/play/pro-array-table-shadow) | ProArrayTableWithShadow | 每行「编辑」打开同一个影子弹窗，确定写回这一行；两个「添加」（弹窗、抽屉）共存，追加后翻到新行所在页。 |
| [ShadowForm](/play/shadow-form) | ShadowFormAll | 弹窗、气泡、抽屉、内联（render prop / `useShadow`）、纯 `useShadowForm`。确定才写回，取消不动。 |
| [ProEnum](/play/pro-enum) | ProEnum | 静态和懒加载枚举（同一个 Enum 只请求一次），阅读态文字 / 徽标 / 标签，远程联想，级联懒加载，整组切换 READ PRETTY。 |
| [CascaderPlus](/play/cascader-plus) | CascaderPlus | 全量 / 懒加载、多选、labelInValue，已有值逐级加载后反显。 |
| [Suggestion](/play/suggestion) | Suggestion | 远程联想的四种值形状：string、labelInValue、multiple、两者都开。 |
| [QueryList](/play/query-list) | QueryList | 可折叠查询表单 + 服务端分页表格，每页结果是可编辑的表单行，刷新、列配置。 |
| [QueryList + 添加 / 编辑](/play/query-list-add) | QueryListAdd | 在 QueryList 上加影子弹窗编辑行、ProAddition 追加。 |

这些页面随 `npm run build` 和文档一起构建，地址是 `/play/...`，刷新也能打开。这里与教程运行同一个正式库（`src/core`、`src/react`、`src/pro`、`src/antd`）。可直接改输入观察行为；源码在 `playground/pages/`，这些完整场景暂不支持页内改代码。Pro 组件的 API 见 [Pro Hooks](/reference/pro-hooks) 和 [Pro 组件](/reference/pro-components)。

完整分组入口与能力边界见 [复杂示例](/examples)。
