# 快速开始

## 准备

ShikiForm 目前没有发布到 npm（`package.json` 是 `private`）。在仓库里运行 `npm ci && npm run build:lib` 生成 `lib/`，再以 workspace 或 `file:` 依赖接进你的项目。四个入口是 `shikiform`、`shikiform/core`、`shikiform/pro`、`shikiform/antd`。

| peer 依赖 | 版本 | 什么时候需要 |
|---|---|---|
| `react` / `react-dom` | `^18 \|\| ^19` | 用 React 层时 |
| `antd` / `dayjs` | `^5` / `^1` | 只在用 `shikiform/antd` 时 |

## 第一张表单

三步：`useForm` 建引擎，`<Form>` 提供它，`<Field>` 声明每个字段。

```tsx preview
import { useState } from 'react';
import { Button, Form as AntdForm } from 'antd';
import { Field, Form, useForm } from 'shikiform';
import { FormItem, FormLayout, Input, InputNumber } from 'shikiform/antd';

type Values = { name: string; email: string; age: number | null };

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm<Values>({ initialValues: { name: '', email: '', age: 18 } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <Field name="name" title="姓名" required decorator={[FormItem]} component={[Input, { placeholder: 'Ada' }]} />
        <Field name="email" title="邮箱" required rules={{ format: 'email', message: '邮箱格式不对' }}
          decorator={[FormItem]} component={[Input]} />
        <Field name="age" title="年龄" rules={{ min: 0, max: 150 }} decorator={[FormItem]} component={[InputNumber]} />
        <AntdForm.Item wrapperCol={{ offset: 4, span: 20 }}>
          <Button type="primary" htmlType="submit">提交</Button>
        </AntdForm.Item>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

直接点提交，必填项会报错；离开输入框时也会校验（默认触发时机是 `onBlur` 和 `onSubmit`）。全部通过后，`onSubmit` 才收到值。

- `<Field>` 是字段的唯一拥有者：`name`、`title`、`required`、`rules` 都写在它上面。
- `decorator={[FormItem]}` 负责标签、星号和错误；`component={[Input, props]}` 负责输入。两个槽都可以是组件本身或 `[组件, props]`。
- `FormItem` 和 `Input` 都不需要 `name`，它们从外层 `<Field>` 读字段。
- 组件外创建引擎用 `createForm(options)`，选项和 `useForm` 相同。

## 不用 antd

UI 库不是必需的。`useField(name)` 返回一个绑定（`value`、`onChange`、`onBlur`、`errors` …），接到任何控件上：

```tsx preview
import { Form, useField, useForm, type FieldBinding } from 'shikiform';

function TextInput({ field, label }: { field: FieldBinding<string>; label: string }) {
  return (
    <p>
      <label htmlFor={field.id}>{label} </label>
      <input id={field.id} value={field.value ?? ''} onChange={(event) => field.onChange(event.target.value)} onBlur={field.onBlur} />
      {field.errors[0] && <small role="alert" style={{ color: 'crimson' }}> {field.errors[0]}</small>}
    </p>
  );
}

function NameField() {
  const field = useField<{ name: string }, 'name'>('name', { required: true });
  return <TextInput field={field} label="姓名" />;
}

export default function App() {
  const form = useForm({ initialValues: { name: '' } });
  return (
    <Form form={form} onSubmit={(values) => alert(JSON.stringify(values))}>
      <NameField />
      <button type="submit">提交</button>
    </Form>
  );
}
```

`useField` 必须在 `<Form>` 的后代组件里调用，所以字段放进 `NameField`，而不是直接写在 `App` 里。
