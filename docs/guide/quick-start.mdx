# 快速开始

应用表单从这里开始：`useAntdForm` 创建引擎，`AppField` 的 `name` 按 `initialValues` 检查，`field.Input` 已经包好标签和错误。`<Field decorator component>` 留给自定义控件，见 [Field、装饰器与组件](/guide/field)。

## 准备

ShikiForm 目前没有发布到 npm（`package.json` 是 `private`）。在仓库里运行 `npm ci && npm run build:lib` 生成 `lib/`，再以 workspace 或 `file:` 依赖接进你的项目。四个入口是 `shikiform`、`shikiform/core`、`shikiform/pro`、`shikiform/antd`。

| peer 依赖 | 版本 | 什么时候需要 |
|---|---|---|
| `react` / `react-dom` | `^18 \|\| ^19` | 用 React 层时 |
| `antd` / `dayjs` | `^5` / `^1` | 只在用 `shikiform/antd` 时 |

## 第一张表单

```tsx preview
import { useState } from 'react';
import { Button, Form as AntdForm } from 'antd';
import { Form } from 'shikiform';
import { FormLayout, useAntdForm } from 'shikiform/antd';

type Values = { name: string; email: string; age: number | null };

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useAntdForm({ initialValues: { name: '', email: '', age: 18 } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <form.AppField name="name" title="姓名" required>
          {(field) => <field.Input placeholder="Ada" />}
        </form.AppField>
        <form.AppField name="email" title="邮箱" required rules={{ format: 'email', message: '邮箱格式不对' }}>
          {(field) => <field.Input />}
        </form.AppField>
        <form.AppField name="age" title="年龄" rules={{ min: 0, max: 150 }}>
          {(field) => <field.InputNumber />}
        </form.AppField>
        <AntdForm.Item wrapperCol={{ offset: 4, span: 20 }}>
          <Button type="primary" htmlType="submit">提交</Button>
        </AntdForm.Item>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

直接点提交，必填项会报错；离开输入框时也会校验（默认触发时机是 `onBlur` 和 `onSubmit`）。全部通过后，`onSubmit` 才收到值。

- `useAntdForm` 就是 `useForm` 加上有类型的 `AppField`。`name="emial"` 这种拼写在类型检查里失败。
- `title`、`required`、`rules` 写在 `AppField` 上。`field.Input` / `field.InputNumber` 外面已经是 `FormItem`，显示标签和错误。
- 这些规则挂在组件上：`AppField` 卸载后不再查。折叠、未打开的标签页、虚拟行之外仍要校验的规则，写在 `useAntdForm({ fields })` 里。
- 组件外创建引擎用 `createForm(options)`，选项和 `useAntdForm` 相同。

## 不用 antd

UI 库不是必需的。`useField(name)` 返回 `value`、`onChange`、`onBlur`、`errors`，接到任何控件上。它必须写在 `<Form>` 里面的子组件里。完整例子在 [Headless Hooks](/guide/headless)。
