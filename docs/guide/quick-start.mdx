# 快速开始

从安装到一张会校验、会提交的表单。antd 用 `useAntdForm`；自己的控件用 `createFormHook`。

## 准备

ShikiForm 还没有发布到 npm。在仓库里运行 `npm ci && npm run build:lib` 生成 `lib/`，再以 workspace 或 `file:` 依赖接进项目。

| peer 依赖 | 版本 | 什么时候需要 |
|---|---|---|
| `react` / `react-dom` | `^18 \|\| ^19` | 用 React 层时 |
| `antd` / `dayjs` | `^5` / `^1` | 只在用 `shikiform/antd` 时 |

## 第一张表单

`useAntdForm`（`shikiform/antd`）是接好的工厂：返回引擎，再加上 `AppForm`、`AppField`、`Submit`。`name` 按表单值类型检查；没写泛型时，这个类型从 `initialValues` 推断。`field.Input` 是 connect 过的控件，外面已经包了 `FormItem`（标签、星号、错误），不用再写 `decorator` / `component`。

```tsx preview
import { useState } from 'react';
import { Form as AntdForm } from 'antd';
import { FormLayout, useAntdForm } from 'shikiform/antd';

type Values = { name: string; email: string; age: number | null };

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useAntdForm<Values>({ initialValues: { name: '', email: '', age: 18 } });
  return (
    <form.AppForm onSubmit={(values) => setResult(JSON.stringify(values))}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <form.AppField name="name" title="姓名" required>
          {(field) => <field.Input placeholder="Ada" />}
        </form.AppField>
        <form.AppField name="email" title="邮箱" required rules={{ format: 'email', message: '邮箱格式不对' }}>
          {(field) => <field.Input />}
        </form.AppField>
        <form.AppField name="age" title="年龄" rules={{ min: 0, max: 150 }}>
          {(field) => <field.InputNumber />}
        </form.AppField>
        <AntdForm.Item wrapperCol={{ offset: 4, span: 20 }}>
          <form.Submit>提交</form.Submit>
        </AntdForm.Item>
      </FormLayout>
      <pre aria-live="polite">{result}</pre>
    </form.AppForm>
  );
}
```

直接点提交，必填项报错；失焦时也会校验。全部通过后 `onSubmit` 才收到值。

- `title`、`required`、`rules` 写在 `AppField` 上。
- `<form.Submit>` 在已经有错误、或正在提交时不可点（`$canSubmit` 为 false）。还没校验过的空必填项不挡住它，第一次点击仍会跑校验。
- `AppForm` 自己就是 `<form>`，不要再套一层。组件外创建引擎用 `createForm`，选项和 `useAntdForm` / `useForm` 相同。

## 不用 antd

预绑定自己的输入：模块顶层 `createFormHookContexts` 和 `createFormHook` 各调用一次，组件里用返回的 `useAppForm`。`AppField` / `AppForm` 挂在表单实例上，**不是** `shikiform` 的具名导出。

```tsx preview
import { useState } from 'react';
import { createFormHook, createFormHookContexts } from 'shikiform';

type Values = { username: string };
const contexts = createFormHookContexts();

function TextInput({ label }: { label: string }) {
  const field = contexts.useFieldContext<string>();
  return (
    <p>
      <label htmlFor={field.id}>{label} </label>
      <input id={field.id} value={field.value ?? ''} onChange={(event) => field.onChange(event.target.value)} onBlur={field.onBlur} />
      {field.errors[0] && <small role="alert" style={{ color: 'crimson' }}> {field.errors[0]}</small>}
    </p>
  );
}

const { useAppForm } = createFormHook({
  fieldContext: contexts.fieldContext,
  formContext: contexts.formContext,
  fieldComponents: { TextInput },
});

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useAppForm<Values>({ initialValues: { username: '' } });
  return (
    <form.AppForm onSubmit={(values) => setResult(JSON.stringify(values))}>
      <form.AppField name="username" required>{(field) => <field.TextInput label="姓名" />}</form.AppField>
      <button type="submit">提交</button>
      <pre aria-live="polite">{result}</pre>
    </form.AppForm>
  );
}
```

`useFieldContext()` 没有 name，必须写在 `AppField` 的子组件里。输入组件自己把 `value` / `onChange` / `onBlur` 接到控件上。字段组、`withForm` 见 [组件 Hook 工厂](/reference/form-hook)。

## 进阶：直接写 Field

要自己指定装饰器和控件时，用 `<Field>`。它拥有这个 path，`decorator` 包住 `component`，二者从上下文读字段，不再写 `name`。`useAntdForm` 的 `AppField` 内部就是它。

```tsx preview
import { useState } from 'react';
import { Field, Form, useForm } from 'shikiform';
import { FormItem, Input } from 'shikiform/antd';

export default function App() {
  const [result, setResult] = useState('还没有提交');
  const form = useForm({ initialValues: { fullName: '' } });
  return (
    <Form form={form} onSubmit={(values) => setResult(JSON.stringify(values))}>
      <Field name="fullName" title="姓名" required decorator={[FormItem]} component={[Input]} />
      <button type="submit">提交</button>
      <pre aria-live="polite">{result}</pre>
    </Form>
  );
}
```

四种写法和 UI 属性分层见 [Field、装饰器与组件](/guide/field)。只要绑定、不要工厂时用 `useField`，见 [Headless Hooks](/guide/headless)。
