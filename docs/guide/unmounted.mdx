# 没挂载的字段

<div className="tutorial-step">
<div className="tutorial-copy">

关掉「填写更多」，昵称和邀请码的输入框都不在页面上。直接提交，现在没有错误。

输入框卸掉之后还校不校验，以库的行为为准。在这个库里：`reaction` 写上的 `$rules` 会一直校验；写在 JSX 上的 `rules`，只在 `Field` 挂载时生效。

**可以改成这样：**

1. `defineEffects` 里写 `d.code.$rules = [{ required: true, message: '邀请码必填' }]`，并把 effects 传给 `useForm`。
2. `useForm` 加上 `fields: { code: {} }`。
3. 邀请码的 `Field` 去掉 `rules`。昵称的 JSX 规则留着。

关掉开关再提交。参考写法仍然列出 `code：邀请码必填`。昵称卸掉之后不再校验。
