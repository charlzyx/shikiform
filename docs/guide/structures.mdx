# 数组、树与嵌套对象

值就是普通的嵌套对象和数组。字段一多，每个都写完整 path（`contacts.2.phone`）既啰嗦又跟不上行的增删。结构组件给里面的字段一个**作用域**，字段只写相对名字。

| 组件 | 作用域 | 行 / 节点操作 |
|---|---|---|
| `<ObjectField name="profile">` | `profile.*` | — |
| `<ArrayField name="items" rowKey="id">{({ index, key }) => …}</ArrayField>` | 每行 `items.N.*` | `form.pushArray` / `insertArray` / `removeArray` / `moveArray` / `swapArray` / `replaceArray`，行内 `useArray()` |
| `<TreeField name="nodes">{(tree) => …}</TreeField>` + `<RowScope path pos>` | 每个节点 | `tree.move(from, to)`（`form.moveTree`） |

## 对象与数组

```tsx preview
import { Button, Space } from 'antd';
import { ArrayField, Field, Form, ObjectField, Watch, useArray, useIndex, useForm, type Draft } from 'shikiform';
import { FormItem, FormLayout, Input } from 'shikiform/antd';

type Contact = { id: number; name: string; phone: string };
type Values = { profile: { name: string; address: { city: string } }; contacts: Contact[] };

let nextId = 3;

/** 行内操作：不需要知道数组名和行号，从作用域里拿。 */
function RowActions() {
  const array = useArray<Contact>();
  const index = useIndex();
  return (
    <Space.Compact>
      <Button disabled={index === 0} onClick={() => array.move(index, index - 1)}>上移</Button>
      <Button disabled={index === array.keys.length - 1} onClick={() => array.move(index, index + 1)}>下移</Button>
      <Button danger onClick={() => array.remove(index)}>删除</Button>
    </Space.Compact>
  );
}

export default function App() {
  const form = useForm<Values>({
    initialValues: {
      profile: { name: 'Ada', address: { city: '伦敦' } },
      contacts: [{ id: 1, name: 'Charles', phone: '100' }, { id: 2, name: 'Mary', phone: '200' }],
    },
    fields: { 'contacts.*.name': { required: true } },
  });
  return (
    <Form form={form}>
      <FormLayout labelCol={{ span: 4 }} wrapperCol={{ span: 20 }}>
        <ObjectField name="profile">
          <Field name="name" title="姓名" decorator={[FormItem]} component={[Input]} />
          <ObjectField name="address">
            <Field name="city" title="城市" description="path 是 profile.address.city" decorator={[FormItem]} component={[Input]} />
          </ObjectField>
        </ObjectField>
      </FormLayout>
      <ArrayField name="contacts" rowKey="id">
        {() => (
          <FormLayout layout="inline" feedbackLayout="terse" style={{ marginBottom: 8 }}>
            <Field name="name" title="联系人" decorator={[FormItem]} component={[Input, { style: { width: 120 } }]} />
            <Field name="phone" title="电话" decorator={[FormItem]} component={[Input, { style: { width: 120 } }]} />
            <RowActions />
          </FormLayout>
        )}
      </ArrayField>
      <Button onClick={() => form.pushArray('contacts', { id: nextId++, name: '', phone: '' })}>添加联系人</Button>
      <Watch select={(d: Draft<Values>) => d.$value}>{(values) => <pre>{JSON.stringify(values, null, 2)}</pre>}</Watch>
    </Form>
  );
}
```

- 行身份用 `rowKey`（这里是 `id`）。移动后字段状态（错误、touched）跟着行走；path 里的下标会变，不要拿下标当身份。
- `contacts.*.name` 是行模板：已有的行和以后添加的行都带这条设置，行没渲染也会校验。
- 写死下标的声明（`fields: { 'contacts.0.name': { virtual: true } }`、`registerField('contacts.0.name', …)`）属于**这个路径**，不属于行：移动、交换、插入、删除后，它留在 `contacts.0.name`，作用于此刻占着第 0 行的那一行。要让设置跟着行走，用 `contacts.*.name` 或 [`reaction.each`](/guide/linkage#reactioneach每一行一个实例)。
- 增删改行走 `form.*Array` 或 `useArray()`，不要原地 `push` 到 `getValue` 拿到的数组。`ArrayField` 的父组件只订阅结构（行数、行 id），不订阅单元格的值。

树的节点由你渲染，每个节点包一层 `<RowScope path pos>`；`trees` 选项让联动在组件挂载前就认识树根。例子见 [联动 · reaction.walk](/guide/linkage#reactionwalk每个树节点一个实例) 和 [Headless Hooks](/guide/headless)。

## 嵌套值：按 path 写

表单值按 path 写，只唤醒读过这个 path 的订阅者：

```ts
d.user.name.$value = 'x'                              // ✓ 只改一个字段，只唤醒 user.name 的读者
d.user.$value = { ...d.user.$value, name: 'x' }       // 整体替换：所有读 user 的地方都会重跑
d.user.$value.name = 'x'                              // ✗ 改了不可变快照，开发构建直接抛错
d.items.$value = [...d.items.$value, row]             // 整体替换数组（effects 外用 form.pushArray）
```

`$componentProps` 这类对象型 UI 状态不按 path 写，而是按键打补丁，见 [UI 状态三层叠加](/guide/field#ui-状态三层叠加)。
