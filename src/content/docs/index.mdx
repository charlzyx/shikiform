JSX 描述结构，draft 和 `$` 描述状态，`reaction` / `watch` 描述联动。显隐跟字段的 `display` 走。声明过的字段会参加校验，即使用户没把 `<Field>` 挂上。

## 包

| 入口 | 内容 |
|---|---|
| `shikiform` | 核心引擎和 headless React：`useForm`、`useField`、数组 / 树、`useWatch`、`createFormHook` |
| `shikiform/core` | 不依赖 React 的表单引擎 |
| `shikiform/pro` | headless `useQueryTable`，不依赖 Ant Design |
| `shikiform/antd` | Ant Design 输入、`ProQueryTable`、`ArrayTable`、`MergedTable` |

Peer 依赖是 `react` ^18 或 ^19。代码只用 React 18 已有的 Hook。

## 从这里开始

- [快速开始](/start/)：最小表单，以及 Ant Design 的预绑定输入。
- [字段](/guides/fields/)、[联动](/guides/effects/)、[校验](/guides/validation/)、[查询表](/guides/query/)、[无头 Hook](/guides/hooks/)。
- [示例](/demos/)：本地 playground 里的查询表、校验、SKU、合并表和大表。

```tsx
import { Field, Form, useForm } from 'shikiform'

const form = useForm({ initialValues: { email: '' } })

<Form form={form} onSubmit={(values) => console.log(values)}>
  <Field name="email" rules={{ format: 'email', message: '邮箱格式不对' }}>
    {(field) => (
      <input
        value={field.value ?? ''}
        onChange={(event) => field.onChange(event.target.value)}
        onBlur={field.onBlur}
      />
    )}
  </Field>
  <button type="submit">提交</button>
</Form>
```
