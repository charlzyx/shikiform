菜单编辑器：节点模板递归，节点即 record。**2026-10-27：树节点比数组行多一个 `pos`**——索引路径二维坐标，如 `[0,2,1]`：`pos.length` = 层级 depth，最后一位 = 兄弟中的 index，数据 path 由它推出（`menus.0.children.2.children.1`）。移动全部用 pos（`move(fromPos, toPos)`、缩进 / 反缩进 / 上下移），禁止移入自身后代 = 目标 pos 以源 pos 为前缀；按 depth 做联动和分层校验；按 pos 查询。

**演示的特性：** TreeField · pos / depth · useNode / useTree · 跨层移动 · 分层校验
