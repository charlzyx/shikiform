# Array 增删排序

行是对象（姓名 + 电话），列表操作就是数组操作。关键一条：React key 用稳定 id，不用 index——排序只换顺序不 remount，输入框不会丢焦点、内容不会串行。

<ArrayDemo client:load />

## 点什么、会发生什么

- **点“新增联系人”**：列表末尾多一行空联系人，计数加一。
- **在某一行输入姓名 / 电话，再点它的“上移”或“下移”**：整行带着输入内容一起移动，内容不丢、不串到别的行。
- **点某一行的“删除”**：该行消失，剩下的行序号自动重排（1、2、3……），其他行的输入内容保持不变。
- **看下方 JSON**：提交形态就是联系人对象数组，顺序就是当前列表顺序。
