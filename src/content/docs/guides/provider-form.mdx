# 供应商 / Provider 真实复杂表单

这就是 PLAN 里的第 10 项：一个真实的供应商配置表单，不是两个输入框的玩具。基本信息、认证、模型、限流、高级设置全在一页里。

<ProviderFormDemo client:load />

## 点什么、会发生什么

- **填基本信息**：名称、类型、描述进提交值。
- **认证方式切到 OAuth**：API Key 输入框隐藏，Client ID / Client Secret 出现；切回 API Key 时，OAuth 的输入框隐藏但值保留，再切回 OAuth 还能看到之前填的内容——隐藏不是清空。
- **模型多选**：勾选 / 取消勾选，提交值里的模型数组跟着变。
- **改限流数字**：提交值里的每分钟请求数跟着变。
- **点“展开高级设置”**：出现超时、重试次数；填好后点“收起高级设置”，再点“提交”——提交值里仍然有高级设置的超时和重试次数。折叠不是清空，展开不是重建。
- **点“提交”**：下方出现完整提交值 JSON；点“重置”全部清空。
