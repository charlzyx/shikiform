## 这一页演示的复杂 case

- **Grid 自动算宽度**：查询字段不用每个手写 span。Grid 按容器宽度 / 断点自动排几列（&lt;600: 1、&lt;900: 2、&lt;1200: 3、否则 4），最后一行查询 / 重置按钮自动占剩余格子；字段增减、显隐、折叠后自动重算。拖动浏览器宽度看列数变化。
- **折叠高级查询**：默认只显示前 3 个字段，展开后其余字段出现；收起时高级字段的值保留在 store 里，不清空（显隐语义见设计页）。
- **提交 transform**：查询时空值省略、日期范围拆成 `dateStart` / `dateEnd`、多选原样传。提交参数直接显示在表格下方。
- **新查询回第 1 页，翻页不丢查询**：点查询后分页回到第 1 页并清空选择；翻页 / 改每页条数不改查询条件。
- **列头筛选汇合**：状态列头里的下拉筛选和上面查询表单汇到同一份查询参数里，改列筛选也触发刷新并回到第 1 页。
- **多行选择批量操作**：多选行，批量删除 / 改状态 / 导出 JSON。选择是 transient UI 状态，不进提交数据；新查询后选择清空并提示。跨页选择语义先定为“当前查询结果内选择”，翻页保留选择。
- **查询字段内部联动**：选 Provider 后模型下拉范围被过滤（复用 SKU 那套数据驱动算法），模型已不合法时自动清除。
