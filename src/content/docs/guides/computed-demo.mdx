# Computed 派生

Computed 已定名（不叫 Virtual）：只读、只展示、不提交，值是算出来的。脏检查、校验、提交都跳过它，重置时重算。

<ComputedDemo client:load />

## 点什么、会发生什么

- **改单价或数量**：总价立刻变成“单价 × 数量”，折扣后价格跟着变。
- **改折扣**：折扣后价格 = 总价 × (1 - 折扣率)，总价本身不变。
- **改 Base URL 或模型**：预览地址立刻变成 `baseUrl + '/' + 模型`，末尾多余的 `/` 会被处理掉。
- **点“提交”**：下方提交值 JSON 里只有单价、数量、折扣、Base URL、模型——没有总价、折扣后价格、预览地址。Computed 只展示，不进提交。
