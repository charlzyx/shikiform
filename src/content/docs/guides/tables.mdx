## 嵌套合并表格

数据保持嵌套，不拍平，如供应商 → 产品列表。表格只是视图：父字段只注册一次，其他行对应位置不注册字段，只是 rowspan 占位。rowspan 本身就是 Computed：`rowspan = 可见子项.length`。编辑合并格 = 编辑父对象一次。排序按组排序。完整可点 Demo 见 [行展开二级表格 + SKU 完整版](/guides/nested-table/)。

## 超大表格性能

1. 字段级订阅：改一个格子只重渲染该格子 + 直接依赖的 Computed。
2. 行虚拟化：只挂可视区，状态在 store 里。
3. 按 record 缓存 Computed：只重算该组（本轮已把 Computed 缓存做实：依赖不变不调用 compute，见 `tests/performance.test.ts`）。
4. 编辑中格子用本地 transient 状态，blur / 回车才提交一次。
5. 稳定 id 当 key，排序不 remount。

可点 Demo 与对比模型见 [超大表格性能](/guides/performance/)。增量 reaction 按依赖交集跳过（每 setValue 只跑相关 reaction）仍是剩余工作：目前 reaction 循环仍跑全部 reaction，但只提交有效写入、只渲染一次；不要把它说成已实现。
