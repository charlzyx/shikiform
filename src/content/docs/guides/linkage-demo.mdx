# 联动：一对多 / 多对一 / 多对多

联动只写一个集中 effect，不在 JSX 里散落三元和 per-field effect。同一页三组，互不干扰。

## 点什么、会发生什么

### 一对多：一个源影响多个目标

- **供应商类型切到“本地”**：API Key 字段隐藏（值保留、校验跳过），Base URL 由必填变选填，模型列表变成只有本地模型。
- **类型切回 OpenAI / Anthropic**：API Key 重新出现，Base URL 恢复必填，模型列表跟着变；之前选的模型若不在新列表里会被清掉。
- **Base URL 为空时点“校验本组”**（非本地类型）：出现“baseUrl 必填”。

### 多对一：多个源影响一个目标

- **只填姓名、只填邮箱、或没勾协议**：提交按钮保持禁用，提示说明缺哪类条件。
- **姓名 + 合法邮箱 + 勾选协议三项齐了**：按钮可用。

### 多对多：迷你 SKU，双向过滤

- **先选颜色“红色”**：配置里“基础版”被置灰不可选（红 + 基础版不在 SKU 表里），只剩 Pro / Max。
- **反向先选配置“Max”**：再看颜色，三个颜色都还能配 Max；改选“基础版”后，颜色只剩黑色、白色。
- **颜色 + 配置选满**：出现唯一 SKU 的价格和库存；选不满时显示价格区间。
- **选了某个配置后再换一个配不上的颜色**：已不合法的配置会在同一处被清掉，不会留一个非法的组合。
