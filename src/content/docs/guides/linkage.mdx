## 集中 effect

所有 if/else、显隐、禁用、校验联动都集中写，不在 JSX 里散落 `useEffect`。
写法像 proxy，只写数据。引擎在 store 内跑：一次 `setValue` 在一个 Immer 事务里跑完，只提交一次；写的结果没变就不触发下一轮；跑满 10 轮不收敛就报环，不死循环。

## record / array 作用域

借鉴 Formly 的 `$record` / `$array`，但不用 `$` 字符串 DSL，改成带类型的 context：

- `ctx.record`：最近一级 object
- `ctx.array`：最近一级 array / tree
- `ctx.parent`、`ctx.root`：作用域链往上走

作用域按结构解析。对象被复制、数组排序、树节点移动，record 自动跟自己那个实例走。Tree 节点本身就是一个 object。

## Computed

Computed 是只读派生字段：总价、预览地址、SKU 最终价格 / 库存。脏检查、校验、提交都跳过它，重置时重算。Computed 的依赖在 compute 跑的时候被记录，用于缓存和后续的增量跳过。
