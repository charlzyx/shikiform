# 嵌套 Object

`ObjectField` 是嵌套对象容器：子节点用相对名，不重复写全路径。`provider` 里嵌 `api`，里面的字段只写 `baseUrl`、`model`，地址自动拼成 `provider.api.baseUrl`。

<NestedObjectDemo client:load />

## 点什么、会发生什么

- **在“供应商名称”里输入**：提交值里出现在 `provider.name`，而不是顶层 `name`。
- **在“Base URL / 默认模型”里输入**：提交值里出现在 `provider.api.baseUrl` / `provider.api.model`——写 JSX 时子字段只用了相对名 `baseUrl` / `model`。
- **点“提交”**：下方出现提交值 JSON，结构就是嵌套对象本身。
- **看页面下方的地址清单**：`provider / provider.api / provider.api.baseUrl / provider.api.model`——这是 `data-address`（UI 树地址）。本页没有 `VoidField`，所以数据路径（path）和地址一致，不含 Void；Grid、查询表单布局这类纯布局节点才用 VoidField，它们不进数据路径。
