# Tree 排序移动

Tree 节点本身也是 Field。先做按钮版（拖拽是待定项，见 PLAN 第 11 节）：展开 / 收起、上移 / 下移同级、缩进、移出，全部是按钮操作。

<TreeDemo client:load />

## 点什么、会发生什么

- **点“展开 / 收起”**：子部门显示或隐藏，子节点数据不丢。
- **点某节点的“上移 / 下移”**：它在同级兄弟里换位置，不跨层。
- **点“缩进”**：该节点变成上一兄弟的子节点（向里一层）；已经是第一个子节点时，出现提示“已是第一个子节点，无法缩进”，不执行。
- **点“移出”**：该节点变成父级的同级节点（向外一层，排在父级后面）；已是顶级节点时提示“已是顶级节点，无法移出”，不执行。
- **非法移动校验**：源选“研发部”、目标选“前端组”，点“尝试移动”——前端组是研发部的后代，会出现“不能移入自身后代”，树保持不变。源和目标选同一个节点时提示“不能把节点移入自身”。
