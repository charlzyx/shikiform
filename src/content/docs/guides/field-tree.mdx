---
title: 统一 Field 树
description: 一切节点都是 Field，共享 address、path、visible、disabled、errors、children。
---

一切节点都是 Field：

- **Field**：普通数据字段，有值、可提交
- **ObjectField**：嵌套对象容器，子节点用相对名
- **ArrayField**：列表，行是 Object，增删排序
- **TreeField**：树，节点本身也是 Field，主要用于排序；禁止移入自身后代
- **VoidField**：纯布局，无值、无数据路径
- **Transient**：有用户输入、但提交时过滤，如确认密码
- **Computed**：只读、只展示、不提交，值是算出来的。**不叫 Virtual**，已定名 Computed。

address 是 UI 树地址（含 VoidField），path 是数据路径（不含 VoidField）。字段注册一次，地址稳定，排序不靠 index 当 React key。
