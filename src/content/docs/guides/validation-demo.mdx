# 校验与枚举交互

基础校验层（`src/core/validation.ts`）和枚举层（`src/core/enum.ts`）的可点版：每种校验都有办法触发，错误文本稳定，可直接断言。更完整的分层说明见“校验与枚举”页。

## 点什么、会发生什么

- **点“一键填非法值”再点“提交校验”**：同时出现五种错误——姓名必填、编码“格式不正确：应为 ABC-123 形式”、年龄“年龄不能小于 18”、结束日期“结束日期必须晚于开始日期”（结束 10-10 早于开始 10-20）、状态“值不在可选范围内”（被填了 `bogus`）。
- **名称框输入 `admin`**：先显示“检查中…”，约 300ms 后出现“名称已存在”；输入 `openai` / `demo` 同样已存在，输入其他名字显示“名称可用”。
- **快速连续改名称**（例如先输 `admin` 马上改成 `zhangsan`）：旧请求的“名称已存在”不会覆盖新结果——旧请求过期作废。
- **点“填一个非法枚举值”再点“提交校验”**：状态出现“值不在可选范围内”；把状态选回正常选项，错误消失，下方的 Pretty 展示恢复成对应颜色的中文标签（进行中绿色、已禁用红色、待处理金色）。
- **编码填 `ABC-123`、年龄填 `20`、结束日期晚于开始日期**：对应错误逐项消失；全部通过时点提交，下方出现提交值 JSON。
