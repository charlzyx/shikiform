# 基础表单

Antd Form 常见模式的 shadcn 版：不用 Antd，不用 schema，字段就是 JSX，校验只在提交时跑。

<BasicFormDemo client:load />

## 点什么、会发生什么

- **什么都不填点“提交”**：姓名、邮箱、密码下方出现错误（姓名必填、邮箱必填、密码必填），提交值不展示。
- **邮箱填 `abc`**：邮箱下方出现“邮箱格式不正确”。
- **年龄填 `200`**：年龄下方出现“年龄不能大于 150”；填 `-1` 出现“年龄不能小于 0”。
- **密码和确认密码填得不一样**：确认密码下方出现“两次密码不一致”。这是单向校验：只有确认密码读密码，改密码不会反向去校验确认字段以外的东西。
- **全部填对点“提交”**：下方出现提交值的 JSON。
- **点“重置”**：所有输入、错误、提交值全部清空。
