# @shikiform/react

[简体中文](./README.md) · **English**

Headless React bindings and pro hooks (query tables, shadow forms, editable array tables, column settings) for ShikiForm. Re-exports common `@shikiform/core` APIs.

```bash
npm i @shikiform/react
```

Peer dependencies: `react` and `react-dom` (`^16.8.0 || ^17 || ^18 || ^19`).
