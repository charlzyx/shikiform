# @shikiform/core

[简体中文](./README.md) · **English**

ShikiForm engine: values, draft effects, validation, and tree moves. No React.

```bash
npm i @shikiform/core
```

Most React apps should install `@shikiform/react` instead — it depends on this package, re-exports common engine APIs, and includes all headless React bindings and pro hooks.
